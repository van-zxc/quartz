肽键&酰胺键
PCR允许从右到左，而蛋白质==必须从左到右==（原因：mRNA翻译有严格方向性）
测不到$\alpha$氨基：焦谷氨酸/环肽
胞外环境才有可能形成二硫键（因为体内为还原环境）

definition：比胰岛素大的叫蛋白质（且必须核糖体合成） 小叫多肽
阿斯巴甜、胰岛素、催产素、促甲状腺激素释放激素(nmol级别)、鹅膏蕈碱、舒缓激肽

估算：蛋白质质量/110=氨基酸数

蛋白质/核酸只有一种链接方式——肽键/磷酸二酯键   然而在缀合蛋白中，不止一种连结方式（糖苷键、磷酸键etc.）

分类：
+ 单纯蛋白质
+ 复合蛋白质（有辅基 非氨基酸成分）
	+ 双缩脲反应——==二肽以上才能反应==

肽的性质：两性离子

结构：
+ 一级结构：氨基酸序列
+ 二级结构：$\alpha$螺旋、$\beta$折叠（不受序列干扰 只收肽键作用）若外界侧链形成更加强有力的作用 则二级结构被破坏
+ 三级结构：静态稳定结构
+ 四级结构：蛋白质复合物 可以大量扩充（非共价键）==决定生命活动（跟其他东西互作才有意义）==

# 蛋白质一级结构
蛋白质是线性结构！
N端测序：Edman试剂/Sanger试剂/丹磺酰氯试剂

障碍：三维构象→暴力拆解

测定步骤：
+ 蛋白质分离纯化
+ 二硫键拆分&保护（分泌蛋白，尤以胶原蛋白为多）
+ 亚基分离
+ 利用各种方法得到小段多肽
+ 分离多肽
+ 测序
+ 重叠
+ 确定二硫键

多肽链拆分：8mol ==尿素==/6mol 盐酸胍（帮助变性蛋白质变为水相）
容易透析
蛋白质沉淀：盐析/变性

二硫键切割保护：
1. 过甲酸：氧化为磺酸 不可逆
2. DTT/巯基乙醇+卤化剂：不可逆，还原+烷基化  ==有毒！==
3. 亚硫酸分解：可逆

水解：
1. 酸水解：6mol 盐酸/4mol 硫酸  105℃  优点：不引起产物消旋化，破坏==色氨酸==（吸光性小事），羟基氨基酸部分破坏，酰胺基完全水解为羧基（使用是电荷判断）
2. 碱水解：5mol NaOH  不会破坏色氨酸
3. 酶水解：水解产物为较小肽端
	1. 内切酶（内部切割）： 木瓜蛋白酶   脯氨酸抑制水解！ 
		1. 胰蛋白酶：R1=Arg Lys，R2不为Pro
		2. 胰凝乳蛋白酶：R1=Phe Trp Tyr（等疏水性AA），R2不为Pro
		3. 胃蛋白酶：R1不为Pro，R2=Leu Phe Trp Tyr（等疏水性AA），充分破坏疏水性内核，变为小肽端，便于降解
		4. 溴化氰（剧毒）：==Met==，得率很高6
	2. 外切酶：羧肽酶/氨肽酶

N端测定方法：
1. Sanger试剂
2. Edman试剂+荧光基团（主峰到后面会越来越不清晰）
3. 丹磺酰氯+Edman试剂（取样标记开头→酸水解→Edman降解→循环）
质谱法

二硫键位置确定：
胃蛋白酶不破坏二硫键
电泳，半路用过甲酸打开二硫键，旋转90度再电泳
