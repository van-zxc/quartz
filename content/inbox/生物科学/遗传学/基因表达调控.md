# 原核
1. 以大肠杆菌LacZ为例：
2. RNA聚合酶共六个多肽：$\alpha\alpha\beta\beta^{'}\omega + \sigma$，$\sigma$用于识别特定基因序列
3. 启动子：和转录调控识别位点相关的特定DNA区域
	1. 在大肠杆菌内大约为-10区和-35区
	2. -10区保守序列为TATATA
	3. -35：TTGACA
4. $\sigma$因子有七种，不同的$\sigma$会对应不同环境下的不同功能
5. [[基因#操纵子]]显然就是调控的例子
6. 色氨酸基因的衰减作用（衰减子）
	1. 在富含GC的回文序列下游连接了AT碱基对，它们倾向于形成发卡结构，导致聚合酶构型改变
	2. 色氨酸充足：核糖体顺利翻译前导肽中的色氨酸密码子，遮挡区域2 $\rightarrow$区域3与区域4配对形成3-4终止发夹 $\rightarrow$ RNA 聚合酶解离，转录提前终止
	3. 色氨酸匮乏：核糖体滞留在色氨酸密码子处，区域2保持暴露 $\rightarrow$区域2与区域3配对形成2-3反终止发夹$\rightarrow$阻止3-4结构生成$\rightarrow$RNA聚合酶继续转录下游合成基因
	4. 也就是说，当色氨酸充足，核糖体移动的快，就能形成终止序列；反之，当色氨酸不充足，那么核糖体移动的慢，mRNA就会优先伸长，无法形成终止序列
# 真核
1. 不同于原核，真核细胞转录无法偶联，转录和翻译在空间上隔离
2. 转录前
	1. 染色质结构
	2. DNA修饰
	3. DNA重排
	4. DNA多态
3. 转录起始调控
	1. RNA聚合酶
	2. DNA调控元件
	3. 转录因子
	4. 共激活/共抑制因子
4. 转录后调控
	1. mRNA加帽加尾
	2. mRNA剪切编辑
	3. mRNA出核定位降解
## 转录前调控
### RNA聚合酶
1. RNAI：pre rRNA 45S（5.8S 18S 28S rRNA的前体）
2. RNAII：所有pre mRNA，小核仁RNA，大部分小核RNA，大部分miRNA
	1. 12个亚基复合物
	2. 和原核含有大量的同源结构域
3. RNAIII：tRNA，5S rRNA，部分小核RNA，部分miRNA和其他ncRNA
### DNA调控序列
1. 启动子
	1. TATA box：-30~-40
	2. BRE
	3. INR
	4. DPE
	5. 需要至少两个启动子才能启动
2. 非核心启动子：起始点上游100-200bp的DNA元件
3. 增强子：调控转录起始前Complex的组装
4. 沉默子：增强子的反面，负调控元件
5. 绝缘子：不让其他的基因元件对基因的调控生效
### 转录因子
1. 普遍转录因子：识别结合不同的核心启动子，组装转录起始前复合物
	1. eg. TFII（ABDEFH等）
	2. 它和RNA聚合酶和启动子可以启动管家基因的表达
2. 特异转录因子
	1. 激活型转录因子/抑制型转录因子
3. 都有DNA结合域和激活结构域
### 其他调控蛋白
1. 共激活/共抑制因子：不能和DNA结合，通过和转录因子结合参与到转录起始复合物组装
2. 中介子：介导特异性转录因子和转录起始复合物相互作用
## 转录中调控
1. RNA工厂：转录起始前复合物，处理mRNA
2. mRNA加帽：在5‘末端加上7-甲基鸟苷酸
	1. 帮助mRNA稳定你
	2. 帮助mRNA出核
	3. 便于核糖体识别
3. mRNA加尾：前体的3’末端加上多聚腺苷酸
	1. 提高mRNA稳定性
	2. 促进内含子剪切
	3. 帮助mRNA进入细胞质
4. 剪接：把内含子剪掉，随后把外显子首尾相连
5. mRNA编辑：对mRNA进行直接修改，比如特异性的插入或修改某些特定碱基
## 出核调控
1. 出核因子参与，5‘帽和polyA也十分重要
2. 可以利用细胞骨架进行运输，或者直接结合
## 翻译&降解
1. 半衰期约0.5h，保持动态平衡
2. 降解途径：
	1. 脱腺苷化依赖：脱掉polyA尾巴，展示信号
	2. 脱腺苷化非依赖
	3. 核酸内切酶介导：切割mRNA导致降解
3. 翻译
	1. 需要大量蛋白质因子参与，机制复杂
## 蛋白质加工
1. 蛋白质正确折叠
2. 共价修饰：磷酸化，糖基化，乙酰化，甲基化等
3. Complex组装：二聚体&多聚体
4. 泛素蛋白酶体降解
	1. 和蛋白质底物赖氨酸共价连接，形成多聚泛素化链
	2. 指导标记蛋白被蛋白酶体识别降解
	3. 剩下内容详见[[细胞分裂与细胞周期]]

# 表观遗传
1. 组蛋白修饰
	1. 染色质重塑：核小体包装程度在转录复制修复等发生的动态变化
	2. 异染色质&常染色质
	3. 阅读复合物可以识别和结合核小体，招募其他蛋白
2. DNA水平修饰
	1. DNA甲基化：C被甲基化修饰为5mC，主要发生在CpG岛上
	2. CpG岛：富含CpG二核苷酸，长度为0.3-3kb的DNA序列
	3. 基因组印记：亲本来源不同导致等位基因出现差异
3. RNA介导基因沉默
	1. siRNA
		1. 20-25nt，3’末端有2bp突出的粘性末端和羟基，5‘有磷酸基团
		2. 来自dsRNA，被DICER处理后变成siRNA
		3. 组装到RISC上，随后siRNA解旋，反义链和mRNA互补配对，随后被介导降解
		4. 可以级联方法作为特殊引物
	2. miRNA
		1. 被RNAII转录为pri miRNA
		2. 随后被核酸酶加工为pre miRNA
		3. 随后出核，再被改造为miRNA
	3. X染色体失活
		1. 剂量补偿效益，哺乳动物XX中X会失活
