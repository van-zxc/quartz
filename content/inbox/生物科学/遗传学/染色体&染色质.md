# 染色体结构变异
平衡：不伴随可以检测的遗传信息的量变
## 染色体缺失
1. 缺失纯合体活力<杂合体（显然的）
2. 中间缺失：同一条染色体臂上发生了两次断裂，断点之间无着丝粒片段丢失，其余片段重接
3. 末端缺失：一条染色体发生一次断裂后未发生重接，丢失无着丝粒的染色体片段
4. 细胞学观察出现弧状结构
5. 拟显性：由于杂合子中显性基因缺失导致隐性基因被迫表达
## 染色体重复
1. 对生活力影响不大，但是大段重复也会有影响
2. 有顺接交换&逆接交换
3. 可能通过表达剂量改变而产生生物学效应
4. 还可能由不等交换导致
## 染色体倒位
1. 即染色体某部分发生完全颠倒
2. 臂内倒位&臂间倒位
3. 倒位杂合子在配对过程中会形成特殊的”倒位环“结构
4. 倒位染色体发生交换时会出现所谓的”桥“和断片
	1. ![[PixPin_2026-10-19_23-14-14.png]]
	2. 臂内倒位杂合子形成配子，重组型配子中存在桥和断片，可造成配子死亡
	3. ![[PixPin_2026-10-19_23-15-44.png]]
	4. 臂间倒位杂合子形成配子，重组型配子携带重复与缺失，不能存活
	5. 因此倒位现象可以抑制重组
5. 倒位的发生位置可能造成突变表型，称之为位置效应
6. 平衡致死系：保存纯合致死的基因
	1. 利用两个致死基因的组合即可制作平衡致死系
	2. 利用倒位来抑制重组交换
## 染色体易位
1. 染色体片段的转移
2. 类型
	1. 相互易位：非同源染色体互相交换染色体片段，会出现十字型联会；同时会导致半不育现象（部分配子联会不平衡致死）和拟连锁（非致死分离方式的基因必然连锁
	2. 罗伯逊易位：长-短+长-短=长-长+短-短；会导致染色体数量异常
## 其他染色体变异
1. 环状染色体
2. 双着丝粒染色体：两个染色体重接
3. 等臂染色体：着丝粒异常横裂后把两个同源染色体的长+长、短+短相接了
4. 插入
# 染色体数目变异
1. 大多数真核生物为二倍体
2. 非整倍体：体细胞的染色体组中的一条或几条染色体发生改变
3. 单倍体通常进行假减数分裂，结果仍为单倍体
4. 同源多倍体细胞在联会时会形成“多价体”
	1. 联会采用若干二价体+一价体，分离结果可能为二倍体、单倍体、非整数体（最多）
	2. 联会为三价体，可能得到各种东西
5. 非整倍体
	1. 单体：只少一条
	2. 双单体：两对分别少一条
	3. 三体：多一条
	4. 缺体：少一对
