# 概念
+ 基因组：细胞内全套染色体及其所携带的全部基因，包括基因序列和基因间序列
+ C值：每一种生物中其单倍体基因组的DNA总量
	+ C值悖论：生物的C值并不与生物复杂程度（或进化上所处地位）相关
	+ G值悖论：基因组中全部基因的数目与物种的复杂程度同样没有明显的相关性
# 物种基因组
## 病毒
1. 基因组大小从几kb到几百kb不等
2. 基因组的结构形式多样
3. 通过多种方法在较小的基因组容量内提高携带遗传信息的效率（eg. 基因组内非编码序列所占的比例极少，含有大量的重叠基因）
4. 基因组内存在操纵子结构
## 原核生物
1. 闭合的环状双链DNA分子（类核与质粒）；质粒是染色体外DNA，不是细菌存活所必需
2. 多数基因为单拷贝；两条DNA链都可编码基因，非编码序列的比例很低。重叠基因的比例显著减少
3. 含有少量重复序列及一些特殊的DNA结构元件
4. 基因的组织顺序和染色体复制方向有关，存在大量操纵子
## 线粒体
1. 环形DNA分子裸露
2. 主要编码少量rRNA、↑RNA和部分呼吸链组分蛋白质
3. 线粒体基因组大小和生物的复杂程度无关
4. 多拷贝，在胞质分裂的过程中不同的线粒体DNA随机分配给子细胞
## 叶绿体
1. 闭合环状DNA，有多个拷贝，且拷贝数可变；多为几百kb
2. 编码的基因数较多，包括+RNA基因，rRNA基因，RNA聚合酶基因，核糖体蛋白编码基因，光合作用相关蛋白组分的编码基因等
3. 含有大量内含子序列
4. 含有两段数十kb大小的反向重复区(IR区），将环状DNA分子分隔成大单拷贝区(LSC区）和小单拷贝区（SSC区）
## 真核
1. 单细胞：出现遗传冗余
2. 多细胞
	1. 有遗传冗余，存在大量重复序列，且基因在染色体上的密度低
	2. 编码大量独特的细胞间信号转导蛋白
# 人类基因组
1. 23对染色体，3.2Gb序列
2. 20687个蛋白质编码基因，平均含有9个外显子，长度27kb，但不同基因间的差异极大
3. G+C含量偏低，仅占38%；不同染色体的不同区段上GC含量亦不相同
4. 基因在染色体上不均匀分布

## 基因及其序列
1. 基因座：基因在染色体上所处的位置
2. 基因簇：一些基因序列和功能高度一致的基因分布在染色体的相同位置，紧密连锁
3. 基因家族：人类基因组中的一些基因，其全部或部分序列高度同源，能够编码保守的蛋白质结构域或者氨基酸基序
	1. 基因家族的成员在进化上具有共同祖先，功能相似或相近
	2. 基因家族的成员有的以基因簇的方式存在，有的散在分布
4. 基因超家族：基因组中部分基因序列同源性低但功能相关，且具有相同的特征结构
5. 假基因：与基因组中有功能的基因具有相似的序列，但失去蛋白质编码功能或者不能正常转录表达的DNA序列
	1. 人基因组中约10%的基因有拷贝数不同的假基因，全部假基因及基因片段约11224个
	2. 可分为常规假基因和加工假基因
	3. 常规假基因：在基因组进化过程中功能基因复制后发生突变产生的失活产物
	4. 加工假基因：功能基因的mRNA转录产物反转录为cDNA后再次插入基因组，形成一个新的基因拷贝（eg. Alu、LINE1）
