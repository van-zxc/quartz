# 订正
1. 突变单位：
	1. 一个基因的内部可能有多种突变形式，基因并非突变的单位
	2. 顺反子（cistron）即在互补实验中的功能单位。一个顺反子的突变顺式杂合子为野生型，突变反式杂合子为突变型
	3. 两个突变基因才能组成一个顺反子
	4. 真核生物中大多属于单顺反子，多顺反子存在于原核生物中（即一个核苷酸序列可以翻译成多种多肽）
2. 重组单位
	1. 实际上一对核苷酸才是重组单位
	2. 同点等位基因：在同一个基因内部的相同位点或重叠位点的不同突变基因，同点等位基因之间既不能互补也不能重组
	3. 异点等位基因：在同一个基因内部的不同位点的不同突变基因，异点等位基因之间不能互补，但可以重组
3. 功能单位
	1. 一个基因一个酶→
	2. 一个基因一条多肽

# 基因的控制

操纵子只包括启动子+操纵基因+结构基因
## 操纵子
此处以经典的乳糖操纵子为例：![[PixPin_2026-10-09_11-41-23.png]]

乳糖操纵子机制：
1. 当环境内无乳糖时，LacI编码的阻遏蛋白能够与操纵基因结合，阻断RNA聚合酶在启动子上的移动，从而导致非常低水平的基因转录
2. 环境内出现乳糖后，乳糖被细菌代谢为异乳糖，异乳糖与阻遏蛋白结合改变构型，失去与操纵基因结合的能力，RNA聚合酶转录下游结构基因，开启转录

色氨酸操纵子则反之：![[PixPin_2026-10-09_11-44-51.png]]
![[PixPin_2026-10-09_11-45-41.png]]
本质上都是负反馈调节，一个是外界产物吸收的调节，一个是自身合成的调节

诱导操纵子：游离的阻遏蛋白是有活性的，可以直接结合操纵基因，关闭基因表达，如乳糖操纵子
抑制操纵子：游离的阻遏蛋白没有活性，只有在与共抑制物结合形成复合物的情况下，才能与操纵子结合，关闭基因表达，如色氨酸操纵子

操纵基因发挥顺式作用，调节基因发挥反式作用

# 可动
1. 在生物中有大量的转座子
2. 三种Copy：
	1. 剪切-黏贴
	2. 复制-粘贴（经过逆转录）
	3. 复制-粘贴（不经过逆转录）
	4. ![[PixPin_2026-10-18_23-54-50.png]]
3. 分类
	1. DNA转座子
		1. 自主性：完整的
		2. 非自主性：中间不完整
	2. 反转录转座子
		1. LTR反转录转座子：来自病毒
		2. 非LTR反转录
4. 细菌转座子
	1. 插入序列（IS）：末端反向回文序列+转座酶
	2. IS插入宿主基因组后会造成交错切割，从而在插入位置上产生短正向重复序列（DR），插入序列如果切离精确，可使IS诱发的突变回复为野生型
	3. 插入序列的不精确切离，可使插入位置附近的宿主基因发生缺失
	4. 复合转座子（Tn）：两端两个 IS，内部携带结构基因（如抗药基因）。插入宿主的靶序列后，也形成DR
5. 植物转座子：玉米激活-解离系统
	1. ![[PixPin_2026-10-19_00-00-36.png]]
	2. 特点：在籽粒上形成不均匀的色斑
	3. Ac发挥trans作用，Ds只有cis
6. 果蝇P因子
	1. 只在生殖细胞中进行特殊可变剪切，发挥特殊功能导致败育
7. 人反转录元件：LINE家族，占据大量基因组空间
8. 反转录病毒
	1. 单链DNA结构：R-U5-结构基因-U3-R
	2. 反转录作用后形成长末端重复LTR：末端形成U3-R-U5重复序列；整合的必须元件
9. 可能遗传效应：
	1. 插入突变
		1. 新基因的获得
		2. 原有基因的沉默
		3. 基因的转录激活/沉默
		4. 形成新的正向重复序列
	2. 不精确解离导致基因突变
	3. 染色体断裂和丢失
	4. 产生大量的重复序列，诱导染色体变异等
