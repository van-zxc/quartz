# 交换&重组
1. 交换指的是事件，同源染色体的非姐妹染色单体发生局部互换。交换可能导致重组
2. 重组指的是结果，交换能导致互换位置两侧的连锁基因发生重组；但是交换只是重组的机制之一
	1. 重组可以分为染色体内重组和染色体间重组（自由组合）
	2. 再比如转座、逆转录病毒等都算重组

测交子一代表型比等于配子分离比；从合子来判断无法判断父本和母本的分离比分别是多少。因此我只能用测交

干涉：一次单交换对双交换的影响

当两对等位基因呈现的比例为1:1:1:1时，则完全遵循[[孟德尔遗传]]中的自由组合定律；当比例完全为1:1时则是**完全连锁**；处于期间的则为不完全连锁
# 重组率&遗传距离
1. 遗传学距离！=重组率，最高不能过50%
2. 重组率=重组型数目/(亲本型数目+重组型数目)，1%重组率为1cM
# 三点测交
1. 假设有abc和ABC三个基因，则有Abc-aBC、abC-ABc、AbC-aBc三种变体
2. 先确定三个基因之间的位置关系
3. 则A-B基因的遗传距离为(Abc+aBC+AbC+aBc)/2
4. B-C基因遗传距离类似
5. 并发系数=(AbC+aBc)/(总数\*比例1\*比例2)；干涉率=1-并发系数
# 遗传标记
1. 限制性片段长度多态性RFLPs：不同DNA在同一限制酶切割时产生不同长度的DNA片段
2. 简单序列长度多态性SSLP：即类似微卫星序列那种，短的重复序列
3. 单核苷酸标记SNP：数量大范围广
