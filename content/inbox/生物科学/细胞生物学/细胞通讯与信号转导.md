# 概念
1. 细胞通讯
	1. 细胞之间通过分泌信号分子/直接接触实现调控
	2. 短距离通讯：局域范围的信息交流，分为直接接触/间接
	3. 长距离：内分泌激素、长轴突神经元
2. 信号转导：细胞感知环境中各种信号，把这种信号转导进入细胞内，作出反应的过程
# 细胞通讯
1. 接触依赖
	1. 缝隙连接
		1. 两个膜上的六聚体蛋白对接形成缝隙连接通道
		2. 优点：直接通讯、速度快、电信号同步快、允许细胞群体协调
		3. 缺点：分子选择有限、传递范围有限、不适用于大分子
	2. 受体介导
		1. 即配体-受体作用，很多了，不再赘述
		2. 优点：特异性高、调控精确，响应迅速
		3. 缺点：传递范围有限、速度慢、细胞接触复杂
	3. Notch/Delta通路
		1. Notch和相邻细胞的Delta结合
		2. 信号引发Delta内吞，使得Notch胞外被拉伸
		3. ADAM10切割Notch为胞内和胞外，Notch胞外结构域和Delta一起被信号细胞内吞
		4. $\gamma$分泌酶的n亚基和Notch残基结合，p1蛋白酶催化膜内切割，释放Notch胞质段
		5. Notch胞质段转移到细胞核内，和转录因子作用
2. 短距离接触
	1. 旁分泌
		1. 优点：局部调控、快速响应
		2. 缺点：扩散受限、容易被外界干扰、持续时间短
	2. 自分泌
		1. 快速反馈，精确调控、帮助信号放大（癌细胞自分泌生长因子以抵抗凋亡）
		2. 缺点：信号容易过度传递导致失调、缺乏多细胞协同
3. 长距离接触
	1. [[内分泌]]
		1. 优点：长距离信号、持续影响、多靶点系统性调控
		2. 缺点：反应慢、信号稀释、信号终止复杂
	2. 长轴突神经元（[[神经]]）
		1. 优点：快速、长距离、高精度、信号多
		2. 缺点：高耗能、易受损、生长能力有限

# 信号受体
1. 细胞膜或细胞内可以识别信号分子并引起细胞功能变化的大分子，有结合配体部分和产生效应部分
2. 区别：亲水性、疏水性（一般核受体）
3. 分类
	1. 离子通道受体
	2. 酶联受体
	3. G蛋白偶联受体
4. 转导引发快反应/慢反应
	1. 快：改变蛋白活性&功能
	2. 慢：基因表达变化、蛋白质合成等
5. 信使
	1. 第一信使：来自细胞外的信号分子
	2. 第二信使：cAMP、cGMP、钙离子、DAG、IP3、PIP3等
		1. 在细胞膜上生成，放大信息
		2. 受第一信使调控
		3. 不可能出细胞
6. 分子开关：活化/开启调控下游蛋白
	1. G蛋白超家族
		1. GAP：GTP促进蛋白，加速GTP水解，抑制
		2. GEF：鸟苷酸交换因子，帮助GTP添加，激活
		3. GDI：鸟苷酸解离抑制蛋白，抑制GDP释放，维持抑制
		4. RGS：G蛋白信号调节子，加速GTP水解，抑制
		5. eg. NLS（[[细胞核与染色体#NLS]]）
		6. ![[Pasted image 20260627202529.png]]
	2. 蛋白激酶/蛋白磷酸酶
		1. 磷酸/去磷酸化可以激活或抑制蛋白活性，改变三维构象等
	3. 钙调蛋白
# 信号转导
1. 特征
	1. 信号分子大多不可进入细胞
	2. 多步骤级联反应，有放大功能
	3. 机制相对保守
	4. 不同转导通路可以crosstalk
2. 转导过程：激活受体→产生第二信使/膜蛋白→级联效应→细胞应答
3. 不同细胞对同一种细胞外分子反应很可能不同（eg. ACh降低心率，促使骨骼肌运动，刺激唾液分泌）
	1. 骨骼肌：作用于nAChRs尼古丁乙酰胆碱受体，结合后钠离子进入细胞，导致细胞去极化
	2. 心肌：作用于mAChRs毒蕈碱乙酰胆碱受体M2，通过G蛋白偶联激活钾通道，导致钾离子流出；抑制cAMP生成
	3. 唾液腺：M3受体，G蛋白偶联激活磷脂酶，合成IP3和DAG，激活唾液腺分泌水和电解质
4. 信号蛋白复合物组装
	1. 预先组装好各种因子，等待信号来时在同一处被激活；信号执行更快速准确
	2. 先被激活磷酸化后自行招募因子，依次组装；调控高效精确
	3. 被激活后活化旁边的脂质（磷脂酰肌醇），随后脂质招募信号复合体
5. 蛋白质模式结合域
	1. 可以识别其他蛋白质特定motif，亲和性不强，适合快速反复进行调控
	2. eg. SH2结合域，特异性识别磷酸酪氨酸
	3. eg. 信号分子结合→多重磷酸化→对接蛋白对接后也多重磷酸化→适配蛋白识别磷酸化并联系其他蛋白→下游信号蛋白连接，激活小G蛋白启动通路

# NO介导的信号转导
1. 由精氨酸分解为瓜氨酸得来[[鸟氨酸循环]]，可以自由穿过膜并作用于靶分子
2. ACh激活NO释放
	1. 乙酰胆碱作用于血管内皮细胞，产生IP3信号，导致胞内钙离子上升
	2. 激活NO合酶NOS，NOS催化形成NO
	3. NO迅速扩散到附近平滑肌细胞中
	4. 进入后和GMP环化酶结合，激活并生成cGMP
	5. cGMP充当第二信使，触发下游一系列信号通路，松弛平滑肌
		1. 激活下游cGMP依赖激酶PKG，激活靶蛋白
		2. 导致细胞内钙离子外流、抑制肌球蛋白-肌动蛋白作用，和[[肌肉]]和[[细胞骨架#微丝]]有关
3. 药物
	1. 硝酸甘油可以释放NO，因此可以促使血管扩张，缓解心绞痛
	2. 磷酸二酯酶PDE5分解cGMP，抑制舒张
	3. 西地那非抑制PDE5，防止cGMP降解，延长舒张

# 细胞膜受体介导信号
1. 离子通道偶联受体（配体门控通道）
	1. 主要受神经递质等调节
	2. 去极化/超极化，参见[[神经递质]]
2. G蛋白偶联受体
	1. 一般及以上为嗅觉受体，其他占350-400
	2. 结构：包含$\alpha$亚基或$\beta/\gamma$亚基
	3. 七次跨膜蛋白，C端富含Ser或Thr，由G蛋白偶联受体激酶GRK调控
	4. 配体包括但不限于：激素、神经递质、气体分子、味觉分子、光子等、
	5. ![[Pasted image 20260627212028.png]]
	6. 大G蛋白由Ga、Gb、Gg三种构成
		1. Ga有GTPase活性，当做分子开关
		2. Gb和Gg为二聚体形式
		3. 分别被脂质分子锚定在细胞上
	7. 激活步骤
		1. 配体结合，使得GPCR构象改变，随后GPCR和G蛋白三聚体结合
		2. 结合后$\alpha$亚基结合从GDP变为GTP，激活G蛋白
		3. 随后G蛋白解离，$\alpha$亚基和$\beta\gamma$亚基（均可激活）；分别和下游效应蛋白结合，触发生化反应
		4. 一段时间后GTP水解，$\alpha$失活，重新结合
		5. （optional）重复激活时，GPCR激酶磷酸化某些区域，阻断G蛋白再次激活（随后可能被降解回收）
	8. 分激活型受体和抑制型受体，即对cAMP环化酶有不同的提高/抑制酶活性
		1. 激活：肾上腺素、胰高血糖素、ACTH等，激活cAMP合酶
		2. 抑制：前列腺素、腺苷等，抑制cAMP合酶
		3. 双重调控，对不同信号做出不同响应，控制细胞反应
	9. G蛋白有不同亚型/异构体且有不同组合，可以激活不同合酶，产生不同的第二信使
		1. Gs激活cAMP，Gi抑制cAMP
		2. Gt激活cGMP、Gq同PLC偶联
	10. 调节
		1. 霍乱毒素：导致Gs$\alpha$亚基丧失GTP酶活性，锁定在活化状态，大量增加cAMP，导致大量离子通道被激活，钠离子和水外流，个体严重脱水
		2. 百日咳毒素：阻止Gi$\alpha$的GDP释放，cAMP无法受抑制，持续增多，导致出现持续咳嗽
3. G蛋白偶联受体介导信号通路
	1. 激活离子通道
		1. 心肌细胞M受体：ACh→M型受体→Gi蛋白→G$\beta\gamma$→钾离子通道→钾离子外流超极化→减缓收缩频率
	2. 激活cAMP环化酶：cAMP-PKA途径
		1. PKA：两个R亚基（调节，抑制催化活性位点）+两个C亚基（催化）
		2. 走Gs$\alpha$途径生成cAMP→cAMP和PKA结合，释放催化亚基，激活PKA
		3. 进入细胞核后，PKA磷酸化CREB，随后CREB和CBP与之结合，进一步增强转录活性
		4. 复合物结合到启动子的cAMP反应元件上，促进转录
	3. 激活磷脂酶C（IP3和DAG双信使）
		1. 信号分子激活GPCR，激活Gq蛋白
		2. 活化的Gq和磷脂酶C-$\beta$结合并激活，PLC可以水解细胞膜上的磷脂酰肌醇为IP3和DAG
		3. IP3和ER内的IP3受体结合，释放内部储存的钙离子
		4. DAG留在细胞膜，与PKC结合并激活
		5. 钙离子可以和钙调蛋白结合，形成的复合体与PKC激酶结合，增强其活性，PKC自磷酸化，完全激活
		6. PKC可以激活MAPK通路产生级联反应；也可以激活NF-$\kappa$B受体磷酸化，解除某些基因的抑制状态抑制状态
4. 酶联受体
	1. 又是跨膜蛋白又是酶，被配体激活后具有酶活性可以放大信号
	2. 受体酪氨酸激酶RTK
		1. 信号结合受体后被激活，磷酸化酪氨酸残基
		2. ![[Pasted image 20260627220947.png]]
		3. 激活机制
			1. 配体和RTK的胞外域结合，两个RTK发生二聚化
			2. 各自激活活性区域，二聚体中酪氨酸激酶活性部分会在对方位点加上磷酸基团（交叉磷酸化）
			3. SH2结构域识别磷酸化酪氨酸残基，招募带有SH2结构域的蛋白
			4. SH3结构域识别带有大量脯氨酸的序列
			5. 如PI3激酶，GAP，磷脂酶$\gamma$等都有SH2/SH3结构域，随后被招募，激活下游反应
		4. RTK-Ras蛋白
			1. Ras：小G蛋白，分子信号
			2. 配体结合RTK引发二聚化和交叉磷酸化，结合带有SH2结构域的GRB2传导蛋白，其SH3结构域结合Sos（Ras的GEF），随后激活Ras，转变为活性状态，继续激活下游
			3. Ras激活MAPK级联反应（我们有巨量的MAPxK）
		5. PI3K-PKB通路
			1. PI3K两个亚基：p110催化，p85调节（SH2结构域）
			2. 具有磷脂酰肌醇激酶活性&Ser/Thr激酶活性；膜上有大量锚定位点，可以被激活
			3. Akt被激活的PI3K产生的PIP3招募到膜上，同时招募了PDK1、mTORC1磷酸化Akt
			4. 完全活化的Akt从膜上脱离，游离到细胞核中产生效应
	3. 受体蛋白Ser/Thr激酶（以TGF-$\beta$为例）
		1. TGF-$\beta$配体受体结合，激活II受体，产生-OH激酶活性
		2. II对I受体进行磷酸化，随后招募SMAD2、SMAD3蛋白并将其磷酸化
		3. 招募后的蛋白和SMAD4组成SMAD复合物，进入细胞核，激活特定靶基因转录
	4. 偶联蛋白质激酶受体
		1. 一般自身没有催化功能，但是能够结合另一个激酶
		2. 以JAK-STAT受体为例：细胞因子（干扰素、白细胞介素等）和配体
			1. 细胞因子和细胞因子受体结合形成二聚体，此时胞内各有一个JAK激酶
			2. JAK激酶接近后互相磷酸化，互相激活；对受体的酪氨酸进行磷酸化
			3. STATs具有SH2结构域，结合受体酪氨酸残基，被JAK进一步磷酸化
			4. 磷酸化后的STAT从受体中解离，形成STAT二聚体；随后进入细胞核，招募其他调控蛋白
	5. cGMP环化酶受体
		1. 受体就是cGMP环化酶，其可以激活cGMP依赖蛋白激酶PKG，磷酸化特定蛋白
	6. 受体酪氨酸蛋白磷酸酯酶PTP：取出已磷酸化的酪氨酸残基的磷酸根，和RTK效果相反
# 细胞核受体介导
1. 位于胞质中或核内，核受体和配体结合后进入细胞核，发挥转录因子的功能
2. 常见于脂溶性化学信号的受体
3. 核受体
	1. 转录激活域：AF1不依赖配体，AF2配体依赖
	2. 核受体调节因子：
		1. 共激活因子：促进转录活性（组蛋白乙酰化，解除共抑制作用，招募其他因子等）
		2. 辅抑制因子：招募其他蛋白，帮助组蛋白去乙酰化
4. 激素的两级响应
	1. 初级：先激活转录，激活初级响应基因表达
	2. 次级：初级响应蛋白激活次级响应基因，启动新基因表达

# 信号转导的整合和控制
1. 特异性、放大效应
2. 正反馈、负反馈
3. 整合作用
4. 信号的复杂性
	1. 收敛性：不同受体发出的信号导致了一个结果（不同蛋白都可以激活Ras）
	2. 发散性：相同类型的受体可以激活不同的通路
	3. Crosstalk：不同信号通路存在交互（肾上腺素）
5. 脱敏：细胞对信号分子反应钝化
	1. 受体没收（内吞）：进入细胞形成囊泡
	2. 受体下调：受体被水解了
	3. 受体失活：被蛋白结合失活或磷酸化（如GPCR被$\beta$-arrestin结合失活）
	4. 信号蛋白失活
	5. 产生抑制蛋白，发生负反馈
