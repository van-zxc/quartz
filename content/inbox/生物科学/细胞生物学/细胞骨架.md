# 概念
广义的细胞骨架包括细胞质骨架、细胞核骨架和细胞膜骨架，在此只讨论细胞质骨架（cytoskeleton），即微丝、微管、中间纤维

细胞骨架参与各种细胞运动
# 微丝
1. 微丝由肌动蛋白组成，直径约7 nm，相对较软
2. 肌动蛋白单体有ATP/ADP结合位点；微丝由两根原纤丝组成，呈螺旋状
3. 肌动蛋白具有极性，因此微丝也具有极性；开始结合为微丝时使用ATP-actin；随时间推移自动水解为ADP-actin，易脱落
4. 装配过程
	1. 首先以三个肌动蛋白单体为核心开始组装
	2. 正极装配速度大于负极
	3. 当达到肌动蛋白临界浓度时，正极装配，负极解聚，形象的称之为“踏车行为”
	4. 在体外，组装和解聚都需要有大量Na+、K+；组装需要镁离子，解聚需要钙离子
	5. 部分微丝是永久性的（如[[肌肉#骨骼肌结构]]里的细肌丝），有些是暂时性的
	6. ![[Pasted image 20260627110111.png]]
5. 影响药物
	1. 鬼笔环肽：结合排列成微丝的F-actin，导致微丝无法解聚，可以用来帮助染色
	2. 细胞松弛素：细胞+端无法再上肌动蛋白，导致-端持续降解，微丝迅速分解
	3. 猪苓内酯A：导致微丝中间被切断，产生大量游离的正极和负极，通常导致局部解聚
	4. 拉春库林：结合游离的G-actin，导致无法再结合到微丝上
6. 微丝结合蛋白
	1. 微丝组装有关
		1. 胸腺素：与肌动蛋白单体结合抑制组装
		2. 前纤维蛋白：和肌动蛋白单体结合，促进组装
		3. 封装蛋白：结合于纤维一侧，防止继续添加或解聚
	2. 微丝结构/空间排布
		1. α辅肌动蛋白：帮助把微丝聚集成束
		2. 组蛋白：介导微丝结合于细胞膜
		3. 绒毛蛋白（绒毛发生）
		4. 截断蛋白：把肌动蛋白从半路截断并封装
	3. 肌肉收缩：肌球蛋白、原肌球蛋白、肌钙蛋白等
	4. ![[PixPin_2026-06-26_21-14-26.png]]
	5. ![[Pasted image 20260626212018.png]]
7. 微丝的束状/网状排列（交联蛋白）
	1. 交联蛋白为二聚体，可以分别和两根微丝结合
	2. Arp2/3为核心形成分支微丝，组成的微丝为网状分布
	3. formins为核心形成不分支，微丝平行排列并附着到细胞膜上
8. 肌球蛋白为+向的马达蛋白（详情参见[[肌肉#肌丝滑行学说]]，就是很类似的模式）
9. 微丝的功能
	1. 肌肉收缩，参见肌丝滑行学说
		1. 细肌丝为肌动蛋白、原肌球蛋白（肌动蛋白螺旋结构的沟中，长度为7个肌动蛋白分子）、肌钙蛋白（TnC和钙离子结合、TnT和原肌球蛋白结合、Tnl抑制肌球蛋白ATPase活性）
		2. 粗肌丝为肌球蛋白HMM（重链）+LMM（轻链）；肌球蛋白尾尾相对，排列成粗肌丝；头部具有ATP酶活性，构成粗肌丝的横桥，和肌动蛋白分子结合
		3. 和ATP结合时，肌球蛋白和肌动蛋白分离；ADP结合时再结合；每水解一个ATP，移动一个肌动蛋白
		4. 原肌球蛋白在没有钙离子时会封闭肌球蛋白结合部位；有了钙离子后暴露
	2. 应力纤维
		1. 又称张力纤维，由大量反向平行排列的微丝和结构蛋白组成
		2. 通过[[细胞黏着与连接#细胞连接|黏着斑]]和细胞外基质相连，能起到对细胞整体的支持和细胞膜的局部运动
	3. 细胞皮层&伪足
		1. 细胞膜下一层富含微丝的区域，在此区域内微丝结合蛋白将微丝交联为网状结构，使得细胞质成凝胶状
		2. 细胞伪足中充满网状&同向平行排列的微丝，细胞可以沿着伪足形成的方向前进
		3. Arp可以以70°角组装到微丝上，产生Y形分支，在运动细胞中网状分布微丝产生推力，推动细胞膜移动
			1. 组装微丝，微丝延伸
			2. 到达稳定状态后，微丝被帽状蛋白封堵，激动蛋白变为ADP结合 形式，随后容易被cofilin解聚
		4. 微绒毛与胞质分裂环
		5. ![[PixPin_2026-06-26_21-54-06.png]]
# 微管
1. 微管由微管蛋白异二聚体形成，$\alpha$亚基的GTP不可解离，$\beta$亚基上的GTP可以交换
	1. 异二聚体头尾相连形成原纤维，正极为$\beta$，负极为$\alpha$
	2. 13根原纤维组成24--26 nm的圆柱管
	3. ![[Pasted image 20260627103543.png]]
2. 微管为网状/束状分布，呈现为单管、双联管（纤毛、鞭毛）、三联管（中心粒、基体）等
3. 纤毛&鞭毛？
	1. 纤毛像甩尾巴一样一下一下往外面甩，产生动力驱动、收集食物等
	2. 鞭毛频繁的在后面做正弦运动，驱动细胞
	3. 结构：9+2结构
		1. 9个双联管+2个单管，有中央辐条和动力蛋白
		2. 简单来说，动力蛋白结合在双联管上，当水解ATP时，两根微管之间产生相对滑行；但是由于两者都固定，因此只能通过使得微管弯曲来满足相对位移的要求，故产生9+2结构的整体弯曲
4. 微管的组装
	1. 过程：原纤维装配，形成核心，继续装配使微管延长
	2. 装配过程中具有极性，正极装配速度大于负极，所以会出现踏车行为
	3. 体外装配
		1. 聚合：镁离子、GTP、微管蛋白浓度高、体温
		2. 解聚：低温高压、有钙离子
	4. 和上面的微丝也非常相似，也是有GTP的时候就稳定，失去ATP时就容易解聚
5. 分布
	1. 在基体中分布，充当纤毛、鞭毛或中心粒
	2. 树突中维持结构
	3. 在纺锤体中/中心粒中出现，帮助捆绑染色体
6. 影响因素
	1. 秋水仙素：阻止微管装配
	2. 紫杉醇：阻止微管解聚
7. 微管组织中心MTOC
	1. 解聚后重新装配的发生处，其决定微管的极性（靠近一端为负极）
	2. [[中心体]]
8. γ-微管蛋白环：介导微管蛋白成核
9. 微管结合蛋白
	1. 稳定微管结构、促进微管蛋白/装配平衡
	2. 常见于轴突/树突中
## 功能
1. 维持细胞形态：微管有机械强度，可以为细胞提供支撑
2. 细胞内物质运输
	1. 物质运输需要马达蛋白：
		1. 微管：驱动蛋白（kinesin）&动力蛋白（dynein）
		2. 微丝：肌球蛋白（myosin）
		3. DNA马达：解旋酶、聚合酶
		4. 旋转马达：纤毛、ATP酶
	2. 驱动蛋白
		1. 组成：头部（与微管表面直接结合，催化水解ATP）、尾部（特异性地挂载不同货物，有亚型）
		2. 在微管上行进，从负端走向正端
		3. 两个马达头部轮流交替与微管结合。每消耗1 ATP，后方的头部就会向前跨越一个微管二聚体周期的距离
		4. 步行模型
	3. 动力蛋白
		1. 多种蛋白组成（2-3重链，其他轻链）
		2. 轻链通过辅助蛋白，和膜泡&染色体结合
		3. 负向马达蛋白，将细胞器等从边缘向中央转移
3. 鞭毛与纤毛运动
	1. 9+2结构，之前有过阐述
4. 有丝分裂中纺锤体形成和染色体移动
5. 形成基体/中心体
# 中间纤维
1. 种类
	1. 角蛋白纤维：上皮细胞
	2. 波形纤维：中胚层来源细胞
	3. 结蛋白纤维：肌细胞
	4. 神经元纤维：神经元
	5. 神经胶质纤维：神经胶质细胞
2. 结构
	1. ![[Pasted image 20260627134632.png]]
	2. 中间的一段$\alpha$螺旋区高度保守；非螺旋区的N端和C端都高度可变
3. 组装
	1. 二聚体：$\alpha$螺旋区形成双股超螺旋
	2. 四聚体：两个二聚体反向平行，1/4分子重叠；是IF解聚的最小单位
	3. 原纤维：8个四聚体组装成，非共价结合
	4. 中间纤维由8个原纤维组装而成
	5. 没有极性→没有特异性药物；游离单体很少
4. 中间纤维结合蛋白
	1. 丝聚蛋白filaggrin：使角蛋白纤维形成聚集物
	2. 网蛋白plectin：在三种细胞骨架中形成横桥
	3. BPAG1：为桥板蛋白，使IF与桥粒连接
	4. MAP2：参与IF与MT间的横桥
	5. 锚蛋白：参与IF 与膜的结合
5. 功能
	1. 提供细胞质机械强度
	2. 参与细胞连接（桥粒连接）
	3. 参与核膜组装和去组装
		1. 核纤层结构和中间纤维结构相似
		2. 核纤层磷酸化，即崩解，核膜破坏；反之则核膜重建
	4. 参与细胞分化
# 比较

| **对比内容**      | **微丝 (Microfilaments)** | **微管 (Microtubules)**             | **中间纤维 (Intermediate filaments)**                     |
| ------------- | ----------------------- | --------------------------------- | ----------------------------------------------------- |
| **化学组成与亚型**   | 肌动蛋白 (Actin)            | 微管蛋白 ($\alpha, \beta, \gamma$ 亚型) | 几类不同的特异性蛋白 (如角蛋白 keratins、波形蛋白 vimentin、核纤层蛋白 lamins) |
| **纤维直径 / nm** | **7 - 9** _(精确范围修正)_    | 25                                | 10                                                    |
| **物理机械特性**    | 柔性聚合物                   | 相对刚性的聚合物                          | 绳索状纤维，极具抗张力                                           |
| **结构形态与组装**   | 两条原纤维组成的双股螺旋结构          | 13 根原纤维围成的长而中空的圆柱体                | 8 条由四聚体构成的原纤维平行组装成的多级螺旋                               |
| **空间锚定特征**    | 集中分布于细胞膜内侧 (形成皮层网络)     | 通常有一端锚定在**微管组织中心 (MTOC)** 上       | 纵横交错于整个细胞，与桥粒和半桥粒相连，延伸至核内                             |
| **极性与踏车行为**   | 有极性，有踏车行为               | 有极性，表现出高度的动态不稳定性                  | 无极性 (具有结构对称性)，无踏车行为                                   |
| **特异性小分子药物**  | 细胞松弛素、鬼笔环肽              | 秋水仙素、长春花碱、紫杉醇                     | 无特异性解聚药物                                              |
| **演化分布特征**    | 真核细胞普遍保守存在              | 真核细胞普遍保守存在                        | 仅存在于多细胞生物中                                            |
| **核心生理功能**    | 维持细胞形状，介导细胞运动与肌肉收缩      | 维持细胞形状，介导胞内囊泡运输、鞭毛/纤毛运动以及**有丝分裂** | 提供细胞与组织的机械强度与稳定结构                                     |
