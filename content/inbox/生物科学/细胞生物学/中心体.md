# 概念
1. 中心体由两个中心粒组成，两个中心粒互相垂直
2. 中心粒有九个三联管，辐射状排列

![[Pasted image 20260627113017.png]]
可以分为母中心粒和子中心粒；母中心粒至少成熟两个细胞周期，子中心粒上一个细胞周期才刚刚成熟
# 功能
1. 形成动物细胞中主要的MTOC[[细胞骨架#微管]]
2. 母中心粒同时用作纤毛的基体
	1. 母中心粒帮助锚定锚定细胞膜，随后二联体迅速向外聚合，产生轴丝（上端是正端）
3. 中心体在S期生成，依赖母中心粒
	1. 中心粒生物发生需要一个环状的“摇篮”状结构
		1. Late G1 期：CEP192和CEP63-CEP152复合体被招募到母中心粒外侧壁上，在母中心粒的基部环绕形成一圈环状结构，该结构招募PLK4，使之以二聚体的形式结合在环上，并自磷酸化激活
		2. Early S 期：PLK4激酶磷酸化STIL蛋白，进而招募 SAS-6 和 CEP135。9个SAS-6二聚体自发地组成一个九辐射车轮结构
		3. S $\rightarrow$ G2 期：车轮结构的边缘开始招募CPAP和CEP120。CPAP抓取细胞质中的 $\alpha/\beta$-微管蛋白二聚体，开始在外周组装微管。 新生的子中心粒始终与母中心粒的轴向保持垂直
	2. 脊椎动物细胞利用摇篮体/次中心体来扩增大规模中心粒
4. 正常情况下，一个母中心粒只能生成一个子中心粒；但是在多纤毛细胞中，不仅一个母中心粒可以形成多个子中心粒，还能无中生有组装出摇篮体以生成大量中心粒
5. 细胞接受到FoxJ1信号后，打破生成单一中心粒限制，可以形成多个中心粒
	1. 光晕期：信号发出后，新生子中心粒驱动摇篮体自组装。大量颗粒状摇篮体聚集，随后若干批原中心粒启动空间成核。原中心粒呈现出光晕状；此时，成熟母中心粒保持独立
	2. 在子中心粒表面完成初步成核后，摇篮体复合物被释放
	3. 花蕾期：游离的摇篮体核心外周的原中心粒开始摄取微管蛋白二聚体，辐射状延伸；此时，母中心粒和子中心粒同样排列出大量原中心粒
	4. 基体期：原中心粒的微管结构完全发育成熟后，摇篮体核心解聚新生的中心粒被释放，并被修饰上摇篮结构，可以介导微管轴丝延伸；最后这些中心粒向细胞膜迁移，形成基体启动纤毛组装
