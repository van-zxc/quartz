# 概念
1. 形态为粒状或杆状
2. 组成：蛋白质&脂质
	1. 蛋白质占65-70%
	2. 外膜主要卵磷脂，内膜主要心磷脂
3. 大量出现在需要高耗能的位置（如心肌细胞、精子鞭毛等）
4. 超微结构
	1. 外膜：有孔蛋白porin，通透性高（<5kD自由通过）
	2. 内膜：高度不通透，向内折叠形成嵴，含有与能量转换相关的蛋白
	3. 膜间隙：可溶性酶、底物、辅因子等
	4. 基质：三羧酸循环酶系、线粒体DNA、RNA、线粒体表达酶系等
5. 反应定位
	1. 外膜：[[脂肪的合成|脂肪酸延长]]、[[脂肪的分解|脂肪酸去饱和]]、磷脂合成；marker：单胺氧化酶
	2. 基质：[[丙酮酸脱氢]]、TCA循环、脂肪酸$\beta$氧化、线粒体基因表达；marker：苹果酸脱氢酶
	3. 内膜：电子转移、氧化磷酸化、代谢物转运；marker：细胞色素氧化酶
	4. 间隙：核苷酸磷酸化；marker：腺苷酸环化酶
6. 质子动力势可以用来物质转运，或产热
# 线粒体的质控
1. 线粒体融合蛋白（MFN、OPA-1）和分裂相关蛋白（Drp1、Fis-1）等融合轻微受损的线粒体，促进修复
2. 细胞通过线粒体生物发生增加线粒体数目，应对外界应激压力
3. 线粒体清除
4. 内体分选系统（参见[[囊泡系统#受体介导的胞吞]]）
5. 线粒体自噬：巨自噬、微自噬等（[[溶酶体#作用]]）
