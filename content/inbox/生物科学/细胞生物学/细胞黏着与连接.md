# 细胞黏着
1. 细胞黏附分子（CAM）：介导细胞间或细胞与细胞外基质间相互接触的分子统称，整合膜蛋白
2. 黏着方式
	1. 同嗜性结合：同一种细胞粘结分子结合
	2. 异嗜性结合：不同分子结合
	3. 通过胞外连接分子：两个CAM之间隔着一个分子X（如凝集素）
3. 细胞黏附/细胞连接
	1. 细胞黏附一般是短暂的，可逆的（钙黏素、整合蛋白、选择素等）
	2. 细胞连接通常是稳定持久的结构（各种连接+胞间连丝）
4. CAM介绍
	1. 钙黏蛋白：钙依赖，介导细胞黏附，末端与细胞骨架相连，同嗜性结合
		1. 上皮-间充质转化：钙黏蛋白表达下降，细胞粘着性减弱，从上皮细胞向可以自由游走的间充质细胞转化
	2. 选择素：单链跨膜糖蛋白，胞浆区与细胞骨架相连，能够与特异糖链识别并结合，异嗜性结合
	3. 免疫球蛋白超家族：和[[免疫学]]强相关，其黏着与钙离子不相关
	4. 整联蛋白：介导细胞与细胞外基质黏附，有$\alpha, \beta$两个亚基；配体有纤维连接蛋白、层纤维蛋白、胶原蛋白、纤维蛋白、免疫球蛋白超家族
	5. 黏蛋白：上皮细胞分泌的高度糖基化的蛋白，对上皮起润滑保护功能，亲和选择素
	6. 钙黏蛋白和整联蛋白家族能够形成稳定连接
# 细胞连接
1. 封闭连接、锚定连接、通讯连接
2. 封闭连接：典型的如紧密连接
	1. ![[PixPin_2026-06-22_21-32-14.png]]
	2. 连接两个细胞，同时封闭两个细胞之间的空隙，帮助维持细胞极性
	3. 紧密连接蛋白颗粒形成连接线
	4. eg. 小肠上皮细胞顶端主动运输葡萄糖和钠离子，基底侧膜将葡萄糖释放到血液中
3. 锚定连接：帮助细胞承担外界各种力的作用
	1. 涉及两类蛋白：附着蛋白（在细胞内中间纤维/微丝结合到一起，涉及[[细胞骨架]]）和跨膜连接糖蛋白（钙黏蛋白+整联蛋白）
	2. 锚定在中间纤维的连接：桥粒和半桥粒
		1. 桥粒：在细胞间形成纽扣状结构，可以承受强拉力，中间有相互作用的钙黏蛋白
		2. 半桥粒：桥粒的一半，钙黏蛋白换为整联蛋白，连接细胞和细胞外基质
	3. 锚定在肌动蛋白纤维的联系：黏着带与黏着斑
		1. 黏着带：细胞与细胞之间的连接，整联蛋白连接，
		2. 黏着斑类似半桥粒，将肌动蛋白丝和胞外基质联系
4. 通讯连接：细胞通讯和信号转导
	1. 间隙连接：细胞膜上连接蛋白六聚（连接子），相邻细胞对接形成联通的孔道（直径约1.5 nm）
		1. 电突触：突触前后神经元使用间隙连接，让小分子自由扩散
	2. 胞间连丝：相邻细胞的质膜穿过细胞壁，形成一个孔径达20-40 nm的管道，出现在高等植物中，是高等植物唯一的连接形式
	3. 化学突触

# 细胞外基质
1. 细胞外被：又叫糖萼，细胞膜外糖蛋白和糖脂结合的寡糖或多糖的组合体
2. 细胞外基质：细胞的糖蛋白和蛋白聚糖组成的复杂的网状结构
	1. ![[PixPin_2026-06-22_22-04-34.png]]
	2. 组成：糖胺聚糖、蛋白聚糖、结构蛋白、黏着蛋白
	3. 透明质酸：可以在细胞外游离存在，本质上是糖胺聚糖，具有抗压、润滑等能力
	4. 胶原：动物最丰富的蛋白，胞外基质中最主要的蛋白
		1. 甘-脯-羟脯氨酸组成的重复序列，在[[氨基酸#翻译后修饰]]中出现
	5. 弹性蛋白：组成弹性纤维
3. 黏着蛋白：高分子糖蛋白，促进细胞和基质的结合
	1. 层黏连蛋白：成体组织基膜和胚胎的组成成分，为三聚体（一重二轻，十字结构），桥梁分子
	2. 纤黏连蛋白：血浆纤黏连蛋白（二聚体，V字型）、细胞纤黏连蛋白（多聚体）
4. 细胞壁
	1. 动物细胞无！
	2. 作用：增加机械强度，控制生长
	3. 90%为多糖（纤维素&果胶）、10%为蛋白质、酶和脂质
