# 概念
1. 又称微体
2. 有单层膜，含有若干种氧化酶，pH中性
3. 使用分子氧去氧化不同物质，生成过氧化氢
4. 随后由过氧化物酶分解为水
5. 电镜下其中的尿酸氧化酶形成晶格状结构
# 功能
1. 解毒
	1. FAD依赖酶，氧化
	2. 将过氧化氢分解
2. 分解脂肪酸，提供热能
3. 植物细胞
	1. 催化光呼吸反应
	2. 催化[[乙醛酸循环]]
# 生物发生
1. 分裂后形成子代细胞器
2. 蛋白由核基因编码，胞质中合成
3. 蛋白分选信号：PTS1（SKL，蛋白质C端）、PTS2（N端）
	1. 都能和Pex14p结合，将蛋白转入膜内
	2. 随后N端被移除，SKL保留
