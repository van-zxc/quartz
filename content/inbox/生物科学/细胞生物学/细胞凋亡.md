# 概念
1. 细胞程序性死亡，apoptosis
2. 基因主动决定自杀（自刎归天！），相当正常
3. 最终以凋亡小体的形式被消化
# 特征
1. 细胞膜保持完整，细胞内含物不泄露，无炎症反应
2. DNA按核小体形式发生断裂，DNA长度约200 bp
3. 起始：表面特化结构消失、核糖体从ER上剥落，ER膜开始和内质网膜融合、染色体固缩
4. 凋亡小体：断裂的DNA和其他内容物被反折的细胞膜包裹，表面形成泡状凸起（类似出芽），形成单个圆形小体
5. 最后被吞噬细胞或其他邻近细胞吞噬并消化
# 凋亡标志
1. 早期会释放低水平ATP/UTP，结合巨噬细胞受体
2. 凋亡细胞会激活磷脂酶，将部分磷脂切割成溶血磷脂酰胆碱，给巨噬细胞
3. 上调鞘氨醇激酶产生1-磷酸鞘氨醇并释放
4. 磷脂酰丝氨酸外翻，暴露在细胞膜表面（抗凝血剂Annexin V可以结合PS，特异性检测）
5. 凋亡细胞产生200 bp的DNA梯状条带
6. TUNEL：DNA断裂的原位标记
# 分子机制
1. 诱导因子
	1. 物理刺激：射线、热刺激、冷刺激等
	2. 其他因子：ROS、钙离子载体、激素、生长因子、细胞毒素等
2. Caspase依赖性途径
	1. Caspase：半胱天冬蛋白酶
	2. Caspase平时以单体形式存在，信号发出后单体二聚化，交叉剪切断开大小亚基，重新组装为功能完备的四聚体，出现活性中心
	3. 启动型Caspase：初始为游离单体，自剪切脱去前体结构域
	4. 执行型Caspase：初始为二聚体，被上游酶切掉前体开始执行
	5. Caspase级联反应
		1. 外源途径：依靠8和10启动，靠3和7执行
		2. 内源（线粒体）：靠2和9启动，3和6和7执行
	6. ![[Pasted image 20260628173717.png]]
	7. Bcl-2家族：调控线粒体外膜通透化，定位于线粒体
		1. BH3结构域：促凋亡；BH4：抗凋亡蛋白，可以同时含有
		2. 有BH1-BH4：阻止效应蛋白结合，保证线粒体完整
		3. 有BH1-BH3：组成Bax-Bak复合体，在线粒体外膜形成跨膜大孔MOMP，导致细胞色素c游离到细胞质，触发Caspase级联反应（如Bak、Bax）
		4. 只有BH3：中和抗凋亡蛋白，释放Bax/Bak；或直接诱导Bax、Bak（Bim、Bid等）
		5. 多定位于线粒体外膜上
	8. 凋亡抑制蛋白IAP
		1. 内源性Caspase抑制因子，如XIAP等
		2. 共有BIR结构域，可以直接和Caspase结合，阻止其对底物切割
	9. p53蛋白：抑癌因子，可以促进多个促凋亡因子表达
	10. 凋亡机制
		1. Caspase2和9含有CARD和DD，通过结构域聚合，Caspase可以彼此结合或被其他蛋白结合，被招募到上游复合物发生活化
		2. 死亡受体机制
			1. CD95/CD95L途径
				1. Fas ligand（killer cell）结合细胞表面的Fas receptor后，招募FADD（死亡信号衔接蛋白）于细胞膜上
				2. 随后FADD再次招募有DED序列的Caspase 8，激活
			2. TNFR1途径：肿瘤坏死因子通过TNFR介导
			3. TRAILR途径：肿瘤坏死因子相关 诱导配体
		3. 线粒体凋亡途径
			1. 受刺激后，Bax/Bak打孔，释放Cyto C；随后激活Apaf-1，自组装为七聚体凋亡复合体，随后再招募proCaspase9，随后再激活Caspase3/7级联放大
			2. 还会释放两个蛋白：依靠Caspase通路和不依靠（AIF，释放后易位至细胞核，诱导染色体凝聚等）
		4. ![[Pasted image 20260628185707.png]]
3. Caspase非依赖性途径
4. 转录因子
	1. p53促进凋亡
	2. NF-$\kappa$B抑制凋亡
	3. c-Myc诱导细胞做出选择
5. 细胞存活通路
	1. 激活转录因子，帮助转录Bcl2，阻止凋亡
	2. 激活后磷酸化Akt，激活Bad结合Bcl2，阻止凋亡
	3. 激活MAPK，使Hid失活，间接促进IAP蛋白表达，IAP可以阻止Caspase激活
6. p53参与细胞凋亡/衰老选择
# 细胞坏死
1. 细胞受到急性损伤或严重病理刺激发生的死亡
2. 表现
	1. 钙离子升高，ATP迅速下降
	2. 线粒体外膜肿胀、细胞骨架破坏
	3. 溶酶体释放、pH下降、DNA降解、蛋白质合成减慢
	4. 细胞器和细胞膜破裂，细胞内容物被释放，引发炎症反应
3. 程序性细胞坏死：坏死性凋亡、细胞焦亡、铁死亡等
	1. 大量释放促炎因子
	2. 促进胚胎发育&成年组织稳态，可以被特定受体诱导，受调控
	3. 磷酸化MLDL执行细胞膜穿孔和破裂
	4. 通常由TNF家族和Toll-like受体触发，向RIP1和RIP3传递死亡信号
	5. 病毒可能诱导程序性坏死
# 细胞自噬
1. 膜可以包裹部分需要降解的细胞器形成自噬体，随后被溶酶体融合吞噬
2. 自噬泡、和溶酶体进行融合等
3. 受基因调控：ATG、蛋白激酶、磷酸酶等调控
	1. ![[Pasted image 20260628191145.png]]
4. 自噬泡有双层膜，自噬溶酶体则只有一层膜
5. 自噬和凋亡会互相抑制，但是过度自噬会导致自噬性死亡
