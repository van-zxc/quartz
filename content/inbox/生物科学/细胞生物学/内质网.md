即the endoplasmic reticulum（ER）
# 概念
1. 内质网是由膜包围的管状结构和囊状腔组成的网络，从核膜开始并贯穿细胞质
2. （大多数真核）最大的细胞器，膜总量大，占体积大
3. 生成蛋白数量大（30%，其他生成区域在胞浆/线粒体）
# 区别
1. 内质网外表面为胞质面，内表面为潴泡面
2. 特殊内质网有微粒体和肌质网（[[肌肉]]）
	1. 微粒体：均质化和离心人工造出来的膜性小颗粒
	2. 肌质网：肌肉细胞内特化的肌质网，释放/储存钙离子以控制肌肉收缩
3. 粗面内质网：
	1. 表面附着大量的核糖体，显微镜下显得粗糙
	2. 扁平状，有大的腔室结构，便于蛋白质合成和运输
4. 光面内质网
	1. 表面光滑，呈管状或网状
	2. 不参与蛋白质合成，进行钙离子存储或脂质合成
# 粗面内质网
1. 合成跨膜蛋白、分泌蛋白、糖基化修饰蛋白，需要严格空间区室分隔的酶
2. 信号肽！
	1. 序列：15-35个aa，引导肽链进入内质网腔
	2. 一般位于N端或肽链内部
3. 蛋白质合成过程：
	1. 合成开始于游离核糖体，若蛋白质含有信号肽则会被信号识别颗粒（SRP）识别
	2. SRP会引导核糖体-肽链复合物结合在内质网膜上的SRP受体上，随后核糖体与转运通道结合
	3. 核糖体继续翻译蛋白质，合成的肽链穿过转位子进入ER中；进入后信号肽被剪切掉，蛋白完全进入腔内
	4. 膜蛋白：若肽链中含有一段疏水序列（停止转移序列），进入通道时迫使易位子侧向打开，导致蛋白质被”固定“在膜上形成膜蛋白
4. SRP：翻译暂停结构域、信号肽识别结合位点、SRP受体蛋白结合位点
5. 跨膜蛋白
	1. 终止转移序列进入易位子后，会导致构象改变，使得其从侧向释放肽链到脂层主，切除信号肽
	2. 有正电荷氨基酸（碱性）的那一侧倾向于留在细胞质基质
	3. 起始转运初段：疏水区
		1. 位于N端（信号肽）：成熟N端在ER腔内，C端在细胞质中
		2. 位于内部：不切除，直接变为跨膜部分
	4. 多次跨膜蛋白：类似之前的操作，就是屡次重复过程，把起始转移序列转移到细胞膜上而已
	5. ![[PixPin_2026-06-25_19-41-38.png]]
6. 尾锚定蛋白（解决信号肽在尾端的问题）
	1. Get ATPase包裹住信号肽，形成蛋白-get3复合物
	2. 靶向ER膜的Get1-Get2受体，定位
	3. 水解ATP，将序列锚定到1-2复合体中
7. GPI蛋白
	1. 并非疏水的a helix锚定在膜上，而是通过GPI磷脂、多糖和磷酸乙醇胺锚定
	2. 可以自由扩散，多绑定在脂筏上，容易被磷脂酶剪切
8. 翻译后跨膜
	1. 后翻译转运机制
	2. 后翻译转运通常被用在高度折叠蛋白或膜蛋白上
	3. 受BiP分子伴侣影响，转运后蛋白进一步修饰
# 光面内质网
1. 糖原合成和游离葡萄糖释放
	1. 在肝细胞中，通过内质网膜跨膜蛋白，G6P酶水解G6P为葡萄糖
2. 脂类的合成&转运
	1. 磷脂酰胆碱合成：（胞质面）脂肪酸结合在膜上，加甘油再加胆碱；合成后磷脂通过转位酶翻转
	2. 质膜磷脂来自内质网，随后通过囊泡转移、直接接触或脂质结合蛋白传递到质膜上
	3. 囊泡：出芽+融合，蛋白质/脂类等常见转运方式
	4. 膜接触转运：快速直接，通过转运蛋白，维持脂质平衡
	5. 脂质转运蛋白：不接触，无囊泡
3. 解毒
	1. 大量氧化酶系统（P450/NADH-细胞色素C还原酶等）：位于胞质面，在肝脏中丰富
	2. 单加氧酶：混合功能的氧化酶（CYP2E1，氧化乙醇为乙醛）
4. 释放钙离子
# 蛋白质的加工和修饰
1. 二硫键的生成
	1. PDI介导二硫键的生成和重排
2. N-糖基化
	1. N-乙酰葡萄糖胺和天冬氨酸的氨基连接，形成糖蛋白
	2. 先在腔外加糖基，再翻转到腔内，再添加葡萄糖
	3. 衣霉素能抑制加糖链这一步，导致无法转移上糖基，糖蛋白无法正确这得，导致内质网应激
3. 蛋白质质控
	1. ER途径：内质网降解
		1. 未折叠蛋白质被分子伴侣标记，随后被引导进入易位子，返回细胞膜基质
		2. 去糖基化，方便降解
		3. 泛素化修饰：被标记上多泛素链，随后被蛋白酶体识别，将损坏蛋白拉进蛋白酶体中，水解为短肽或aa
		4. 刚产生的内质网会给蛋白上一个糖链，随后与内质网膜蛋白互作，进行折叠，葡萄糖苷酶水解掉糖，释放；若折叠完毕，直接进入高尔基体；如果不完全折叠（有疏水中心），重新上一个葡萄糖继续循环；多次循环失败后会被按照ER途径降解
	2. UPR：未折叠蛋白质反应
		1. 蛋白质折叠错误或蛋白负荷过大时激活，应对细胞应激
		2. stress适中时，UPR增强折叠，促进错误降解，适应环境
		3. stress过强时，UPR激活CHOP，JNK等促进细胞凋亡/坏死
		4. IRE1通路：错误折叠蛋白结合内质网伴侣蛋白，IRE1结合后二聚化&磷酸化，核酸内切酶活性增强，剪切XBP1mRNA（转录因子），激活ER伴侣蛋白有关基因，帮助折叠（分子伴侣感知不正确构象）
		5. PERK通路：stress后PERK激活elF2α（翻译起始因子），减少ER新合成蛋白
		6. ATF6通路：平时和BIP结合，应激下解聚转移至高尔基体，释放胞质结构域，激活ER伴侣转录表达
4. KDEL序列：包含此类序列的一般锚定于内质网内，当意外转运入cis-内质网时，会被包裹进COPI囊泡，送回内质网（与pH强相关）
	1. 在高尔基体，由于pH下降，KDEL受体识别ER驻留蛋白
	2. H+帮助受体和KDEL更紧密结合
	3. 当回到受体后，由于pH低，KDEL释放蛋白
5. ERGIC
	1. [[高尔基体]]和内质网之间的一个中间区室
	2. 负责在两者间转运蛋白质和脂质
