# 概念
1. 异质性细胞器，呈小球状
2. 外面单层膜包被，大小差距很大（1μm-20nm）
3. 标志：酸性磷酸酶
4. 植物的中央[[液泡]]在某些功能上与溶酶体类似，作用更广泛
# 膜稳定性
1. 膜上有大量质子泵（P型）
2. 膜上有多种载体蛋白便于运出产物
3. 膜蛋白高度糖基化
4. 膜表面含有大量胆固醇
# 作用
1. ![[PixPin_2026-06-25_21-07-41.png]]
2. [[囊泡系统#吞噬作用]]
	1. 常见于免疫细胞，如中性粒、巨噬、树突等
	2. 病原体和受体结合后内吞，随后溶酶体与吞噬体结合形成次级溶酶体将病原体消化
3. 自噬作用（与自噬体有关）
	1. 巨自噬：多种自噬蛋白相互作用，形成自噬小体将物质/细胞器投到溶酶体降解（常被直接简称为自噬）[[细胞自噬]]
		1. 细胞应激时，激活mTOR（饥饿解除抑制）和AMPK（缺能促进自噬），会聚到ATG1/ULK1 复合物和PI3K复合物，开始招募膜结构
		2. ULK和PI3K催化形成隔离膜，包住线粒体
		3. 自噬体形成时，LC3和膜磷脂酰乙醇胺偶联形成LC3-II（自噬标志物）
		4. 在RAB7（小GTP酶）以及 LAMPs（溶酶体相关膜蛋白）和 SNARE 蛋白复合物的介导下，自噬体和溶酶体融合
	2. 微自噬：胞质中微小的物体通过溶酶体膜自噬/晚期内体清除
	3. 分子伴侣调节自噬
4. 内吞作用（内吞体）
5. 自溶作用
# 生物发生（M6P途径）
1. 溶酶体酶上有标记M6P，TGN通过识别M6P分选出来
	1. 来自粗面内质网的糖基化和磷酸化
	2. N-乙酰葡萄糖胺磷酸转移酶、N-乙酰葡萄糖苷酶
	3. 过程：带有甘露糖残基，被GlcNAc转移酶识别；随后GlnNAc和磷酸基团转移，再水解GlcNAc，形成M6P
2. 信号斑：信号肽形成的三维结构的表面，被磷酸转移酶识别，转移上乙酰葡萄糖胺
3. 分选：
	1. 来到高尔基体后，和M6P受体结合（TGN），装载到囊泡中运输到溶酶体；到了溶酶体，低pH将M6P受体和酶分离
	2. 释放后水解掉M6P的磷酸（放置溶酶体酶再次与M6P结合），溶酶体酶出现活性
4. 还有非M6P途径
# 疾病
1. 包涵体细胞病
2. 溶酶体贮积症：溶酶体无法降解特定生物大分子导致异常
3. 矽肺、类风湿关节炎
4. 肺结核等
