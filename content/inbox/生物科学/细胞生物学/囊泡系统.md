# 概念
1. 一种细胞内物质转运形式（囊泡运输）
2. 在细胞器间和细胞外环境之间运输各种物质
# 种类
1. 内吞作用 ^b77164
	1. 细胞形成囊泡，把外部物质吸到内部
	2. 吞噬作用：吞噬细胞，把大物质吞进来，肌动蛋白介导
	3. 胞饮作用：小型囊泡吸收物质
	4. 受体介导的内吞：特定分子和受体结合后选择性摄取（LDL、转铁蛋白等）
2. 外排作用
3. 囊泡转运
4. 跨膜转运
# 过程概述
1. 需要适配蛋白
2. ==GTP很重要==，尤其是小GTP酶（Rab、ARF、Sar1）
	1. 调控囊泡形成、运输、膜融合
	2. 周期性结合&水解以调控过程
3. 融合需要蛋白作用
4. 组成性分泌：小泡形成&转运蛋白质至细胞表面，提供脂质&蛋白
5. 调节性分泌：激素、粘液等储存在分泌小泡中，直到受到外界刺激再分泌
6. 分泌颗粒：外分泌（酶原颗粒）、内分泌、神经
7. 极性细胞：各侧细胞膜不同，通常定向运输
# 胞吐作用 exocytosis
1. 出芽、运输、定位、融合
2. 运输过程中转运蛋白和脂质的取向不改变
3. 过程
	1. 分泌小泡接近细胞膜
	2. 小泡和细胞膜开始接触&融合，需要膜蛋白
	3. 细胞膜破裂
	4. 小泡内容物被释放到细胞外
	5. 稳定有效的释放内容物，保持细胞稳定&连续
# 胞吞作用 endocytosis
1. 内陷摄取各种东西的过程
2. 种类见[[囊泡系统#^b77164]]
3. 过程
	1. 细胞内陷形成小囊泡
	2. 囊泡内陷收缩，包裹细胞外物质
	3. 细胞膜闭合，形成独立囊泡
	4. 囊泡和细胞膜分离形成胞吞小泡
## 吞噬作用
1. 由==肌动蛋白==介导
2. 细胞通过延伸伪足包裹吞噬大颗粒物质
3. 主要由巨噬细胞&中性粒细胞细胞进行，免疫防御机制
4. 过程
	1. 表面抗体受体识别并结合吞噬细胞，导致PI3激酶在细胞膜上激活，招募其他信号分子
	2. 肌动蛋白聚合，形成吞噬泡包裹细菌；肌动蛋白引导膜融合，待融合形成吞噬体后自发解聚
## 胞饮作用
1. 非特异性摄取细胞外液和溶解小分子
2. 持续进行
3. 过程
	1. 外界信号分子融合
	2. 不同于吞噬作用，细胞表面形成一个突出结构；该突出结构膜融合，形成巨胞饮体
## 受体介导的胞吞
1. 高度选择性摄取（特定受体结合）
2. 过程：受体和特定配体结合、内陷、小泡与内体融合，配体释放，受体返回细胞膜
3. 可能受体循环，配体降解（LDL）；可能受体和配体一起循环（转铁蛋白均回收至膜表面）；可能受体和配体都被降解（EGF&EGFR）；可能转胞吞作用（将物质从一侧转运到另一侧（抗体、营养吸收）
4. 再循环内体：可以当做特定质膜蛋白的内储存库，便于在特殊情况迅速补充至细胞膜表面（如[[内分泌#胰岛|胰岛素]]作用，GLUT4迅速被调动到细胞膜上）
### LDL回收
1. ApoB是LDL的重要标志蛋白
2. 胆固醇摄取：
	1. 血液LDL介导内吞，LDLR主要蛋白
	2. 肠道NPC1L1介导，即[[胆固醇代谢#消化吸收]]
	3. 囊泡封装后内吞LDL
3. 胆固醇输出
	1. 血液：逆向胆固醇转运，ABCA1、ABCG1等等将胆固醇输出至HDL
	2. 胆固醇分泌：ABCG5、ABCG8
	3. 直接跨膜转运，需要ATP
### 其他受体介导
1. transferin结合TfR受体启动内吞
	1. 低亲和力，在内体中会解离
	2. 最终不会被泛素化，两者都重新回归细胞膜
2. EGF结合EGFR启动MAPK通路，启动内吞&溶酶体降解过程
	1. 强亲和力，不会在内体中解离
	2. 被泛素化标记后降解
# 囊泡类型&分选信号
1. 类型
	1. 披网格蛋白小泡（clathrin-coated vesicle）
	2. COPII被膜小泡
	3. COPI被膜小泡
	4. ![[PixPin_2026-06-26_14-21-56.png]]
2. 运输路径
	1. 网格蛋白被膜小泡
		1. 通过胞吞作用/跨高尔基到溶酶体运输
		2. 受体介导内吞中，网格蛋白介导，将蛋白质和酶从高尔基体中运到溶酶体
		3. 被膜：由网格蛋白覆盖，形成笼状结构
	2. COPI
		1. 高尔基体内各囊泡运输（从cis到trans的运输）及高尔基体回流到内质网的运输）
		2. 被膜：由COPI复合物包被，适合高尔基体之间或向内质网回流的运输
	3. COPII
		1. 负责内质网到高尔基体的顺向运输
		2. COPII复合物包被，将内质网新合成的蛋白质/脂质运送到高尔基体
## 网格蛋白小泡
1. 网格蛋白：二聚体，重链+轻链
2. 三个clathrin单体通过重链之间互作形成triskelion，形成三联体结构，是包被的基本结构单元，窝起来形成五边形/六边形的网格结构，组装为网格蛋白小泡
3. ![[PixPin_2026-06-26_14-32-35.png]]
4. 完整的clathrin笼通常需要36个triskelion
5. 形成过程：网格蛋白小窝→小泡→有被小泡→无被小泡→和早期内体融合
6. 衔接蛋白
	1. 在细胞质表面将网格蛋白固定在囊泡表面
	2. 在内侧表面，和整合膜蛋白胞质尾部的分选信号结合
	3. 有AP1到AP4四种
	4. ![[PixPin_2026-06-26_14-38-56.png]]
7. 磷酸肌醇PIP
	1. 肌醇环的羟基可以被随意上羟基
	2. 不同种类的肌醇在细胞内严格区室化，不同的PIPs会标记不同的细胞器/细胞器的不同膜表面
8. 网格蛋白有被小泡被切断
	1. 膜表面的PI（4,5）P2招募了衔接蛋白AP complex，随后再招募网格蛋白和货物
	2. 膜颈部的脂质环境招募了动力蛋白dynamin，其水解GTP产生动力，将囊泡收紧，切离小泡和质膜
9. 详细过程：
	1. 受体激活（EGFR、GPCR、Grb2等）招募PI3K，将PI（4,5）P2变为PI（3,4,5）P3
	2. 激活Arf6，将PIP5K定位到膜上，合成PI（4,5）P2；富集后召集AP2，clathrin，epsin等；通过结合磷酸肌醇诱导膜弯曲
	3. dynamin结合PI（4,5）2，完成膜颈切割，随后去磷酸化，移除clathrin
## COP-被膜小泡
1. COPI&COPII
	1. COPI：胞质溶胶蛋白，7个亚基，可以结合KDEL
	2. COPII：多亚基（Sec23/24、Sec13/31等），识别为双羧基信号；融合成大泡后以微管为运输通道
2. 小G蛋白：
	1. 活性由GTP调节，典型如ARF（调节COPI）、SAR1（调节COPII）等
	2. 受GNRF/GEF和GAP调节
	3. GNRF：诱导小G蛋白释放GDP，自发结合GTP，从而改变构象
	4. GAP：提高小G蛋白水解酶活性，帮助水解GTP为GDP
3. COPI囊泡
	1. GEF诱导ARF结合GTP后，招募外被体，随后外被体交联形成完整的COPI囊泡
	2. 随后GAP诱导ARF水解GTP，ARF改变构象脱离膜表面，导致外被体随之分离
4. COPII囊泡
	1. SAR1被Sec12诱导后结合GTP，插入内质网膜
	2. 随后招募 COPII 的外被亚基Sec23/Sec24（内层，结合膜蛋白）和Sec13/Sec31（外层，形成规则结构），累积后形成囊泡
5. Retromer复合体
	1. 逆向运输，从晚期内体运输到高尔基体TGN处
	2. Vps26、Vps29、Vps35 三个亚基组成Vps三聚体），结合某些跨膜受体胞质侧尾区，决定哪些货物需要被打包运回高尔基体
	3. SNX家族蛋白（如 SNX1, SNX2, SNX5, SNX6）组成膜二聚弯曲体，拥有BAR结构域，用以形成管状结构
	4. 过程：内吞体膜上高浓度的$PI(3)P$和Rab7-GTP共同招募细胞质中的 Retromer，Vps 三聚体结合目标，SNX 蛋白把膜向外拉成细长管状结构，随后管状囊泡断裂释放，沿着微管网络，逆向运回TGN
## 多泡体
1. 是溶酶体降解过程中的重要中间体，通过膜内陷封装内容物
2. 膜蛋白先被单个泛素分子修饰，随后泛素标签促进受体进入内吞囊泡，随后被介导分选过程的蛋白再次识别，最终进入多泡体的内部膜囊泡
3. ![[PixPin_2026-06-26_19-55-34.png]]
4. 内吞体分选转运复合体ESCRT
	1. 真核生物中高度保守
	2. ESCRT0-III参与构成
	3. 受体结合→货物传递→3向腔内组装小泡→水解0-3，释放到细胞质中，回收利用

# SNARE
1. 膜融合特异性通过囊泡上的v-SNARE蛋白和靶膜上的t-SNARE特异性作用介导
2. 过程
	1. v-SNARE和t-SNARE在Rab-GTPase（不同Rab指导不同内体）指导下定位
	2. 两者形成“拉链”结构，四螺旋束使得膜接近并融合
	3. 两个膜的亲水头部形成中间结构，形成稳定的膜孔
	4. SNARE复合体解离
	5. ![[PixPin_2026-06-26_20-04-13.png]]
3. SNARE蛋白之间的作用是通过两侧的结合缠绕完成的；结合后两者越拧越紧，使得中间出现无水区，导致膜被迫融合
4. 扭绞在一起的SNARE一起游离于膜表面，随后$\alpha$-SNAP结合SNARE，引导NSF结合；随后NSF通过大量水解ATP进行旋转，帮助肽链解旋，分离后各自回归细胞质
5. Rab蛋白：和Ras家族有关
	1. 在膜泡运输和融合中有广泛作用
	2. 比如Rab效应引自帮助v和t的两条肽链结合（扭在一起）
	3. Rab被Rab-GEF激活后，会协同PI3P一同招募clathrin或AP蛋白，组成复合体结合目标蛋白
