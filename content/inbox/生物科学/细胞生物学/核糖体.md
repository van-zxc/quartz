# 类型

2. 线粒体核糖体（55S，35S+25S）
3. 叶绿体核糖体

或真核/原核核糖体
1. 原核：
	1. 70S（50S大亚基+30S小亚基）
	2. 大亚基：31种蛋白，23S+5S rRNA
	3. 小亚基：21种蛋白，16S rRNA
2. 真核：
	1. 80S（60S大亚基+40S小亚基）
	2. 分为游离核糖体和附着核糖体（[[内质网]]上）
	3. 大亚基：49种蛋白，28S+5.8S+5S rRNA
	4. 小亚基：33种蛋白，18S rRNA

# 生物发生
1. 转录与加工
	1. rRNA基因在DNA内有大量复制拷贝
	2. 真核生物中28S、18S和5.8S rRNA基因串联分布，5S rRNA基因独立存在；原核生物中5S rRNA和其他基因在同一条染色体上
2. 自我装配：
	1. 真核生物在核仁装配，原核生物在细胞质
	2. 过程（真核）
		1. 核糖体蛋白被核孔复合体转运进来
		2. rDNA被转录产生pre-rRNA，随后被外部蛋白自发折叠和剪切
		3. 外部再插入一个5S rRNA，自发形成大小亚基；最后被核孔复合物转运出去
		4. 镁离子浓度决定大小亚基是否结合（1-10结合、<1 mM分开）
	3. 过程（原核）
		1. 小亚基：2/3的蛋白质先在较低温和16S rRNA结合形成21S中间颗粒；37℃时中间体构象改变，变为26S；其他蛋白质再和中间体结合形成30S
		2. 大亚基：23S和5S rRNA和蛋白组成33S颗粒，温度上升至44℃变为41S，再结合蛋白变为48S，最后上升至50℃变为50S
# [[肽——蛋白质一级结构|蛋白质]]的生物合成
1. 核糖体的功能位点（以原核为例）
	1. ![[PixPin_2026-06-24_14-29-55.png]]
	2. A位点：主要在大亚基上，可以接受氨酰tRNA
	3. P位点：主要在大亚基上，释放tRNA的部位
	4. E位点：中间站，氨酰tRNA和E结合时，A的亲和力下降
	5. mRNA结合位点：16S rRNA的3‘端；
		1. 原核mRNA结合部位为SD序列，在mRNA 5’处富含嘌呤的短核苷酸
		2. 真核没有SD序列，mRNA结合依赖5‘的帽子结构（m7G）识别
2. 蛋白合成主要由rRNA催化完成（肽酰转移酶、提供tRNA结合位点等），蛋白质可能对核糖体进行微调而已
3. 具体过程
	1. 氨基酸被ATP活化，转移到tRNA上，ATP释放PPi；过程被氨酰tRNA转移酶催化，有高度专一性，每种氨基酸都有专一氨酰tRNA
	2. 肽链的合成
		1. 合成方向：N to C；翻译方向：5’→3‘
		2. 起始：小亚基和mRNA起始密码子结合，招募第一个氨酰tRNA进入核糖体
			1. IF3先结合到30S亚基上，放置50S和30S结合；IF1结合到小亚基A位点，IF2结合GTP；mRNA结合到小亚基上，被引导将AUG置于P位点
			2. 甲酰甲硫氨酸进入，IF2引导进入fMet-tRNA进入p位点
			3. IF2将GTP水解，使之离去，导致IF1和IF3也离去，大亚基迅速结合
		3. 延伸：氨酰tRNA进入A位点，形成肽键，转位随后去氨酰tRNA
			1. tRNA进入A位点且反密码子配对后，EF-Tu释放，进入位点A
			2. 23S rRNA催化P位点肽链转移到A位点的tRNA上
			3. EF-G推动核糖体向前移动一个密码子，E位点的tRNA被释放，重新循环
		4. 终止：到达终止密码子后脱离
			1. 到达终止密码后，RFs识别并进入P位点，催化肽链水解
			2. 使用RRF和EF-G将核糖体复合物拆解，重新释放
4. 肽链后续加工：
	1. 切掉N端的Met或fMet
	2. 切除没有功能的肽段
	3. 生成二硫键
	4. 氨基酸残基修饰
	5. ![[PixPin_2026-06-24_15-15-33.png]]
5. 分子伴侣/泛素修饰
6. 调节
	1. 嘌呤霉素结合位点，转移肽链后会脱落，导致产生大量断头肽；有广谱毒性

# 多聚核糖体
1. 核糖体在细胞内由几十个核糖体串联在一条mRNA分子进行合成
2. 意义
	1. 短时间合成大量多肽，有利于调控浓度以及迅速响应
	2. 合成的多肽数大抵相同
