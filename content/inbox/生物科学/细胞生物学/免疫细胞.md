# 免疫系统
1. 先天性免疫：无延时、无特异性、无记忆性；NK细胞、巨噬细胞、肥大细胞、树突状细胞
2. 获得性免疫：有；淋巴细胞、细胞因子、抗体
# 免疫器官
1. 骨髓：造血干细胞产生白细胞
2. 胸腺：T细胞成熟
3. 脾脏：大量免疫细胞，过滤血液
4. 淋巴结：淋巴液的免疫过滤器
# 先天免疫系统
## 先天免疫细胞
1. 巨噬细胞
	1. 由单核细胞分化，从血液中迁移到组织，分化为巨噬细胞
	2. 分化后留在组织中，吞噬病原体、激活免疫反应等功能
	3. 活性
		1. 直接内吞
		2. 分泌ROS、溶菌酶、补体系统等杀灭病原体
		3. 启动促炎反应，分泌肿瘤坏死因子、白细胞介素等
		4. 感染消除后抑制过度免疫
		5. 使用MHC分子呈递抗原肽
2. 树突状细胞DC
	1. 散落分布，数量不多
	2. 表面抗原呈递分子极其丰富，主要的抗原呈递细胞
	3. 功能
		1. 未成熟：感知入侵、获取外界抗体
		2. 成熟后迁移至淋巴器官，产生细胞因子，并且呈递给T细胞
		3. 大量表达TLR受体
	4. 可以激活MHC蛋白、共刺激蛋白、粘附因子等
3. 自然杀伤细胞NK
	1. 选择性清除MHC I表达量低的细胞
	2. 可以诱导细胞凋亡（Fas）
4. 粒细胞
	1. 受T细胞分泌的因子活化，分为嗜酸性粒、中性粒、嗜碱性粒
	2. 中性粒：含量最大，可以吞噬病菌，运动性高，急性炎症的主要响应细胞
	3. 酸性粒：破坏寄生虫，吞噬
	4. 嗜碱性粒&肥大：介导超敏反应
5. Toll-like受体（TLR）
	1. 高表达于免疫细胞上，可以识别病原体分子模式（PAMPs），识别后诱导促炎细胞因子产生
## 抗菌物
1. 补体系统
	1. 不耐热、活化后有酶活性
	2. 由肝脏产生，被抗体激活，和抗体协同作用
	3. 是先天免疫系统的一部分
2. 干扰素：防止细胞被感染

# 适应性免疫
1. B细胞
	1. 分为B细胞、浆细胞、记忆B
	2. 骨髓内成熟，可以呈递抗原
	3. 克隆选择理论
		1. 发育早期会产生大量淋巴细胞，此时抗体镶嵌在膜表面
		2. 当抗体识别到病原体时，会发生迅速增殖
	4. 体液免疫：抗体，结合病原体后，末端能够被细胞表面受体Fc识别，诱导吞噬
2. T细胞
	1. 记忆T、辅助T、细胞毒性T
	2. 胸腺内成熟
	3. CD：白细胞分化抗原
	4. 存在T细胞受体TCR帮助识别特殊抗原（与抗体同源、有特异性）
	5. CD8 T细胞：分泌穿孔素在细胞膜上打孔，溶解靶细胞，被白细胞介素激活，也可以通过Fas通路杀死
	6. CD4 T细胞：识别MHC II，分泌共刺激信号&细胞因子帮助其他细胞发挥作用，会分化为不同亚群
		1. Th1刺激B细胞繁殖（分化为浆细胞的必要条件）
		2. Th2分泌IL2，帮助CD8 T增殖分化
	7. 记忆T

## 抗体
1. 免疫球蛋白，有两个相同的抗原结合位点，有相同的重链轻链
	1. ![[Pasted image 20260628202806.png]]
	2. 重链和轻链都有可变区和恒定区
2. 抗原决定簇：抗原分子中可以和抗体/淋巴受体结合的部分
3. 抗体基因组
	1. Light链由CVJ三个基因编码，Heavy链由CVDJ四个基因编码
	2. V为可变区、D为高变区、J为连接区、C为恒定区
	3. 轻链会有VJ重排![[Pasted image 20260628203023.png]]
	4. 重链可能有更多选择
	5. RAG介导DNA重组
4. 抗体的多样性
	1. 初级：CV（D）J
	2. 次级：抗原激活B细胞后，膜上分泌的抗体会有IgG、IgM、IgA、IgE等类别
		1. 可变区不变，重链恒定区变化
	3. AID可以将胞苷脱氨为尿嘧啶，导致转换抗体类别
	4. AID可以作用于抗体重链恒定区上游的S区导致DNA损伤，随后再修复过程中和下游S区相连，于是导致重链可变区发生改变；修复过程还可能导致移码突变等

# 免疫耐受
1. 克隆删除：识别自身抗原的细胞会自发凋亡
2. 克隆无能：可以识别，但是不能激活，被沉默
3. 受体编辑：会自发改变抗原受体
4. 克隆抑制：Treg调节T细胞会抑制活性
