# 概念
1. 细胞分裂增殖时基因表达受调控，在形态功能上发生稳定性差异
2. 全能性：细胞分裂分化后，在某些条件下仍能发育成一个完整个体的潜能
	1. eg. 植物组培、动物克隆等
	2. 植物细胞全株有全能性、动物细胞体细胞只有细胞核有全能性
# 干细胞
1. 能分裂出保持未分化的子代和一些会分化的子代，可以自我更新
2. 分类
	1. 全能干细胞：哺乳动物只有受精卵
	2. 多潜能干细胞：囊胚期，无法发育成完整个体只能发育为特定胚层的细胞
	3. 多能干细胞：可以分化为不同类型，如造血、神经、肠等干细胞
		1. 间充质干细胞：胚胎发育时期存在的结缔组织，可以分化为骨细胞、软骨细胞、脂肪细胞、肌肉细胞等
		2. 可以产生过渡增殖细胞
	4. 单能干细胞：来源于多能干细胞，只能向特定种类细胞分化
3. 非对称分裂：干细胞壁龛
	1. 内部因素：决定子定位和分类不对称
	2. 决定子：可以影响细胞向不同方向分化的细胞质成分
	3. 组合调控：一种关键蛋白对其他蛋白的级联放大
4. 主调控基因：主导分化
	1. 如MyoD：分化为骨骼肌细胞的调控蛋白；Ey：调控果蝇眼部发育
5. 干细胞壁龛：干细胞微环境
	1. 成体干细胞通常静息，组织损伤后信号被发送，机体开始自我更新
	2. 作用因素：cell-cell communication，和其他的communication
	3. 常见信号通路![[Pasted image 20260628193538.png]]
6. 获得：
	1. 胚胎干细胞
	2. 体外诱导分化细胞
	3. 成体干细胞采集
	4. 诱导多能干细胞iPS
7. 去分化&转分化（先去再分化）
	1. eg.胃的肠化生
	2. 上皮-间质转化：上皮细胞会向间质细胞转分化，常见于胚胎发育、伤口愈合、器官纤维化等
	3. 间质-上皮转化：上面的逆过程
