# 类型
1. 有丝分裂
2. 无丝分裂
3. 减数分裂
4. 二分裂
# 二分裂
1. 细菌的拟核：简单DNA环状分子结合在蛋白核上缠绕成花束状，在细胞内形成相对致密的区域；形成约100个环，环两侧固定在蛋白质核上
2. 从固定起始点开始，双向复制（形成复制叉）
3. 分裂前，DNA先结合在细胞膜上开始复制；上一次细胞分裂未结束时，下一次复制已经开始
# 无丝分裂amitosis
1. 直接进行核分裂，不进行染色体有规律的平均分配
2. 核膜、核仁都不消失，不出现染色体凝聚，不形成纺锤体
# 有丝分裂
## 动物
1. 最重要的细胞分裂机制之一，对染色质和子细胞一致性有精确调控
2. ==细胞周期==：细胞分裂结束到下一次分裂结束经过的时间
	1. 细胞分裂间期
		1. DNA合成前期（G1）
		2. DNA合成期（S）
		3. DNA合成后期（G2）
	2. 细胞分裂期（M）
		1. 前期
		2. 早中期
		3. 中期
		4. 后期
		5. 末期
		6. 胞质分裂期：从后期启动，延续至末期
3. 分裂间期：完成DNA复制、中心体复制、蛋白质合成等步骤
4. 分裂过程：核膜、核仁消失和重现；纺锤体形成；染色质凝缩（染色体）和去凝缩
5. 有丝分裂中，[[中心体]]大量参与
	1. 两个中心粒，由微管构成，9+2微管系统
	2. G1晚期中心体分裂，S早期中心粒轻微分裂，G2期中心体分裂（半保留复制），最后聚集于细胞一侧
	3. 中心体复制错误可能导致后续纺锤体数量错误和染色体错离
### 前期
1. 动物细胞中心体作为[[细胞骨架#微管]]组织中心MTOC，帮助纺锤丝形成、微管生长排列、染色体捕捉等事件
2. 复制后中心体分开并移向两极，伸出放射状排列的微管（形成星状结构——星体），核膜保持完整；
3. 星体到达位置后，在细胞核外形成有丝分裂的纺锤丝
	1. 星体有一对中心粒+一组微管蛋白
	2. 负端锚定在中心体上，正端相对自由
4. 有丝分裂器
	1. 星体
	2. 极间微管：自由端伸长重叠，构成纺锤体基本骨架
	3. 星体微管：始于两极，帮助稳定星体位置
	4. 动粒微管：和染色体主缢痕的动粒复合体结合，捕捉染色体
5. 粘连蛋白Cohesin
	1. 由四个亚基组成
	2. 存在一个ATP酶活性结构域和一个允许二聚化的铰链区，允许形成一个环状结构，可以环绕姐妹染色单体
	3. G1期cohesin与染色体结合，随着DNA复制，蛋白聚合将姐妹染色单体结合；该复合物在G2期到前期之间被去除
	4. ![[Pasted image 20260628105306.png]]
	5. 和凝缩蛋白Condensin的联系：结构相似，都有ATP、DNA结构域，都能和DNA结合；但是一个胶联两个姐妹染色单体，一个维持蛋白和DNA之间的卷曲状态
### 前中期
1. 核仁消失，核膜解体
2. [[高尔基体]]、[[内质网]]等细胞器解体，形成小囊泡
3. 动粒微管接近染色体并且和动粒结合，捕获染色单体并不断移向赤道板
4. 动粒微管和着丝-动粒复合体结合后，向相反方向拉动染色体
	1. 参见[[细胞核与染色体#染色质]]
	2. Kinesin-7驱动蛋白帮助运动
5. 微管捕捉染色体
	1. 末端在正向运动，和动粒直接接触
	2. 大多数情况，动粒到微管侧面，动粒沿着染色体滑动，随后染色体滑向微管末端，稳定动粒微管
	3. 两侧纺锤体会同时锚定一个染色体，使其处于受力平衡
### 中期
1. 染色体会排列到纺锤体的赤道面上
2. 微管力驱动染色单体分开并移向两极；连接附属物，使姊妹染色单体保持
	1. 导致染色体开始震荡，调节位置
	2. 最终在细胞周边排列成环状，形成中期盘
3. 中期盘
	1. 牵拉学说：动粒微管越长，拉力越大；两侧平衡稳定在赤道面上
	2. 外推学说：星体排斥力把染色体外推，离中心体越近，对其推力越强
	3. 两者都有作用
### 后期
1. 染色单体之间的连接物断开，染色单体分开移向正反两极
2. 纺锤体附着检查点：检查是否所有染色体都位于赤道板上
3. Mad2和Bub1位于动粒，可以帮助动粒敏化；被纺锤丝捕捉后迅速消失（抑制Cdc20活性）
4. 后期姐妹染色单体的断裂
	1. 等待纺锤体附着检查点检查完毕后，亚基Cdc20被释放并结合到APC/C上，组装成泛素连接酶
	2. 中期时，Securin与Separase分离酶活性中心结合抑制其活性；组装后，在Securin上连接多泛素链，被26S蛋白酶体降解
	3. Separase活性启动，剪切姐妹染色单体周围的Cohesin，让染色单体游离，被两侧纺锤丝牵拉
5. 染色体的移动：两种机制
	1. 机制1：动粒微管收缩，导致着丝粒拖拽姐妹染色单体运动到极点（微管正端去聚合，同时驱动动力蛋白一起移动）
	2. 机制2：极点向更远处移动，极点微管的滑动力将两个极点分开（极间微管末端长度增加，微管聚合，微管亚基同时加到所有末端上）
	3. ![[Pasted image 20260628112110.png]]
### 末期
1. 染色体到达两极后，细胞重新进行分子组装，形成新的子细胞核
2. 核膜小泡围绕染色体聚集形成新核膜、还有核孔和核纤层
3. 详见[[细胞核与染色体]]
### 胞质分裂
1. 母细胞一分为二，开始于有丝分裂后期
2. 质膜在后期形成分裂犁沟
	1. 发生在有丝分裂长轴的垂直面上，沿犁沟将细胞一分为二
	2. 犁沟化前重置细胞分裂期可以改变分裂方向；启动后不可改变
3. 收缩环：肌动蛋白+肌球蛋白构成，提供收缩力帮助细胞分裂，中间有微管丝
## 植物
1. 其他的基本都和动物细胞一致，但是动物细胞流动性好，植物细胞无法缢裂
2. 没有星形微管，只有纺锤体；没有赤道板，有细胞板
3. 胞质分裂
	1. 高尔基小泡聚集到赤道面上
	2. 形成细胞板/成膜体
	3. 形成初生细胞壁
## 细胞器
1. 叶绿体/线粒体：一般分一半，但是无法绝对平均
	1. 叶绿体和线粒体有自主性，可以自行增殖
2. 内质网、高尔基体：先裂解后集中
# 减数分裂
1. 有性生殖的基础
2. 生成配子：同源染色单体（父系&母系）
3. 和有丝分裂的对比![[Pasted image 20260628113416.png]]
## 过程
1. 间期：包括G1、S、G2
	1. S期比有丝分裂长
	2. DNA绝大部分在S期合成；还有极少部分在M1前期完成
2. I前期
	1. 细线期：染色体为细长的线状，核仁存在；部分染色质局部浓缩形成染色粒，染色体端粒和核膜相连
	2. 偶线期：细线状同源染色体联会（联会复合体帮助）  ——双价体
	3. 粗线期：染色体完全联会，缩短变粗，核仁存在  ——四联体
	4. 双线期：染色质进一步变粗，每条染色单体出现分离；非姐妹染色单体发生交叉（交换&交叉）
	5. 浓缩期：同源染色单体进一步收缩，完成染色单体交换
3. I染色体联会
	1. 发生于偶线期、粗线期大量进行，双线期消失
	2. 开始和偶线期DNA开始
	3. 联会复合体SC：三联体结构，主要起支持染色单体作用
	4. 染色单体可能进行交叉交换
4. I中期：核膜核仁消失，染色体排列到赤道面上
	1. 同源染色体之间有两种连接：非姊妹染色单体的交叉；交叉染色单体末端的粘连蛋白的连接
5. I后期
	1. 同源染色体彼此分离，向相对的两极移动；染色体着丝点不分开
	2. 两个子细胞核中染色体数目是原染色体一半，分裂为两个细胞
	3. 可能存在短暂间期，这里不考虑
6. M2期：同有丝分裂相同
# 细胞周期
1. ![[Pasted image 20260628115556.png]]
2. $G_{0}$期：可逆，细胞暂时退出细胞分裂循环状态
3. 细胞间期
	1. G1期：合成大量RNA和蛋白质（酶），异染色质大量解螺旋，变为常染色质
	2. S：完成DNA倍增，大量合成组蛋白，组装为核小体；中心体复制
	3. G2：少量RNA和蛋白质哦合成，组装微管蛋白&调控蛋白（Cyclin）；线粒体增殖
4. 特殊的细胞周期：非洲爪蟾早期胚胎
	1. 细胞分裂没有G1和G2期，几乎只进行S和M
	2. 在分裂中总体积不变
	3. 复制过程被简化为Cyclin B-CDK1，复制开始时全起点同步激活，迅速开始全身复制
	4. 当进行到12次分裂时，出现G1和G2，细胞周期恢复正常
## 细胞同步化
1. 即把培养的所有细胞都调节为细胞周期的相同阶段
2. 自然同步化：发育过程只进行细胞核分裂而非胞质分裂，共享胞质环境
3. 人工选择同步
	1. 培养基中摇晃使得M细胞脱落，可以获得相对高同步的细胞，但是量少
	2. 对细胞进行密度梯度离心也可以进行，同步化不高
4. 诱导同步法
	1. TdR阻断法
		1. 一般采用胸腺嘧啶核苷进行阻断：可逆，不影响其他部分进行
		2. 对对数生长期细胞加入TdR，所有处于S期细胞立刻被抑制，其他细胞允许到G1-S期交界处被抑制
		3. 洗脱TdR，当细胞已经完全脱离S期，且没有到达G1期终点时再次加入TdR，将所有细胞都抑制在G1-S检查点处
	2. 其他![[Pasted image 20260628134142.png]]
5. 检测方式：流式细胞术
## 调控核心
1. MPF：被发现在M期细胞质中存在的高度活性分子，这种因子可以诱导细胞染色体进行凝聚，促进细胞分裂
	1. 随后MPF被发现实际是Cycli B-CDK复合物
	2. ![[Pasted image 20260628135513.png]]
2. Wee家族蛋白
	1. Wee1：即CDK激酶给CDK1上磷酸化修饰，抑制CDK活性
	2. Cdc25：对CDK去磷酸化，激活CDK活性
	3. Wee2：即cdc2或CDK1，被称为周期引擎
3. Cyclins：在间期积累，分裂期消失，随着细胞周期重复该过程
	1. 11种亚型，均含有同源序列Cyclin box，其能够和Cdk形成活性复合物，对细胞周期起到关键的调控作用
	2. M-cyclinN端有序列称为降解框，参与由泛素介导的Cyclin A和B的降解
	3. G1/S-cyclin在G1期结束时与Cdks结合，促使细胞进行DNA复制；S-cyclin在S期结合Cdks，启动DNA复制；M-cyclin促进有丝分裂；G1细胞周期蛋白浓度在整个细胞周期中逐渐增加
	4. ![[Pasted image 20260628142131.png]]
4. Cdks：1:1的和Cyclin结合，被激活调控细胞周期变化
5. CDK inhibitors
	1. KIP/CIP：抑制G1和S期CDK酶
	2. Ink4：抑制所有Cyclin D/CDK复合物，如p27
6. p53：转录因子，转录p21
	1. 当外界收到刺激（如DNA受损）时，p53被激活，磷酸化转录p21
	2. p21是CDK-cyclin抑制剂，阻止其形成，从而延长细胞周期，争取DNA修复时间
7. 泛素化依赖的降解：将周期蛋白标记泛素化后降解
	1. SCF：间期活性
	2. APC：有丝分裂期有活性
		1. ![[Pasted image 20260628143539.png]]
8. 生长因子刺激下，cyclin大量表达，同时使得下游蛋白磷酸化，促进大量基因转录
9. 总结![[Pasted image 20260628143634.png]]
# 检查点
1. 即细胞周期的关键时刻存在的调控机制，保证基因组和细胞的总体稳定性
2. 主要由四个细胞周期检查点
	1. G1期检查点
		1. 检查细胞大小、营养、生长因子和DNA损伤情况
		2. 在G1期可以进入休憩状态G0期暂停继续细胞周期
		3. ATM控制
			1. ATM/ATR可以结合在损伤DNA上，使下游Chk2、Chk1被激活，随后将Cdc25蛋白磷酸化；磷酸化后无法进入细胞核，或在胞质内降解，MPK复合物磷酸化水平上升，失活
			2. 同时ATM可以磷酸化或通过Chk2磷酸化p53，迫使Mdm与p53解聚，导致转录进行
	2. S期检查点
		1. 检查DNA是否复制且仅复制一次
		2. S期发生DNA损伤时，检查点抑制晚复制起点的启动、启动DNA修复等
		3. 细胞内存在一种因子，可以和G1期染色体结合引导复制；复制完成后失效以防止再次复制，该因子主要为Mcm蛋白（解旋酶）
		4. 当细胞DNA复制受阻时，ATR-Chk1通路被激活，释放Chk1
		5. 随后Chk1通过抑制Cdc25A抑制CDK活性；同时Cdc6去磷酸化、Geminin被降解，释放复制复合体
		6. ![[Pasted image 20260628155439.png]]
	3. G2检查点
		1. 检查细胞大小和DNA复制
		2. 发生DNA损伤时G2检查点防止细胞进入M期
		3. 机制：在CDK和M-cyclinn结合后，CAK给CDK上磷酸基团，同时Wee1给CDK上磷酸；确认无误后，Cdc25切割掉Wee1上的磷酸，迅速启动转录
	4. 纺锤体装配检查点
		1. 详见上面的，有securin、separase、Cohesin等
		2. APC/C帮助Securin降解，separase使得separase能够切割
		3. CDK1-cyclin B对separase进行负调控
	5. Mad2定位于有丝分裂未对齐的中期染色体信号，阻止细胞周期继续；Mad2可以通过结合Cdc20抑制APC的激活
3. 生长因子通过作用于Ras、Raf、ERK等通路促进Cyclin D合成，通过G1限制检查点
4. 三种生长控制模型
	1. 生长是分裂的前提，外源因子→细胞生长→分裂
	2. 生长由生长因子调控；分裂由有丝分裂原调控
	3. 外源因子同时调控生长&分裂通路
