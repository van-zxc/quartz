# 真核生物调控
1. 转录水平调控
	1. cis作用元件：影响自身基因表达活性，如启动子、增强子、沉默子等
		1. 启动子：位于5‘上游，指导RNA聚合酶和模板正确结合，启动转录
			1. 最简单的启动子：TATA区域+转录起始位点（部分含有GC/CAAT)
			2. 不含TATA区的一般含有多个转录起始位点
		2. RNA聚合酶
			1. I在核仁合成rRNA
			2. II在核质中合成hnRNA-mRNA、miRNA等
			3. III在核质中合成tRNA和snRNA
			4. 依靠转录因子TFIID识别&结合起始序列，开始启动转录
		3. 增强子：和启动子相连/重叠，帮助启动转录
		4. 沉默子：负性元件，可以阻止远距离调控
	2. trans作用元件：某基因表达的蛋白质和非自身cis元件相互作用调节表达，例子太多不再赘述
	3. 过程：染色质重塑→组蛋白修饰→转录因子富集→转录起始复合物组装→开始转录
	4. 可能作用机制：核小体滑动、核小体移除、组蛋白置换、特异性组蛋白修饰等
2. RNA产生后调控
	1. mRNA处理：加帽、加尾、剪切
	2. 可变剪切
		1. GU-AG法则：内含子5’均有GU、3‘均有AG
		2. 剪切体由snRNA和其他组成，构成核糖核蛋白颗粒snRNP；依赖snRNA进行剪切
		3. 内含子被套索状剪切掉
		4. 可变剪切产生不同功能的蛋白质
