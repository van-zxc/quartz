# 概念
1. 光合作用的场所
2. 形态：扁平的椭球形
3. 组成
	1. 外被
	2. 类囊体
	3. 基质
4. 同时含有外膜、内膜、类囊体膜三种膜；有膜间隙、基质、类囊体腔
# 类囊体
1. 膜围成的扁平囊，膜流动性较高
2. 分为基粒类囊体&基质类囊体
	1. 基粒类囊体：扁平小囊堆叠
	2. 基质类囊体：连接基粒的没有堆叠的
3. 分别掌握光系统1和光系统2
# 结构
1. 天线复合物LHC
	1. 主要作用是捕捉光能
	2. 光照射叶绿体分子时，能量迅速转移，最终反应中心产生高能电子，传递给类囊体膜上的电子载体（醌）
	3. ![[Pasted image 20260627152259.png]]

2. 基质
	1. 碳同化有关的酶类（大量的RuBP羧化酶）
	2. 叶绿体DNA以及基因表达体系
	3. 淀粉粒、质体小球、植物铁蛋白等颗粒成分
3. 色素
	1. 叶绿素分为叶绿素a,b
	2. 辅助色素为类胡萝卜素（$\beta$胡萝卜素+叶黄素）
	3. 色素都包埋在类囊体膜中，与蛋白质非共价结合
	4. ![[Pasted image 20260627152731.png]]
4. 光系统
	1. 反应中心：跨膜蛋白+色素复合体
	2. 天线色素：大量叶绿素分子
