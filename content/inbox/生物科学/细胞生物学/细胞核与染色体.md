# 核被膜
1. 分类
	1. 外层核膜：与内质网联系，常带有核糖体颗粒
	2. 内层核膜：光滑，无核糖体，内部贴近核纤层蛋白B受体
	3. 内外膜平行，中有核孔复合物NPC
2. 功能
	1. 区室化，防止干扰
	2. 物质交换&信息交流
3. 组装
	1. 细胞有丝分裂前期末期双层膜破裂，末期围绕染色体重新合成
	2. 单层小泡附着在染色质表面，随后逐渐相互融合形成双层膜
# 核孔复合体NPC
1. 结构
	1. 胞质环（外环）
	2. 核质环（内环）
	3. 辐
	4. 中央栓
	5. ![[Pasted image 20260627170842.png]]
2. 呈八角形或圆形
3. 功能
	1. 充当核质交换通道，亲水
	2. 可以主动运输也可以被动扩散（<10 nm）
	3. 主动运输更有效，可以每分钟转运3核糖体亚基/100组蛋白，消耗GTP；可以双向主动运输
4. 亲核蛋白
	1. 需要核定位序列NLS
	2. 输入蛋白：识别和定位信号的受体，两个亚基，在胞质中，结合穿过核孔后再返回
5. 核质蛋白：通过和定位信号运送到细胞核；在核小体装配中有作用，促进组蛋白和DNA相互作用
## NLS
1. 特点
	1. 富含碱性氨基酸
	2. 通常为连续多肽
	3. 可为多肽链任意区段
2. 含有NLS蛋白仍可能因NLS被修饰或结合蛋白导致滞留于细胞质中
3. 入核过程
	1. NLS和输入蛋白结合成转运复合物
	2. 随后同NPC的胞质纤维结合，从胞质面到核质面
	3. 再和Ran-GTP（小G蛋白）结合，复合物解离，亲核蛋白释放
	4. ![[Pasted image 20260627171624.png]]
	5. 钙离子可以通过激活磷酸酶去磷酸化，阻断出核信号暴露入核信号，调控出核信号
4. 转录产物的输出
	1. mRNA 5‘端先通过NPC
	2. RNA需要结合特殊的蛋白腻子（有NES出核信号），从而从细胞质中运出
	3. exportin核输出蛋白（XPO），XPO5介导蛋白质输出（和miRNA生成）、XPO1：mRNA、XPO3：tRNA
# 核纤层
1. 位于核膜内侧，由ABC三种核纤层蛋白组成的纤维网络结构
2. 并非层黏连蛋白
3. 通过磷酸化/去磷酸化使核纤层解体/重新装配，对核膜裂解起调节作用
4. 核膜的重建
	1. 有丝分裂末期，核膜&内质网衍生膜泡被募集到染色体周围，通过膜定向蛋白组装
	2. NPC组装
	3. lamins去磷酸化后重新整合，形成核纤层
5. 功能
	1. 与中间纤维相连，形成细胞核-细胞质的连续网状结构
	2. 维持细胞核/核膜形态
	3. 参加核膜组装/去组装
	4. 核纤层异常影响转录
# 染色质
1. 三种DNA序列
	1. 蛋白编码/单一序列（60-65%）
	2. 中度重复序列（20-30%）
		1. 串联重复：rRNA、tRNA、组蛋白
		2. 散在重复：SINE家族、LINE家族
	3. 高度重复序列（10%）
		1. 卫星DNA、小卫星DNA、微卫星DNA
2. 蛋白
	1. 组蛋白
		1. 核小体组蛋白：H2A、H2B、H3、H4；帮助DNA卷曲成核小体，进化非常保守
		2. H1组蛋白：连接核小体，有种间特异性
		3. 特点：碱性蛋白质，和NDA紧密结合；只在S期合成
	2. 非组蛋白
		1. 序列特异性DNA蛋白
		2. 多样性/异质性：酶、核质蛋白、染色体骨架蛋白等
		3. 识别特定DNA序列
		4. 结构：螺旋-转角-螺旋（识别特定碱基）、锌指结构（Cys和His结合在Zn上，氨基酸形成指状结构）、亮氨酸拉链（亮氨酸二聚体、剪刀状与DNA结合）、螺旋-环-螺旋基序、HMG-框基序（可以弯折DNA，促进邻近结合的转录因子相互作用）
## 组装
1. 自然状态下染色质直径30 nm；解聚后为10 nm串珠结构
2. 核小体结构：先形成2 H3+2 H4四聚体；随后再和两个H2A/H2B二聚体形成八聚体
3. ==重点==：
	1. 核小体单位：200 bp DNA，一个8聚体、一个H1
	2. 组蛋白八聚体构成核小体盘状核心
	3. 146 bpDNA盘绕八聚体，H1锁住核小体DNA进出端，稳定核小体
	4. 相邻核小体之间DNA约60 bp
4. 30 nm的形成
	1. 螺线管结构：核小体串珠装排列，每六个核小体转一圈，外径30 nm（也有双起点模型）
	2. DNA核小体之间顺着左手螺旋让DNA沿Z字向上堆叠，形成30 nm
5. 高级结构：染色体骨架放射环
	1. 非组蛋白构成的染色体骨架+伸出的DNA侧环
	2. 30 nm染色体折叠成环状结构，沿着染色体纵轴，由中间向四周伸出，构成放射环
	3. 放射环结合在非组蛋白骨架上形成微带，微带沿纵轴构建成染色单体
## 修饰
1. 染色质重塑复合体SWI或SNF可以利用水解ATP能量，破坏组蛋白&DNA间相互作用
2. 转录因子&染色质重塑因子结合启动位点，引发核小体位置改变
3. 组蛋白修饰阅读器：蛋白复合体，招募其他催化修饰蛋白，识别染色体标记
4. 常见修饰
	1. 乙酰化：活跃转录基因的组蛋白；降低正电荷以开放结构，抑制核小体聚集
	2. 甲基化
	3. 磷酸化
	4. 泛素化
5. 组蛋白修饰常共同发生（修饰盒：组蛋白尾部多个共价修饰）
6. 反式组蛋白通路：不同组蛋白/核小体间共价修饰，使得染色质结构开放
7. 基因激活蛋白可以招募乙酰化酶和组蛋白重塑复合体，帮助TATA motif开放，促进转录
8. 异染色质（非活性染色质）形成
	1. 给组蛋白上甲基化，甲基化蛋白相互作用发生寡聚化，促进染色质紧密压缩
	2. 活性染色质和异染色质之间有边界，阻止异染色质扩展
9. 活性染色质
	1. 对DNAse I敏感
	2. 转录时核小体打开，组蛋白解体/变性，使得DNA展开，便于trans factor结合
10. X染色体的失活（巴氏小体）
	1. Xist：非编码RNA，cis作用
	2. Xist转录产物包裹在X染色体上使之失活，诱导基因沉默（除Xist本身）
# 染色体
1. 中期染色体形态结构
	1. ![[PixPin_2026-06-27_18-58-17.png]]
2. 必需三种功能元件：
	1. 自主复制DNA序列ARS
		1. 11-14 bp富含AT序列的区域
		2. 含有起始识别复合物ORC结合的部位
	2. 着丝粒DNA序列CEN
		1. 分为CDE123
		2. CDE3应是与纺锤丝结合的识别为点
	3. 端粒DNA序列TEL
		1. 端粒：染色体两端，高度重复，富含G的短串联重复序列，高度保守
		2. 重复序列由端粒酶合成后添加到染色体末端
		3. 作用：维持染色体稳定性：防止染色体末端降解、防止进行非同源末端交联，保持完整性
		4. 端粒的复制
			1. 端粒酶：RNA+蛋白，催化复制，延伸端粒末端的核糖核蛋白
			2. 以RNA为模板，催化逆转录合成端粒DNA并添加与染色体末端
		5. 随细胞复制进行，端粒逐渐变短；过短的端粒会导致DNA游离，引起细胞增殖停止
3. 动粒
	1. 位于着丝粒外表面，和纺锤丝微管连接；为蛋白
	2. 包含内板（和异染色质结合）、中间间隙、外板、纤维冠（结合马达蛋白）
	3. 着丝粒功能：帮助姐妹染色单体配对，帮助染色体运动，细胞周期检查点控制等
# DNA复制
1. 简单过程
	1. 首先解旋酶打开DNA双链，同时拓扑异构酶切割&重新连接DNA链，帮助减小超螺旋应力
	2. 引物酶合成引物，和DNA结合
	3. DNA聚合酶III顺着引物酶向下合成
	4. DNA聚合酶I补上开始的一段
	5. DNA连接酶把所有DNA链之间有断的地方弥补上
	6. ![[Pasted image 20260627192332.png]]
2. DNA复制机器组成
	1. ![[Pasted image 20260627192353.png]]
3. 前导链和后随链
	1. 前导链：新链合成方向与复制叉移动方向一致。由DNA聚合酶$\epsilon$（Pol $\epsilon$） 结合，连续合成
	2. 后随链：新链合成方向与复制叉移动方向相反。随着复制叉向前移动，不断暴露出新的单链模板，DNA 聚合酶$\delta$（Pol $\delta$）必须顺次以不连续的方式合成一段段的冈崎片段
	3. 原因是，DNA聚合酶只能从5’到3‘进行合成
	4. 当冈崎片段聚合到上一个的引物时，被DNA连接酶I缝合（有更详细的机理，不赘述）
4. 端粒酶
	1. 复制末期，端粒酶会被激活。它以自身的RNA为模板，延长亲代DNA的 3' 末端，维持了染色体长度的动态平衡
5. 核型：即染色体组在有丝分裂的表型（数目、大小、形态等），物种特征
6. 染色体显带技术：经过处理后再进行特定分化染色，使之呈现带纹（展示带型和脆性位点），如Giemsa染出来的G带
7. 巨大染色体
	1. 多线染色体：体型巨大，DNA多次复制细胞不分裂（1024条同源DNA，线性排列）
	2. 灯刷染色体：常见于鱼类~爬行卵母细胞减数分裂的双线期，染色体主轴两侧有侧环
# 核仁
1. 细胞核中的圆球状结构，蛋白质合成旺盛/分裂增殖快时核仁大且多
2. 分裂前期消失，分裂末期重组
3. 转录rRNA和组装核糖体的亚单位
4. 结构：
	1. 不被膜
	2. 纤维中心：RNA聚合酶+rDNA、致密纤维组分、颗粒组分
5. 功能
	1. rDNA：多拷贝重复序列，构成核仁（真核细胞的5S RNA不在NOR区）
	2. 核仁组织区：NOR区，形成核仁等染色质区，定位于核仁染色体次缢痕部，核仁从此产生
	3. rRNA转录：游离端形成核糖核蛋白RNP颗粒
	4. rRNA前体加工：把尿嘧啶换成假尿嘧啶
	5. 5S rRNA：核仁外转录，由RNA聚合酶III组成（其他是RNA聚合酶I）
6. 核仁周期
	1. 动态变化
	2. 依赖rDNA活性和细胞周期
# 核基质
1. 非组蛋白构成的三维网架结构，又称核骨架，和中间纤维、核纤层连接
2. 蛋白+RNA+DNA，少量磷脂/糖
3. 核骨架结合序列：和核骨架不分离，富含AT、DNA解旋元件，反向重复序列等
4. 核骨架结合蛋白：包括转录因子、酶、DNA聚合酶、脂溶性分子的核受体等
5. 功能：支持核膜、支持基因转录加工、构建染色体骨架等
