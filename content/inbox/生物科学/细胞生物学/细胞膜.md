标签: [[生物]] [[细胞生物学]] [[概念]]

包裹在细胞外层的一层膜结构被称为细胞膜，细胞膜和细胞内膜统称生物膜。由脂质和蛋白质共同由非共价作用结合的疏水性膜结构
# 膜的作用
1. 区室化，形成边界或屏障
2. 发生某些生化反应
3. 物质选择性透过通道
4. 物质转运场所
5. 外界信息感知与交换
6. 细胞间交流
7. 能量的生成
# 组成
1. 基本结构：脂质双分子层，包括但不限于磷脂、胆固醇、鞘脂、糖脂等（参见[[脂质]]）
	1. 糖脂在膜外层广泛存在，由高尔基体添加糖链
	2. 胆固醇、鞘脂、长链磷脂、饱和链通常会降低膜的流动性
2. 膜蛋白
	1. 膜蛋白和膜的功能高度相关，功能越复杂的膜蛋白质含量越高（如线粒体内膜）
	2. 整合膜蛋白：有脂质长链或疏水多肽插入双层膜中心；周围：没插入
	3. 跨膜蛋白：$\alpha$ helix（参见[[肽——蛋白质一级结构]]），中间疏水；对多次跨膜蛋白也可能出现$\beta$折叠
	4. 通道、载体、细胞识别、受体、酶
	5. 糖蛋白（寡糖糖链，短）/蛋白聚糖（大量糖，结合大量糖胺聚糖）
	6. 参见[[血液#血型]]
	7. 作用：提高膜稳定性、蛋白酶耐性、帮助蛋白正确三维结构构建、信号识别&信号连接、保护细胞等
# 结构模型
1. **磷脂双分子层模型**
2. **流动镶嵌模型**：膜上脂质分子排成双层构成生物膜的骨架，蛋白质分子以不同方式镶嵌或联结于脂双层上；膜的两侧结构是不对称的，膜脂和膜蛋白具有一定的流动性。
	1. 膜脂不对称：含有胆碱的脂质（如鞘磷脂）外侧为主，磷脂酰丝氨酸内侧为主
	2. 脂筏模型：部分脂质会聚，形成稍厚的脂区，脂区内流动性差，像筏子一样带着膜蛋白运动。和膜的信号转导，蛋白质分选等均有联系
	3. 膜蛋白不对称
# 细胞膜的流动性
1. 膜脂流动性
	1. 脂质可以侧向运动
	2. 脂质分子可以旋转、也可以（少数情况下）反转到另一边
	3. 膜脂在低温下会发生相变，从非晶态转为晶态
	4. 不饱和程度越高、链越短，流动性越高，越不容易冻结
	5. 胆固醇的作用
		1. 高温时胆固醇的刚性环戊烷多氢菲环能抑制磷脂尾部的摆动，降低膜流动性
		2. 低温时胆固醇能插入磷脂分子的密集排列中，打破紧密堆积，增加膜流动性
	6. 卵磷脂多流动性高，鞘磷脂多流动性低
2. 膜蛋白流动性
	1. 膜蛋白倾向于在膜上的侧向扩散
	2. 成帽效应：抗体结合淋巴细胞后，受体向结合抗体一侧会聚形成帽状结构
	3. 影响因素：整合蛋白、膜骨架、细胞外基质、相邻细胞、细胞外配体、抗体、及药物大分子等
# 跨膜运输
1. 只允许气体和小分子不带电分子经过脂质双分子层，但是膜上有蛋白帮助转运
	1. 转运蛋白：跨膜转运分子，类似酶催化（参见[[酶]]）
	2. 通道蛋白
2. 被动运输
	1. 简单扩散（就是简单的热力学方向的演进）
	2. 易化扩散
		1. 具有上限——膜表面运输蛋白的数量
		2. 特异性
		3. 通道蛋白有高特异性，只有特定大小的分子才能进去（eg. 水通道、钾通道）
		4. 离子通道在长期的电刺激下可能会进入不应期（想到了快钠通道[[细胞的兴奋]]）
		5. 关闭$\neq$失活
3. 主动运输
	1. 协同运输：通过一种物质的转运驱动另一种物质的同步转运（eg. 葡萄糖-钠同向转运、氯-碳酸氢根反向转运）
	2. ATP驱动泵：直接消耗ATP提供的能量，将物质逆浓度梯度跨膜运输
		1. P型：直接利用ATP水解产生构象变化，帮助离子转运（钠钾泵）
		2. V型：泵入氢离子降低pH
		3. ABC运输蛋白：可以转运相对大分子的物质
		4. F型：ATP合酶（也可以反过来）
		5. 胃液分泌（[[消化#胃液]]）：碳酸酐酶催化碳酸水解产生氢离子，使用钾氢转运体将氢离子运入胃中，随后再借助氯-碳酸氢转运体将碳酸氢根运入血液中，交换氯离子；钾通过钾通道回到胃壁细胞中
	3. 光驱动泵：吸收光子导致构象改变，启动转运（视紫红质）
4. 离子载体
	1. 可以促进特定离子跨过细胞膜，可以充当抗生素使用
