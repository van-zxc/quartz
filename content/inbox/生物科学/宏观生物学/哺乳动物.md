# 胎生哺乳及其意义
1. 胎盘：胚胎绒毛膜&尿囊膜+母体子宫内膜结合而成
2. 绒毛嵌入子宫内膜形成胎盘, 胎儿和母体血液循环不相通, 扩散传播
3. 扩散作用有高度选择性，同时可以遗传双亲抗原
4. 胎生哺乳提高胎儿存活率
# 特征
1. 体型
	1. 四肢位于身体腹部的侧下方
	2. 体型多样化
	3. 大多数哺乳动物为白垩纪末到第三纪初出现
2. 皮肤
	1. 结构致密, 表皮角质层发达
	2. 真皮下血管丰富，有大量神经末梢和感觉器官
	3. 皮下脂肪层发达
	4. 体表有毛发（针毛 触毛 绒毛）
	5. 皮肤腺特别发达（皮脂腺 汗腺 乳腺 味腺）
3. 骨骼：发达
	1. 骨化完全, 为肌肉附着提供条件；某些骨头愈合
	2. 双平型椎体，中间有椎间盘
	3. 有肘和膝
4. 肌肉
	1. 有膈肌，分隔胸腔和腹腔
	2. 皮肤肌发达，咀嚼肌发达
5. 消化
	1. 再生牙（乳牙和恒牙） 槽生齿 异型齿
	2. 有肉质的唇
	3. 唾液腺可以分泌酶
	4. 无泄殖腔，直肠直接开口道肛门外侧
6. 呼吸
	1. 喉咙具有声带（呼吸道+肺），喉可以发声
	2. 肺具有肺泡（气管→支气管→肺泡囊→肺泡）
	3. 进行胸式呼吸（肋间肌）/腹式呼吸（膈肌）
7. 循环
	1. 闭管, 只有左体动脉弓
	2. 静脉系统简化, 提升血压
	3. 红细胞无细胞核, 体积小，双凹形
8. 排泄
	1. 后肾, 卵圆形，排出尿素
	2. 皮质部+髓质部+肾盂
	3. 由肾单位(肾小体+肾小囊+肾小球)和集合小管组成
	4. 尿液的形成: 肾小体的过滤（原尿）→肾小管和集合管的重吸收→集合管的调节
9. 神经
	1. 大脑皮层增大, 皮层厚, 表明出现沟回. 新脑皮成为高级神经活动中枢
	2. 出现胼胝体, 小脑皮层和脑桥
	3. 嗅觉发达 听觉敏锐
10. 生殖
	1. 除了原兽亚纲之外, 全部胎生
	2. 雄性：睾丸 附睾 输精管 尿道 副性腺和阴茎
	3. 雌性：卵巢+输卵管+子宫+阴道
	4. 受精
# 分类
1. 原兽亚纲
	1. 卵生 泄殖腔 成体无齿 无胼胝体
	2. 有毛 有乳腺但是无乳头 有横膈膜 体温略低但是恒温
	3. 鸭嘴兽科&针鼹科
2. 后兽亚纲(有袋亚纲)
	1. 体温为33-35℃, 无胼胝体, 胎生但是无胎盘, 母婴有育婴袋
	2. 袋鼠/袋狼/袋熊
3. 真兽亚纲
	1. 胎生 有真正胎盘
	2. 不具有泄殖腔，单开消化道口
	3. 有胼胝体
	4. 体温一般有37℃
	5. 分类
		1. 水中: 鲸目, 海牛目, 鳍足目
		2. 陆地: 兔形目(有唇裂 大门齿) 啮齿目（数量最多）
		3. 反刍动物: 先有多胃的形成才有分化
			1. 反刍：进食一段时间后，把胃中半消化的事物返回嘴中再次咀嚼
			2. 偶蹄目：第三第四趾同等发达(反刍)
			3. 奇蹄目：第三趾发达
		4. 食虫目: 原始的目，刺猬
		5. 食肉目: 肉食性/杂食性
		6. 长鼻目: 亚洲象&非洲象
		7. 翼手目: 前肢特化为翼, 指骨延长, 骨头之间出现皮膜(蝙蝠), 可以飞翔
		8. 鳞甲目: 穿山甲
		9. 灵长目
