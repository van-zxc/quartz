# 特征
1. 出现上下颌
	1. 主动追逐捕食猎物, 增加获得食物机会
	2. 利用牙齿, 提升食物利用率
	3. 帮助鱼类生存与繁殖（捕食、攻击、防御，营巢、求偶、呼吸）
	4. 促进运动感觉器官发展, 拉动进化
2. 出现成对附肢(胸鳍 腹鳍)和发达的尾部
	1. 偶鳍保持平衡, 改变方向
	2. 奇鳍
		1. 背鳍&臀鳍：维持稳定，防止摇摆
		2. 尾鳍：提供动力，控制方向，充当舵的作用
3. 脊椎代替脊柱, 内有脊髓
	1. 脊索被一系列脊椎骨构成的脊椎替代
	2. 身体支持能力和脊髓保护能力被加强
4. 终生以鳃呼吸
5. 循环系统为单循环
	1. 静脉窦+1心房+1心室
	2. 心脏内有缺氧血
6. 感觉器官有点发达
	1. 有侧线
	2. 侧线管开口和体表侧线鳞上小孔连接而成；其中充满粘液，有感觉细胞与神经相连。可以评估水流方向和低频震动
	3. 1对鼻孔，三个半规管
7. 体表有丰富粘液腺
	1. 减少水的摩擦
	2. 形成隔离膜, 减少水分渗透, 维持渗透压
	3. 保护身体不受微生物侵袭
8. 具有鳞片, 为皮肤衍生物
	1. 楯鳞：软骨鱼特有；真皮+表皮共同构成，和牙齿同源
	2. 骨鳞：由真皮演化而来，为圆形鳞片（圆鳞、栉鳞）
	3. 硬鳞：真皮演化 原始硬骨鱼特有
	4. 硬骨鱼和软骨鱼?在鳞片上能区分
	5. 外形各有不同
9. 体型
	1. 形态多元 依据生活环境而定
	2. 分为三部分：头、躯干、尾（头(前端-鳃裂)+躯干(鳃裂-肛门)+尾(肛门-尾鳍基部)）
	3. 尾部分为3种
		1. 原尾型: 尾椎末端平直, 尾鳍分为对称上下. 出现于幼年期/胚胎
		2. 歪尾型: 尾椎末端上翘, 不对称, 软骨鱼类
		3. 正尾型: 尾椎末端只达尾椎基部, 外形比较对称, 硬骨鱼类
	4. 鱼鳍中有鳍条，作为分类依据
10. 肌肉：由肌节组成，分化程度不高
11. 骨骼: 
	1. 脊椎: 分化少，只有体椎和尾椎，无颈椎；脊椎骨和头部相连；椎体间有残余脊索
	2. 头骨: 脑颅+咽颅. 
		1. 软骨鱼脑: 软骨脑箱；硬骨鱼: 许多骨片. 
		2. 咽: 保护和支持咽部
			1. 颌弓：1，形成上下颌（软骨鱼初生，硬骨鱼次生）
			2. 舌弓：2，连接脑颅和颌弓
			3. 鳃弓：3-8，支持鳃
	3. 颌弓和脑颅链接方式: 
		1. 双接式：颌弓自身直接和脑颅相连，同时颌弓通过舌弓与脑颅相连，见于原始的软骨鱼
		2. 舌接式：借助舌弓连接，多数鱼类
		3. 自接式：颌弓和脑颅相连，舌弓和脑颅分离，肺鱼+陆栖脊椎动物
		4. ![[PixPin_2025-12-29_22-06-12.png]]
	4. 附肢骨：和脊柱没有联系
12. 消化系统:
	1. 无唾液腺
	2. 软骨鱼有形态固定的肝脏和胰脏；硬骨鱼将这两者混淆了，统称肝胰脏
13. 呼吸：鳃
	1. 鳃弓：骨架
	2. 鳃耙：滤食器官
	3. 鳃丝：有丰富毛细血管，进行气体交换
	4. 水流逆向经过鳃丝时，达到最大气体交换效率
	5. 有辅助呼吸器官（皮肤（弹涂鱼）肠（泥鳅）口咽腔表皮（黄鳝）鳔（肺鱼））
	6. 大多数硬骨鱼有鳔，保持比重、调节升降
14. 循环: 
	1. 缺氧单循环: 静脉窦→心房→心室→动脉球(圆锥)→入鳃动脉→鳃毛血管网→动脉
	2. 静脉窦给压力, 动脉圆锥有部分搏动能力
	3. 心脏小, 血少（飞鱼血量占比大）
15. 中肾排泄，排泄氨和尿素
16. 生殖
	1. 卵生 胎生 卵胎生(母体不给营养 其余类胎生)
	2. 雌性：卵巢+输卵管+泄殖腔
	3. 雄性：精巢+输精管+泄殖腔
17. 神经
	1. 中枢神经：脑+脊髓，高级/初级活动指挥
		1. 脑: 五部脑--大脑 间脑 中脑 小脑 延脑
		2. 脊髓有分节现象，每节发出一对脊神经
	2. 外周神经：脑+脊神经，传导感觉o/运动冲动
	3. 植物性神经系统：交感神经&副交感神经，支配内脏/新陈代谢
18. 感觉: 
	1. 视觉: 晶状体无弹性, 近视; 多无眼睑; 有银膜（反射光至视网膜上）
	2. 听觉：内耳+三个半规管
	3. 侧线
19. 鱼的洄游
	1. 生殖洄游(寻找产卵场所): 集群大, 肥育程度高, 停止进食
# ==分类==

2. 软骨鱼类
	1. 全头亚纲：有皮膜状鳃盖褶，没有鳞片（银鲛目）
	2. 板鳃亚纲：五个鳃裂，没有鳃盖褶，表面有楯鳞
		1. 鲨形总目：鳃裂在侧面，大多为纺锤形
		2. 鳐形总目：鳃裂在肚子上，身体宽大扁平，头和胸连接成体盘
2. 硬骨鱼类
	1. 肺鱼亚纲：终身有脊索，脊椎骨没有椎体，鳔可以呼吸（肺鱼）
	2. 总鳍鱼亚纲：偶鳍基部有发达的肌肉，有内鼻孔和喉板，可以使用鳃和鳔呼吸（腔棘鱼）
	3. 辐鳍亚纲：骨骼几乎全部为硬骨，各鳍由真皮性鳍条支持，无内鼻孔，以鳃呼吸，体表多被圆鳞或栉鳞（绝大部分鱼类）
		1. 鲟形目：骨骼大多为软骨，体表裸露或有5行硬鳞，歪尾（中华鲟
		2. 鲱形目：头骨骨化不完全，无侧线，鳔有鳔管（鲥鱼）
		3. 鲑形目：类似鲱形目，有侧线，背鳍后有脂鳍（大马哈鱼）
		4. 鲤形目：鱼类第二大目，生活于淡水中，有韦伯氏器，鳔有鳔管（青草鲢鳙、鲤鱼鲫鱼）
		5. 鳗鲡目：圆筒状，无腹鳍，背尾臀鳍相连，鳞细小，洄游至海产卵（鳗鲡）
		6. 鳕形目：鳍中无棘，颏部有须（鳕鱼）
		7. 鳢形目：鳞为圆鳞，鳔很长，没有鳔管（乌鳢）
		8. 合鳃目：蛇形，光滑无鳞，鳃退化（黄鳝）
		9. 鲈形目：鱼类第一大目，背鳍两部分，前半段有鳍棘支持，栉鳞，鳔无鳔管（大黄花 小黄花 鳜鱼 鲈鱼）
		10. 鲉形目：头部粗壮，常具棘棱或骨板。胸鳍基部宽大，左右腹鳍常相密接
		11. 蝴蝶鱼目：腹鳍胸位，奇鳍具有高阔的鳍条，基部多被以细鳞，体形短扁而高（金钱鱼）
		12. 鲽形目：成体两眼位于头部同侧，鳍无棘，无鳔，习惯平卧海底（比目鱼）
		13. 鲀形目：齿变为骨板，体表裸露或有颗粒鳞、骨板、刺等（星点东方鲀）
		14. 多鳍目：背部分布很多小鳍（多鳍鱼）
