# 特征
1. 只有一个细胞 具有一般细胞的基本结构
	+ 单细胞，细胞内有核膜，有膜结构细胞器，有丝分裂
	+ 所有细胞器都是器官 生理技能由细胞器发挥作用
	+ 具有完整生理机能
	+ 简单动物 复杂细胞
2. 身体微小 非常原始
3. 一些为群体单细胞（单细胞聚类，没有有机结合）
# 代表：草履虫
![[PixPin_2025-12-28_16-11-42.png]]
1. 膜分为三层
	1. 最外层膜在体表和纤毛上
	2. 中层和内层构成==表膜泡嵌套系统==：增加表膜硬度、有柔韧性，保护细胞质、防止内部物质穿过细胞膜etc.
	3. ![[PixPin_2025-12-28_16-13-58.png]]
	4. 表膜上有纤毛&口沟（进食）
	5. 口沟：从草履虫前端开始延伸向中部，在表膜上的一条沟子
2. 纤毛&鞭毛：运动器官，9+2微管系统
3. 细胞质分为外质&内质
	1. 外质：有刺丝胞，位于表膜下部
	2. 刺丝胞：防御功能，可以释放内含物
	3. 内质：有颗粒状结构，有食物泡
4. 消化：口→食物泡→溶酶体→胞肛（直接排出食物残渣 居然是可以伸出来的！那肯定没有痔疮）
5. 伸缩泡&收集管：排出水分，维持渗透压
6. 细胞核\*2：大核营养，小核生殖
	1. 大核：肾形，多倍体，营养核
	2. 小核：1/多，大核凹陷处，二倍体，主管基因交换&繁殖，生殖核
7. 呼吸排泄均靠渗透，循环为内质环流
8. 生殖: 
	1. 无性生殖：横二分裂
	2. 有性生殖：接合生殖

# 分类
+ 鞭毛纲植鞭亚纲：眼虫，自养，鞭毛
+ 鞭毛纲动鞭亚纲：锥虫，异养（渗透吞食），鞭毛
+ 纤毛纲：草履虫，异养，纤毛（短而数量多）
+ 肉足纲：变形虫，异养，伪足
+ 孢子纲：疟原虫，寄生
# 应对不利环境？
1. 形成包囊：分泌胶质形成包囊膜，随后休眠  eg. 小瓜虫：包囊（失去大部分结构后缩成一团，分泌胶质分隔开，休眠  环境良好时出来）相当于受精卵
2. 迟发孢子型：eg. 疟原虫：休眠状态结束后疟原虫复发
3. [[节肢动物]]：
	1. 休眠
	2. 隐蔽（形态和环境相像）
	3. 保护色（体色和环境颜色一致）
	4. 警戒色（颜色鲜艳，警示捕食者）
	5. 拟态（模仿另一种不可食动物   缪勒拟态：有毒相互模仿  贝茨拟态：无毒模仿有毒）
