# 分类
1. 果实来源
	1. 真果（全部由子房发育而来）
	2. 假果（不止子房，花托等也干了）
2. 形成果实的雌蕊和花的数目
	1. 单果（从**一朵花的一个子房**发育而来）
	2. 聚合果（一朵花里几个雌蕊，每个雌蕊发育为一个小果）
	3. 聚花果（多个雌蕊发育的果实聚合）
3. 果实成熟时果皮性质
	1. 肉果
		1. 核果：内果皮木质化，平时吃的是中果皮，真果（杏）
		2. 梨果：假果，吃的是花托（苹果）
		3. 浆果：内外果皮界限不清楚（葡萄）
		4. 瓠果：由下位子房和花托一同发育，胎座发达（xx瓜）
		5. 柑果：内果皮出现汁囊，为内果皮（橘子）
	2. 干果
		1. 裂果：成熟后开裂，散发出种子
			1. 荚果：一个心皮发育，成熟后沿着背缝线和腹缝线开裂（豌豆）
			2. 蓇葖果：一个心皮，通常沿着一条线开裂（八角）
			3. 蒴果：两个+心皮发育（芝麻）
			4. 角果（长角/短角）：十字花科，成熟时种子留在两个心皮之间的假隔膜上（油菜/芥菜）
		2. 闭果：成熟后不散发种子
			1. 坚果：果皮坚硬，一个种子（榛子）
			2. 瘦果：果皮和种皮只有一个点相连，易分离（葵花籽）
			3. 翅果：果皮延伸成翅状（枫树）
			4. 颖果：种皮和果皮高度愈合（小麦）
			5. 双悬果：伞形科，两心皮，成熟时心皮不开裂但分离（胡萝卜）
