# 特征
1. 体型为两侧对称
	1. 分化出前后左右，运动可以定向
	2. 开始分化出头部（神经&感觉集中），背部和腹部
2. 形成中胚层，分化为两种组织
	1. 实质组织：合胞体结构的柔软结缔组织
	2. 实质组织充满在各组织器官之间，但是是==无体腔动物==
	3. 出现肌肉组织：运动v↑，导致神经系统&感觉完善
3. 较复杂器官系统：
	1. 出现较完整生殖系统
	2. 有不完全的消化系统（有口无肛门）
	3. 原肾管排泄系统
	4. 梯形神经系统
# 代表动物：三角涡虫
1. 体壁三层结构：单层表皮、基膜和肌肉层
2. 消化系统：口+咽+肠道
3. 无专门呼吸&循环系统：渗透，实质组织可以运输
4. ==排泄系统==：
	1. ![[PixPin_2025-12-28_19-13-22.png]]
	2. 原肾管型排泄系统，由焰细胞（相当于泵，使用渗透压抽废物）、排泄管和排泄孔组成
	3. 帽细胞鞭毛摆动产生负压，大量水通过管细胞。管壁上有小孔，可以通过细胞膜过滤，排出水分和代谢废物
5. 神经系统&感觉
	1. 梯形神经系统：脑神经节向后伸出两条腹神经索，中间由横神经相连
	2. 感觉器官：
		1. 眼点：只能感光，不可成像（趋弱光避强光）
		2. 耳突
		3. 触觉细胞
6. 生殖系统高度发达
	1. 无性生殖：横二分裂
	2. 有性生殖：==雌雄同体，异体受精==
		1. ![[PixPin_2025-12-28_19-29-30.png]]
		2. 有交配行为，体内受精
7. 涡虫再生能力极强

# 分类
1. 涡虫纲
	1. 自由生活，体表腹面有纤毛
	2. 三角涡虫
2. 吸虫纲
	1. 寄生生活，体表无纤毛，有吸盘
	2. 日本血吸虫
3. 绦虫纲
	1. 体表无纤毛，无消化道，头节有钩
	2. 猪带绦虫
# 寄生虫与宿主共进化？
1. 寄生虫对宿主适应性进化
	1. 大量器官退化
	2. 产生某些特异性进化：表皮抵抗酶侵蚀，发生吸盘勾爪等固着
	3. 生殖系统及其发达
2. 共进化定义？：生态关系极其密切，相互施加选择压力，均产生适应对方的进化（eg. 捕食者&猎物，互助，竞争）
3. red queen理论：相互左右的两个生物需要不断进化才能保持现有状态
