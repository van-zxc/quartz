# 特征
1. 孢子体生活史、形态结构等等更完善(木质部通常具有==导管==，韧皮部有==筛管&胞==)
2. 有真正的花: 有花柄、花托、花被(花萼和花冠)、雄蕊&雌蕊，传粉方式多样
3. 子房包藏胚珠，并且发育成果实
4. 双受精&3n胚乳（7细胞8核）
5. 配子体进一步退化
# 分类
![[Screenshot_2025-10-13-10-07-09-240_md.obsidian-edit.jpg]]
1. 叶：互生、对生、簇生、轮生、集生
2. 果实种类：
	+ 聚合果：由一朵花多雌蕊发育来
	+ 聚花果：由花序上的花发育而来
	+ 单果
		+ 干果
		+ 肉果：有饱满多汁的子房？
	+ 真果：只由子房发育来
	+ 假果：由(不止子房)子房发育而来
3. 花序
	1. 有限花序：顶端→底端
	2. 无限：底端→顶端
4. 胎座：胚珠附着在子房内壁/心皮的部位&方式

# 花程式
K为花萼
C为花冠
P为花被
A为雄蕊
G为雌蕊

$\overline{G}$为子房下位
$\underline{G}$为子房上位
$\underline{\overline{G}}$为半下位

数字用来表示实际数目，写在右下角  $\infty$表示多数，$x$表示少数，$o$为缺失
雌蕊后三个数字：心皮数目、子房室数、每室胚珠数，使用：隔开

\*为辐射对称、↑为两侧对称. 使用性别符号表明是两性花还是单性花
合生加（），+表示成轮/分组，排序从外到里
