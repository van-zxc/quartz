# 进化地位

出现最早的孢子繁殖的陆生维管植物，唯一孢子体&配子体都可以独立生活

# 维管植物
有维管植物的系统，包括蕨类和种子，大多为陆生，孢子体发达，配子体退化

## 维管束：
+ 中柱是维管植物根茎中复合组织，中柱鞘、维管系统、髓
+ ==维管系统主要由木质部&韧皮部组成。木质部有运输水分&无机盐的管胞&导管，韧皮部中含有运输有机物质的筛管&筛胞==
+ 只有被子植物才会有导管&筛管，其他植物都只有xx胞

1. 原生中柱：只有木质部&韧皮部，（单中柱，星形中柱，编织、多体）
2. 管状中柱：中间有髓，木质部围绕中央髓部形成圆筒状（双韧管、外韧管、多环管状etc.）
3. 网状中柱：木质部&韧皮部不成圆圈，中柱中间被薄壁分隔开
4. 具节中柱：髓腔、脊腔、槽腔
5. 真中柱：
6. 散生中柱：

# 特征
+ 广泛分布，喜阴湿温暖环境
+ 孢子体：生活史占优势，多为多年生草本，少数为一年生/木本，有真正根茎叶分化，有维管组织
	+ 根：真正根（不定根：不是胚根长出来的），少数假根
	+ 茎：根状茎，少数为直立地上茎，部分有气生茎&根状茎。中柱为原生中柱、管状、网状等等。多数管胞少数导管，有筛胞
	+ 叶：小型&大型。小：无叶柄/叶隙，仅有不分支叶脉。大型叶：叶柄叶隙叶脉，单叶&复叶
		+ ==营养叶：行光合作用
		+ ==孢子叶：生孢子囊，减数分裂产生孢子进行繁殖。
		+ 同型叶：同一植株的叶无明显分化，有营养&生殖功能；异型叶：明显形态差异
	+ 孢子囊：无性繁殖器官，孢母细胞经过减数分裂产生孢子
		+ 着生方式：聚囊、孢子叶球/穗、孢子囊群/堆、孢子果
		+ 结构：
			+ 厚：多层细胞，
			+ 薄：一层细胞，进化，一个原始细胞发育来
		+ 环带：孢子囊壁上，不均匀增厚。对于水分敏感，吸收水分产生压力，导致孢子囊裂开
	+ 孢子：
		+ 同型孢子：大部分蕨类，形态相同
		+ 异：有大孢子&小孢子
	+ 配子体：
		+ 腹面颈卵器，腹部埋入配子体组织内，颈部短，颈沟细胞少
		+ 腹面精子器，球形，精子具鞭毛，受精无法离开水

# 生活史

明显世代交替。孢子体和配子体均可独立生长。
