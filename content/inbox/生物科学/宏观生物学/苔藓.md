# 分布
+ 常见于世界各地
+ 绝大部分陆生，少部分水生
+ 阴湿环境中
# 形态
+ ==矮小 无维管束==
+ ==叶状体==：于叶片相似 无茎叶分化 有背腹之分 假根单细胞(细胞伸长)
+ ==茎叶体==：有类似茎叶分化 假根单列细胞

雄性生殖器：精子器，外面一层细胞为精子器壁，每个精子==两条鞭毛==，成熟时精子借助水进入颈卵器
雌性生殖器：颈卵器 ==外面有颈卵器壁，上部颈部下部腹部==。颈部一串颈沟细胞，腹部一个腹沟细胞&卵细胞. 成熟时沟细胞退化
# 生活史
+ 配子体：单倍植物体，有性生殖，占优势
+ ==孢子体：寄生于配子体上，有基足、蒴柄、蒴帽和孢蒴==
+ ![[PixPin_2025-12-30_16-04-41.png]]
变水性：能够数十秒内从干燥变湿润，可以迅速从休眠复苏
# 分类
苔亚纲、藓亚纲和角苔亚门
## 苔亚纲
+ 配子体：==扁平叶状体==、有背腹之分。==背面中肋有胞芽杯==，腹面有多数==单细胞假根==和多细胞的紫色==鳞片==。
+ 孢子体：==基足，短的蒴柄和孢蒴。成熟时两纵裂, 孢子具有弹丝==
+ 营养繁殖：==胞芽==，绿色圆片形，两侧有缺口
+ 有性生殖：==雌雄异株==，雄生殖托托盘内有精子器，雌生殖托托盘内倒生颈卵器
+ 孢子与配子体世代的==异型世代交替==
+ ==孢子萌发产生原丝体(不发达)，每个原丝体只形成一个新植物体==
+ 典型：圆叶裸蒴苔（匍匐茎肉质根状，精子器簇成熟时呈黄色），光苔（黑夜时因反射略微发光），叶附生苔（难以区分、统称）
## 藓亚纲
+ 配子体：==茎叶体==，直立丛生，基部==单列细胞假根==。假根起吸收&固着作用。拟茎输导能力不强，基部分支，支持。拟叶一层细胞，吸收&光合(==有初步根茎叶类似分化 但并非真实==)
+ 蒴柄长且发达，孢蒴具有==蒴轴，蒴齿&蒴盖==。孢子无弹丝，成熟时孢蒴盖裂
+ 有性繁殖：雌雄同株异枝，雄器苞中==精子器==&侧丝，精子体棒状，内部镜子具有两条鞭毛，颈卵器生在雌枝两端
+ 生活史：配子体&孢子体世代交替
+ ==原丝体可以长出多个芽，每个芽长出一个配子体==
+ eg. 泥炭藓，白发藓

## 角苔亚纲
+ 植物体多为平坦/带状体
+ ==假根单细胞==
+ 原丝体不发达，只有几个/一个芽体
+ ==孢子体由基足、孢子囊&孢囊柄组成，孢子成熟时盖裂，孢子无弹丝==
+ 芽孢角苔叶状体边缘具有近圆形芽孢, 叶状体呈匍匐状,
