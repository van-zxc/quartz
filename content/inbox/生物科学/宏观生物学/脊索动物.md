# 特征
1. 具有脊索
	1. 纵贯躯体背部，在消化管上, 神经管下, 与之平行的一条索状结构, 起支撑身体的作用
	2. 低等脊索动物终身保留; 高等动物变为脊柱
	3. 由柔软弹性的结缔组织构成, 有弹性&硬度
2. 有中空的背神经管
	1. 位于脊索上方, 管内腔为神经腔, 由外胚层下陷卷曲而成. 
	2. 前部膨胀成脑, 神经腔形成脑室
	3. 后部为脊髓, 神经腔形成中央管
3. 有咽腮裂
	1. 咽部的两侧壁出现成对裂缝, 与外界相通, 进行气体交换
	2. 高等脊索动物只见于胚胎/幼年期保留
4. 心脏位于消化道的腹面，骨骼由中胚层形成，尾部位于肛门后
# 分类
1. 原索动物: 脊椎动物的低等亚群, 无脊椎
	1. 半索动物亚门
	2. 脊索动物亚门
	3. 头索动物亚门（无头类）
2. 脊椎动物亚门: 有头, 背神经管前段分化出脑及各种感觉器官
	1. [[圆口动物]]: 无颌类
	2. [[鱼类]]: 有下颌
	3. [[两栖动物]]: 四肢
	4. [[爬行动物]]: 羊膜卵
	5. [[鸟]]: 卵生恒温
	6. [[哺乳动物]]: 胎生 哺乳
# 半索动物亚门
1. 有背神经索
2. 消化管前端具有鳃裂，为呼吸器官
3. 有口索
4. 和棘皮动物关系比较亲近
# 尾索动物亚门
1. 幼体尾部有脊索和背神经管
2. 有逆行变态现象（幼体高级 成熟后反而退化）
3. 成体体外有被囊（被囊动物）
4. 例子：海鞘
# 头索动物亚门
1. 终生具有脊索、背神经管和咽腮裂
2. 脊索纵贯全身，超过背神经管到达躯体的最前端
3. 中空的背神经管位于脊索之上，前端膨大形成脑泡（缺乏真正的头脑，称为无头类）
4. 咽部有7+对咽腮裂
5. 出现了肌节，有奇鳍，肛后尾，闭管式循环系统；类似脊椎动物
6. 没有骨化的骨骼，没有成形心脏（腹大动脉有搏动能力，称狭心动物），排泄器官为肾管
7. 代表：文昌鱼
