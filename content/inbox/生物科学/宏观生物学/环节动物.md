# ==真体腔==
+ 有中胚层细胞团→中空体腔囊→外侧分化为体壁肌肉层&体腔膜，内侧肠壁肌肉层&体腔膜
+ 体壁中胚&肠壁中胚层围成的腔即为真体腔
+ 真体腔=裂体腔=次生体
# 特征
1. 形成真体腔（导致排泄能力&循环能力加强，出现循环系统）
2. 身体分节：分成许多体节，体节间有双层隔膜，中间有孔相通，体腔充满体腔液
	1. 同律分节：基本相同
	2. 异律分节：各体节分节不同
	3. 分节有效增强了身体的运动能力
3. 出现运动器官：刚毛（寡毛纲）/疣足（多毛纲）
4. 闭管式循环系统：首次出现循环系统，出现血管&血液
5. 索状神经系统
	1. ![[PixPin_2025-12-29_11-15-47.png]]
	2. 出现脑神经节，各体节均有神经节
	3. 脑主导感觉运动，腹神经节主导反射，整体类似索状
6. 呼吸
	1. 无呼吸器官
	2. 皮下大量毛细血管，可通过体表进行皮肤呼吸（某些海栖种类出现鳃）
7. 排泄器官
	1. ![[PixPin_2025-12-29_11-24-35.png]]
	2. ==后肾管型==，从肾口吸入，从肾孔排出
	3. 肾脏密布微血管，可以排出血液代谢废物和多余水分，也可以回收水分
# 代表动物：环毛蚓
1. 外部形态
	1. 身体圆而细长，同律分节
	2. 浑身生有刚毛
	3. 前段第一节为围口节，可以摄食，掘土等
	4. 有环带，位于14-16节，上可以分泌粘液形成卵茧
	5. 背孔、三对纳精囊孔、雌/雄生殖孔
2. 体壁
	1. 角质膜，表皮，肌肉，体腔膜
	2. 真体腔，四层结构组成皮肌囊（有环肌/纵肌）
3. 体腔
	1. 真体腔
	2. 体腔内有大量体腔液
4. 消化系统
	1. 口，口腔，咽，食道，砂囊（前肠，均有腺体 外胚层）；胃，小肠（中肠 内胚层）；直肠，肛门（后肠 外胚层）
	2. 有黄色细胞，可以储存or合成糖原
5. 循环系统：闭管式循环系统，有纵血管&环血管&微血管
6. 呼吸：体表皮肤呼吸，通过渗透吸收溶解在粘液中的少量氧气
7. 排泄系统：后肾管型小肾管
8. 神经系统：索状神经系统，有中枢神经系统（脑）+外周神经系统
9. 感觉器官：不发达，有表皮、口腔、光感受器
10. 生殖系统：雌雄同体，异体受精（特化性极高），生殖产生蚓茧
# 分类
1. 多毛纲：
	+ 代表沙蚕
	+ 头部&躯干部，头部分化，感觉器官发达
	+ 疣足发达，可以运动
	+ 在水中进行受精，异沙蚕相，群浮，雌雄异体
2. 寡毛纲：
	1. 以刚毛为运动器官
	2. 雌雄同体，有生殖带
	3. 代表蚯蚓
3. 蛭纲：
	1. 暂时性外寄生生活，无刚毛&疣足，身体前后有吸盘
	2. 雌雄同体 有生殖带
