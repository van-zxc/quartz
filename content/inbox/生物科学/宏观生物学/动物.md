# 特征

### ==胚胎发育的规律==
1. 由受精卵发育而来
2. 卵裂期：
	+ ![[PixPin_2025-12-28_16-56-03.png]]
	+ 分为动物极和植物极，植物极含卵黄多
	+ 卵黄含量和分布对受精卵卵裂方式有影响
		+ 卵黄少：完全卵裂
			+ 分布均匀：均等卵裂（文昌鱼），卵裂球大小均匀
			+ 分布不均匀：不均等卵裂（蛙），分裂求不均匀
		+ 卵黄多：不完全卵裂
			+ 只限于动物极细胞质：盘裂（鸡）
			+ 只限于卵的表面：表面卵裂（昆虫）
	+ 卵裂期细胞分裂越长越小
3. 囊胚期：
	+ 受精卵通过卵裂形成中空球状胚
	+ 中央形成明显空腔（囊胚腔），囊胚腔周围为囊胚层
4. 原肠胚：
	+ 形成两胚层。外面的细胞为外胚层，内部细胞为内胚层。内胚层腔为原肠腔，与外界相通的孔为原口
	+ 形成方式：
		+ ![[PixPin_2025-12-28_16-59-17.png]]
		+ 内陷：囊胚植物极细胞内陷
		+ 内移：一部分囊胚细胞移到内部
		+ 外包：动物极细胞分裂快，动物极细胞逐渐包围植物极形成外胚层
		+ 分层：囊胚细胞分裂时就形成了内外两层，原肠胚继承
		+ 内转：通过盘裂形成的囊胚，分裂的细胞由下面边缘内转，伸展形成内胚层。
5. 继续发展则形成中胚层：
	+ 中胚层之间是一个空腔，为真体腔
	+ ![[PixPin_2025-12-28_17-07-10.png]]
	+ 内外层细胞交接处各有一个细胞多次分裂形成很多细胞，成索状深入体腔：裂体腔（端细胞法）：原口动物
	+ 原肠背部两侧内胚层向囊胚腔突出成对的体腔囊，逐步扩展成中胚层：肠体腔（体腔囊法）：后口动物（棘皮，毛颚，半索，低等脊索）
6. ==原口动物&后口动物==： ^a7353d
	+ 原口形成口则为原口动物，原口形成肛门则为后口（反方向内胚层内陷形成口）
	+ 节肢动物及以前则为原口，棘皮动物及以后为后口
7. ==生物发生律==：动物个体胚胎发育的几个早期发育阶段非常相似，都按一定渐进的顺序进行，这种相似性反映了动物界系统发育渐进的顺序性
