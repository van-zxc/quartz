# 分类
1. 类型分为定根(主根&侧根)和不定根
	1. 主根即胚根生长后的结果. 在主根上萌发的侧向支根称为侧根
	2. 除了从主根和侧根长出来的根, 即从茎, 叶或胚轴等部位生长出来的根即为不定根
2. 可以分为直根和须根
	1. 直根有明显的主根和侧根区别的根系
	2. 须根无明显的主根和侧根区分的根系，或根系全部由不定根和它的分校组成，粗细相近，无主次之分，呈须状
3. 直根系多为深根系, 须根系多为浅根系
# 结构
1. 根尖分为根冠, 分生区, 伸长区和成熟区
	1. 最前端为根冠, 保护&感受重力
	2. 分生区位于根冠上, 由分生组织细胞构成, 细胞始终保持分裂能力, 部分分化为伸长区以及补充根冠
	3. 伸长区位于分生区上方, 细胞迅速伸长, 体积增大, 开始分化. 为根尖向土壤内部延伸提供动力
	4. 成熟区位于伸长区后方, 可以分化形成各种成熟组织, 表皮向外部突出形成根毛, 同时形成根的初生构造
2. 初生结构
	1. 双子叶植物: 由表层, 皮层和中柱构成
		1. 表皮由原表皮细胞发育而来, 一般由一层近似长方形的生活细胞构成, 排列整齐, 细胞壁薄, 角质层薄, 无气孔, 有根毛. 有吸收&保护功能
		2. 皮层位于表皮和中柱间, 由基本分生组织发育来. 分为外皮层, 皮层薄壁组织和内皮层
		3. ![[PixPin_2025-12-27_15-17-14.png]]
		4. ==内皮层的上下向壁和径向壁常常形成木质化和栓质化的带状增厚(即凯氏带), 在横切面上其径向壁则形成点状增厚, 即凯氏点. ==
		5. 中柱为内皮层以内所有组织统称, 分为中柱鞘, 初生木质部, 初生韧皮部和薄壁细胞
			1. ![[PixPin_2025-12-27_15-52-26.png]]
			2. 中柱鞘紧靠内皮层细胞的内侧, 由一层薄壁组织构成, 可以脱分化形成部分维管形成层, 木栓形成层以及侧根, 以及起到一定保护作用
			3. 薄壁细胞位于初生木质部和初生韧皮部之间, 可以形成大部分维管形成层
	2. 单子叶植物: 也是表皮 皮层和中柱
		1. ![[PixPin_2025-12-27_16-35-14.png]]
		2. 皮层同样分为外皮层, 薄壁组织和内皮层, 但是是散生中柱
	3. 后期中柱鞘木质化, 变为厚壁组织起支持作用
	4. 韧皮部和木质部起输导作用
	5. 髓位于根的中央, 后期也分化为厚壁组织
3. 次生结构
	1. 次生生长即为, 初生生长完成后, 次生分生组织的活动产生维管组织和周皮的过程
	2. 本质上就是维管形成层和木栓形成层的发生和活动
	3. ![[PixPin_2025-12-27_16-41-22.png]]
4. 有变态根的出现
	1. 肉质直根: 地下变态根, 上部来源于下胚轴无侧根, 下部来自于主根, 有多列侧根(萝卜)
	2. 块根: 地下, 由不定根/侧根发育而来, 所以可以有多个(红薯)
	3. 支持根: 地上, 从茎上伸出不定根进入土中(榕树)
	4. 板状根: 地上, 由侧根发育而来, 固定植物(热带雨林)
	5. 呼吸根: 地上, 伸出水面/地面, 便于根部呼吸(水松)
	6. 攀援根: 地上不定根, 从茎上长出来(爬山虎)
	7. 寄生根: 寄生植物的根(菟丝子)
# 功能
固着, 吸收, 贮藏, 物质合成, 繁殖
