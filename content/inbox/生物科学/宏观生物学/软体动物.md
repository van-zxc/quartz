# 特征
1. 分为头，足，内脏团三部分，左右对称
	1. 头部分化程度明显（发达：章鱼，不发达：石鳖，退化：牡蛎）
	2. 足：身体后部，肌肉组织丰富 ，形态丰富（发达/退化/固着/特化成腕）
	3. 内脏团：生殖，消化等功能，多数左右对称
2. 有==贝壳&外套膜==
	1. 多数软体有贝壳，是特征之一
	2. 贝壳由外套膜分泌而成，主要成分为==碳酸钙&贝壳素==
	3. 贝壳为三层结构：角质层（薄而透明有光泽，壳质素，面积增大而厚度不增加，保护不受酸碱侵蚀）、棱柱层（方解石晶体，厚度不增加）、珍珠层（有珍珠光泽，霰石薄片，面积和厚度都持续增加）；贝壳的生长线
	4. 外套膜：
		1. 两层上皮细胞（外层分泌贝壳，内层有纤毛）+结缔组织+肌肉纤维
		2. 边缘分泌角质层&珍珠层
	5. 外套腔（外套膜&内脏团之间的腔）：有呼吸器官鳃
3. 真体腔退化：
	1. 开管式循环系统（血窦无血管壁包围，血液循环不完全封闭在血管中，某些迅速运动者为闭管式）
	2. 初生体腔内充满血液，称为血窦（真体腔退化形成）
	3. 心脏→动脉→血窦→静脉
4. 呼吸系统：鳃的出现
	1. 外套膜上皮延伸
	2. 水中为鳃，陆上为肺囊
5. 消化系统：
	1. 口中有颚片&齿舌（舌表面有大量角质齿，软体动物特有）
6. 排泄器官：
	1. ==后肾管型==排泄系统（腺体部&管道部）
7. 神经系统：
	1. 四对神经系统（脑、足、侧、脏神经节）
	2. 分散中心神经系统，头足类：形成脑并且有软骨包围
8. 生殖发育：
	1. 异体受精，雌雄同体/异体
	2. 海产为担轮幼虫/面盘幼虫，某些淡水为钩介幼虫
# 代表动物：河蚌
1. 形态
	1. 头部退化，有两片瓣状贝壳，背部有韧带
	2. 壳内部有闭壳肌开关贝壳
	3. 贝壳后端外套膜有两个孔，背部为出水孔，腹部为入水口
2. 肌肉
	1. 闭壳肌+缩足肌+伸足肌
3. 消化系统
	1. 口+触唇+食道+胃+肠+肛门+消化腺
	2. 触唇有上下
	3. 胃有胃盾（可以脱落的厚皮）和晶杆（可以搅拌，也可以分泌消化酶）
	4. 消化系统旁有肝脏，可以分泌消化酶
4. 呼吸
	1. 河蚌有瓣鳃，鳃上有鳃小瓣，有鳃丝
	2. ![[PixPin_2025-12-29_13-48-01.png]]
	3. 水流从入水孔进入外套腔后，经鳃小孔进入鳃水管 ，向上流入鳃上腔 ，从出水孔排出体外。鳃丝上有丰富的毛细血管，水流经过时进行气体交换
5. 循环系统：心脏（1心室1心耳）+血管+血窦
6. 排泄系统：肾脏+围心腔腺
7. 神经：分散中心式神经系统（脑神经节+足神经节+脏神经节）
8. 生殖：雌雄异体
	1. 成熟卵从雌蚌的鳃上腔进入外鳃瓣。精子从雄蚌出水孔排出，到雌蚌的入水孔进入雌体的外套腔，再进入外鳃瓣鳃水管内受精。受精卵在外鳃瓣内继续发育成钩介幼虫。外鳃瓣=育婴囊
	2. 钩介幼虫用足丝钩于鱼鳃/鱼鳍上，营寄生生活；发育成熟后形成幼蚌脱离鱼类，5年后发育为成体

# 分类
1. 双壳纲（代表：牡蛎，固着生活，担轮→面盘→固着）
2. 腹足纲
	1. 10w种（最多的）
	2. 头部发达，体表有一螺旋状贝壳，大型块状足；
	3. 内脏团不对称
	4. 生境多潮湿
3. 头足纲：左右对称，分为头、足、躯干三截；乌贼可洄游
4. 单板纲：非常原始，多为化石；软体动物起源，于海底滑行，左右对称，腹部足肌肉发达
5. 多板纲：石鳖。8块贝壳，==吸附能力强==，足四周&外套膜之间有外套沟
