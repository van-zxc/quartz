# 特征
+ 光合色素多样 光合自养
+ 无根茎叶分化
+ 生殖器官多为单细胞
+ 合子不发育为多细胞的胚
+ 广泛分布于水中和潮湿环境
# 分类
### 形态
+ 单动胞（有鞭毛）
+ 群体（可分可合 单细胞和多细胞之间）
	+ 动群体（有鞭毛）
	+ 圆球形群体（不动细胞连接而成的群体）
+ 丝状体
	+ 简单（排列成单列）
	+ 分支丝状体(略进化)
	+ 异丝体（匍匐+直立）
	+ 假薄壁组织体（丝状体++++）
+ 薄壁组织体（2+个分裂面）
### 鞭毛有无
### 光合色素种类
+ 叶绿素 胡萝卜素 类胡萝卜素 叶黄素 藻胆素
### 载色体结构
+ 螺旋状 杯状 星芒状 etc
### 储藏养分类别
### 繁殖方式
+ 营养繁殖
	+ 细胞分裂生殖
	+ 藻体断裂繁殖
	+ 分出繁殖小支繁殖
+ 无性生殖
	+ 不动孢子
	+ 游动孢子
	+ 厚壁孢子
	+ 似亲孢子
	+ 外生孢子（异裂 小的部分形成孢子）
+ 有性生殖
	+ 同配生殖
	+ 异配生殖
	+ 卵生殖
