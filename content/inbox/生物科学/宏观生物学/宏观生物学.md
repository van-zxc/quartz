# 基本特征
1. 除病毒外都由细胞构成
2. 新陈代谢（物质和能量的交换）
	+ 同化（摄取外界作为自己的）
	+ 异化（分解自身释放到外界）
3. 生长/发育/繁殖
	+ 由小到大：生长
	+ 受精卵$\to$性成熟：发育（由life cycle确定繁殖世代） 发育产生形态变化
	+ 产生后代：繁殖（K/R策略）
4. 生物的遗传和变异
	+ 繁殖产生后代与亲代相似：遗传（性状：可以传递给下一代 traits$\leftrightarrow$genetics）
	+ 不会完全相同：变异
	+ 遗传保证物种相对稳定$(10^{-8})$ 变异导致物种变化
	+ 多样性丰富$\to$应对多样的选择压力$\to$应对多样环境
5. 感应性/应激性
