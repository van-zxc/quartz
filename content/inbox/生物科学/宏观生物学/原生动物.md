# 特征

1. 只有一个细胞 具有一般细胞的基本结构
	+ 所有细胞器都是器官 生理技能由细胞器发挥作用
	+ 具有生理机能
	+ 简单动物 复杂细胞
2. 身体微小 非常原始
3. 一些为群体单细胞（单细胞聚类，没有有机结合）

# 代表：草履虫

==表膜泡嵌套系统==：增加表膜硬度、有柔韧性，保护细胞质etc.

#  应对不利环境？

eg. 小瓜虫：包囊（失去大部分结构后缩成一团，分泌胶质分隔开，休眠  环境良好时出来）相当于受精卵
eg. 疟原虫：迟发性子孢子。休眠状态结束后疟原虫复发

[[节肢动物]]：休眠、隐蔽（形态和环境相像）、保护色（体色和环境颜色一致）警戒色（颜色鲜艳，警示捕食者）、拟态（模仿另一种不可食动物   缪勒拟态：有毒相互模仿  贝茨拟态：无毒模仿有毒）

分子机制（模式产生？）：实验室构建杂交后代、全基因组测序、找到基因（dsex）、发现可变剪切
