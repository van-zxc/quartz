# 特征
+ 孢子体发达: 
	+ 多年生木本植物
	+ 维管组织进步 出现形成层和次生生长层 但只有管胞和筛胞
	+ 表皮有厚角质层和下陷气孔
+ 胚珠裸露 种子裸露
+ 孢子叶聚集: 
	+ 小孢子叶球(雄花)/大孢子叶球(雌花)
	+ 小孢子叶球: 小孢子叶(雄蕊)聚合, 减数分裂形成小孢子, 随后发育成雄配子体(花粉粒)
	+ ==大孢子叶变态==：羽状大孢子叶(苏铁)、珠领(银杏)、珠托(红豆杉)、珠鳞(松柏)、盖被(买麻藤)、套被(罗汉松)
	+ 大孢子叶聚生成大孢子叶球
+ 配子体退化：
	+ 雄配子是小孢子发育的花粉粒
	+ 雌配子由大孢子发育来，产生2－多个颈卵器。1卵细胞+1腹沟细胞，无颈沟细胞
+ 形成花粉管、受精脱离水
	+ 花粉粒萌发形成花粉管
+ 有种子 无果实
	+ 送2精子入颈卵器，一个和卵细胞结合形成胚，胚周围雌配子其他部分形成胚乳
	+ 胚为新孢子体世代、胚乳为配子体世代、种皮为老孢子体世代
+ 有多胚现象：（最后都只会留下一个胚）
	+ 简单多胚：多个颈卵器同时受精（异卵）
	+ 裂生多配：胚细胞分裂（同卵）
	+ 进化原因：增大存活几率？
# 生活史(松)
+ 雄球花穗状，由多数螺旋状排列的小孢子叶（雄蕊）组成，每个小孢子叶上有2个小孢子囊（花粉囊）。小孢子囊内多个小孢子母细胞（花粉母细胞）经减数分裂产生小孢子
+ 小孢子（单核花粉粒）第一次有丝分裂产生==1个大的胚性细胞和1个小的原叶细胞==（第一原叶细胞）。胚性细胞再经过有丝分裂形成==1个大的精子器原始细胞和1个小的原叶细胞==（第二原叶细胞）。精子器原始细胞再进行有丝分裂产生1个大的管细胞和1个小的生殖细胞。同时，雄配子体的细胞壁也向外突起，形成2个翅膀状的气囊。成熟雄配子体即为花粉粒。
+ 雌球花由多数螺旋状排列的==珠鳞和苞鳞==组成，苞鳞与珠鳞分离。珠鳞腹面基部有两个==倒生==的胚珠。
+ 胚珠的大孢子囊内，大孢子母细胞减数分裂产生==4个单倍体大孢子，3个退化，1个发育形成雌配子体的第一个细胞==。大孢子核分裂形成==16-32个游离核==而后休眠。春天来临，游离核继续分裂形成几千个细胞核，逐渐由周围向中心形成细胞壁。珠孔端的几个细胞膨大形成颈卵器原细胞。经过几次有丝分裂，发育成颈卵器。成熟的雌配子体由2-7个颈卵器组成。每个颈卵器有==4个颈细胞，1个卵细胞和1个腹沟细胞，无颈沟细胞==。
+ 晚春时，花粉粒飘到珠孔上，管细胞伸长，长出花粉管。生殖细胞进行一次有丝分裂，形成==柄细胞和精原细胞==。然后雄配子体休眠，等待成熟。==次年春天==，花粉管继续伸长，精原细胞分裂为==2个大小不等的精核==。当花粉管碰到颈卵器，花粉管先端破裂，2个精子核和管细胞、柄细胞流入卵细胞细胞质中，大精核与卵结合成受精卵，管细胞、小精核和柄细胞解体。受精作用在传粉后13个月才进行。==传粉在第一年春季，受精在第二年夏季==。
# 分类
1. 苏铁亚纲
	1. 花无假花被, 次生木质部无导管
	2. 大型羽状复叶聚生茎顶、茎不分支
	3. 孢子叶球：大孢子叶球圆球状、特化为羽状；小孢子叶球圆柱形
2. 银杏亚纲
	1. 花无假花被, 次生木质部无导管
	2. 落叶乔木, 叶扇形、二叉脉序、精子多纤毛
	3. 长短枝，长枝螺旋状，短枝簇生
	4. 雌雄异株; 雄球花柔荑花序状, 顶端两个小孢子囊组成小孢子囊群; 雌球花具长梗，两叉分别一个直立胚珠
	5. 在花粉室内存储水分，花粉管逐渐生长将精子释放到水中，
3. 松柏亚纲
	1. 花无假花被, 次生木质部无导管
	2. 叶针状/鳞状、无二叉脉序、精子无纤毛
	3. 松目 柏目 南洋杉目
4. 买麻藤亚纲
	1. 花有假花被、次生木质部有导管、亚灌木或木质藤本
	2. 孢子叶球单性
	3. 除麻黄科外雌配子体无颈卵器
	4. 与被子植物高度相似(木质部具有导管；有类似花的结构；有双受精现象：精子没有鞭毛，胚是两枚子叶，叶子是阔叶，虫媒传粉。)
	5. 麻黄科、买麻藤科、百岁兰科
