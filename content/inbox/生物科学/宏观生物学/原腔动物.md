# 假体腔
+ 中胚层体腔囊在发展过程中靠向体壁，形成肌肉层，==但是没有形成新空间==。该腔只有体壁中胚层，没有==肠壁中胚层和中胚层形成的体腔膜包围==，不是真正意义的体腔，称为假体腔
+ 第一次出现体腔，也为初生体腔
+ 为内脏器官和系统发展提供空间
+ 有体腔液，相当于循环系统，可以有效运动营养和代谢物质
+ 维持体型

# 有性生殖
why sex?
+ 无性生殖繁殖快
+ 有性生殖增加了遗传变异，使得自然选择更加高效
+ 增强适应能力，固定有利突变，消除有害突变
+ 无性生殖下有害突变会迅速累计导致种群死亡

是否需要后代是决定婚配制度进化的重要因素
