动物数量最多
完全适应陆生生活，是原口动物的进化顶点
# 特征
1. 由许多体节构成，异律分节
	1. 昆虫：头 胸 腹；甲壳：头胸、腹；蛛：头胸、腹；多足：头、躯干
	2. 体节分化组合，增强运动&适应力
2. 附肢：按节排列，优于疣足，有关节
3. 体表有含有几丁质的外骨骼
	1. 分片排列，节间柔软，利于运动
	2. 有蜕皮现象：蜕皮激素（胸腺：褪皮激素，促进；咽侧体：保幼激素，抑制）
4. 有发达的横纹肌，都为分离的肌肉束
5. 呼吸器官多样
	1. 小型动物：体壁
	2. 鳃：水生甲壳动物在足基底向外凸起薄膜状结构
	3. 书鳃：足基部体壁向外凸起折叠形成书页状（鲎）
	4. 书肺：体壁向内凹陷形成书页状（蜘蛛 蝎）
	5. 气管：体壁内陷形成的管状结构，无毛细血管，直接输送氧气（陆生昆虫 蜈蚣马陆）
	6. 水生动物都是向外凸起，陆生动物都是向内
6. 有混合体腔和开管式循环系统
7. 排泄管：
	1. 马氏管型
		1. 昆虫 蜘蛛等有马氏管
		2. 消化道中，后肠交界处的肠壁向外凸起形成的管状结构；浸没在血液中，可收集废物；可以尽可能回收水分，代谢废物以固体形式排出
	2. 后肾管型：有触角腺，常分布于甲壳纲
# 分类
1. 原节肢动物亚门：身体不分节，附肢为中空的体壁凸起，代表栉蚕
2. 真节肢动物亚门：身体分节，附肢分节
	1. 肢口纲：鲎
		1. 头胸部，腹部，尾剑
		2. 有头胸甲，无触角，使用书鳃呼吸
		3. ![[PixPin_2025-12-29_16-39-24.png]]
		4. 6对附肢
	2. 蛛形纲：蜘蛛 蝎子 蜱螨
		1. 分为头胸部和腹部，无触角，8只单眼
		2. 头胸部1 2对附肢为鳌肢和脚须 有4对足
		3. 用书肺/气管呼吸
	3. 甲壳纲：虾蟹 水蚤
		1. 头胸部&腹部，触角两对，有头胸甲
		2. 足至少5对
		3. 以鳃呼吸
	4. 多足纲(蜈蚣 马陆)
		1. 蠕虫形，头部+躯干部；触角1对
		2. 皮肤腺发达
		3. 躯干部每一个体节有1-2对足
		4. 使用气管呼吸
	5. ==昆虫纲==
		1. 头胸腹三节
		2. 头部是感觉中心
			1. 有一对触角 
				1. 梗节 柄节 鞭节(多节)
				2. 触觉 感觉与分泌激素功能
				3. 触角形态多样
			2. 大多数昆虫有1对复眼（识别形状和颜色），2-3个单眼（只可以感光 不可以成像）
			3. 有口器（上颚 上唇 下颚 下唇 舌）
				1. 重要分类依据
				2. 咀嚼式口器：取食固体食物
				3. 刺吸式口器：特化为针状，适合吸取液体食物
				4. 虹吸式口器：不用时盘曲，适合吸取花蜜，鳞翅目特有
				5. 嚼吸式口器：上唇上颚保持咀嚼，可以同时吮吸花蜜和咀嚼花粉，蜜蜂特有
				6. 舐吸式口器：可以吸取液体类食物或分泌唾液，蝇类特有
		3. 胸部是运动中心
			1. 胸部三节（前中后），每一个胸节有一对足；后两个节常各有一对翅
			2. 足为基节、转节、腿节、胫节、跗节；分类参考（形态差异很大）
			3. 一般两对翅膀，和体壁相同结构，形态差异大，分类最重要参考（膜翅 鞘翅 鳞翅 半翅 双翅） 有无 不同质地 形状 数目？？
		4. 腹部是营养繁殖中心：10-11节，无运动器官，附肢大部分退化（少数变为外生殖器）
		5. 体壁
			1. 表皮层: 外分泌 薄而透明 上表皮（蜡质+酚）+外表皮（几丁质+鞣化蛋白）+内表皮
			2. 上皮层
			3. 基膜
		6. ![[PixPin_2025-12-29_17-26-53.png]]
		7. 消化系统
			1. 前肠：口、咽、食道、嗉囊（贮存食物）砂囊/前胃（有角质齿）
			2. 中肠：主要的食物消化吸收（胃盲囊：中肠前端凸起；围食膜：几丁质）
			3. 后肠：回肠 结肠 直肠（重吸收营养，形成便便）
			4. 唾液腺 
		8. 呼吸系统
			1. 气门：调节水分&气体流通，10对
			2. 气管、微气管
		9. 循环
			1. 开管式，循环系统不发达
			2. 心脏为1心室+心孔+心瓣
		10. 排泄：马氏管or后肾管
		11. 生殖系统极其发达，雌雄异体
			1. 雌性：卵巢 (1 对 ) - 侧输卵管 (2 条 ) - 中输卵管 - 阴道 - 生殖孔；阴道背面有受精囊，有储存精荚的作用；输卵管前端有副性腺：分泌粘液，把卵粘结成卵块
			2. 雄性：精巢 (1 对 ) - 输精管 - 储精囊 - 射精管 - 阴茎 - 生殖孔；射精管前端或输精管基部常有副性腺，能分泌粘液，使精子形成精荚
		12. 神经&内分泌: 中枢神经系统(运动能力强)
			1. 脑(3对神经节 分化为前中后脑)-咽下神经节(3对)-腹神经链
			2. 周边神经、交感神经
			3. 感受器灵敏
			4. 内分泌：心侧体、脑神经分泌细胞、保幼激素(咽侧体)&蜕皮激素(胸腺)
		13. 生殖方式: 有性生殖
			1. 卵生or卵胎生（受精卵在子宫内发育成个体，营养通过卵黄给予）
			2. 偶发性（蚕）/周期性（蜜蜂etc.）孤雌生殖?
			3. 休眠：不良环境下暂时停止发育
			4. 滞育：周期性出现、新陈代谢抑制程度更深
			5. 变态
				1. 完全变态：卵到成虫的过程中出现蛹；幼虫和成虫形态功能明显差异
				2. 不完全变态：卵→幼体（蜕皮）→成虫
					1. 渐变态：个体大小变化而已
					2. 半变态：幼体外形和成虫完全不同（蜻蜓等，水生幼虫称稚虫）
		14. 趋性：趋光性 趋化性；有昼夜节律
		15. 多态性、集群社会性 eg. 工蜂 工蚁
		16. 分类
			1. 依据：翅的有无、质地；口器类型；变态类型；胸节、触角、跗节的特征；马氏管的数目
			2. 两个亚纲, 34个目
			3. 无翅亚纲: 系统发生过程中没有出现过翅的
				1. 原尾目：身体微小、触角和眼睛退化、前胸小、前足长于头部、咀嚼式（原尾虫）
				2. 双尾目：体细长扁平，咀嚼式、有一对管状尾须（双尾虫）
				3. 弹尾目：触角四节、复眼退化、腹部有弹器、无马氏管（跳虫）
				4. 缨尾目：触角丝状、咀嚼式口器、有一对尾须和一根中尾丝（衣鱼）
			4. 有翅亚纲：多有1-2对翅，可能退化
				1. 外生翅类: 不完全变态(19目)
					1. 直翅目: 前翅革质、后翅膜质；渐变态、咀嚼式口器、发音器&听器发达（蝗虫、蟋蟀）
					2. 半翅目: 前翅基部革质、端部膜质，有臭腺、渐变态、刺吸式（臭虫、蝽蟓）
					3. 同翅目: 刺吸式口器、膜质翅、分泌蜡质粉末（蚜虫、蝉）
					4. 蜻蜓目: 复眼大、幼虫水生、咀嚼式、前后翅长度相等不可折叠、触角刚毛状、腹部细长（蜻蜓、豆娘）
					5. 蜉蝣目: 复眼大、触角细小，翅膜质、成虫不取食（蜉蝣）
					6. 蜚蠊目: 体型扁平、触角丝状、咀嚼式、头部在背板下（蟑螂、土鳖）
				2. 内生翅类: 翅膀藏在体壁中发育，完全变态
					1. 鳞翅目: 躯体和翅膀有鳞片和毛、口器虹吸式，两翅扁平（蝴蝶 蛾子）
						1. 蝴蝶触角细长，末端膨大成鼓槌状，幼虫不作蛹
						2. 蛾子触角不成鼓槌状，形态多元；光线暗行动；幼虫作蛹
					2. 鞘翅目: 动物界最多的目、前翅角质，后翅膜质，咀嚼式（天牛、瓢虫）
					3. 双翅目: 一对翅、后翅退化为平衡棍
						1. 长角亚目：身体细小，刺吸式、触角为毛状（蚊）
						2. 短角亚目：身体粗壮、舐吸式、触角刚毛状（蝇）
					4. 膜翅目: 膜质翅、翅脉少、前翅大于后翅，翅膀之间靠翅钩连接（蜂、蚁）
					5. 蚤目: 体型小、翅膀退化、刺吸式、后肢为跳跃足、全部为寄生虫（跳蚤）
