# 羊膜卵
1. 胚胎表层胚膜向两个方向发生环状褶皱, 包围后愈合, 两侧边缘相通, 内层包住胚胎, 称为羊膜
2. 羊膜内腔称为羊膜腔，充满羊水, 胚胎悬浮于羊水中
3. 折叠外层胚膜为绒毛膜
4. 胚胎消化道后端的囊状凸起为尿囊，外壁紧贴绒毛膜，是胚胎的排泄和呼吸器官
5. 内层为卵黄囊
6. 意义: 外层有东西包被，防止卵的变性损伤; ==无需借助水为介质==； 在稳定环境中发育, 减少振动和机械损伤. 
# 特征
体被鳞片/硬甲、在陆地繁殖的变温动物
1. 体型多样（头+颈+躯干+四肢+尾）  龟鳖型 蜥蜴型 蛇型
2. 表面有角质鳞片or骨板，皮肤干燥
	1. 可以蜕皮
	2. 表皮色素细胞多
3. 骨骼: 多硬骨, 有坚硬的爪
	1. 脊椎骨: 颈椎 胸椎 腰椎 荐椎 尾椎
	2. 蛇类附肢退化
	3. 头骨出现单一枕髁
	4. 头骨上出现颞窝，咀嚼能力和自主捕食能力增强
	5. 首次出现次生腭(把口腔和鼻腔 食管和气管分开)
	6. 开始出现胸廓，可以保护内脏和加强呼吸（羊膜动物特有）
4. 肌肉系统：肋间肌 咬肌 附肢肌
5. 消化系统: 
	1. 出现牙齿, 可以更换
	2. 出现发达的口腔腺，毒蛇特化为毒腺
	3. 肌肉质的舌发达
	4. 出现盲肠 和纤维素消化有关
6. 呼吸：
	1. 海绵状肺，咽式呼吸/胸式呼吸
7. 循环系统
	1. 两心房 一心室 不完全循环系统
	2. 鳄类接近完全双循环
8. 排泄系统
	1. 有后肾, 作为排泄系统，主要排泄尿酸
	2. 盐腺：肾外盐排泄功能
9. 神经系统
	1. 分为两个半球，纹状体加厚，出现新脑皮
	2. 延脑发达，有12对脑神经
10. 感觉器官：
	1. 出现耳蜗和外耳道
	2. 具有犁鼻器
	3. 某些种类具有红外感受器：颊窝
11. 生殖: 
	1. 体内受精 体外发育
	2. 大多数为卵生, 少数卵胎生
# 分类
1. 喙头目（1属1种）
2. 龟鳖目：背腹有坚硬的甲板（龟科 鳖科 海龟科 棱皮龟科）
3. 有鳞目：体表有大量骨质鳞片（蜥亚目 蛇亚目）
	1. 蛇：游蛇科眼镜蛇科蝰蛇科
4. 鳄目：体型蜥蜴型
