# 能量代谢

## 分类

2. 化能异养

## 化能异养
1. 形式：脱氢，脱电子，和氧结合
2. 阶段：脱氢，递氢，受氢
3. 功能：产ATP，产还原力，产小分子代谢物
4. ![[PixPin_2026-11-02_10-10-53.png]]
### 脱氢途径
1. EMP途径（[[糖酵解]]），产生6ATP
	1. 供给ATP和NADH
	2. 提供中间代谢物
	3. 逆向可以形成多糖
2. HMP途径（[[磷酸戊糖途径]]）
	1. 产35 ATP
	2. 产磷酸戊糖→ 核苷酸、核酸、NAD(P)+等
	3. 产4-磷酸赤藓糖→苯丙氨酸、酪氨酸、色氨酸等
	4. 产生大量NADPH₂形式的还原力 →脂肪酸、固醇和能量
	5. 固定CO₂的中介：5-磷酸核酮糖（Calvin循环）
	6. 扩大碳源利用范围：C₃ - C₂多种碳源
	7. 连接 EMP途径（1,6-二磷酸果糖和3-磷酸甘油醛）
3. ED途径（KDPG途径）
	1. 葡萄糖只经过4步变为丙酮酸
	2. ![[PixPin_2026-11-02_10-15-28.png]]
	3. 细菌乙醇发酵
	4. 有KDPG醛缩酶。将其裂解为丙酮酸+3-磷酸甘油醛→2丙酮酸
	5. 产能效率低（1 Glu产生1ATP）
4. [[TCA循环]]：需要有氧，产生30ATP
### 递氢和受氢
1. ![[PixPin_2026-11-02_10-21-40.png]]
2. 有氧呼吸：[[氧化呼吸链]]
3. 无氧呼吸
	1. 电子受体可能是硝酸根，硫酸根，二氧化碳等无机物或者延胡索酸等有机物
	2. 需要细胞色素，伴随磷酸化作用
	3. eg. 把$NO_{2}^{-}$还原为$N_{2}$，即反硝化作用
	4. eg. 硫呼吸，碳酸盐呼吸（碳酸盐→乙酸/甲烷），硫酸盐呼吸（产$H_{2}S$）

## 化能自养
1. 底物脱下的氢或者电子可以直接从任意位置进入呼吸链
2. 效率低于化能异养
3. 顺呼吸链获得能量，逆呼吸链获得还原力
4. ![[PixPin_2026-11-02_11-21-43.png]]
5. 氨的氧化
	1. 亚硝化：氨氧化为亚硝酸盐
	2. 硝化：把亚硝酸盐氧化为硝酸盐
		1. 电子受体为水分子的氧
		2. 顺呼吸链产1ATP
		3. 逆呼吸链，消耗大量ATP才能产生少量H
	3. ![[PixPin_2026-11-02_11-12-45.png]]
	4. 普遍生长缓慢
6. 氢的氧化
	1. 以氢为电子供体，O2为电子受体生长
	2. 一般为革兰氏阴性
	3. 膜上氢化酶参与ATP，胞质氢化酶参与NADH
7. 硫氧化
	1. 顺呼吸链产生ATP，逆呼吸链产生NADH
	2. 合成还原力H需要的ATP比硝化细菌少
## 光合营养
1. 光合磷酸化：和[[氧化呼吸链]]类似，通过电子传递系统传递ATP
2. 光合自养：以CO2为主要碳源，用无机物作为供氢体或电子供体，合成细胞物质
3. 光能异养：有机物为供氢体，需要外源生长因子
4. 光合磷酸化
	1. 循环光合磷酸化
		1. 光能启动下电子从菌绿素中离开又回来，产生质子势，帮助ATP合成
		2. 产ATP和产氢分别进行
		3. 还原力来自无机氢供体，不产氧，一般厌氧
	2. 非循环光合磷酸化
		1. 电子传递非循环，在有氧条件下进行
		2. I利用红光，II利用蓝光
		3. 反应同时产生ATP，氧气，还原力（来自水分子）
	3. 嗜盐菌紫膜
		1. 细胞膜红色部分：有氧作用，含有细胞色素和黄素蛋白等呼吸链载体
		2. 紫色部分：明亮处形成，无氧，由细菌视紫红质组成
		3. 视紫红质有质子泵功能，可以把氢离子排出到细胞外，即合成ATP
# 生物固氮
## 种类
1. 自生固氮
2. 共生固氮
3. 联合固氮
## 条件
1. 大量ATP，还原力（强的产能手段）
2. 有效的固氮酶
3. 大量氮气
4. 有利的介质环境（镁离子，严格厌氧）
## 固氮酶
1. 对氧高度敏感，结构几乎相同
2. 组分1：固二氮酶，含钼和铁，对铁敏感，还原氮气的活性中心
3. 组分2：固二氮酶还原酶，只含铁，电子活化后传递
4. ![[PixPin_2026-11-02_12-05-10.png]]
5. 过程：![[PixPin_2026-11-02_12-06-56.png]]
6. 抗氧机制
	1. 呼吸驱氧：呼吸极强，迅速将附近氧气全部消耗
	2. 构象保护：固氮酶组分和耐氧的硫铁蛋白形成复合体
	3. 形成粘液层抗氧（棕色固氮菌）
	4. 蓝细菌
		1. 时间间隔（白天光合，晚上固氮）
		2. 束状群体：光合细菌在中间厌氧的细胞失去产氧系统，严格隔氧、
		3. 提高SOD活性
		4. 分化出还原性异形胞：体积大，壁厚，氢化酶/SOD活性高
	5. 共生根瘤菌
		1. 形成类菌体：只生长不分裂，固氮活性强，被类菌体膜包被
		2. 豆血红蛋白：亲氧，屏蔽氧气（豆科和根瘤菌合作产生）
