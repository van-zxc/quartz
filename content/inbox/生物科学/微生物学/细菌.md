# 细菌定义
+ 狭义：细胞细短、结构简单、细胞壁坚韧、以二分裂方式繁殖和水生能力强的原核生物
+ 广义：[[原核微生物]]
# 形态
1. 球状菌（第二多）
	1. 双球菌
	2. 单球菌
	3. 链球菌：肺炎链球菌
		1. 革兰氏阳性菌
		2. 具有荚膜
		3. 容易产生抗药性
	4. 四联球菌
	5. 八叠球菌
	6. 葡萄球菌：金黄色葡萄球菌
		1. 革兰氏阳性球菌
		2. 可以产生溶血素溶解红细胞（菌落周围产生溶血环）
		3. 感染性很强
2. 杆状菌（最多）
	1. 细胞外形：短杆、长杆；形态容易因生长和培养条件发生变化
	2. 病原菌：炭疽芽孢杆菌、白喉棒状杆菌（外毒素）、鼠疫杆菌、铜绿假单胞菌（革兰氏阴性菌、鞭毛单向运动性、好氧、易形成生物被膜、耐药性强）、肉毒梭杆菌（厌氧、有芽孢、革兰氏阳性、芽孢呈卵圆形、可以产生毒性极强的肉毒素）
	3. 可以产生大量酶（枯草芽孢杆菌、地衣芽孢杆菌），可以生产抗菌活性物质
3. 螺旋菌（第三多）
	1. 弧菌
		1. 小于一环，长得像C，鞭毛偏端生
		2. 霍乱弧菌（G-、单鞭毛、部分有荚膜）
		3. 蛭弧菌（G-、可以寄生于细菌）
	2. 螺旋菌
		1. 2-6环，鞭毛二端生，菌体坚硬
		2. 幽门螺旋杆菌
	3. 螺旋体菌
		1. >6环，菌体柔软，有用于运动的类似鞭毛的轴丝
		2. 梅毒螺旋体（荧光密螺旋体抗体结合实验）
		3. 轴丝（周质鞭毛）快速旋转，推动细胞做拔塞钻式前进
4. 柄状杆菌：细胞上有柄、菌丝、附器等；粘附能力强
5. 球衣菌：G-、能形成衣壳、可以排列成丝状
6. 支原体：只有细胞膜没有细胞壁，形态多变；部分对人体有传染性
## 异常形态
1. 正常
2. 异常：环境条件的胁迫对其造成影响
	1. 形态结构、毒力、菌落、耐药性变异
	2. 基因突变、转移、重组等
	3. 物理化学因素刺激/培养时间过长
3. 古菌形态和细菌域微生物类似
# 大小
1. 球菌：0.5-1μm
2. 杆菌：直径0.2-1μm、长度1-80μm
3. 螺旋菌：直径0.3-1μm、长度1-50μm
4. 较大细菌：高度卷曲的质膜组成的外层；最大长度1cm左右（DNA被膜包裹、巨大液泡样结构以存储硝酸盐、核糖体结构）
5. 极简真核生物：丢弃了大量复杂结构，只有核、线粒体和叶绿体
## 细胞壁
1. 研究方法
	1. 细菌超薄切片电镜观察
	2. 适当的质壁染色可以在光学显微镜下看到
	3. 机械法破碎得到纯细胞壁
2. 功能
	1. 固定细胞外形（分类依据）、提高强度
	2. 细胞生长、分裂、鞭毛运动（支点）必须
		1. 鞭毛结构复杂
		2. L环：细胞壁外膜
		3. P环：细胞壁内层肽聚糖
		4. MS环：细胞膜&周质空间
		5. C环：膜质交界处
	3. 渗透屏障、阻拦酶蛋白、抗生素等有害物质进入细胞
	4. 细菌特定的抗原、致病性、对外界反应敏感性
3. 染色法
	1. 活细菌：美蓝/TTC作活菌染色（细胞代谢脱氢）
	2. 死菌
		1. 正染色：简单染色法（草酸铵结晶紫染色&石炭酸复红染色）
		2. 鉴别染色法：革兰氏染色、抗酸性染色
		3. 负染色：荚膜染色法
	3. 革兰氏染色：G+紫色、G-红色
		1. 结晶紫对菌液初次染色
		2. 碘溶液进行媒染
		3. 乙醇/丙酮冲洗脱色（阳性菌紫色、阴性菌无色）
		4. 用另一种碱性染料复染得到革兰氏阴性菌的颜色
		5. G+肽聚糖层次多厚、含有肽聚糖&磷壁酸，容易保留结晶紫和碘的复合物；乙醇脱水时肽聚糖脱水导致孔隙缩小，染料更加不容易溢出
		6. G-含有类脂质&蛋白质，交联松散不容易被染色；乙醇处理后部分脂质溶解，孔隙更大，容易被脱色
		7. G+：金黄色葡萄球菌、溶血性链球菌、肺炎链球菌、白喉杆菌、炭疽杆菌
		8. G-：百日咳杆菌、大肠杆菌、伤寒杆菌、痢疾杆菌、霍乱弧菌、淋病双球菌等
	4. 革兰氏阳性细菌
		1. 化学组分简单，含有90%肽聚糖+10%磷壁酸
		2. 肽聚糖
			1. 细胞壁中特有，网状分子
			2. 乙酰葡萄糖胺+乙酰胞壁酸重复排列形成的二糖单位（$\beta-$ 1,4糖苷键，容易被溶菌酶水解）、末端以四肽尾相连（LAla-DGlu-LLys-DAla）
				1. 关于为什么可能是LDLD交替构型的氨基酸，我利用Gemini找到了可能的解释：
				2. 生物体内普遍是L型氨基酸，因此酶普遍也是催化L氨基酸的，因此使用D氨基酸有助于规避酶的降解
				3. 单一构象的氨基酸由于空间构象的原因，容易自发卷曲；而交替的肽链则能保持一个相对柔性的构象，防止卷曲，保持一定的机械结构
			3. 五肽桥连接前后四肽尾分子的桥梁，氨基酸多样性强
			4. 青霉素是四肽尾末端D-丙氨酰-D丙氨酸结构类似物，可以和转肽酶结合，阻止肽聚糖单体合成
		3. 磷壁酸是G+细胞的特有酸性多糖
			1. 成分：甘油磷酸/核糖醇磷酸
			2. 膜磷壁酸：和细胞膜磷脂共价连接
			3. 壁磷壁酸：和肽聚糖分子共价结合，受培养条件影响
			4. 功能：浓缩二价阳离子、贮藏磷元素、调节自溶素、抗免疫等
	5. 革兰氏阴性菌
		1. 肽聚糖+外膜+外膜蛋白+周质空间
		2. 肽聚糖
			1. 1-2层，机械强度弱，占比少
			2. 四肽尾的第三个aa更换为内消旋氨基庚二酸m-DAP
			3. 没有特殊肽桥，部分亚单位交叠为网状
		3. 外膜：脂多糖+磷脂+脂蛋白
			1. 脂多糖：O特异侧链、核心多糖、类脂A
			2. O侧链：抗原性、结构多变，可以躲避宿主免疫攻击
			3. 核心多糖：有负电荷，可以吸附阳离子，稳定细胞膜结构（正点多粘菌素可以靶向LPS并破坏）
			4. 类脂A：2个N-乙酰葡萄糖胺+xxx（内毒素）
			5. 作用：
				1. G-因为拥有LPS，可以更能抵抗毒素和抗生素
				2. 噬菌体吸附受体
				3. 控制物质选择性进出
		4. 外膜蛋白
			1. 孔蛋白：三聚体，中间有孔道，通过孔的开关选择物质（特异/非特异）
			2. 脂蛋白：识别附着
		5. 周质空间：外膜和细胞膜之间的狭窄空间
			1. 周质蛋白：水解酶、合成酶、结合蛋白、受体蛋白
			2. 革兰氏阳性菌将水解酶直接释放到体外
	6. 抗酸性细菌
		1. 细胞壁中含有大量分枝菌酸：蜡质物质
		2. 被酸性复红染料结合后，很难被酸性脱色剂脱色
		3. 分枝杆菌/诺卡氏菌
		4. 含有60%类脂，肽聚糖含量少，染色反应为G+
		5. 生长缓慢、对药物高度抵抗
		6. 过程：碱性复红+苯酚染色、酸性酒精脱色
4. 古菌细胞壁
	1. 细胞壁中没有肽聚糖，而是多糖（假肽聚糖）、糖蛋白、蛋白质
	2. 热原体属没有细胞壁，极度强化细胞膜
	3. 假肽聚糖
		1. 糖苷键且$\beta$-1,3糖苷键，不被溶菌酶水解
		2. N-乙酰葡萄糖胺+N-乙酰塔罗糖胺糖醛酸
		3. 肽尾：LGLu-LAla-LLys
		4. 肽桥只有一个LGlu
		5. 对青霉素不敏感
	4. 盐杆菌属：细胞壁由糖蛋白组成（蛋白大量含酸性氨基酸，带有强负电荷）
5. 缺壁细菌
	1. 人为
		1. 缺壁突变：L型细菌
			1. 自发突变形成的遗传稳定细胞壁缺损
			2. 细胞膨大&多态化，部分可以通过细胞滤器、对渗透压敏感
			3. 高渗含血清培养基培养
			4. 可以进行无细胞壁生长
		2. 人工去壁
			1. 原生质体：G+，溶菌酶消化等处理，容易导入外源物质，可以新生细胞壁、球形
			2. 球状体：G-，没有完全处理干净（有外膜）
			3. 无法进行无细胞壁生长
	2. 自然：支原体
		1. 无细胞壁、细胞膜中有甾醇，机械强度高
# 结构
## 细胞膜
1. 原核生物蛋白质含量高（50-70%），没有甾醇结构（除支原体）
2. 细菌结构中含有藿烷分子
3. 支原体细胞膜中的甾醇来自真核生物；细菌则是自己合成藿烷
4. 古菌通过醚键连接甘油+异戊二烯，称为植烷/二植烷；同时具有单双分子混合膜（抗高温更稳定）
## 细胞质
1. 贮藏物
	1. 碳源
		1. 糖原
		2. 聚$\beta$羟丁酸（PHB）：降低渗透压，不溶于水，容易被脂溶性染料染色
		3. 硫粒：化能自养细菌
	2. 氮源
		1. 藻青素：精氨酸：天冬氨酸=1：1的分支多肽
		2. 藻青蛋白
	3. 磷源类：异染粒：偏磷酸聚合物
2. 羧酶体
	1. 蛋白质纳米细胞器，专职固定CO2
	2. 典型区室化
3. 磁小体
	1. 内部有大量四氧化三铁or硫化铁
	2. 有类似生物导航系统功能
4. 核区
	1. 环状双链DNA，一般没有DNA分子
	2. 自制力
## 特殊结构
1. 糖被
	1. 某些细菌外壁的胶状物质
		1. 荚膜：单个细胞，可以染色；有一定外形，200nm，相对稳定
		2. 粘液层：松散，可以向外界扩展
		3. 菌胶团：细胞群体荚膜相互融合产生的大型胶黏物
	2. 成分：多糖/多肽
	3. 功能
		1. 保护细菌，防止干旱、噬菌体吸附、重金属离子等
		2. 贮藏养料
		3. 信息识别
		4. 堆积代谢产物，帮助附着
2. 鞭毛
	1. 某些细菌的长丝状波浪形的蛋白质附属物
	2. 单端生、双端生（翻滚前进，方向多变，较快）、周生鞭毛（直线，最慢）
	3. 观察：电镜、光学镜、显微镜穿刺、半固体穿刺
	4. 构造
		1. 革兰氏阳性菌有两个环，阴性菌有四个环
		2. 鞭毛着生于细胞膜上，能量来自于质子势
	5. 鞭毛能实现细胞的趋性
	6. 周质鞭毛：螺旋体菌独有，被细胞壁外膜覆盖
3. 菌毛
	1. 空心蛋白质，250-300条
	2. 表面可以吸附or注入毒素，以G-致病菌居多
	3. 性菌毛：构成和菌毛相同，比菌毛长，仅数根；见于G-雄性菌，其参与质粒转移，诱导水平基因转移
4. 芽孢
	1. 一个胞内形成圆形or椭圆形，厚壁，抗逆性极强的休眠体
	2. 多为杆菌（也有球菌）
