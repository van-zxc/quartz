标签：[[生物]] [[微生物]] [[概念]]

包括立克次氏体、支原体、衣原体等
# 特性
1. G-，代谢能力差
2. 一般寄生
3. 介于细菌-病毒
4. 寄生性：支原体<立克次氏体<衣原体
# 支原体
1. 无细胞壁，最小的能自我复制的原核生物
2. 多数为致病菌
3. 没有细胞壁，膜含有甾醇
4. 菌落为油煎蛋状
5. 二分裂/出芽生殖
6. 渗透压敏感，营养需求高，基因组小
# 立克次氏体
1. 专性活细胞寄生
2. 有细胞壁，不能独立生活
3. 体内酶系不全，某些物质必须从宿主细胞获得
4. 部分可以通过细菌滤过器
# 衣原体
1. 专性活细胞内寄生
2. 有细胞壁
3. 缺乏ATP再生体系，最小的G-细菌
4. 细胞结构可以和细菌类似
5. 可以通过细菌滤器
6. 不耐热，可以耐受强低温
