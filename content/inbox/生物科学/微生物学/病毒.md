# 定义
1. 微小，不具有细胞结构
2. 只含有一种类型核酸
3. 严格在活细胞内寄生复制
4. 酶体系极不完全
5. 部分对干扰素敏感
6. 病毒粒：乘数，结构完整，有感染性的单个病毒
7. 形态
	1. 细胞外：颗粒形式，无自主代谢，无生命力但是有侵染力
	2. 细胞内：合成新的基因组&合成衣壳，依赖宿主合成物质，同时可以反过来指导代谢
# 繁殖方式
1. 感染
2. 病毒核酸复制&表达，合成新物质
3. 组装释放
# 特征
1. 30-300 nm，大部分只能通过电镜观察；存在巨大病毒
2. 化学组成
	1. 基本结构：核心（DNA/RNA）、衣壳（衣壳粒蛋白）
	2. 辅助结构：包膜（来自宿主细胞膜）、刺突
	3. 核心：只含有DNA/RNA，感染性核酸（具有感染性的病毒核酸，导入细胞可以启动病毒复制循环
3. 核酸：单链/双链RNA，基因组大小从670K到5k都有![[PixPin_2026-10-12_11-02-32.png]]
	1. ![[PixPin_2026-10-12_11-03-32.png]]
4. 进化速率极快
	1. RNA病毒缺乏纠错机制，变异更快
	2. 病毒间容易发生基因重组
	3. 自然选择和遗传漂变也影响病毒种群进化
5. 衣壳
	1. 蛋白
	2. 保护核酸，有抗原性
	3. 可以参与感染
6. 包膜
	1. 类脂、多糖、蛋白质等
	2. 双层膜
	3. 具有抗原性，可以参与病毒感染
7. 刺突：保护核衣壳，启动病毒感染
8. 病毒的对称性
	1. 螺旋对称or二十面体对称or复合对称
	2. 螺旋对称：亚基有规律的沿着中心轴螺旋排列
	3. 二十面体对称：正多面体的角和边
	4. 复合对称：噬菌体，头部二十面体对称，尾部螺旋对称
9. 酶
	1. 感染酶：噬菌体的裂解酶
	2. 聚合酶：RNA聚合酶、逆转录酶
	3. 帮助从宿主中释放：神经氨酸酶
# 研究方法
1. 形态&数量观察
	1. 电镜/X衍射
	2. 包涵体：病毒粒大量聚集使宿主细胞发生一定病变
	3. 噬菌斑（细菌病毒）
	4. 空斑（动物病毒）
	5. 枯斑（植物病毒）
2. 测定
	1. 双层平板法
	2. 免疫学方法（ELASA）
	3. RT-PCR
# 复制
1. 吸附：病毒配体+细胞受体特异性结合；特异性且不可逆
	1. 耐受方式：部分丢失DNA大片段
2. 侵入（病毒内化）
	1. 以噬菌体为例，其注射遗传物质进入细胞
	2. 尾部刺突固着，随后尾鞘收缩，核酸通过尾管压入细胞内，蛋白质外壳留在细胞外
3. 增殖
	1. 病毒利用宿主的生物合成磁场所，让病毒核酸复制表达
	2. 有强时序性![[PixPin_2026-10-12_11-48-38.png]]
4. 装配
	1. ![[PixPin_2026-10-12_11-50-54.png]]
5. 释放-离开细胞
	1. 细胞解体
	2. 出芽
6. 不分裂or出芽，病毒先消失后迅速增长
7. 一步生长曲线：潜伏期、裂解期、平稳期
	1. 潜伏期还分为隐晦期和成熟期：裂解后的裂解液是否具有感染性
	2. 潜伏期：噬菌体xx min；动植物病毒xx h or xx d
8. 动物病毒：类似的吸附-侵入-脱壳-复制-装配释放
	1. 吸附：
		1. 吸附蛋白/反受体：壳体蛋白（无包膜病毒）、包膜糖蛋白（有包膜）
		2. 细胞受体：被吸附蛋白特异性结合，介导进入细胞
	2. 侵入：
		1. 裸病毒通过特定受体转移
		2. 有包膜病毒和细胞膜融合
		3. 包膜病毒被胞吞
	3. 脱壳：
		1. 部分动物病毒的包膜在病毒进入受感染细胞时被除去
		2. 部分动物细胞壳体可以沿着细胞骨架移动，释放病毒基因组进入细胞核内
		3. T-偶数噬菌体：脱壳与侵入一起发生，仅病毒核酸和蛋白进入细胞，壳体留在细胞外
		4. 非感染性核酸病毒：均不完全脱壳，以核蛋白体形式复制
	4. 复制增殖：![[PixPin_2026-10-19_11-01-10.png]]
	5. 释放：
		1. 无包膜病毒：细胞裂解直接释放
		2. 有包膜：通过细胞质通道释放
		3. 部分病毒直接出芽释放

# 多样性
1. 噬菌体
	1. 形态结构：![[PixPin_2026-10-19_11-15-34.png]]
	2. 烈性噬菌体：短期完成五个阶段，正常复制杀死细菌
	3. 温和噬菌体：感染细胞后不能完成循环，基因组被整合到宿主上![[PixPin_2026-10-19_11-16-44.png]]
		1. 特点：都是dsRNA、能整合、能同步复制
		2. 存在形式：游离、整合、营养
		3. 溶原性：侵染细菌后不引起宿主降解，反而和宿主共存
		4. 可以结合一个位点/多个位点
	4. $\lambda$噬菌体的溶原反应：
		1. 溶原途径基因转录3个阶段：极早期、晚早期、晚期。晚期产生阻遏蛋白CI，与左右两个操纵子结合，阻断基因和蛋白表达，不能产生子代噬菌体，DNA整合到宿主基因组中，成为前噬菌体，不影响宿主生长
	    2. 早期基因表达，产生CRO、CII及CIII（防止宿主裂解酶对降解CII）
	    3. CII促使阻遏蛋白CI的表达，CI导致噬菌体基因转录终止，形成原噬菌体
	    4. 早期表达CRO与CI的竞争确定λ噬菌体进入溶原状态还是进入裂解循环
	    5. CI抑制其它新侵入的λ噬菌体的表达，使溶原性细菌具有一定“免疫性”
	    6. CI通常通过自身的转录激活保持低水平的表达，偶然转录水平下降时偶尔导致溶原性噬菌体进入裂解循环
	    7. ![[PixPin_2026-10-19_11-34-28.png]]
	5. 判断溶原反应方法：与敏感性指示菌混合后倒平板
# 亚病毒
1. 只含有一种RNA或只有蛋白质构成的分子病原体，或由缺陷病毒构成的功能不完全的病原体
2. 类病毒
	1. 最小、最简单、可卡因自主复制的可以传染的致病因子
	2. 只有环状ssRNA，专性细胞内寄生
	3. 可以在敏感细胞内自我复制
	4. 完全依赖宿主细胞酶
3. 卫星病毒
	1. 基因组缺失，需要专一转移辅助病毒（伴生）
	2. 与辅助病毒没有同源性，无法独立感染，只能编码自身蛋白
4. 卫星核酸
	1. 完全依赖辅助病毒才能复制
	2. 多个卫星RNA可以共存于辅助病毒衣壳内
	3. 无独立侵染性、无同源性、可以干扰病毒复制
5. 朊病毒
	1. 不含核酸的传染性蛋白质
	2. 可以在宿主细胞内复制
	3. 呈淀粉颗粒状、无免疫原、无核酸、抗逆性极强
