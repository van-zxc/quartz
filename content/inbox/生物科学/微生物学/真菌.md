# 细胞壁
1. 多糖，少量蛋白质+脂质
2. 低等：纤维素、酵母：葡聚糖、高级：几丁质
# 运动
1. 鞭毛长而少、纤毛短而多
2. 鞭毛：
	1. 基体着生于质膜，9+0型，中央没有微管和鞘
	2. 鞭杆：9+2型，1对中央微管+9个微管二联体
# 细胞膜
1. 有固醇（胆固醇、麦角固醇等）
2. 磷脂酰胆碱+磷脂酰丝氨酸
3. 表面有糖脂，可以胞吞
# 细胞质

# 酵母
## 特点
1. 个体一般以单细胞非菌丝状态存在
2. 多数营出芽繁殖
3. 兼性厌氧，能发酵糖类产能
4. 细胞壁常含甘露糖
5. 常生活在含糖量较高、酸度较大的环境中
## 形态
1. 假菌丝：连串的细胞组成的看着像菌丝的东西，藕节状
2. 假丝酵母：和子代细胞组成的形成
3. 真菌丝：链接紧密

## 细胞核
1. 细胞核DNA+线粒体DNA
2. 2 μm DNA：1967年在S.cerevisiae的细胞核中发现的，是一个闭合环状超螺旋DNA分子，长约2 μm（6 kb）
## 繁殖
1. 芽殖：细胞一段生成一个小突起（芽体），膨大后和母体分离；不脱离母体继续出芽则形成假菌丝
2. 裂殖：二分裂生殖
3. 无性孢子生殖：
	1. 掷孢子：外表呈肾状，在卵圆形营养细胞上生成小梗、随后在其上形成掷孢子，成熟后通过特有喷射机制射出
	2. 节孢子：地霉属酵母，短柱状或筒状，或两端钝圆的细胞，称为节孢子
	3. 厚垣孢子：只不过花呗诡异赌博管得严发生局部细胞质浓缩和细胞壁加厚，抗逆性强

5. 生活史：![[PixPin_2026-09-28_11-04-01.png]]
## 菌落
1. 较温润光滑，有一定透明度
2. 单细胞球状或椭圆状
3. 容易挑起，有酒香
4. 部分酵母菌落可能产生较大、较厚、外观较稠、较不透明等有别于细菌的菌落

# 霉菌
## 特点
1. 霉菌是丝状真菌的俗称
2. 由分枝或不分枝的菌丝构成；许多菌丝交织在一起，称为菌丝体
3. 引起霉变
4. 菌丝体发达，但不产生大型子实体
# 菌丝
1. 直径3-10 μm，比放线菌粗
2. 许多菌丝纠缠在一起为菌丝体
3. 某些病原真菌在菌丝态和酵母态之间互变，称为二相性真菌
4. 无隔菌丝/有隔菌丝
	1. 无隔：低等
	2. 有隔：高等
5. 菌丝隔膜：![[PixPin_2026-09-28_11-18-30.png]]
6. 营养/气生菌丝
	1. 营养：生长于培养基内部，吸收营养
	2. 气生：伸向空气，分化
	3. ![[PixPin_2026-09-28_11-21-26.png]]
7. 特化营养菌丝体：
	1. 吸器：专性寄生真菌形成，菌丝形成旁枝，侵入寄主细胞内吸收养料，有球状、根状和指状
	2. 菌环：捕虫类真菌的特化菌丝，可捕捉小型原生动物或无脊椎动物，菌丝穿入体腔，吸取营养
	3. 菌网：菌环构成的网状组织
	4. 匍匐菌丝/假根
	5. 附着胞/附着枝
	6. 菌核：一种休眠的菌丝组织，由菌丝密集地交织在一起，其外层坚硬、色深，内层疏松，大多呈白色（还有假菌核：寄生真菌+宿主共同形成）

	5. 担子菌担子：锁状联合（双核菌丝细胞进行特殊分裂），分裂时顶端膨大为担子（单倍体）
