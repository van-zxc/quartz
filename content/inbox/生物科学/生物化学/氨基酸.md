蛋白质内的氨基酸$\neq$核糖体下来的氨基酸（磷酸化修饰 糖苷化修饰etc.） 核糖体下来的氨基酸称为一级氨基酸（只有20种 可以+硒代半胱氨酸 只有这些可以掺入t－RNA）

# 氨基酸
羧基+氨基 蛋白质+强酸/强碱水解后可以得到各种氨基酸
22种一级氨基酸名称&符号：==全背！！（英语 缩写 中文 字母缩写）==

# 基本结构
+ $\alpha$碳是手性碳 $sp^{3}$杂化 链接在$\alpha$上的基团称为手性基团/$\alpha$基团
+ 任何都有一个$\alpha$氨基和$\alpha$羧基 一个$H$ 剩下一个残基$R$
+ 疏水性氨基酸不是重点！==考具有生理活性的氨基酸==

# 分类
除了甘氨酸 至少一个$\beta$碳
+ 非极性基团（疏水，在水中倾向于抱团 故R实际不甚重要，只是大小和长短有区别）：
	+ 甘氨酸：R=氢 甜味增强剂 最简单的氨基酸(G)
	+ 丙氨酸：R=甲基（A 三个碳）
	+ 缬氨酸：R=异丙基（V）
	+ 亮氨酸：R=甲基+异丙基（L）
	+ 异亮氨酸：R=亮氨酸异构（I）
	+ 甲硫氨酸：R=CH2CH2SCH3（M）
		>腺苷甲硫氨酸：提供甲基 活跃参与反应
+ 芳香族：（可以吸收紫外光）
	+ 苯丙氨酸：R=苯甲基  代谢失常$\to$苯丙酮尿症（F）
	+ 酪氨酸：R=4－羟基苯基  可以代谢为黑色素（Y）
		>酪氨酸是多巴 真黑素 褐黑素的前体
	+ 色氨酸：R=丙氨酸+吲哚基团（可以吸收紫外光 W）  ==强烈吸收280nm紫外光==
		>[[朗伯比尔定律]]
		>分光光度计：测量一定波长范围内光的吸收度
		>吸光光度计：有色溶液对某一个波长光的吸收情况
+ 极性不带电：
	+ 丝氨酸：R=羟基甲基（S）
	+ 苏氨酸：R=1－羟基乙基，多了一个$\gamma$位的甲基（T）
		>很容易亲核反应，容易磷酸化（带电荷）  很容易改变蛋白质构象$\to$信号传导
		>可以互换
	+ 半胱氨酸：硫代丝氨酸，容易作为亲核试剂。可以氧化形成二硫键，改变蛋白质构象  胱氨酸溶解度低（C）
	+ 脯氨酸：$\alpha-$亚氨基酸，具有极其特殊的环状侧链基团，且非常容易溶于水，能够对抗外界的渗透压上升（P）
		> 溶解度反常极大(1.62g/ml), 被广泛用作渗透保护剂(不管是渗透胁迫下的植物自身还是实验)
+ 极性带正电：
	+ 赖氨酸：R=$\epsilon-$氨基  必需氨基酸（K）
	+ 精氨酸：R=$\delta-$胍基（R）
	+ 组氨酸：R=咪唑基，可以吸收和释放质子(有碱性，也可以和二价金属离子进行配位（H）
+ 极性带负电：
	+ 天冬氨酸：R=甲基羧基，一般在生理情况下为xx盐  鲜(D)
	+ 谷氨酸：R=乙基羧基，味之素（E）
	+ 天冬酰胺(N)和天冬氨酸(Q)、谷氨酰胺和谷氨酸都非常容易互换！
+ 硒代半胱氨酸：替代掉了巯基的半胱氨酸(U)
	> 亲核性更加强，参与甲状腺素氧化还原去碘。相对保守. 常常参与还原性酶系的结构, 是强有力的还原剂口牙! 
+ 吡咯赖氨酸：古细菌中特殊酶。从核糖体中掺入进去在产甲烷菌中含有特异的吡咯赖氨酰-tRNA合成酶(PVRS)和吡咯赖氨酸tRNA(tRNAPy), tRNAPyl结构和经典tRNA不同

# 其他氨基酸（非一级） 
## 翻译后修饰

1. 羟基化修饰：4/5－羟基脯氨酸$\to$出现氢键  大量出现在胶原蛋白
2. 甲基化：赖氨酸侧链氨基（组蛋白 与带负电DNA结合），不影响电荷
3. 乙酰化修饰：从正电荷变为0电荷，导致DNA展开，促进转录
4. $\gamma$位羧基化(凝血酶)&磷酸化(信号转导)
5. 谷氨酸&焦谷氨酸(增加乙酰胆碱合成, 神经肽的N端)

理论也可以掺入D型氨基酸，也可以形成异肽键

## 游离性氨基酸  ==不重要==

1. 鸟氨酸：存在于精氨酸生物合成过程
2. 瓜氨酸：存在于尿素循环中
3. 5－羟色氨酸：血清素（5－羟色胺）和褪黑素的前体, 由酪氨酸代谢而来
4. 高丝氨酸&高半胱氨酸, 多一个亚甲基
5. 酪氨酸$\to$多巴$\to$多巴胺$\to$去甲肾上腺素$\to$肾上腺素
6. 谷氨酸$\to$$\gamma$氨基丁酸$\to$左旋肉碱（帮助脂肪酸进入线粒体内膜氧化）
7. 酪氨酸→三碘甲腺原氨酸→甲状腺素

# 酸碱性
+ 无色晶体，熔点比较高，水中溶解度不同
+ 可以通过280nm吸收来判断是否有芳香族氨基酸（尤指==色氨酸==）
+ 两性电解质。当所带电荷总量为0时，外界pH为等电点  ==amphoteric两性氨基酸！==
+ 偏离pH=2时可以认为完全质子化/去质子化（H－H方程，一般不考）
+ 组氨酸主要发挥稳定pH的作用，可以吸收/释放质子
+ 天冬氨酸&谷氨酸在某种微环境下可以自由释放/吸收（线粒体ATP合成酶）
+ 判断蛋白质电荷：pX小则作为酸

# 氨基酸混合物分离

+ 最简单：茚三酮(0.2% 95%EtOH溶液)

## 层析
混合物在两相之间进行分配。一项流动相，一相固定相。不同组分在固定相内滞留时间不同，故可以依次流出。
不断在两相之间进行分配，从而进行分离

某一个溶质在两相之间比例为一个定值——==分配系数==（K_d)记忆英语
几种极端可能：均在流动相、完全分离开和均被固定

流动相分配次数越多，淀粉不越接近正态分布。单向过程中被累计。且样品相对于其直径==越少越好==

故技术路径：
1. 加大口径
2. 内部固定相粒径越来越小
3. 加压

滤纸层析：便宜直观，利用茚三酮观察氨基酸路径，Rf值（氨基酸路径/有机溶剂路径） 先进行预实验   一维若区分不了则可以进行二维双向纸层析

离子交换层析：利用静电作用进行区分，拉大分配系数
	阴离子交换柱：交换阴离子，自身带==正电荷==——强：季胺基团/弱：叔胺基团
	反之 阳离子交换柱带负电荷——强：磺酸/中：磷酸/弱：酚基羧基
	什么都不知道时使用中等
	离子交换凝胶
气相：把氨基酸汽化能够拉长柱子长度，便于区分
	经过PITC处理后再经过三甲基硅烷基化, 可以很好的汽化, 便于操作.
