# 氨基酸

羧基+氨基 蛋白质+强酸/强碱水解后可以得到各种氨基酸

22种一级氨基酸名称&符号：==全背！！（英语 缩写 中文 字母缩写）==

# 基本结构

+ $\alpha$碳是手性碳 $sp^{3}$杂化 链接在$\alpha$上的基团称为手性基团/$\alpha$基团
+ 任何都有一个$\alpha$氨基和$\alpha$羧基 一个$H$ 剩下一个残基$R$
+ 疏水性氨基酸不是重点！==考具有生理活性的氨基酸==

# 分类

除了甘氨酸 至少一个$\beta$碳
+ 非极性基团（疏水，在水中倾向于抱团 故R实际不甚重要，只是大小和长短有区别）：
	+ 甘氨酸：R=氢 甜味增强剂 最简单的氨基酸
	+ 丙氨酸：R=甲基（A 三个碳）
	+ 缬氨酸：R=异丙基（V）
	+ 亮氨酸：R=甲基+异丙基（L）
	+ 异亮氨酸：R=亮氨酸异构（I）
	+ 甲硫氨酸：R=CH2CH2SCH3（M）
		>腺苷甲硫氨酸：提供甲基 活跃参与反应
+ 芳香族：（可以吸收紫外光）
	+ 苯丙氨酸：R=苯甲基  代谢失常$\to$苯丙酮尿症
	+ 酪氨酸：R=4－羟基苯基  可以代谢为黑色素
	+ 色氨酸：R=丙氨酸+吲哚基团（可以吸收紫外光）  强烈吸收280nm紫外光
		>==[[朗伯比尔定律]]==
		>分光光度计：测量一定波长范围内光的吸收度
		>吸光光度计：有色溶液对某一个波长光的吸收情况
+ 极性不带电：
	+ 丝氨酸：R=羟基甲基
	+ 苏氨酸：R=1－羟基乙基，多了一个$\gamma$位的甲基
		>很容易亲核反应，容易磷酸化（带电荷）  很容易改变蛋白质构象$\to$信号传导
		>可以互换
	+ 半胱氨酸：硫代丝氨酸，容易作为亲核试剂。可以氧化形成二硫键，改变蛋白质构象  胱氨酸溶解度低
	+ 脯氨酸：$\alpha-$亚氨基酸，具有极其特殊的环状侧链基团，且非常容易溶于水，能够对抗外界的渗透压上升
+ 极性带正电：
	+ 赖氨酸：R=$\epsilon-$氨基  必需氨基酸
	+ 精氨酸：R=$\delta-$胍基
	+ 组氨酸：R=咪唑基，可以吸收和释放质子，也可以和二价金属离子进行配位
+ 极性带负电：
	+ 天冬氨酸：R=甲基羧基，一般在生理情况下为xx盐  鲜
	+ 谷氨酸：R=乙基羧基，味之素
	+ 天冬酰胺和天冬氨酸、谷氨酰胺和谷氨酸都非常容易互换！
+ 硒代半胱氨酸：替代掉了巯基的半胱氨酸，亲核性更加强，参与甲状腺素氧化还原去碘。相对保守
+ 吡咯赖氨酸：古细菌中特殊酶。从核糖体中掺入进去

必需氨基酸：甲硫氨酸、色氨酸、赖氨酸、缬氨酸、异亮氨酸、亮氨酸、苯丙氨酸、苏氨酸（分支氨基酸，芳环氨基酸）   半胱氨酸、酪氨酸、组氨酸、精氨酸 婴幼儿需要

# 其他氨基酸（非一级） 
## 翻译后修饰

1. 羟基化修饰：4/5－羟基脯氨酸$\to$出现氢键  大量出现在胶原蛋白
2. 甲基化：赖氨酸侧链氨基（组蛋白 与带负电DNA结合），不影响电荷
3. 乙酰化修饰：从正电荷变为0电荷，导致DNA展开，促进转录
4. $\gamma$位羧基化&磷酸化
5. 谷氨酸&焦谷氨酸

理论也可以掺入D型氨基酸，也可以形成异肽键

## 游离性氨基酸  ==不重要==

1. 鸟氨酸：存在于精氨酸生物合成过程
2. 瓜氨酸：存在于尿素循环中
3. 5－羟色氨酸：血清素（5－羟色胺）和褪黑素的前体
4. 高丝氨酸&高半胱氨酸
5. 酪氨酸$\to$多巴$\to$多巴胺$\to$去甲肾上腺素$\to$肾上腺素
6. 谷氨酸$\to$$\gamma$氨基丁酸$\to$左旋肉碱（帮助脂肪酸进入线粒体内膜氧化）

# 酸碱性

+ 无色晶体，熔点比较高，水中溶解度不同
+ 可以通过280nm吸收来判断是否有芳香族氨基酸（尤指==色氨酸==）
+ 两性电解质。当所带电荷总量为0时，外界pH为等电点  ==amphoteric两性氨基酸！==
+ 偏离pH=2时可以认为完全质子化/去质子化（H－H方程，一般不考）
+ 组氨酸主要发挥稳定pH的作用，可以吸收/释放质子
+ 天冬氨酸&谷氨酸在某种微环境下可以自由释放/吸收（线粒体ATP合成酶）
+ 判断蛋白质电荷：pX小则作为酸
