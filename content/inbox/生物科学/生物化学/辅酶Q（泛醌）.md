# 结构
结构如下：
![[PixPin_2026-06-07_09-31-42.png]]
辅酶 Q 在细胞线粒体氧化磷酸化过程中发挥作用，辅助生成（ATP），ATP 参与细胞内的能量转移。 辅酶 Q 的结构由苯醌部分和异戊二烯侧链组成，数字指的是其尾部异戊二烯亚基的数量。

异戊二烯长链决定其脂溶性，其来自于乙酰辅酶A。
# 功能
1. 可以充当抗氧化剂，和维生素E一起帮助清除细胞内活性氧
2. Q3在溶酶体质膜上转运质子以维持PH
3. 将电子从线粒体复合物传递到ETC的泛醇-细胞色素c还原酶（复合物 III），从而将脂肪酸和支链氨基酸氧化（通过黄素连接的脱氢酶）到ETC的泛醌-细胞色素c还原酶（复合物 III）
4. CoQ在呼吸链中接受黄素酶的H，本身被还原为氢醌，再把电子传递给Cyt体系被氧化，接受1e变为自由基半醌，接受2e变为对苯二酚（QH2）。
