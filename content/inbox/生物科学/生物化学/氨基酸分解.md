# 氧化脱氨
1. 生成一个亚胺，然后变为酮酸
	1. 黄素蛋白酶催化FADH2夺走两个电子形成亚胺，同时经过电子传递给到氧气，最终配合铁硫蛋白生成过氧化氢
	2. 亚胺在酸性溶液内自然转变为酮
2. 氨基酸氧化酶：
	1. 黄素蛋白酶，三种亚型
	2. L-氨基酸氧化酶，分布不广、活力低，以FAD/FMN为辅基（人和动物）。对Gly、L-Ser、L-Thr、L-Glu、L-Asp、Lys、Arg、鸟氨酸无作用。
	3. D-氨基酸氧化酶
	4. 专一性氨基酸氧化酶（Glu氧化酶、Asp氧化酶）
	5. L-谷氨酸脱氢酶（GDH）：使用NAD+脱掉氨基生成$\alpha$-酮戊二酸，GTP为变构抑制剂；同时可以逆反应生成谷氨酸（消耗NADPH）
3. 转氨作用
	1. 转氨酶催化，消耗NAD+
	2. 一个L-氨基酸的a-NH2转移到一个a-酮酸上使之变成相应的L-氨基酸，自身转变为相对应的a-酮
	3. 酶均以[[维生素B6|磷酸吡哆醛]]PLP为辅基，共价结合于酶上
	4. Lys, Arg, Thr, Pro不能通过转氨酶转氨。
	5. 脱氨过程
		1. 酶上的磷酸吡哆醛和赖氨酸残基配合形成内亚胺
		2. 当外界氨基酸进攻时，内亚胺解开，磷酸吡哆醛和氨基酸的氨基结合成醛亚胺
		3. 醛亚胺通过电子重排形成醌类中间体
		4. 随后反应分为两步：脱氨或脱羧；若脱氨，则被水进攻，形成磷酸吡哆胺+$\alpha$-酮酸

	6. 上氨过程
		1. 脱氨反应的逆反应
# 其他脱氨方式
1. 联合脱氨
	1. 简单来说，就是转氨酶将其他氨基酸的氨基转移到$\alpha$-酮戊二酸上形成谷氨酸
	2. 在胞质内聚集的大量谷氨酸被转运进线粒体，随后被L-谷氨酸氧化酶氧化为酮戊二酸，同时释放出NH3
	3. 在减少体内专职氨基酸分解酶量的同时，做到充分利用L-谷氨酸氧化酶的高效率
2. 嘌呤-核苷酸联合脱氨
	1. 参见[[核酸代谢]]中的部分
	2. 简单来说，转氨酶把天冬氨酸的氨基上到次黄嘌呤嘌呤环上形成腺嘌呤代琥珀酸
	3. 随后腺嘌呤水解为次黄嘌呤，同时释放出游离氨
# 脱羧
1. 在脱氨反应时不同，并没有断裂C-H键，而是选择断裂C-COOH键
2. 脱羧反应无广谱酶，特异性极强；除His外其他都需要磷酸吡哆醛作为辅酶
3. 主要产物
	1. 组氨酸→组胺：降胃酸，过敏反应
	2. 酪氨酸→酪胺
	3. 谷氨酸→GABA：广为人知的抑制性神经递质
