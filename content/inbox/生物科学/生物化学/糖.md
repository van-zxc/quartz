# 分类
+ 单糖: 不可水解为其他糖的糖(丙糖, 丁糖, 戊糖, 己糖)
	+ 只有一个手性碳不一样的: 差向异构体 ==epimers==
	+ 一般醛糖居多, 但是也有酮糖
+ 寡糖: 可以水解为其他糖的糖(大约2~10左右)  二糖, 三糖及其他寡糖
+ 多糖: 同多糖(同一种单糖构成)/杂多糖(不同单糖/单糖衍生物)
+ 糖的衍生物: 糖的氧化还原产物, 氨基取代物, 糖苷化合物等
+ 多糖复合物: 糖蛋白, 糖脂, 蛋白多糖etc.

# 糖苷
半缩醛处羟基可以和酸酯化, 使得糖类的还原性失去. 该羟基比较活泼, 可以和其他分子的羟基反应, 缩去一分子水, 形成糖苷. 称糖苷键. 糖成苷后无变旋现象, 无还原糖反应. 

在酸催化下只有半缩醛羟基才可以和醇形成醚键
碱性条件下稳定, 可以使用温和酸性条件水解, 然而普通醚键稳定
酶可以促使糖苷水解
糖脎反应: special 特征
糖递增反应: Kiniani氰化增碳法
差向异构化: 可以进行简单的构型变换

# 寡糖
+ 麦芽糖: 一分子$\alpha$葡萄糖和一分子$\beta$葡萄糖形成麦芽糖. 没有破坏半缩醛羟基
+ 蔗糖: 一分子$\alpha$葡萄糖和一分子$\beta$果糖形成糖苷键. 半缩醛羟基被破坏. 
+ 乳糖: $\beta$半乳糖和$\beta$葡萄糖形成$\beta$ 1,4糖苷键, 半缩醛羟基保留
+ 纤维二糖: 两个$\beta$葡萄糖形成糖苷键($\beta$ 1,4糖苷键)
+ 海藻糖
+ 棉子糖: 缓冲作用, 形成水解形成$\alpha$葡萄糖, $\alpha$半乳糖和$\beta$果糖

	+ 鞘糖脂, 甘油糖脂, 类固醇衍生糖脂
	+ 细胞膜上组分, 作为糖蛋白特异性识别位点

	+ 凝集素: 特异性识别糖蛋白/糖脂中复杂的糖基结构, 具有唯一性
