# 结构
![[PixPin_2026-06-12_19-27-30.png]]
1. 主要由环戊烷多氢菲骨架构成
	1. 平面甾核+一个极性羟基+一个疏水尾端构成
	2. 刚性强, 保证细胞膜抗变形能力
	3. 可以和[[鞘磷脂代谢|鞘脂]]共同组成脂筏，在细胞膜表面游弋，帮助信号转导和内吞
# 消化吸收
1. 再循环系统：
	1. 经胆汁或部分经胆汁排入肠道的物质，如胆固醇、胆汁酸、胆红素等在肠道中被重新吸收，经门静脉又返回肝脏重新利用
	2. 胆固醇由肠肝循环回收, 可以往复循环
	3. 可能有肠道菌群代谢, 即次级代谢胆汁酸
2. 来源
	1. 饮食中胆固醇通过乳糜微粒&LDL摄入
	2. 肝脏合成（>85%）
	3. 回收利用、其他组织合成等
3. 去路
	1. 分泌HDL或VLDL
	2. 被分泌入胆汁，随后排出体外
	3. 在肝脏内被代谢为胆酸（盐）
4. 吸收延迟且有限

### 类固醇激素
![[PixPin_2026-06-12_19-55-43.png]]
1. 胆固醇侧链的20,22号碳之间被肾上腺皮质铁氧化还原蛋白加了两个氧，生成2NADPH，同时生成两个羟基
2. 随后受碳链裂解酶催化，20和22之间碳链断裂，生成两个羰氧键；裂解生成异己酮+孕烯醇酮
3. 孕烯醇酮随后被光面内质网上的$3\beta$-羟基类固醇脱氢酶/$4,5$-异构酶（$3\beta\text{-HSD}$）复合体进行两步反应：3号碳的羟基变为羧基，同时将C5-C6的双键变为到C4-C5处，形成孕酮
4. 性激素的合成
	1. 底物为孕酮，在17号碳上引入叔羟基，随后脱掉乙酰基的同时将羟基氧化，形成雄甾二酮
	2. 雄甾二酮可以直接在芳香化酶的作用下，生成雌激素酮
	3. 雄甾二酮也可以先将17C的羰基还原为羟基生成睾酮，随后再芳香化睾酮生成雌二醇
### [[维生素D]]
1. 在光面内质网上，胆固醇氧化为7-脱氢胆固醇（增添了一个双键、形成了共轭烯烃），随后被大量运输至皮肤的下表皮部分
2. 紫外线照射下，C9-C10之间的单键裂开，多余的两个电子在C5-C10形成双键，即形成三个共轭的前维生素D3，随后自发的扭转为维生素D3随后被转运到肝脏
3. 在肝脏,25号位修饰上一个羟基，增加水溶性；随后被转移到肾脏
4. 最后在C1位引入一个羟基，形成骨化三醇
5. 若一开始的底物不是胆固醇而是麦角硫醇，则生成维生素D2
### 胆固醇酯
1. 脂酰辅酶A-胆固醇脂酰转移酶（ACAT）
	1. 催化胆固醇和长链脂酰CoA链接形成胆固醇酯
	2. 和动脉粥样硬化强相关

# 从头合成
1. 原料：乙酰CoA
2. 场所：肝脏细胞质/内质网
3. ![[PixPin_2026-06-12_20-47-45.png]]
4. 过程
	1. ![[PixPin_2026-06-12_20-37-19.png]]
	2. 乙酰CoA合成甲羟戊酸（[[酮体代谢#^9eef2b]]感谢曾经的我...）
		1. 不过值得注意的是，后半段还是不一样的
		2. 在HMG-合成酶作用后，HMG-CoA还原酶使用2 NADPH还原羧基为伯羟基，同时放出CoA，合成甲羟戊酸（MVA）
	3. 甲羟戊酸活化为异戊烯焦磷酸酯
		1. 被两个kinase激活的ATP上两个磷酸基团变为甲羟戊酸焦磷酸酯
		2. 随后再3号碳上的羟基上一个磷酸活化羟基
		3. 被活化的羧基在焦磷酸甲羟戊酸脱氢酶作用下脱去，在电子重排及共轭效应作用下合成异戊烯焦磷酸
	4. 角鲨烯合成
		1. 异戊烯焦磷酸（IPP）有共振体——二甲基烯丙基焦磷酸（DMAPP），分别为电子供体和电子受体
		2. 在法尼基焦磷酸合酶的作用下，DMAPP脱去焦磷酸被活化形成碳正离子，随后异戊烯焦磷酸作为亲电试剂进攻，首尾相连合成香叶基焦磷酸，继续作用形成法尼基焦磷酸（15C）
		3. 两分子法尼基焦磷酸在内质网内，被角鲨烯合酶及2 NADPH作用面对面链接，脱去焦磷酸，形成单键，即角鲨烯（30C）
	5. 胆固醇合成
		1. 角鲨烯环氧化酶在最底部的双键引入一个环氧基，消耗NADPH和氧气。众所周知环氧基高能量，为后续关环铺垫
		2. 羊毛甾醇合酶提供酸性环境导致环氧基变为羟基，过程中产生的碳正离子进攻旁边的另一个双键，导致另一个碳正离子的产生......如此循环往复，最终全部关环，形成羊毛甾醇
		3. 在细胞色素P450酶系的作用下，羊毛甾醇主要发生以下三步反应：
			1. 脱去C4的两个甲基、脱去C14的一个角甲基，将30C体系缩减为27C
			2. 将双键从C8-C9移动至C5-C6
			3. 把侧链全部还原
	6. 胆固醇成功合成！！
### 合成调节
1. 受胞内胆固醇浓度和激素浓度影响
2. 主要限速步：HMG-CoA合成MVA
	1. HMG-CoA还原酶催化
	2. 受胆固醇衍生物及MVA的变构抑制
	3. 磷酸化失活（激素影响，胰岛素促进）
3. 高的胞内胆固醇浓度激活ACAT，促进胆固醇酯化
4. 高的胞内胆固醇浓度引起LDL受体减少，减缓向血液中吸收胆固醇
5. ![[PixPin_2026-06-12_21-09-27.png]]
6. 他汀类药物抑制胆固醇合成
	1. 结构类似HMG-CoA，竞争性结合还原酶的活性位点
# 脂蛋白
1. 乳糜微粒（CM），电泳位置在原点，直径最大，比重最小，含脂比例98%；转运外源性三酰甘油和胆固醇到全身
2. b-前脂蛋白，电泳出现在a2-球蛋白处，直径及含脂比例（90%）仅次于CM，比重大于CM，相当于VLDL；转运内源性脂肪到全身
3. b-脂蛋白，电泳出现在b-球蛋白处，直径及含脂比例（70%）小于前两者，相当于LDL；转运内源性胆固醇从肝到全身各组织
4. a-脂蛋白，电泳出现在a1-球蛋白处，直径及含脂比例（67%）次于前三者，比重最大，相当于HDL；转运胆固醇从身体各部位到肝

疾病？
胆结石：胆固醇溶解度过低导致析出
动脉粥样硬化：动脉内膜形成的胆固醇斑纹造成动脉的粥样硬化。患者血液胆固醇/磷脂升高，脂质向动脉内膜浸润而粘着于血管壁，形成动脉粥样斑
