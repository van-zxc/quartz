空间结构决定活性和理化性质. 

可以理解为：蛋白质有部分不能运动的“骨架”和可以运动的“关节”

测定三维结构: 
+ X-ray(结晶很困难)  
+ NMR: 小蛋白, 动态分子
+ 冷冻电镜: 可膜蛋白

球状蛋白可溶于水, 而纤维状蛋白不溶于水. 

一部分蛋白质可以自行折叠, 另一部分蛋白需要其他因子帮助进行折叠. 若因子消失则蛋白折叠构象会有问题. 

任何的蛋白质都有唯一的构型, 但是构象不唯一(但是在某特定条件下能量最低的构象是唯一的, 不管是单独还是有配体). 这称为所谓的"唯一三维结构". 此种稳定情况蛋白质一般是热力学最稳定的构象. 

弱作用力↑↑就是自由能↓↓

作用力:
+ 氢键: $\alpha$螺旋/$\beta$折叠→尿素, 盐酸胍
+ 疏水作用: 球蛋白→去垢剂, 有机溶剂   驱使蛋白质折叠(避免水在外侧形成有序结构, 降低熵值)
+ 离子键: 三四级结构→酸碱
+ 二硫键: xxx→还原剂
+ 配位键: 四级结构→螯合剂EDTA
+ 范德华力: 主要排斥 阻止原子过近, 稳定分子构象
# 蛋白质二级结构
不依赖侧链结构! 完全来自肽链之间的相互作用. ==如果没有侧链干扰，将会形成单一骨架。直到侧链破坏了二级结构==. 没有那么稳定. 

主化学键: 氢键
### 肽键
+ C-N之间组成$p-\pi$共轭
+ 组成肽键的原子处于同一平面, 有一定共轭性质, 肽键不能随意旋转! 
+ 一般以==反式==结构存在

### 肽平面
肽键导致肽平面, 而$\alpha$碳原子作为旋转点形成二面角. 二面角变化导致不同三维构象基础
绕$N-C_{\alpha}$键轴旋转的二面角为$\phi$, 绕$C_{\alpha}-C$旋转的二面角叫$\psi$.

两个角为180°时最为舒展. 

Ramacandran图: 计算出$\phi$和$\psi$的可能接受范围. 
### $\alpha$螺旋
主链随着中心轴右手螺旋上升. 每隔3.6氨基酸上升一圈, 螺距0.54nm. 每个氨基酸0.15nm. 每个肽键的N-H和第四个肽键的羧基氧形成氢键. 方向和长轴平行. 一个环13个分子. 
左手螺旋极少

前后相差3个原子
破坏者: 
+ 连续同种电荷的极性氨基酸
+ 庞大侧链的氨基酸(Ile)
+ Pro(产生结节, $\phi, \psi$角的区别) Gly(过于活跃)
+ 由于肽键的方向性, 导致末端的N带正电, O带负电. 可以使用金属离子在C端带正电稳定
### $\beta$折叠
+ 同一蛋白/多蛋白均可. 
+ 类似百褶裙, 相邻氨基酸贴紧, 水分子难以进入导致疏水性. 故难溶于水. 
+ 侧链之间存在氢键. 
+ 氨基酸侧链交替处于锯齿状结构的上下方, 因此相对稳定
+ $\beta$折叠平行/反平行均可. 平行折叠不断在旋转角度, 有一定弯曲. 反平行稳定程度>平行

空间特征: 
+ $\beta$构象中, 多肽主链为锯齿状构象, $C_{a},C_{\beta}$为互相垂直于平面. 
+ 平行构象重复周期为0.65nm, 反平行构象为0.7nm(周期为2)
### $\beta$转角
4个氨基酸, 180°转折形成的结构
四个氨基酸, 第一个O和第四个H形成氢键
出现于球蛋白的表面, 中间氨基酸可以和水形成氢键. 
Gly和Pro常出现在$\beta$转角(Pro肽键为顺式结构, 进行过翻译后修饰 由PPI酶指导修饰
)
### 无规则卷曲
EF hand structure. 可以感受钙离子. 
# 纤维状蛋白
往往结构蛋白, 结构高度重复. 
eg. 角蛋白, 丝心蛋白, 胶原蛋白
### 角蛋白
身体外部, 皮肤及其衍生物. $\alpha$-角蛋白
$\alpha\alpha$超二级结构: 两个右手螺旋组成的左手螺旋. 
### 丝心蛋白
反平行$\beta$折叠. 
### 胶原蛋白
胶原纤维形式, 基本单位是原胶原蛋白分子
三条多肽链形成的三姑螺旋. 
96%按照三联体(Gly-X-Y)$_{n}$组成, X通常为Pro, Y为(3,4)Hypro或(5)Hylys
加羟基需要亚铁离子, VC可以防止亚铁离子防止被氧化. 
# 超二级结构&结构域(domain)
超二级结构: 通过二级结构简单组合的结构. eg. $\alpha\alpha$, $\beta\beta\beta$等等
### Domain
在三维蛋白质中空间相对独立, 可以具有一定的生物学功能. 
motif: 基序. 在一级结构中相对恒定的结构, 是组成的一个部分. 
eg. Klenow fragment
# 四级结构
即蛋白质和蛋白质之间, 蛋白质和其他分子之间的复合.
