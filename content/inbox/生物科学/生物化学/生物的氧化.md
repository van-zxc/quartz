# 特征酶
## 脱氢酶
使得代谢物的氢活化脱离, 传递给其他受氢体/传递体. 
绝大部分脱氢酶需要$NAD^{+}$或者$NADP^{+}$
少数使用$FMN$或者$FAD$作为辅酶
## 氧化酶
生物氧化中以氧作为受氢体的氧化还原酶. 
产物为水, 分为两类: 
+ 把氢从底物上剥离, 即金属蛋白
+ 氢不是从底物供给, 即细胞色素氧化酶
产物为过氧化氢基本以黄素核苷酸作为辅基

需要过氧化物酶以及超氧化物歧化酶来清除自由基. 
## 加氧酶
把氧原子直接掺入有机分子
有两种: 
作用于一种氢供体/作用于两种氢供体
## 传递体
电子传递链
# [[氧化呼吸链]]
## 组成部分
+ 烟酰胺脱氢酶类, 以及$NAD^{+}$以及$NADP^{+}$作为辅酶
+ 黄素酶类$FMN$, $FAD$: 铁硫中心
+ 辅酶$Q$ 泛醌: 接受任何地方来的电子
+ 细胞色素类

共有两条: 
+ $NADH$氧化呼吸链
	+ 一般适用于碳氧单键被氧化为碳氧双键，放能多
	+ 只能吸收一个氢负离子
	+ 可以自由扩散
+ $FADH_{2}$氧化呼吸链
	+ 碳碳单键向碳碳双键转化，放能少
	+ 可以进行双电子转移或者两个单电子转移
