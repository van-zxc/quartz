# 来源去路
1. 来源: 食物, 合成, 脂库释放
2. 去路: 氧化功能, 储存, 构成生物膜, 合成其他物质
# 消化过程
发生在小肠里
1. 胆汁酸盐乳化脂肪形成混合微团
2. 肠脂肪酶分解其为甘油和脂肪酸
3. 肠粘膜吸收甘油和脂肪酸, 在肠粘膜中重新合成为脂肪
4. 分解为乳糜微粒
5. 乳糜微粒进入组织
6. 重新水解为甘油和脂肪酸
# 脂肪分解代谢
1. 脂肪动员
	1. 脂肪组织中的脂肪在ATGL, HSL, MGL等酶的作用下水解为甘油和脂肪酸(顺序按照前面顺序依次排列)
2. 甘油代谢
	1. 只能在肝脏被代谢
	2. 经过甘油磷酸激酶活化, 变为$\alpha$磷酸甘油(反方向为磷酸酶), 消耗1ATP
	3. 被磷酸甘油脱氢酶作用变为二羟丙酮磷酸, 互变异构为三磷酸甘油醛, 产生1NADH+H
	4. 随后可以进入糖酵解通路/糖异生通路
	5. 代谢结束总计生成22ATP
3. 脂肪酸的氧化
	1. 活化: 加上CoA, 反应需要2 ATP
		1. 内质网活化酶: 活化>12碳的脂肪酸
		2. 线粒体活化酶: 活化4-10碳脂肪酸
		3. 反应式: 脂肪酸+ATP+HS-CoA→RCO-SCoA+AMP+PPi
	2. 长链脂肪酸需要通过L-肉碱转运进入线粒体
		1. 脂酰辅酶A在CPT1酶的作用下使用肉碱替换辅酶A, 变为脂酰肉碱
		2. 脂酰肉碱通过肉碱运输体进入线粒体基质
		3. 脂酰肉碱变为脂酰辅酶A, 酶为CPT2
	3. 饱和脂肪酸氧化过程
		1. 四个反复的氧化过程
		2. 脂酰辅酶A的脱氢($\alpha$碳和$\beta$碳脱氢), 生成反式烯脂酰辅酶A. 脱氢酶的脂肪酸脱氢酶按照链长度不同有分类. 生成1FADH2
		3. 烯脂酰辅酶A在水作用下变为羟脂酰辅酶A, 由水化酶催化
		4. 脱氢生成$\beta$-酮脂酰辅酶A, 生成1NADH+H, 由脱氢酶催化
		5. 硫解, 变为乙酰辅酶A+少两个碳的脂肪酸链. 由硫解酶催化
	4. 不饱和脂肪酸氧化
		1. 对于3号碳上的双键, 把脂酰辅酶A先顺反异构化, 把顺式脂肪酸变为反式
		2. 对4号位的双键, 先多造一个二号碳的双键, 随后异构变为三号碳的双键
		3. 多不饱和脂肪酸依次处理
	5. 奇数碳脂肪酸
		1. 最后切到丙酰辅酶A后不会继续切除
		2. 动物: 琥珀酰辅酶A通路: 羧化酶作用下变成甲基丙酰CoA, 随后变为琥珀酰CoA, 进入TCA循环
		3. 植物: 类似$\beta$氧化, 最后在丙二酸半醛脱氢酶变成乙酰辅酶A+CO2
	6. 过氧化物酶体也可以氧化脂肪酸
	7. $\alpha$氧化? $\omega$氧化? 
	8. 酮体代谢
		1. 三个乙酰辅酶A合成一个---$\beta$羟基$\beta$甲基乙酰辅酶A (胆固醇重要前体)
		2. 变为乙酰乙酸
		3. 以上都可以出线粒体, 被远程转运
		4. 乙酰乙酸重新在远端变为乙酰乙酰辅酶A, 随后再加一个辅酶A变为两个乙酰辅酶A
		5. 对$\beta$羟基丁酸: 氧化为乙酰乙酸 进入循环
# 脂肪酸合成
1. 脂肪酸全程合成发生在细胞质中, 延伸合成发生在内质网/线粒体内, 双键在内质网内引入
2. 合成过程存在一个三碳中间物: 丙二酸单酰辅酶A
3. 从头合成: 非线粒体系统: 
	1. 原料为乙酰辅酶A, 产物是长链脂肪酸
	2. 乙酰辅酶A以柠檬酸的形式运出线粒体
		1. 乙酰辅酶A+草酰乙酸→柠檬酸→进入胞质→脱去乙酰辅酶A变为丙酮酸→丙酮酸进入细胞
		2. 柠檬酸裂解酶很重要
	3. 乙酰辅酶A加上羧基变为丙二酸单酰辅酶A
	4. 脂肪酸合成酶: FAS复合物
		1. 步骤共有七个: 
		2. 启动: 装一个乙酰辅酶A
		3. 装载: 丙二酸单酰辅酶A
		4. 缩合, 还原, 脱水, 还原(每一次进行这四个步骤就加一个二碳)
		5. ...?
	5. 调节? 
	6. 其他脂肪酸的合成
4. 线粒体系统: 
	1. 只能在C12, C14, C16等往上加两个碳
	2. 大抵是$\beta$氧化的逆反应
5. 内质网体系: 
	1. 多烯不饱和脂肪酸延伸合成
	2. 非甲基端加C2, 机理不清楚
6. 脂肪合成: 
	1. 甘油骨架只能来源于糖代谢产物DHCP
	2. 1,2二酰甘油-磷酸酯脱掉磷酸后可以变为甘油, 或者可以直接变成磷脂. 
# 甘油磷脂代谢
1. 甘油磷脂的酶解
	1. 磷脂酶四大类(ABCD, A_1/A_2)
	2. 能导致细胞膜磷脂破损溶血的称为溶血磷脂
	3. A_1/A_2破坏磷脂的酯键, 为溶血磷脂
	4. B破坏A2水解产物1-脂酰磷脂的剩下的酯键
	5. C/D破坏磷酸酯键
2. 合成
	1. 磷酸二羟丙酮为前体
	2. CDP-二磷酸胞苷→CDP-二脂酰甘油
	3. 大肠杆菌: 磷脂酰丝氨酸→磷脂酰乙醇胺→卵磷脂
	4. 哺乳动物: 磷酸乙醇胺→CDP-乙醇胺→+甘油二酯 磷脂酰乙醇胺→卵磷脂
	5. 补救途径: 先有胆碱, 然后装载到磷脂上去
# 鞘磷脂
1. 鞘氨醇
	1. 有18个碳构成的碳链, 可以构成鞘磷脂
2. 鞘磷脂/鞘糖脂
	1. 软脂酸+丝氨酸脱一个CO2, 合成十八碳胺-脱氢鞘氨醇
	2. NADPH还原为二氢鞘氨醇
	3. 和脂酰CoA合成脂酰二氢鞘氨醇
	4. 脱去两个氢饱和变为鞘氨醇
	5. 在葡萄糖基转移酶作用下将UDP葡萄糖的的单糖转移到神经酰胺的伯羟基, 变为鞘糖脂
	6. 若羟基接的是磷脂胆碱, 则变成鞘磷脂
	7. 鞘磷脂: 膜结构的支撑/内部信号传导
	8. 鞘糖脂: 细胞表面识别
	9. 鞘磷脂能够组成脂筏(更厚的液态有序相), 原因是引入了双键
3. 神经节苷脂: 鞘糖脂引入了至少一个唾液酸
	1. 缺失/富裕会引发若干疾病
# 胆固醇
1. 环戊烷多氢菲为主要结构
2. 刚性强, 保证细胞膜抗变形能力
3. 胆固醇由肠肝循环回收, 可以往复循环
	1. 可能有肠道菌群代谢, 即次级代谢胆汁酸
4. 85%以上肝脏合成, 回收占15%
5. 进入肝脏后, 会合成胆汁酸, 胆盐等
6. 分解
	1. 转变为胆甾烷醇/粪甾醇排泄
	2. 转变为胆酸(盐)
	3. 转变为固醇激素/VD等
7. 胆汁酸盐: 
	1. 充当表面活性剂, 乳化脂肪
	2. 增加胆固醇溶解度, 防止胆结石形成
8. 类固醇激素: 
	1. 合成时侧链裂解
	2. 先加两个羟基, 随后氧化裂解
9. VD
	1. 紫外线开环, 形成共轭结构, 帮助合成
10. 脂酰辅酶A-胆固醇脂酰转移酶: 
	1. 催化胆固醇和长链脂酰CoA链接形成胆固醇酯, 和动脉粥样硬化强相关
11. 合成
	1. 原料是乙酰CoA, 在肝脏细胞质/内质网
	2. 乙酰CoA合成甲羟戊酸
	3. 甲羟戊酸合成异戊烯焦磷酸酯(活化的异戊二烯单位)
	4. 五碳化合物缩合, 形成法尼基焦磷酸(15碳), 随后形成角鲨烯(三萜, 6个碳)
	5. 角鲨烯合成羊毛甾醇, 随后合成胆固醇(环化, 氧化, 甲基去除和双键还原等)
	6. 调节: 
		1. 限速步: 合成甲羟戊酸
		2. 胰岛素促进, glucagon抑制
		3. 产物抑制
		4. 胆固醇合成抑制剂: 洛伐他汀, 抑制HMG-CoA分子结构, 竞争性结合还原酶的活性位点
