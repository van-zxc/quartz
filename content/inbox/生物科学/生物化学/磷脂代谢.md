# 甘油磷脂酶解
1. 磷脂酶（四类）
	1. A1广泛存在于动物的细胞器、微粒体中，专一水解磷脂分子C1上的酯键，水解产物为溶血性磷脂
	2. A2大量存在于蛇毒、蝎毒、蜂毒等，专一水解C2上的酯键，产物为溶血性
	3. B专一水解A2水解产物1-脂酰磷脂C1上的酯键，溶血性磷脂酶。
	4. C主要存在于动物脑、蛇毒和微生物中，作用于磷脂酸C3位的磷酸酯键。
	5. D主要存在于高等植物，水解C3位第2个磷酸酯键。
	6. ![[PixPin_2026-06-11_21-47-25.png]]
2. 能导致细胞膜磷脂破损溶血的称为溶血磷脂
3. A_1/A_2破坏磷脂的酯键, 为溶血磷脂
4. B破坏A2水解产物1-脂酰磷脂的剩下的酯键
5. C/D破坏磷酸酯键
# 甘油磷脂合成
1. 3-磷酸甘油的合成
	1. 在肌肉内，磷酸二羟丙酮被3-磷酸甘油脱氢酶用NADH还原为3-磷酸甘油
	2. 肝脏/大脑内，被甘油激酶上了一个磷酸基
2. 随后两种方式对接极性头部
	1. 磷酸化底物→合成CDP-底物→将底物+磷酸转移到DAG上，催化释放CMP，适用于磷脂酰胆碱、磷脂酰乙醇胺；定位于光面内质网上
	2. 磷脂酸+CDP→CMP-二酰甘油→进攻得到物质，适用于磷脂酰肌醇、磷脂酰甘油、心磷脂等
	3. 演化出这两条通路可能是因为胆碱和乙醇胺都大量从外界摄入，同时消耗量高，通过打一个CDP标签便于运输；注意到1号通路在内质网上进行，因此必然从真核生物开始大量演化；而2号通路在原核生物大量存在
	4. ![[PixPin_2026-06-12_14-38-38.png]]
3. 卵磷脂（磷脂酰胆碱）
	1. 大肠杆菌的合成
		1. 按上述步骤2合成磷脂酰丝氨酸
		2. 磷脂酰丝氨酸脱羧合成磷脂酰乙醇胺
		3. N原子甲基化形成卵磷脂
	2. 真核生物（酵母）内合成
		1. 磷脂酰乙醇胺被磷脂酰乙醇胺甲基转移酶作用，[[S-腺苷甲硫氨酸]]向氨基上了一个甲基，同时生成S-腺苷同型半胱氨酸
		2. 该过程会进行三次，甲基转移酶转移三次，最后生成卵磷脂
	3. ![[PixPin_2026-06-12_15-24-18.png|632]]
	4. 补救途径
		1. 外源摄入的胆碱被磷酸化变为磷酸胆碱
		2. 被CDP转移酶转移为CDP-胆碱
		3. 按照上文2的方式缩合
4. 心磷脂在大肠杆菌的合成
	1. CDP-二酰甘油被3-磷酸甘油进攻，生成磷脂酰甘油-3-磷酸
	2. 水解掉磷酸变成磷脂酰甘油（PG）
	3. 两分子磷脂酰甘油缩合，脱去一分子甘油，合成9碳对称结构-心磷脂
5. 心磷脂&磷脂酰肌醇的合成方式类似，都是CDP-二酰甘油合成
