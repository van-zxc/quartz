# 能量关系
+ 提供能量$ATP, NADH, NADPH, FADH_{2}$
+ 需求能量反过来
+ 高能化合物: 
	+ 磷酸酐: $NTP, PPi$
		+ 高能磷酸键: 水解时$> 25KJ/mol$的磷酸键, 记为$\sim P$
	+ 烯醇磷酸: $PEP$
		+ [[糖]]酵解/糖异生: 磷酸烯醇式丙酮酸
	+ 混合酐: $1, 3-BP-$甘油酸
		+ 高能键, 和$2, 3$磷酸甘油酸互换, 和[[蛋白质功能#^68e2ef]] 结合, 调控载氧能力
	+ 磷酸胍类: 磷酸肌酸
		+ [[肌肉]]内储能
	+ 高能硫酯键: 乙酰$CoA$ etc. 
		+ 脂肪代谢
# 特点
1. 通常并非一步完成, 由一系列中间代谢过程组成, 顺序性强
2. 条件温和, 绝大多数需要酶催化
3. 可以进行非常灵敏的调节(复杂水平)
	1. 分子: 
		1. [[酶]]的活性: 酶的变构效应&酶分子化学修饰
		2. 酶量: 酶蛋白合成/降解调节
	2. 细胞:
		1. 细胞内酶的区隔
		2. 代谢物的区隔
		3. 调控信号的细胞内转运
	3. 整体水平: 
		1. 神经-内分泌调控
