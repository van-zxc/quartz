# 脂肪动员
![[PixPin_2026-06-11_11-11-09.png]]
1. 即身体召集脂肪组织内贮存的脂肪，将其分解为脂肪酸+甘油的过程
2. 脂肪组织内进行，其中的脂肪在ATGL, HSL, MGL等酶的作用下水解为甘油和脂肪酸(顺序按照前面顺序依次排列)
	1. ATGL（脂肪甘油三酯脂肪酶）：限速，水解下第一个脂肪酸
	2. HSL（激素敏感型脂肪酶）：水解第二个脂肪酶，活性受PKA控制
	3. MGL（单酰甘油脂肪酶）：完全水解
3. 受激素控制，肾上腺素+胰高血糖素激活细胞内PKA，随后激活酶活性；胰岛素抑制酶活，促进脂肪合成
	1. 逻辑：激素结合细胞膜表面的G蛋白偶联受体，随后激活细胞内的腺苷酸环化酶，生成cAMP
	2. cAMP作为第二信使传递信号，激活PKA，
	3. 胰岛素可以激活磷酸二酯酶，水解cAMP，间接抑制酶活
4. 进入血液后，脂肪酸会迅速与白蛋白结合，随后被转运；而甘油则可以溶于血液，随后被转运到肝脏，合成3-磷酸甘油，进入糖异生。
# 甘油代谢
1. 只能在肝脏被代谢，因为只有在肝脏才有甘油磷酸激酶
2. 过程
	1. 被甘油磷酸激酶活化, 变为$\alpha$磷酸甘油(反方向为磷酸酶), 消耗1 ATP
	2. 被磷酸甘油脱氢酶作用变为磷酸二羟丙酮, 互变异构为G3P, 产生1NADH+H
	3. 随后可以进入[[糖酵解]]通路/[[糖异生]]通路
3. 如果进入糖酵解通路，最终被氧化分解，则最终产生16.5或18.5 ATP
	1. 区别在于[[能量介质的穿梭系统]]差异
	2. 在苹果酸-天冬氨酸转运通路下，不消耗能量，共计生成6 NADH+1 FADH2+2 ATP共计18.5 ATP
	3. 在3-磷酸甘油酸转运通路下，生成4 NADH+3 FADH2+2 ATP，共计16.5 ATP
# 脂肪酸
一般来说，脂肪酸的氧化是$\beta$-氧化
## 活化
把脂肪酸活化为脂酰CoA
1. 酶？
	1. 内质网活化酶（硫激酶）: 活化>12碳的脂肪酸
	2. 线粒体活化酶: 活化4-10碳脂肪酸
2. 活化为脂酰CoA，增加水溶性便于反应
3. 过程：羧基被上了一个ATP进攻，上了一个AMP基团活化（脱下PPi），随后HS-CoA进攻羰氧键，生成脂酰CoA
## 脂肪酸的转运
1. 脂肪酸的氧化需要在线粒体内进行：中短链脂肪酸亲水性强，可以直接自由扩散进入膜内，在线粒体基质内被活化为脂酰CoA，而长链脂肪酸则需要通过L-肉碱转运进入
2. 长脂酰辅酶A在CPT1酶的作用下使用肉碱替换辅酶A, 变为脂酰肉碱
	1. 酶？CPT1，定位于线粒体外膜
	2. CPT1受丙二酰CoA强烈抑制，且为限速步；存在三种同工酶（肝（丙二酰CoA低敏感）、肌（高敏感）、脑）
	3. CPT2没有什么特殊的
3. 脂酰肉碱通过脂酰肉碱-肉碱运输体进入线粒体基质（酶1），同时输出一个空肉碱（酶2）
4. 脂酰肉碱变为脂酰辅酶A, 酶为CPT2，定位于线粒体内膜的基质侧
## 饱和脂肪酸氧化
![[PixPin_2026-06-11_14-03-47.png]]
1. 四个反复的氧化过程
	1. 脂酰辅酶A的脱氢($\alpha$碳和$\beta$碳脱氢), 生成反式烯脂酰辅酶A，生成1FADH2
		1. 脱氢酶的脂肪酸脱氢酶按照链长度不同有分类，并且都以FADH2为辅基
		2. VLCAD：14-18C  内膜，定位
		3. LCAD：10-14C  基质（灵长类动物退化）
		4. MCAD：6-10C  基质，可溶
		5. SCAD：4-6C  基质，可溶
	2. 烯脂酰辅酶A在水作用下加成为L-$\beta$-羟脂酰辅酶A, 由水化酶催化
	3. 脱氢生成$\beta$-酮脂酰辅酶A, 生成1NADH+H, 由脱氢酶催化
	4. 硫解, 变为乙酰辅酶A+少两个碳的脂肪酸链. 由硫解酶催化
2. 总结，每水解一次，产生1 NADH、1 FADH2、1 acyl CoA
## 不饱和脂肪酸氧化
1. 对于3号碳上的双键, 把脂酰辅酶A先顺反异构化, 把正常的顺式脂肪酸变为反式，随后汇入上述步骤2
2. 对4号位的双键, 先使用FAD+氧化2号位的碳，形成共轭烯烃，随后再使用NADH还原，异构为三号碳的顺式双键，再异构化为反式，回到1
3. 多不饱和脂肪酸：
	1. 对奇数位的碳（如$\Delta-9$）先进行3次$\beta$氧化，变到3号碳的双键，随后由烯酰-CoA异构酶直接异构化处理，然后汇入$\beta$氧化步骤2
	2. 对偶数位的碳（如$\Delta-12$），按照$\beta$-氧化的步骤，这里会再次引入双键，形成共轭烯烃导致难以处理；此时使用NADH还原为3'-烯烃，随后按照4号碳的方法处理
# 其他脂肪酸氧化
1. 奇数碳脂肪酸
	1. 也会按照$\beta$-氧化的规则进行切割，但是当切到只剩下丙酸的时候不能再切了（因为不会）
	2. 此时有两种通路：形成琥珀酰CoA（动物）/乙酰CoA（植物/微生物）
	3. 动物
		1. 丙酰CoA羧化酶催化碳酸氢根添加一个羧基到丙酰CoA上，该酶依赖[[维生素B7|生物素]]作为CO2的载体，生成D-甲基丙酰CoA，消耗1 ATP
		2. 异构为L-甲基丙酰CoA
		3. 甲基丙二酰-CoA变位酶催化羧基变更位置为直链，形成琥珀酰CoA，该酶依赖[[维生素B12|钴胺素]]
	4. 植物（无法利用钴胺素）
		1. 在脂酰CoA脱氢酶作用下，变为丙烯酰CoA；随后水解变为羟丙酰CoA。和$\beta$氧化类似
		2. 随后被硫酯酶催化水解，生成$\beta$-羟基丙酸（浪费能量）
		3. 随后再$\beta$-羟基丙酸脱氢酶使用NAD+氧化生成丙二酸半醛
		4. 最后，丙二酸半醛在经过氧化，脱羧和重新与辅酶A结合后生成乙酰CoA，放出一份子CO2，同时生成1 NADH
# 其他发生场所
## [[过氧化物酶体]]
1. 过氧化物酶体也可以氧化脂肪酸
2. 代谢过程和$\beta$氧化略微不同，氧化第一步生成的FADH2电子被传递给O2生成H2O2，被过氧化氢酶体解毒
3. 可代谢物：超长链（>22C）的脂肪酸、2-甲基支链脂肪酸、胆汁酸代谢中间物、多不饱和脂肪酸、长链二羧酸、二十烷类物质、脂溶性维生素等
![[PixPin_2026-06-11_15-26-08.png]]
## 乙醛酸循环体
+ 发生[[乙醛酸循环]]，同时也是植物主要的脂肪酸氧化场所；多见于萌发的种子，可以认为是过氧化氢酶体的变种
+ 不含有$\beta$氧化的酶
# 其他氧化途径
1. $\alpha$氧化（以植烷酸为例）
	1. 位于过氧化物酶体内
	2. 过氧化物酶体内的植烷酸在特异性脂酰-CoA合酶的催化下生成植烷酰-CoA
	3. 植烷酰-CoA羟化酶（PHYH）在二号碳上引入一个羟基
		1. 该酶为双加氧酶，依赖铁离子、[[维生素C]]以及$\alpha$-酮戊二酸作为共底物
		2. 反应生成2-羟基植烷酰-CoA，同时$\alpha$-酮戊二酸氧化脱羧生成琥珀酸和CO2
	4. 2-羟基植烷酰-CoA裂解酶催化碳碳键断裂。生成甲酰-CoA以及游离的降植烷醛
		1. 甲酰CoA被水解掉生成甲酸，随后借助过氧化氢酶体内强而有力的氧化环境迅速被氧化为CO2排出
	5. 降植烷醛在醛脱氢酶的作用下氧化生成降植烷酸+1 NADH。
	6. 该反应主要用来解除$\beta$碳为叔碳，$\beta$氧化无法进行的问题，在被氧化掉一个碳后，支链消除
	7. 那么还留下来一个$\alpha$碳上有支链怎么办呢？不管它！因为它不阻碍$\beta$氧化，只是氧化结果变成了丙酰CoA而已，进入琥珀酰代谢即可
2. $\omega$氧化
	1. 主要发生在肝脏内质网中，此种氧化从离羧基最远的碳开始作用
	2. 细胞色素P450混合功能氧化酶系（定位于内质网）催化NADPH和O2作用于长链脂肪酸的$\omega$碳上，生成$\omega$-羟脂酸
	3. 醇脱氢酶使用NAD+将羟基氧化为醛基
	4. 随后醛脱氢酶再次使用NAD+将醛基氧化为羧基，形成二羧酸，随后参与$\beta$氧化反应
	5. 生理作用主要是生成二羧酸，可以从两边同时开始氧化，同时增加水溶性
