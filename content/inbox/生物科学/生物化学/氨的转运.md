# 大多数细胞
步骤如下：
1. 上一个激酶，磷酸化一下
2. 随后谷氨酰胺合成酶催化谷氨酸合成谷氨酰胺
3. 谷氨酰胺可以正常被运到肝/肾，参与[[鸟氨酸循环]]
# 肌肉细胞（Cahill循环）
1. 原因
	1. 在长时间饥饿或高强度运动中，肌肉内糖原不够时，会分解自身蛋白蛋白作为能量来源；但是分解过程中产生的游离氨很难处理
	2. 同时，肌肉大量糖酵解释放丙酮酸/乳酸，也难以处理
2. 使用葡萄糖-丙氨酸通路进行
	1. 肌肉分解的氨被转氨酶转到$\alpha-$酮戊二酸上，合成谷氨酸
	2. 谷氨酸在丙氨酸转氨酶的作用下，将氨基转移到丙酮酸上合成丙氨酸
	3. 丙氨酸水溶性大，随着血液转移到肝脏，随后脱氨生成丙酮酸+氨，参与[[鸟氨酸循环]]去了
	4. 随后的丙酮酸进入[[糖异生]]通路，合成葡萄糖返回肌肉
