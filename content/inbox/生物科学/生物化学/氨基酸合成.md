总括来看，氨基酸的合成可以被理解为：糖代谢产生的酮酸+氨基，因此后面的核心必然也会是这个
# 氨基化
1. 还原氨基化：自由氨加酮酸被还原为氨基酸（参见[[氨基酸分解#氧化脱氨]]中的磷酸吡哆醛脱氨机理）
2. 谷氨酰胺酰胺基转移酶
	1. 这个酶很重要！后面一系列氨基酸都需要它转氨
	2. 作用机理（以Cys家族为例）
	3. 该酶核心作用区间有一个半胱氨酸；当谷氨酰胺进来时，半胱氨酸的巯基进攻释放氨，同时形成谷氨酰-酶复合体
	4. 在疏水环境下，氨扩散到目标点位，对活化好的底物亲核进攻上氨基，完成作用
3. 联合氨基化
# 碳骨架
1. 碳架：来自EMP、TCA或PPP等的中间产物
2. 按照合成的核心碳链框架：
	1. $\alpha$酮戊二酸家族：谷氨酸→谷氨酰胺、脯氨酸、精氨酸
	2. 丙酮酸：丙氨酸、缬氨酸、亮氨酸
		1. 转氨形成
	3. 3-磷酸甘油酸：丝氨酸→甘氨酸，半胱氨酸
	4. 磷酸烯醇式丙酮酸+赤藓糖-4-磷酸：苯丙氨酸、酪氨酸、色氨酸
	5. 草酰乙酸：天冬氨酸、天冬酰胺、甲硫氨酸、苏氨酸、赖氨酸、异亮氨酸
		1. 由谷氨酰胺转氨形成
	6. 磷酸核糖：组氨酸家族

来吧，我认为有必要对每一个氨基酸的合成进行一定说明，不管合成路径多复杂。
# 分氨基酸合成
1. 丙酮酸骨架
	1. 丙氨酸：L-谷氨酸+丙酮酸转氨基作用合成丙酮酸+$\alpha$-酮戊二酸
	2. 缬氨酸（非动物）
		1. 类似[[丙酮酸脱氢]]的反应，丙酮酸被TPP进攻生成羟乙基-TPP，其再进攻丙酮酸的$\alpha$羰基，合成$\alpha$-乙酰乳酸
		2. 甲基迁移到羰基碳上，随后NADPH提供两个电子，将羰基还原为羟基；形成2,3-二羟基异戊酸
		3. 脱去3号位上的羟基和附近的氢，形成烯醇式结构，随后互变异构为$\alpha$-酮异戊酸
		4. 类似的，L-谷氨酸转氨基到该酮酸上，形成缬氨酸
	3. 亮氨酸（非动物）
		1. 会复用缬氨酸的代谢通路，到合成$\alpha$-酮异戊酸开始都是一样的
		2. 随后乙酰CoA进攻羰基位，形成$\alpha$-异丙基苹果酸
		3. 羟基位置转移，形成$\beta$-异丙基苹果酸
		4. 随后以NAD+为氢受体，将羟基氧化为羰基；随后触发$\beta$脱羧，脱下一个羧基形成$\alpha$酮异己酸
2. 3-磷酸甘油酸骨架
	1. 丝氨酸
		1. 3-磷酸甘油酸的2号羟基被氧化为羰基，NAD+为氢受体，生成3-磷酸羟基丙酮酸
		2. 转氨酶作用下，接受L-谷氨酸的氨，生成3-磷酸丝氨酸；随后水解磷酸基团形成丝氨酸
	2. 甘氨酸：在[[维生素B9#叶酸的循环]]处已有记载，夺走丝氨酸的羟甲基即形成甘氨酸
	3. 半胱氨酸
		1. 人体内：在[[S-腺苷甲硫氨酸]]出现的同型半胱氨酸和丝氨酸缩合为胱硫醚；随后再被水解形成半胱氨酸+$\alpha$-酮丁酸（进入丙酰CoA被降解）
		2. 植物：将硫酸根加成到腺苷上再上磷酸活化，随后经过一系列强而有力的还原反应形成硫化氢；随后给丝氨酸的O上一个乙酰基；随后H2S亲核进攻，取代掉乙酸根形成半胱氨酸
3. $\alpha$-酮戊二酸骨架
	1. 谷氨酸/谷氨酰胺：不必多说，在之前的[[氨的转运]]或[[氨基酸分解]]中亦有论述；直接转氨酶上去就完事了
	2. 脯氨酸：给谷氨酸的羧基上一个磷酸活化，随后NADPH狠狠的还原它，形成谷氨酸半醛；随后氨基和醛基在溶液内自发缩合形成C=N双键；再随后NADPH再次狠狠还原形成仲氨基
	3. 精氨酸：参考[[鸟氨酸循环]]，我们只需要补充循环里的一个氨基酸——鸟氨酸即可
		1. 动物：在小肠上皮内形成谷氨酸半醛，随后被鸟氨酸转氨酶转为鸟氨酸，自然补充进入循环
		2. 植物：先给N上一个乙酰基保护；随后将谷氨酸还原为谷氨酸半醛；转氨基变为N-乙酰鸟氨酸，随后再脱乙酰变为鸟氨酸。这么做的目的主要是防止自身环化形成脯氨酸
4. 草酰乙酸骨架
	1. 天冬氨酸/天冬酰胺：略过
	2. 赖氨酸（仅讨论DAP途径）
		1. 首先生成的天冬氨酸按照谷氨酸的途径活化为天冬氨酸半醛
		2. 天冬氨酸半醛上一个丙酮酸缩合；随后分子自发缩合为2,6-二羧酸-2,3-二氢吡啶，随后再被NADPH还原四氢吡啶-2,6-二羧酸，最后强行使用琥珀酸进攻N使其开环（防止多余反应）
		3. 开环后原先的双键形成了羰基，正好供转氨酶进攻上一个羰基；随后水化脱去保护用的琥珀酸
		4. 使用内消旋酶将结构转化为内消旋的，随后脱去一个羧基，即形成赖氨酸
	3. 甲硫氨酸
		1. 动物：显然不必说，在[[S-腺苷甲硫氨酸]]内已有叙述
		2. 植物：经过二次还原天冬氨酸形成高丝氨酸；随后迅速被琥珀酸（细菌）/乙酰基（植物/真菌）遮蔽掉；随后按照半胱氨酸剧本走，形成L-同型半胱氨酸；最后，以N-甲基四氢叶酸作为一碳载体，[[维生素B12|钴胺素]]催化上一个甲基
	4. 苏氨酸：同样的合成高丝氨酸，随后再次被ATP活化，被磷酸吡哆醛催化转移羟基到上游$\beta$碳上
	5. 异亮氨酸：苏氨酸被氧化为$\alpha$-酮丁酸以替代丙酮酸作为加成底物，其他部分应该大抵与缬氨酸合成时相似
5. 磷酸核糖骨架

6. 磷酸赤藓糖（[[磷酸戊糖途径]]）+PEP途径
	1. 共有通路：分支酸通路
		1. ![[PixPin_2026-06-14_17-38-20.png]]
		2. 首先PEP和磷酸赤藓糖醛醇缩合，形成旁边又臭又长的东西
		3. 不管了，反正涉及羟醛缩合，形成3-脱氢奎尼酸，出现第一个六元环骨架同时脱氢
		4. 消去一个水，同时把下方的羰基还原为羟基，形成莽草酸
		5. 莽草酸上一个磷酸后，把丙酮酸的中间那部分上上来，随后再在原先上磷酸的地方消去，形成分支酸
	2. 苯丙氨酸：
		1. 分支酸的烯醇丙酮酸基团移位到原先羧基位，形成预苯酸
		2. 预苯酸脱水酶消去一分子水，引发脱羧反应，形成苯丙酮酸
		3. 最后转氨形成苯丙氨酸
	3. 酪氨酸：形成预苯酸后，使用NAD+氧化再脱羧，保留羟基，其余一样
	4. 色氨酸：
		1. 分支酸脱去烯醇丙酮酸基团，同时脱掉羟基（羧基自动掉了），形成邻氨基苯甲酸
		2. 氨基攻击核糖的敏感羟基，形成磷酸核苷氨茴酸
		3. 随后经过重排，磷酸核糖由醛糖变为酮糖；酶促分子内环化，同时脱羧，形成吲哚-3-磷酸
		4. 经过消除反应，切除3-磷酸甘油醛，随后引入丝氨酸，合成色氨酸
		5. ![[PixPin_2026-06-14_18-05-44.png]]

# 氨基酸的个别物质代谢
1. 肌酸合成
	1. 精氨酸的胍基在转脒基酶作用下转移到甘氨酸的$\alpha$氨基上，形成胍基乙酸
	2. S-腺苷甲硫氨酸在原来的N上再上一个甲基即变成了肌酸
2. 谷胱甘肽合成
	1. GSH维持环境的还原性环境
3. 支链氨基酸的代谢
	1. 普遍是先转氨为$\alpha$-酮酸，再通过一系列氧化还原代谢进入三羧酸循环被代谢
	2. ![[PixPin_2026-06-14_19-30-57.png]]
	3. 槭糖尿病：缺乏$\alpha$酮酸脱羧酶，无法经过有效代谢，导致尿液呈焦糖味
4. 吲哚类物质代谢
	1. ![[PixPin_2026-06-14_19-34-14.png]]
	2. 同时还能合成血清素、血管紧张素等
5. 吲哚族氨酸可以被加羟基生成酪氨酸
6. 芳香族[[氨基酸代谢]]
	1. ![[PixPin_2026-06-14_19-37-01.png]]
	2. 苯丙酮尿症：缺乏phe水化酶；此时代谢为转氨形成苯丙酮酸，随后形成苯乙酸/羟基苯丙酸
7. 多巴类代谢
	1. ![[PixPin_2026-06-14_19-39-51.png]]
	2. 白化病：酪氨酸无法氧化为黑色素
	3. ![[PixPin_2026-06-14_19-41-14.png]]
8. 多胺的合成：组氨酸脱羧为组胺、还有亚精胺、尸胺等
9. Glu形成GABA
10. Cys的巯基疯狂氧化，合成牛磺酸
