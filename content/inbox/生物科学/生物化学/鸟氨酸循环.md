# 步骤
1. 氨甲酰磷酸的合成（线粒体）
	1. 受氨基甲酰磷酸合成酶I催化
	2. 碳酸氢根被上一个磷酸，变为羧基磷酸
	3. 氨基进攻磷酸基团，变为氨甲酸
	4. 氨甲酸再被一个ATP进攻，形成氨甲酰磷酸
	5. 消耗2ATP
2. 瓜氨酸的合成
	1. 鸟氨酸氨基甲酰转移酶（OTC）催化
	2. 在酶催化下，氨基甲酰基转移到鸟氨酸的氨基末端，形成瓜氨酸
3. 精氨琥珀酸的合成
	1. 瓜氨酸生成后，通过线粒体内膜的载体，进入细胞质基质
	2. 随后ATP进攻，形成AMP-瓜氨酸，此时形成C=N双键
	3. 随后AMP-瓜氨酸被精氨琥珀酸合成酶（ASS）转移一个天冬氨酸，形成精氨琥珀酸
4. 精氨酸的合成
	1. 在精氨琥珀酸裂解酶（ASL）的作用下，天冬氨酸的碳链自发裂解，形成延胡索酸，进入[[TCA循环]]
5. 尿素的生成
	1. 精氨酸酶含有锰-锰双核心，将水活化为亲核能力强的氢氧根离子
	2. 随后氢氧根离子进攻精氨酸的C，导致C-N断裂，形成尿素+鸟氨酸，重新踏上轮回
# 调节
1. [[氨基酸分解#|转氨]]作用和鸟氨酸循环的一部分都发生在线粒体中，因此可以互相影响
2. 第一步的氨甲酰磷酸合成酶I被N-乙酰谷氨酸别构激活
	1. 当胞内蛋白质含量过高时，L-谷氨酸含量升高，导致N-乙酰谷氨酸含量自然升高
	2. 随后激活后的鸟氨酸循环运转，导致代谢加快排出
3. 氨甲酰磷酸合成酶缺失？
	1. 可以使用苯甲酸/苯乙酸紧急治疗
	2. 苯甲酸会缩合一个N-甘氨酸、苯乙酸会缩合一个N-谷氨酸，帮助绕开尿素循环排氮
4. 血氨？（[[内环境--体液与血液]]）
	1. 来源：氨基酸脱氨、肠道氨、肾上腺皮质分泌的氨（来自谷氨酰胺）
	2. 去路：合成尿素、非必须氨基酸、谷氨酰胺、肾小管泌氨（生成铵根）
	3. 高血氨症？
		1. ![[PixPin_2026-06-13_22-39-42.png]]
		2. 昏迷原因：氨进入血脑屏障消耗$\alpha-$酮戊二酸导致糖含量减少，ATP降低
		3. 抑制性神经递质、兴奋性少；抑制钠钾泵活性
