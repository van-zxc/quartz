# 复合体1: NADH- 泛醌氧化还原[[酶]]

![[PixPin_2026-06-07_15-01-32.png]]
氧化呼吸链复合体A起始
是一个非常大的复合物, 由42条不同的多肽链构成. 
倒L形状, 一个臂伸展到细胞基质中. 

过程：
1. NADH→$NAD^{+}$ + $H^{+}$
2. FMN→FMNH2
3. 铁硫中心传递电子
4. 电子转移到CoQ生成CoQH2
5. 过程中泵出四个氢离子
可以同时催化NADH转移氢到泛醌上, 同时可以将质子从基质转移到内膜外. 因此可以认为其为电子转移能驱动的质子泵. 可以泵出去4个氢离子. 

总反应式为: 
$$
NADH + 5H^{+}_{N} + Q \to NAD^{+} + QH_{2} + 4H^{+}_{P}
$$

# 复合体3: 泛醌-细胞色素c氧化还原酶

![[PixPin_2026-06-07_16-37-33.png]]
由相同单位组成的二聚体(每个单体由11个不同的亚基)
功能核心由: Cyt b, 铁硫蛋白以及Cyt c1

当1个携带两个电子的还原态泛醌（$QH_2$）进入复合体 III 的特定位点（$Q_o$ 位点）时, $QH_2$ 释放2个 $H^+$ 到膜间隙。
- 第 1 个电子传给cyt c1→细胞色素c
- 第 2 个电子经过细胞色素b, 传递给氧化态泛醌
- $Q$ 变成了一个不稳定的自由基中间体（半醌，$Q^{\cdot-}$）。

紧接着，**第二个** $QH_2$ 进入 $Q_o$ 位点，重复同样的动作, 再释放 2 个$H^+$到膜间隙
- 第 1 个电子传给第二个细胞色素$c$。
- 第 2 个电子传给刚才那个已经变成半醌的 $Q^{\cdot-}$。      
- 半醌接收到第二个电子后，从线粒体基质中吸收2个$H^+$，重新变回$QH_2$，回到泛醌库中
- 实际上消耗了 1 个 $QH_2$, 还原了 2 个细胞色素 $c$. 总共将 **4 个 $H^+$** 泵入了膜间隙（全部来自 $Q_o$ 位点的释放），同时从基质中吸收了 2 个 $H^+$。
# 复合体4: 细胞色素氧化酶

![[PixPin_2026-06-07_16-54-15.png]]
1. 首先，还原态细胞色素C将其一个电子转移给双核铜中心，起到电子蓄水池的作用。传递完细胞色素C脱离系统返回复合体3
2. 进入双核铜中心的电子自发的跳跃到下一个血红素a，随后继续跳跃到终点催化中心
3. 血红素a3和单核铜中心组合补充双核中心；当两个电子分别送达时，被分别储存在铁和铜内，随后氧分子进入间隙内，形成桥联中间体；随后等待后续3、4个电子送达，酪氨酸作为质子供体和受体，帮助打断氧氧键，从线粒体基质侧获得四个氢离子，形成水分子。
4. 与此同时，由于复合体4构象改变，于是从线粒体基质侧主动转运4个氢离子到间隙侧

总反应式为
$$
4\text{cyt c} + 8H^{+}_{N} + O_{2} \to 4\text{cyt c} + 4H^{+}_{P} + 2H_{2}O
$$
可以结合四个氢离子, 同时泵出两个氢离子. 
# 复合体5: ATP合成酶
![[PixPin_2026-06-07_19-35-11.png]]

位于线粒体内膜的内表面. 

F1由5种亚基组成，为酶复合物的球状头部，也是活性中心，位于内膜基质表面。
F0横贯内膜，含有质子通道，由4种亚基组成。茎部有寡霉素敏感蛋白（OSCP），有调节F0、F1的功能。

过程：
1. 质子从a亚基进入，挤进c亚基中的某个天冬氨酸/谷氨酸，导致该氨基酸疏水性增强，c亚基自然旋转，带动上面的$\gamma$亚基一起旋转
2. $\gamma$亚基是不规则的，在旋转的过程中会不停的挤压$\beta$亚基，导致$\beta$亚基出现三种不同的构象
	1. 开放构象：上一次合成的ATP脱离；ADP和Pi进入活性位点
	2. 疏松结合构象：将两者限制在同一个区域内
	3. 紧密结合构象：压缩，强迫两者形成化学键

因此每转动一圈：排出10个氢离子，合成三个ATP

两个H经过NADH氧化呼吸链生成水时, 生成2.5 ATP; 
经过琥珀酸氧化呼吸链氧化为水时, 生成1.5 ATP
不同生物似乎还不一样?
# 总结
1. 一个NADH经过一次氧化磷酸化，能向外搬运10个质子；合成2.5ATP
2. 一个FADH2能向外搬运6个质子；合成1.5ATP
![[PixPin_2026-06-07_17-40-39.png]]
# 调节
1. 调节ADP/ATP. ADP高, 表现为促进作用; 反之则为抑制
2. 激素的调节作用: 肾上腺素, 甲状腺激素etc. 
3. 抑制剂的作用:
	1. 鱼藤酮、安密妥、杀粉蝶菌素、异巴比妥：阻断电子由NADH向CoQ的传递。
	2. 抗霉素A，抑制b到c1的电子传递。
	3. 氰化物、硫化氢、叠氮化物、CO等：阻断电子由cyt aa3到氧的传递。
	4. 解耦连剂(2, 4-二硝基苯酚) ：可以携带质子，同时可以自由进出线粒体膜，导致膜两侧氢离子浓度梯度消失
	5. 寡霉素：抑制氧利用和ATP形成
	6. 一氧化碳：和还原型Cyt氧化酶结合
	7. 氰根：和氧化型Cyt氧化酶结合
