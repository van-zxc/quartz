# 神经肌肉接头
1. 运动神经末梢和肌肉细胞组成的特殊结构
2. 将中枢神经的神经冲动传递给肌肉细胞
3. ![[PixPin_2026-03-18_15-31-01.png]]
## 结构
1. 运动神经末端失去髓鞘，嵌入终板膜中
2. 接头前膜中有大量钙离子电压门控通道
3. 囊泡中有ACh（乙酰胆碱）
4. 终板膜中有nAChR（尼古丁乙酰胆碱受体、五聚体、激活后对$Na^{+}+K^{+}$通透）
5. 接头间隙有大量高活性AChE（乙酰胆碱酶）
## 传递过程
1. 突触小泡的释放：
	1. 神经末梢兴奋
	2. 接头前膜去极化
	3. 钙离子通道激活
	4. 钙离子大量内流
	5. 促进突触囊泡和前膜融合，释放ACh到接头间隙（除开视网膜感光细胞/释放脂溶性递质的细胞，绝大多数释放为量子释放，释放单位为一个囊泡）
2. 激活突触后膜
	1. ACh扩散至终板膜
	2. 结合&激活nAChR，钠离子内流
	3. 终板膜发生去极化，产生终板电位
3. 降解与再生
	1. ACh被AChE水解，随后游离的胆碱被胆碱转运体运回细胞内，再次合成ACh
	2. 网格蛋白介导内吞，随后形成早期内体；出芽后消耗ATP搬运进大量神经递质，在此形成囊泡
4. 调控机制？
	1. 筒箭毒和$\alpha$-银环蛇毒素竞争性抑制nAChR活性，导致中毒者肌肉无法接受中枢神经信号，表现出类似重症肌无力现象（nAChR减少）
	2. 扁豆毒碱抑制nAChR活性
# 概念
1. 类型：轴突-轴突、轴突-树突、轴突-胞体、其他
2. 单向突触、交叉型突触、混合突触
3. 定向突触、非定向突触（可以进行广播式信息传递）
4. 传递基本过程：电信号→动作电位→电信号
5. 标准结构：前膜、间隙、后膜
6. 突触后电位：兴奋性突出后电位/抑制性突出后电位
7. 常见的突触结构：辐散、会聚、反馈（正反馈/负反馈）
