# 血流动力学
1. 血流量：单位时间单位面积血量
	1. 参考[[流体力学]]：层流or湍流，临界速度$v = 1000\eta/\rho S$
	2. $\eta$---动力粘度越大，流体越黏；$\rho$--密度、$R$---管径
2. 血流阻力：变为热能，摩擦力
	1. 公式为$R = \dfrac{8\eta L}{\pi r^{4}}$
	2. 血压下降比例和血流阻力成正比
	3. 血管口径上升，阻力增大，血流量增大
	4. 血液粘滞度↑，阻力增大，血流量减少
# 血压
1. 定义为血管中的血液造成的侧压力，测量的是动脉血压
2. 形成：一个前提两个条件
	1. 前提：循环系统内有足够血液（平均充盈压，约0.93 KPa）
	2. 条件1：心脏射血
		1. 动能推动血液流到外周，势能传递给大血管，大血管可以充当弹性储器
		2. 一部分转为血管壁的弹性势能，对血液有压力，导致血液的连续流动
	3. 条件2：外周阻力
3. 收缩压：心室收缩时，主动脉压急剧上升至收缩中期达到的最高值。13~16 KPa(100~120 mmHg)
4. 舒张压：心室舒张时，主动脉压下降，至心室舒张末期达到最低值。8~10 KPa(60~80 mmHg)
5. 脉搏压：收缩压 - 舒张压 = 脉压4~5 KPa(30~40 mmHg)
6. 平均动脉压：一个心动周期中动脉血压的平均值 = 舒张压+1/3脉压 13.3 KPa(100 mmHg)
7. 影响因素：
	1. 每搏输出量：输出多血压自然高
	2. 心率：输出快血压自然高
	3. 外周阻力：阻力大血压自然低
	4. 主动脉&大动脉的弹性：稳定血压
	5. 循环血量和血管系统容量的比例：比例下降，充盈压下降

## 组成
1. 营养通路： 微动脉+后微动脉+毛细血管前括约肌+真毛细血管网+微静脉
	1. 特点：血流缓慢，血管壁薄，有利于物质交换
	2. 20%交替开放
2. 直捷通路： 微动脉+后微动脉+通血毛细血管+微静脉
	1. 血流比真毛细血管网快，管壁厚，经常处于开放状态
	2. 骨骼肌中多见，不进行物质交换
3. 动静脉短路：动静脉吻合支
	1. 管壁类似微动脉
	2. 分布于皮肤、手掌、足低、耳廓等，多用于调节体温
### 影响因素
1. 微动脉开放程度
2. 后微动脉&前括约肌分闸门（主要受体液调节，$p_{O_{2}}$，$p_{CO_{2}}$，各种激素等等）
