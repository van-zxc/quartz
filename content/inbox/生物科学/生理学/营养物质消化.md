# 糖的消化吸收
+ 多糖→寡糖→单糖
+ 目前认为只有单糖才能被吸收
+ 吸收效率：半乳糖>葡萄糖>果糖>甘露糖>...
+ 吸收方式：主动运输
	+ 小肠肠腔→肠粘膜上皮细胞→门静脉...
	+ 跨肠腔运输为SGLT蛋白etc. 
	+ 转运到细胞内用GLUT家族
	+ 葡萄糖的重吸收
# 脂的消化过程
发生在小肠里
1. 胆汁酸盐乳化脂肪形成混合微团
2. 肠脂肪酶分解其为甘油和脂肪酸
3. 肠粘膜吸收甘油和脂肪酸, 在肠粘膜中重新合成为脂肪
4. 脂肪和胆固醇、脂蛋白共同组成乳糜微粒
5. 乳糜微粒通过淋巴系统和血液进入组织
6. 重新水解为甘油和脂肪酸，释放能量etc. 
# 蛋白质消化过程
1. 食物蛋白摄入
2. 被胃蛋白酶（pepsin）降解为短肽
3. 进入小肠，随后在胰蛋白酶和胰凝乳蛋白酶作用下变为更短的短肽
4. 肠粘膜的二肽酶 、氨肽酶和胰脏分泌的羧肽酶作用下降解为超级短的肽
5. 从肠壁进入肝脏，随后被血液运输到身体各处
# 核酸的消化
1. 食物中的核蛋白被胃酸作用，形成核酸+蛋白质
2. 核酸在小肠中被胰核酸酶（DNAse和RNAse）水解为单核苷酸
	1. 核酸酶：磷酸二酯酶，切断3‘-磷酸键
	2. 内切酶：水解分子内的键；外切酶：从一端逐渐水解的
3. 单核苷酸被胰/肠核苷酸酶水解为磷酸+核苷
	1. 两类：核苷磷酸化酶/核苷水解酶
	2. 核苷磷酸化酶：水解的过程中在核糖上加上磷酸根，变为1-磷酸核糖，广泛
	3. 核苷磷酸化酶：只水解，只存在于植物/微生物中，对脱氧核糖不起作用
4. 核苷最后在脾/肝内的核苷酶作用下被降解为戊糖+碱基
5. 碱基最后代谢为尿酸，最后排出
