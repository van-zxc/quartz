# 体液
+ 细胞内液
+ 细胞外液
	+ 组织液
	+ 血浆
	+ 淋巴液

体液: 水+溶质(晶体渗透压: 小分子 胶体渗透压: 大分子)
细胞外液$Na^{+}$多, 细胞内液$K^{+}$多(这是obvious的, 在神经细胞内也是) ^85e8af

+ [[渗透压]]: 
	+ 286-294 mOSM/L
	+ 等渗溶液&等张溶液
# 血液
+ 血浆: 水+离子+维生素+有机物(糖 蛋白 脂质(LDL etc. ) 磷脂 尿素等)+气体  55%
	+ pH约为7.35-7.45
	+ 血浆渗透压内, 晶体渗透压80%来自$Na^{+}$和$Cl^{-}$; 胶体渗透压75-80%来自白蛋白
+ 血细胞
	+ 红细胞  45%
	+ 白细胞, 这部分100%涉及[[免疫学]]的内容. 
		+ 淋巴细胞
		+ 单核细胞
		+ 粒细胞(酸 碱 中)
	+ 血小板: 巨核细胞的碎块
+ 功能: 
	1. 运输: 营养, 代谢废物, 信号分子
	2. 免疫: 中性粒细胞+巨噬细胞(←单核细胞)+T淋巴细胞+B淋巴细胞
	3. 缓冲(维持内环境稳定): 碳酸氢钠-碳酸缓冲对/磷酸氢二钠-磷酸二氢钠缓冲对
	4. 止血: 凝血因子(14种), 瀑布学说,
