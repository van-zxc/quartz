# 跨膜扩散
膜作用: 
1. 区室化
2. 选择性物质转运&通透
## 简单扩散
利于转运: 亲脂性/分子足够小 
菲克定律: 
$$
J = -D \frac{\mathrm{d}C}{\mathrm{d}x}
$$
$$
J = P(C_{o} - C_{i}), P = \frac{kD}{\delta}
$$
## 易化扩散
1. 非脂溶性/脂溶性小的物质, 借助膜上载体/通道运输
2. 特性
	1. 高度特异性
	2. 可逆性
	3. 饱和性（转运时遵守[[酶#米氏方程]]）
	4. 竞争性
	5. 可调节性
3. 通道更快，载体其次
4. 通道种类：离子通道（钾离子）、水通道、孔道
5. 通道选择性是相对的
6. 离子通道的激活形式（各种门控 敏感通道）
### 离子通道：以钾通道为例
1. ![[PixPin_2026-06-15_16-57-14.png]]
2. 出现时间最早的通道之一
3. 特定的离子通道只能选择性地通透特定种类的离子，但是选择性是相对的而不是绝对的，不同离子通道对离子的选择性有很大差异
4. 离子通道的开放有一定随机性
	1. 离子通道有开放、关闭、或失活等状态，对应着通道蛋白的不同构象
	2. 不同离子通道或同一离子通道在不同条件下的P0各不相同
	3. 开放概率P0：处于开放状态的时间在总时间中的比率
5. 离子通道的激活有多种形式：机械激活、温度敏感、电压门控、配体门控、非门控（无特定机制）等
### 渗透：水的跨膜扩散
1. 单纯扩散，速度慢
2. 可以通过小的极性分子，如甘油、尿素等
3. 水通道蛋白：![[PixPin_2026-06-15_16-58-00.png]]
# 主动转运
1. 通过与某种能量的耦联，将特定物质逆电化学梯度转运
2. 原发性主动转运：直接以ATP为能源的主动转运过程，其转运蛋白通常被称泵（P型/V型ATP泵[[细胞膜]]）
3. 继发性主动转运：一种离子（钠离子/氢离子）的顺离子梯度，直接驱动其他离子主动转运
	1. 同向共转运
	2. 反向（钠钾泵等）
	3. 钠钾泵：![[PixPin_2026-06-15_17-18-07.png]]
	4. 钙转运系统
		1. 钙离子通道分布在内质网和肌质网膜上，肌质网钙泵维持内质网-细胞内钙离子梯度，质膜钙泵精细调控并维持胞内钙离子浓度
		2. 这两个细胞器为重要的储存钙离子的场所
		3. 细胞内钠钙交换有赖于细胞钙交换系统
	5. 出胞/入胞：胞吐/胞吞
