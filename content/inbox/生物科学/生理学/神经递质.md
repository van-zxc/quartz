# 定义
1. 突触前神经元能够合成&储存
2. 收到刺激后突触前神经元能够在末梢后释放
3. 释放外源分子可以模拟突触后神经元反应
4. 外源分子可以被突触阻断剂阻断
5. 突触间隙内存在快速灭活/消除的机制
# 种类
1. 气体信使：无需储存&膜受体结合，可以自由扩散
2. 神经肽
	1. 在胞体合成并包装为较大的囊泡，经[[快轴浆运输]]（微管与载体马达驱动）到达末梢
	2. 可能释放的地方离靶细胞有距离，不一定有定向的突触结构
	3. 作用终止于扩散或蛋白水解；潜伏期较长，持续时间几秒
3. 乙酰胆碱：在轴突末梢合成，在较小囊泡中包装，释放至突触间隙、潜伏期与持续时间短
4. 递质共存：多种递质一个神经元（但是不一个突触小泡）
	1. 低频刺激导致小分子释放
	2. 高频刺激导致囊泡大的大分子递质释放
5. 常见种类
	1. 乙酰胆碱
	2. 生物胺类（多巴胺、肾上腺素、5-羟色胺、组胺、去甲肾上腺素）
	3. [[氨基酸]]酸类（谷氨酸、GABA、天冬氨酸、甘氨酸）
	4. 嘌呤/[[核酸|核苷酸]]类（腺苷、ATP）
	5. 气体（CO、NO、H2S）
	6. [[脂类]]（花生四烯酸、固醇等）
	7. [[肽——蛋白质一级结构|肽]]类
# 清除
1. 突触间隙内的酶降解神经递质
2. 突触前膜回收递质
3. 星形胶质细胞代为回收递质

2. 受体通道
	1. 谷氨酸NMDA受体
		1. 需要甘氨酸共激活，特异性钙离子通道
		2. 失活时被镁离子阻断，当细胞电位上升时静电排斥作用导致镁离子脱离通道，被激活
		3. 下游激活AMPA受体，导致钙离子更大量内流
		4. 长程记忆，神经发育等重要
	2. GABA$_{A}$受体
		1. 氯离子通道、抑制性、配体门控类通道
		2. 苯二氮䓬类增强开放频率，巴比妥延长开放时间
	3. $\beta$-肾上腺素受体：激活cAMP环化酶，合成cAMP激活电压门控钙通道
3. G蛋白偶联受体：
	1. $\beta$肾上腺素受体：激活G蛋白后活化cAMP环化酶产生cAMP、激活蛋白激酶，随后激活电压门控钙离子通道
