# 肌丝滑行学说
1. 想要搞清楚肌丝滑行学说，我们首先需要明白肌肉纤维的结构
	1. 如上所示，肌肉由肌束构成，肌束由肌纤维构成，肌纤维由肌原纤维构成，而肌原纤维又由细肌丝和粗肌丝构成
	2. 细肌丝主要由肌动蛋白构成，而粗肌丝主要由肌球蛋白构成
	3. 观察肌肉结构，会容易的发现肌小节的存在：其中分为I带（仅有细肌丝）、A带（粗细肌丝都有）、Z线和H区（只有粗肌丝）
2. 根据下图，主要分为四步：
	1. 当胞质内的胞质内的钙离子浓度上升时，钙离子迅速与细肌丝上的肌钙蛋白C（TnC）结合，导致肌钙蛋白复合体构象变化，拉动原肌凝蛋白位移，暴露横桥结合位点
	2. 肌球蛋白头部结合ATP，导致构象向外侧偏转，脱离肌球蛋白（3）
	3. 肌球蛋白头部水解ATP，释放的能量导致横桥头部立起（4）
	4. 肌动蛋白的横桥结合位点暴露，与肌球蛋白结合，形成横桥的同时水解Pi（1）
	5. 无机磷酸释放后，肌球蛋白头部偏转，产生切向拉力，将细肌丝向中心拖动一小段，同时将ADP水解

# 兴奋收缩耦连
1. 先兴奋后收缩
2. 骨骼肌
	1. ![[PixPin_2026-03-18_16-49-08.png]]
	2. T管与两侧肌质网形成三联体结构
	3. 当动作电位沿肌膜传播并深入横管时，横管膜上（DHP受体）感应到电荷变化并形变
	4. 开启肌质网钙通道（雷诺丁受体 RyR1），导致大量钙离子瞬间进入肌胞质
	5. 肌钙蛋白复合体构象变化，解除细肌丝上的遮挡，启动横桥循环和肌丝滑行
3. 心肌：钙致钙释放
	1. 二联体结构，外侧钙离子通道和内侧通道几乎偶联
	2. 外界传入信号后打开钙离子通道流入微量钙离子，导致钙敏感RyR2大规模开放，随后形成正反馈
	3. 当浓度过高时RyR2自然被抑制，促使关闭通道
# 收缩特点
1. 肌肉自身收缩能力
	1. 活化横桥数（钙离子浓度+对钙离子亲和性）
	2. 肌球蛋白的ATP酶活性
2. 肌肉前收缩的负荷为前负荷
	1. ![[PixPin_2026-06-16_20-02-13.png]]
	2. 调节肌肉长度可以改变前负荷。适当负荷的肌肉能够产生的拉力最大
3. 肌肉收缩后的负荷为后负荷
	1. ![[PixPin_2026-06-16_20-02-47.png]]
	2. 调节肌肉拉力可以改变后负荷。
	3. 后负荷越大，肌丝缩短速度越慢。当后负荷等于或大于肌肉能产生的最大力量时，肌肉虽然在发力，但长度不缩短
4. 运动单位
	1. 一个脊髓前角运动神经元及其轴突分支所支配的全部肌纤维，总称为一个运动单位，参见[[运动]]
	2. 骨骼肌调节收缩强度时按照从小到大的原则进行运动单位的募集
5. 肌肉收缩可以叠加
	1. 单收缩：两次刺激间肌肉完全舒张
	2. 不完全强直收缩：刺激间肌肉可以略微舒张
	3. 强直收缩：刺激导致肌肉无法舒张，后期肌肉疲惫后张力下降
