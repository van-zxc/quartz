# 中枢神经
## 脊髓
1. 接收全身周围的感觉信息并传递给大脑
2. 脊神经：前根+后根
	1. 感觉神经元：以脊神经后背束的形式进入脊髓后部，集合形成单一的后根，其胞体聚集于脊神经节中
	2. 运动神经元：以脊神经前根束的形式从前部离开脊髓，合并形成前根
3. 宏观结构
	1. 31节：8颈 12胸 5腰 5骶 1尾，节间有椎间盘
	2. 从枕骨大孔离开颅腔，沿椎管下行，以脊髓圆锥结束
	3. 脊髓圆锥被包裹在硬膜管内，硬膜管末端形成无脊髓但充满脊神经（腰段+骶段）区域，形成腰池；腰池内的神经称为马尾
	4. 颈膨大+腰膨大，包含更多神经元
4. 脊髓横切
	1. 灰质（胞体）被白质（轴突）包围，脊髓后侧有后外侧沟以容纳后沟；前面有前外侧沟以容纳前外侧沟传出
	2. 灰质
		1. 前角：$\alpha$运动神经元胞体，执行随意运动+不随意运动
		2. 后角：中间神经元、把感觉信息上行传递给大脑的神经元（凝胶质层：痛觉+温度觉上传）
		3. 中间灰质：参与自主功能
	3. 白质
		1. 上行纤维束：感觉信息传递给大脑
		2. 下行纤维束：把运动身体回到身体
		3. 神经索束：后索（传递痛觉+肢体位置觉）、侧索（疼痛通路+引发痛觉的下行通路）、前索（各种）
## 大脑
### 大脑皮层的感觉
1. 分为古皮层&新皮层，以新皮层为主要研究对象
	1. 古皮层：分子层、锥体细胞层、多形细胞层
	2. 新皮层：分子层、外颗粒层、外锥体细胞层、内颗粒细胞层、内锥体细胞层、多形细胞层
	3. ![[PixPin_2026-06-03_15-57-58.png]]
	4. 层状结构+功能柱
	5. 功能柱：直径约为200-500nm，垂直于皮层表面，约含有100-300神经元
2. 根据皮层成分结构特征分为52个区：Brodmann分区
	1. ![[PixPin_2026-06-03_16-05-34.png]]
3. [[感觉]]投射分区
	1. 体表感觉区
		1. 第一感觉区：中央后回3-1-2区、全身体表感觉的投射区
			1. 处理触觉、痛觉、温度觉
			2. 投射区域大小和感觉精细程度有关
			3. 躯体感觉倒置安排；头面部正置
			4. 躯体感觉为交叉投射，头面部感觉为双侧投射
		2. 第二感觉区
			1. 43区附近，小而正立，痛觉相关
		3. 较低等的哺乳动物，体表感觉区&躯体控制区重合
# 丘脑
![[PixPin_2026-06-03_15-44-28.png]]
1. 位于每个大脑半球的脑干上方，充当“中继站”功能
2. 被划分为多种特化的核团
3. 结构
	1. 感觉接替核：接受第二级感觉纤维，向大脑皮层传递特别感觉区域（特异透射系统）
		1. 后腹核：接受三叉丘系，脊髓丘脑束纤维，投射到中央后回
		2. 腹外侧核：接受小脑-红核-丘脑束[[感觉#^64235d]]，投射到初级体感皮层
		3. 内膝体：接受外侧丘系的听觉传入，投射到颞叶
		4. 外膝体：接受视神经传入，投射到枕叶
	2. 联络核群：接受丘脑感觉接替核和其他皮层下中枢来的纤维，交换神经元后投射到大脑皮层某一特定区域（特异投射系统）
	3. 非特异投射核：与脑干网状结构构成丘脑网状结构，主要是髓板内核群，弥散投射到整个皮层，维持皮层的兴奋状态
4. 感觉投射系统
	1. 特异：三级神经元（除嗅、视、听），点对点投射到皮层特定区域
	2. 非特异：通过脑干发出侧支，反复换元上行，弥散性的投射到广泛区域
# 脑干
1. 从大脑底部延伸出来的茎状结构，连接大脑和脊髓
2. 功能
	1. 负责大量上行&下行通路，维持大脑和脊髓、小脑的信号传递
	2. 包含关键的维持生命体征的核团
3. 分区
	1. 延髓：脑干和脊髓连接的起点，包含调控心血管、呼吸系统的核团；包含的核团可以控制多种反射，如咳嗽、呕吐、吞咽、喷嚏等；从此处同样可以发出部分脑神经
	2. 脑桥：圆顶状，连接延髓和中脑；负责处理头面部的感觉信息和面部活动；可以处理听觉、平衡觉和自主功能
	3. 中脑：靠近大脑的脑干最上端，后侧有四个隆起，分别是上丘和下丘
		1. 上丘：眼球运动和视觉处理
		2. 下丘：听觉处理
		3. 腹侧被盖区：VTA、多巴胺生成核团，参与动机和奖赏
		4. 黑质：
			1. 分别在中脑中线两侧，分为黑质致密部和黑质网状部
			2. 黑质致密部有大量多巴胺神经元（同时合成黑色素），黑质网状部分布有大量GABA神经元
			3. 被认为是基底神经节的一部分，大量多巴胺神经元投射到尾核和壳核处，促进运动
# 小脑
1. 与动物生活强相关，神经元占脑总80%左右
2. 分区
	1. 列横向分为前叶、后叶、绒球小结叶
	2. 纵向分为蚓部、半球部
	3. ![[PixPin_2026-06-23_21-03-38.png]]
3. 作用：
	1. 维持躯体平衡
	2. 调节肌肉张力
	3. 协调随意运动
4. 传入纤维来自前庭、脊髓、大脑皮层，分为xx小脑
5. 传出纤维到达大脑皮层运动区和脑干的运动核团中，间接调控运动
6. 在技巧性运动中的获得后建立的运动学习
7. 分类
	1. 前庭小脑
		1. 绒球小结叶
		2. 接受两侧内耳&前庭核输入，控制平衡和眼球运动
	2. 脊髓小脑
		1. 蚓部/半球中间部
		2. 利用外周感觉反馈信息调节肌张力和进行中的运动。配合大脑皮层对随意运动进行管理，调节肌紧张
	3. 皮层小脑
		1. 小脑后叶的外侧区域
		2. 不接收外界感受传入，和大脑皮层感觉区、运动区、联络区形成回路
		3. 参与随意运动设计和程序编制。损伤后形成习惯的动作会缺失
