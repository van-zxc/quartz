# 中枢神经
## 脊髓
1. 24节：7颈 12胸 5腰 1骶 1尾，节间有椎间盘
2. 有灰质和白质，有前角&后角
3. 靠背部分为输入，靠前面为输出
## 大脑
分为古皮层&新皮层，以新皮层为主要研究对象
+ 分子层
+ 外颗粒层
+ 外锥体细胞层
+ 内颗粒细胞层
+ 内锥体细胞层
+ 多形细胞层
![[PixPin_2026-06-03_15-57-58.png]]
+ 出现功能柱，直径约为200-500nm的垂直平面的功能柱，约含有100-300神经元
+ 也可能有层状结构

根据皮层成分结构特征分为52个区：Brodmann区
![[PixPin_2026-06-03_16-05-34.png]]

感觉投射分区
+ 第一感觉区
	+ 躯体感觉为交叉投射，头面部感觉为双侧投射；
	+ 中央后回3-1-2区、全身体表感觉投射区
	+ 投射区域大小和感觉精细程度有关
	+ 躯体感觉倒置安排；头面部正置
+ 第二感觉区
	+ 43区附近，小而正立
	+ 痛觉相关
## 丘脑
![[PixPin_2026-06-03_15-44-28.png]]
细胞群分为三类
1. 感觉接替核：接受第二级感觉纤维，向大脑皮层传递特别感觉区域
	1. 后腹核：接受三叉丘系，脊髓丘脑束纤维，投射到中央后回
	2. 腹外侧核：接受小脑-红核-丘脑束
	3. 内膝体：接受外侧丘系的听觉传入，投射到颞叶
	4. 外膝体：接受视神经传入，投射到枕叶
2. 联络核群：接受丘脑感觉接替核和其他皮层下中枢来的纤维，交换神经元后投射到大脑皮层某一特定区域。
3. 非特异投射核：与脑干网状结构相连续，构成丘脑网状结构，主要是髓板内核群，弥散投射到整个皮层，维持皮层的兴奋状态。

因此我们可以总结为特异性投射系统和非特异性投射系统
