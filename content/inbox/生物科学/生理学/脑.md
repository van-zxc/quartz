# 研究方法
1. 功能性核磁共振成像，关注氢核密度、弛豫时间T1和T2
	1. 神经活化时会消耗氧气，导致脑神经活化。血红蛋白的携氧和脱氧会改变磁性，借此可以判断脑区的活跃程度
2. 正电子发射计算机断层扫描（PET）
	1. 使用放射性短的放射性示踪剂同位素，衰变产生的正电子湮灭
	2. 发生于代谢最旺盛的区域
3. 脑电图
	1. 脑细胞以电活动形式体现
	2. 无明显刺激情况下，大脑皮层自发产生节律变化
	3. 刺激后也会产生其他情况
	4. 脑波型
		1. $\alpha$波：8-13次/s，枕叶显著，成年人的安静脑电波，幅度20-100μV
		2. $\beta$波：大脑皮层紧张活动。14-30次/s，额叶和顶叶显著，幅度5-20μV
		3. $\theta$波：成人困倦/幼儿期可见到，4-7次/s，颞叶/顶叶显著，幅度100-150μV
		4. $\delta$波：睡眠/极度疲劳/婴儿大脑等大脑不活跃时出现，0.5-3次/s，幅度20-200μV
	5. 同步化/去同步化
		1. 低波幅高频率：去同步化，兴奋增强
		2. 高波幅低频率：同步化，抑制变深
	6. 机制：丘脑是脑电波活动的起点
	7. 癫痫？大量神经元同步放电，导致大脑正常活动中断
# 摄食
1. 摄食行为
	1. 摄食能量代谢调控的神经体液网络，枢纽为下丘脑（[[神经#丘脑]]）
2. 摄食行为由下丘脑两个中枢平衡调控
	1. 饥饿中枢：下丘脑外侧区，负责促进摄食
	2. 饱中枢：下丘脑腹内侧核，负责发出饱食信号
	3. 多因素调控？
	4. 瘦素：脂肪细胞分泌，靶向下丘脑弓状核，调控摄食

# 睡眠
1. 觉醒
	1. 觉醒依赖脑干网状结构上行激动系统
		1. 巴比妥类：抑制系统活动，催眠
	2. 行为觉醒/脑电觉醒
		1. 行为觉醒：清醒状态的行为表现，如对新奇现象的探究、黑质多巴胺能系统
		2. 脑电觉醒：脑电波去同步化，和蓝斑上部去甲肾上腺素能系统/脑干网状结构胆碱能系统
2. 睡眠
	1. 慢波睡眠SWS：
		1. 感觉功能减退、腱反射肌紧张减弱，副交感系统支配，生长激素分泌增多
		2. ![[PixPin_2026-06-23_21-47-38.png]]
		3. 促进生长，恢复体力
	2. 快波睡眠REM：
		1. 眼电增强，肌电减弱
		2. 感觉功能减弱，难以唤醒
		3. 有间歇性阵发性表现---眼球快速转动，部分身体抽动，血压上升心率加快等
		4. 做梦
		5. 脑内蛋白质合成、突触建立联系
	3. 机制：慢波睡眠和快波睡眠交换，均可被唤醒，必须先慢波后快波
	4. 机制？
		1. 脑桥被盖外侧区胆碱能神经元：REM
		2. 去甲肾上腺素能（蓝斑）/血清素能神经元（中缝核）：REM关闭神经元
3. 睡眠激素
	1. 生长素、生长素释放激素、生长抑素
	2. 催乳素、血管活性肠肽
	3. 褪黑素：松果体分泌
		1. 松果体细胞持续分泌褪黑素，高峰出现在午夜
		2. 视神经信号传递给下丘脑的视交叉上核，随后间接影响松果体
4. 中枢生物钟：下丘脑视上核SCN

4. 多巴胺能神经元分型
	1. 价值编码：奖赏刺激激活，厌恶性刺激抑制
	2. 厌恶编码：厌恶性刺激激活
	3. 突显性编码：均可

3. 记忆
	1. 感觉性、第一级、第二级、第三级记忆
	2. ![[PixPin_2026-06-23_22-12-32.png]]
4. 遗忘：
	1. 艾宾浩斯遗忘曲线
	2. 顺行性遗忘：不能保留最新获得信息，近事遗忘，记忆不能转入第二级，常见于酒精中毒者，与海马体障碍有关
	3. 逆行性遗忘：脑功能发生障碍前一段时间记忆丧失，第二级记忆发生紊乱，第三级无影响
5. 海马体：
	1. 每个半球的颞叶中存在
	2. 海马复合体：海马体（处理记忆）、海马旁回（靠近海马体的皮层）、齿状回
	3. 输入：穿通束起源于内嗅皮层终止于齿状回，把信号传导至海马体（CA3→CA1）
	4. 输出：海马CA1→下托→内嗅皮层
6. 突触可塑性
	1. 学习和记忆的神经基础
	2. 突触可以在形态结构和接触上都发生改变
	3. 新突出形成/突触重排、突触反复活动导致突触传递效率会变化
	4. 表现形式：长时程增强（LTP）
		1. [[神经递质#受体]]
		2. 钙离子流入导致更多AMPA到膜上，导致更加敏感，正反馈
	5. 对立：LTD长时程抑制，和上面的相反，低浓度的钙离子流入会激活蛋白磷酸酶，导致AMPA减少
7. 记忆的形成（这部分普遍没研究明白，大概了解就行 #补充 ）
	1. 短期记忆：离子通道的改变，导致局部神经递质的增多
	2. 长期记忆：突触蛋白质变化或新突触形成
