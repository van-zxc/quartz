# 神经
[[自主神经系统]]

反射调节: 心脏受心交感神经和心迷走神经支配, 由脊髓发出
+ 心交感神经: 
	+ 支配窦房结, 房室交界, 房室束, 心房肌, 心室肌
	+ 增强心脏收缩
	+ 释放去甲肾上腺素, 作用于心肌细胞膜上$\beta_{1}$受体, 引起cAMP增加
		+ 正性变时作用: 窦房结自律性加强 心率增快
		+ 正性变传导作用: 房室结节传导心率速度增快
		+ 正性变力作用: 心房肌心室肌收缩加强
+ 心迷走神经: 
	+ 释放Ach, 导致cAMP浓度降低
	+ 负性变时作用: 钾离子外流, 心率减慢
	+ 负性变传导作用
	+ 负性变力作用

肾素-血液紧张素系统
![[PixPin_2026-04-08_17-49-52.png]]
血管紧张素受体（AT受体）：AT1，AT2，AT3，AT4 受体

血管紧张素II作用于血管平滑肌，使全身微动脉收缩，血压升高。是已知的最强缩血管物质之一
同时刺激肾上腺皮质球状带细胞合成和释放醛固酮，增加细胞外液。
血管紧张素I不具生物活性
血管紧张素III与II有相似的生物效应，但是缩血管效应仅为血管紧张素的10%~20%。

肾素-血管紧张素的升高血压机制约需20min才能全部生效，相比较肾上腺素和去甲肾上腺素的作用机制，其启动慢但持续时间长很多。
