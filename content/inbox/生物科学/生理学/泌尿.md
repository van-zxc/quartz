	3. 球外系膜细胞：入球出球小动脉和致密斑之间的细胞群，有吞噬和收缩功能，信息传递功能. 
# 血循环特点
1. 血流量大，血流分布不均匀：1200 ml/min，血流量最大的器官之一；94%的血液分布在肾皮质层
2. 肾小球毛细血管网压力高，肾小管周围的则压力低
3. 血流量相对稳定。血压变动在80-180 mmHg附近时能维持相对稳定
# 调节
1. 神经
	1. 交感神经支配：脊髓胸段12节和腰段1,2节发出，调控动脉平滑肌和肾小球旁细胞
	2. 交感神经兴奋时，肾血管收缩，肾血流量减少
# 尿的生成
1. 肾小球滤过
	1. 肾小球滤过率? 每分钟形成的原尿量（125 mL/min）
	2. 滤过率：19%
	3. 内层：毛细血管内皮细胞50-100 nm的孔
	4. 中间层：非细胞性基膜，2-8 nm孔
	5. 外层：肾小囊上皮细胞，有相互交错的大凸起和小凸起；小凸起固定在基膜上
	6. 决定滤过的因素：分子大小（70kDa）、分子电荷（负电荷难以通过，防止白蛋白）
	7. 滤过动力? 有效滤过压 = 肾小球毛细血管压 - （血浆胶体渗透压+囊内压）
	8. 影响滤过因素：
		1. 膜的通透性：炎症时滤过膜通透性增大
		2. 滤过面积：病理时减少
		3. 有效滤过压的改变
			1. 肾小球毛细血管压（80-180 mmHg）
			2. 囊内压
			3. 肾血浆流量
			4. 血浆胶体渗透压
2. 肾小管和集合管的重吸收
	1. 选择性：被动重吸收/主动重吸收
	2. 途径：跨细胞转运途径/细胞旁途径
	3. 水的重吸收
		1. 被动，依靠渗透作用进行；近端小管吸收67%的过滤水；渗透梯度存在于上皮细胞和细胞间隙之间，通过钠离子重吸收进行
		2. 肾小管和集合管细胞膜上存在水通道蛋白，形成水通道（四聚体AQP1）
	4. $Na^{+}$和$Cl^{-}$的重吸收
		1. 近端小管前半段：70%的钠离子和氯离子，水被重吸收
			1. 钠离子泵作用排放钠离子到血液内，胞内浓度下降
			2. 葡萄糖，钠离子同向转运
			3. 葡萄糖易化扩散回到血液
		2. 近端小管后半段：10%钠离子和氯离子通过细胞旁路和跨上皮细胞两条路径被重吸收
			1. 根据下文，碳酸氢根&水被重吸收后，氯离子浓缩。于是CI通过细胞旁路重吸收（顺浓度梯度）
			2. Cl-出去后，环境为正电性，Na+被排斥，同样通过细胞旁路重吸收（顺电位梯度）
		3. 髓袢（主要发生在髓袢升支粗段）
			1. 20%钠离子被重吸收
			2. 10%的Na+通过钠-氯-钾同向转运进入细胞（动力由钠钾泵维持）
			3. 钾泵会将钾离子泵回管腔，这导致溶液电性改变，剩下的正离子被库仑力推到细胞旁路
		4. 远端小管和集合管
			1. 初段：钠离子通过钠-氯同向转运进入细胞，随后钠离子泵出细胞且主动吸收回血，氯离子被动运输回血
			2. 后端&集合管含有主细胞和闰细胞
			3. 主细胞：钠钾交换；闰细胞：交换氢离子和碳酸氢根
	5. 碳酸氢根重吸收
		1. 80%在近端小管重吸收，和小管上皮细胞管腔膜的钠-氢交换有关
		2. 钠氢交换出大量氢离子，在碳酸酐酶催化下分解产生CO2扩散返回细胞
	6. 钾离子重吸收
		1. 67%在近端小管中重吸收，30%左右主要在髓袢中被重吸收
		2. 排除的主要都是在远端小管分泌的
	7. 葡萄糖重吸收
		1. 近端小管前端全部重吸收：葡萄糖只有和载体、钠离子形成复合体后才能被转运
		2. 肾糖阈：最大的可能完全吸收尿糖的血糖阈值，约为1.6-1.8 mg/mL
		3. 最大转运速率出现在3 mg/mL血糖时
3. 肾小管和集合管的分泌
	1. 氢分泌和钠氢交换：主动转运氢离子到外界，使得钠离子被动扩散到细胞内. 正常尿液中一般不含有碳酸氢根
	2. 钾分泌和钠钾交换：钠离子重吸收时，钾离子由于电位差异被动分泌，吸收一个钠就分泌一个钾
	3. 钠钾交换和钠氢交换相互竞争；酸中毒引起高血钾；高血钾引起酸中毒
	4. 氨的分泌：
		1. 谷氨酰胺生成氨分子，扩散到细胞外，结合氢离子生成铵根降低氢离子浓度，有利于氢离子分泌
		2. 生成氯化铵排出体外，有利于排酸

# 尿生成的调节
## 肾血流量的自身调节
1. 在20-80与>180 mmHg时，肾血流随着血压升高而升高
2. 可能受到[[平滑肌]]影响
## 肾小管活动调节
1. 肾内自动调节
	1. 小管液体中溶质浓度：浓度高，渗透压高，阻碍水和氯化钠重吸收，尿量升高，可以使用山梨醇/甘露醇用作利尿剂（渗透性利尿）
	2. 球管平衡：尿液中排出的溶质不会因肾小球滤过的增加或减少而有大幅度的变化，近端小管的重吸收率相对固定
## 神经体液调节
1. 肾交感神经：通过收缩肾小球动脉，促进释放肾素，增加水盐重吸收等减少尿液生产
2. 抗利尿激素ADH：
	1. =血管升压素，来自下丘脑视上核，9个氨基酸的多肽，经由丘脑-垂体束送到神经垂体储存
	2. 激活血管平滑肌V1受体，促血管收缩；激活分布在远端小管和集合管上皮上的V2受体，提高通透性；提升氯化钠重吸收&尿素通透性。帮助尿浓缩
	3. 作用机制：结合V2受体，提升腺苷酸环化酶活性，促进cAMP生成，激活蛋白激酶，释放含有水通道蛋白的小泡向膜迁移，增加水通道蛋白数量
	4. 调节因素：
		1. 体液渗透压：渗透压感受器位于下丘脑视上核等区域，对晶体渗透压敏感；晶体渗透压变化导致ADH分泌变化
		2. 循环血量改变：容量感受器位于左心房心内膜下，血量多会启动反馈
		3. 增加释放：血管紧张素、疼痛等应激刺激、低血糖、恶心等
		4. 减少释放：寒冷、乙醇
3. 肾素-血管紧张素-醛固酮系统
	1. 影响肾素分泌因素：
		1. 入球小动脉处的牵张感受器（循环血量减少→肾内入球小动脉的压力下降一血流量减少→小动脉壁的牵张刺激减弱→激活牵张感受器→肾素释放量增加）
		2. 致密斑感受器（→滤过的Na+量减少→激活致密斑感受器，肾素释放量增加）
		3. 肾交感神经兴奋（肾交感神经兴奋时→肾素的释放量增加)
	2. 血管紧张素Ⅱ
		1. 直接作用于肾小管影响重吸收
		2. 改变肾小球滤过率
		3. 通过对ADH的调节影响尿生成
		4. ![[PixPin_2026-06-20_16-06-33.png]]
	3. 醛固酮：保钠排钾
		1. 醛固酮+胞浆内受体→激素-受体复合物 →进入细胞核→与DNA作用→特异性mRNA转录
		2. 增加钠通道蛋白数量
		3. 诱导合成ATP酶，导致钠泵能量增加
		4. 诱导合成侧膜钠泵，促进钠钙交换，氯离子重吸收增加
		5. 醛固酮受血管紧张素刺激、血钾升高（敏感）和血钠降低调控分泌
# 尿的排放
1. 膀胱和尿道神经支配
	1. 盆神经（副交感）：
		1. 传出神经使得逼尿肌收缩，内括约肌舒张，膀胱胀胀的
	2. 腹下神经（交感）：
		1. 兴奋和盆神经相反，传入膀胱痛觉
	3. 阴部神经（躯体神经）：受意识支配，使外括约肌收缩
2. 排尿反射
	1. 异常：尿失禁 尿频 尿潴留（排尿反射无法发生）
	2. 幼儿/老人大脑发育不完全，容易尿床；成人大脑皮层排尿反射中枢发育完全，几乎不会

# 尿稀释和浓缩
1. 尿液的渗透压可因体内水缺乏/富裕发生大幅度变化
2. 尿液的稀释：
	1. 小管液体中溶质被重吸收而水不被重吸收
	2. 抗利尿激素受到抑制
	3. 浓缩相反
3. 机制：直小血管逆流交换和肾小管逆流倍增系统
	1. 肾皮质的组织间液的渗透压与血浆相比为1.0，随着向髓质的深入，二者之比逐步升高，从2.0、3.0直至4.0，形成一个渗透压梯度。
	2. 髓袢是形成渗透压梯度的重要结构。髓袢越长，尿浓缩的能力越强
	3. 髓袢逆流倍增系统：
		1. 简单来说就是，降支段只能透水、升支段只能吸盐；升支段抽的盐导致组织间隙渗透压增高，随即导致降支段自然浓缩；降支段内渗透压高的液体到了升支段再次被抽盐，导致组织间隙渗透压再次升高，如此循环
		2. 经过循环，在髓质深处，最高渗透压能够达到原先的六倍
	4. 直小血管逆流交换系统
		1. 为了带走被抽走的水，维持高渗透压；全程为被动扩散
		2. 本质上就是前后血压降低，导致由于压力外泌到外侧的水少了；于是在高浓度时吐水、在低浓度时吸水；吸水量高于吐水量，就自然将水转运走了
