# 跨膜离子平衡与细胞膜电位
1. 膜电位：
	1. 膜内侧相对外侧的电位差
	2. 记录方法：胞外记录、胞内记录、电压钳、膜片钳
2. 细胞内主要是钾离子，细胞外主要是钠离子、氯离子、钙离子
3. 平衡电位：
	1. 扩散和静电作用相互作用的平衡，即处于电化学平衡状态
	2. 由[[Nernst方程]]得：电位和电荷密度有关，故只要膜电位不等于平衡电位，就会存在离子的跨膜流动。电位差别越大驱动力越大
	3. 只有当跨膜通道开放时才能实现跨膜 
4. 刺激：引起机体发生内环境的变化
5. 兴奋：狭义通常指细胞的动作电位（可兴奋细胞：感受器、神经、肌肉、腺体等）
# 静息膜电位
1. 静息膜电位：没有刺激时大多数细胞稳定的水平
	1. 多数细胞为-80mV~-50mV
	2. 静息状态下，钾离子自然外流，对细胞电位贡献最大，因此细胞电位正常内正外负
	3. 钠钾泵对静息电位有贡献
2. 膜的被动反应：阈下反应、分级反应（去极化/超极化）、局部反应
	1. 电紧张电位：细胞物理上产生的反应
	2. 阈下反应可以在时间/空间加和
3. 极化状态：内负外正。钾离子的通透性最高，钠钾泵帮助静息膜电位的产生
4. 可以把膜等价为电容和电阻的串联
# 动作电位
+ 可兴奋膜在收到足够大的刺激时，去极化到达阈电位后，所产生的快速去极化和复极化过程，
+ ![[PixPin_2026-03-11_16-27-27.png]]
+ 潜伏期
+ 快速去极化：快速由内正外负变为内正外负
+ 去极化+复极化 == 峰电位/反极化
+ 后超极化最后的低于静息电位的部分（不应期和频率限制）
## 过程
1. 去极化：钠离子通道打开，钠离子大量内流
2. 超极化：钠离子通道失活，钾离子通道打开，钾离子大量外流
	1. 钠离子通道原理：在外界电位迅速改变后，内部电性改变导致通道蛋白构象改变，三个Domain的响应导致通道开放。第四个略慢的Domain响应后导致IFM楔子扭转，关闭通道
3. 后超极化：钾离子通道缓慢失活，打开时间长，钾离子外流的多，导致超极化；一定时间后回到原静息电位
4. 特点
	1. 主动反应
	2. 全或无（有/没有），不可加和
	3. 不应期→一段时间难以受到刺激
		1. 相对：动作电位去极化/部分超极化区，刺激再大也无法触发动作电位
		2. 绝对：部分超极化+后超极化，阈上电位可以刺激产生动作电位
5. 通道有三种状态：开启→失活→关闭，切换状态需要时间
## 动作电位的传导
1. 特点
	1. 不衰减，通过局部电流提供刺激
	2. 自加强
	3. 不应期间不能回传
2. 增加直径可以提高传导速度（减小电阻，增加局部电流的传导速度）
	1. 形成髓鞘，朗飞氏结相当于中继器，有髓鞘包被部分相当于电线，

不同细胞离子通道不同，导致动作电位不同
