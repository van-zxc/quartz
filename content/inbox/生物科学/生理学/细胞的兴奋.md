# 跨膜离子平衡与细胞膜电位
+ 膜电位: 膜内侧相对外侧的电位差
	+ 胞外记录
	+ 胞内记录
	+ 电压钳
	+ 膜片钳
+ 细胞内主要是钾离子, 细胞外主要是钠离子和氯离子. 钙离子在细胞内含量极小
+ 平衡电位: 钾离子扩散和静电作用相互作用的平衡. 即处于电化学平衡状态. 由[[Nernst方程]]得: 电位和电荷密度有关. 故只要膜电位不等于平衡电位, 就会存在离子的跨膜流动. 电位差别越大驱动力越大. 这是显然的. 此外, 只有当跨膜通道开放时才能实现跨膜. 
+ 刺激: 引起机体发生内环境的变化. 
+ 兴奋: 狭义通常指细胞的动作电位. (可兴奋: 感受器, 神经, 肌肉, 腺体等等)
+ 静息膜电位: 没有刺激时, 大多数细胞稳定的水平. (多数细胞为-80mV~-50mV)
+ 极化状态: 内负外正. 钾离子的通透性最高, 钠钾泵帮助静息膜电位的产生. 
+ 被动反应: 阈下反应. 分级电位(可以去极化, 可以超极化), 局部反应(发生衰减)
+ 可以把膜等价为电容和电阻的串联. 
### 动作电位
+ 可兴奋膜在收到足够大的刺激时, 去极化到达阈电位后, 所产生的快速去极化和复极化过程. 
+ ![[PixPin_2026-03-11_16-27-27.png]]
+ 快速去极化: 快速由外正内负变为内正外负. 
+ 去极化+复极化 == 峰电位/反极化
+ 后超极化: 最后的低于静息电位的部分. (不应期和频率限制)
#### 过程
+ 钠离子通道打开, 钠离子大量内流→钠离子通道失活, 钾离子通道打开, 钾离子大量外流→钾离子通道缓慢失活, 打开时间长, 钾离子外流的多, 导致超极化
+ 主动反应
+ 全或无(有/没有)
+ 不应期→一段时间难以受到刺激 相对/绝对
+ 通道有三种状态: 开启→失活→关闭. 切换状态需要时间
#### 动作电位的传导
+ 不衰减, 通过局部电流提供刺激
+ 自加强
+ 不应期间不能回传
#### 传导速度
+ 增加直径可以提高传导速度(减小电阻, 增加局部电流的传导速度)
+ 形成髓鞘. 朗飞氏结相当于中继器, 有髓鞘包被部分相当于电线. 

不同细胞离子通道不同, 导致动作电位不同.
