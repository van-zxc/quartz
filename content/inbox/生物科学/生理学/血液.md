# 血液组成
+ 体液：占体重的60%
	+ 细胞内液：占体重的40%，参与细胞的代谢反应；
	+ 细胞外液：占体重的20%
		+ 4/5在血管外：组织液、淋巴液、脑脊液等
		+ 1/5在血管内：血液(血浆)
	+ 血量：全身血液总量占体重的7-8%。包括循环血量和储存血量

功能：
维持机体内环境稳定-气体和物质交换、参与生理性止血；参与机体防御功能, 散热

+ 血浆: 水+离子+维生素+有机物(糖 蛋白 脂质(LDL etc. ) 磷脂 尿素等)+气体  55%
	+ pH约为7.35-7.45
	+ 血浆[[渗透压]]内, 晶体渗透压80%来自$Na^{+}$和$Cl^{-}$; 胶体渗透压75-80%来自白蛋白
+ 血细胞
	+ 红细胞  45%
	+ 白细胞, 这部分100%涉及[[免疫学]]的内容. 
		+ 淋巴细胞
		+ 单核细胞
		+ 粒细胞(酸 碱 中)
	+ 血小板: 巨核细胞的碎块

红细胞比容: 红细胞占血液容积百分比
所有血细胞都由造血干细胞而来
### 红细胞
形态: 双凹圆盘状, 直径7-8μm
数量: 420w-500w/μL
发育过程: 造血干细胞→成红细胞→网织红细胞→成熟红细胞

特性: 
1. 可塑变形
2. 沉降缓慢, 稳定悬浮于血浆
3. 红细胞生成&破坏
	1. 平均周期120天
	2. 蛋白质, 铁, 叶酸, 维生素B12
	3. EPO(促红细胞生长素)和性激素可以调节生成

### 白细胞
1. 有粒白细胞:占60%
	1. 中性粒细胞: 占95%, 吞噬细菌, 炎症增多
	2. 嗜酸性粒细胞: 占4%, 参与对蠕虫的免疫反应, 颗粒含有过氧化氢酶
	3. 嗜碱性粒细胞: 占1%, 参与过敏反应, 颗粒为肝素, 组织胺
	4. 增多时一般象征细菌感染
2. 单核细胞: 占9%
	1. 进入血液后,迁移到组织中, 成熟后变为巨噬细胞
	2. 释放多种细胞因子, 有吞噬功能
3. 淋巴细胞: 免疫应答反应, 30%
	1. B细胞: 来自骨髓, 体液免疫
	2. T细胞: 胸腺成熟, 细胞免疫
		1. 辅助性T细胞, 抑制性T细胞, 效应T细胞, 细胞毒性T细胞
![[PixPin_2026-03-25_15-35-59.png]]
4. 异常: 
	1. 降低: 药物过敏, 病毒感染, 免疫缺陷
	2. 中性粒升高: 细胞感染, 炎症, 烧伤, 中性粒细胞性白血病
	3. 淋巴增高: 百日咳, 病毒感染,白血病
### 血小板
骨髓中成熟巨核细胞经过胞浆裂解产生的具有生物活性的小块胞质
1. 功能
	1. 维护血管壁的完整性, 弥补血管空隙→出血时间延长
	2. 具有粘附, 聚集和释放功能, 参与止血
# 理化特性
1. 颜色: 血红蛋白→红
2. 黏度: 相对水黏度为1:4
3. 渗透压: 313mOsm/kg. [[内环境--体液与血液#^85e8af]]
4. pH: 7.35-7.45, 缓冲对

### 凝血因子
直接参与凝血的物质有12种 (罗马数字1→13, 6是5的活化形态)
除了IV为钙离子外, 都是蛋白酶
大部分凝血因子是没有活性的抗原, 需要被激活
除III外(组织液), 其他凝血因子都在血浆内
2, 7, 9, 10需要维生素K合成
除此之外还有两个因子: 前激肽释放酶(PKK), 高分子量激肽原(HK)
### 瀑布学说
一系列蛋白质分子的水解过程
1. 凝血酶原酶复合物形成
	1. 内源途径涉及8, 9, 11, 12.    8, 9, 11对应血友病
	2. 外源途径涉及组织因子, 导致弥漫性血管内凝血
2. 凝血酶原变为凝血酶(受凝血酶原酶复合物和钙离子作用)
	1. 激活血小板
3. 纤维蛋白酶变为纤维蛋白

5. 超进化版: 加大外源性作用因子的作用![[PixPin_2026-03-25_16-23-37.png]]
### 抗凝系统
1. 抗凝血酶III: 丝氨酸蛋白酶抑制物, 封闭凝血因子的活动中心, 正常状态慢且若, 但可以和肝素结合, 作用增强2000倍
2. 肝素: 酸性粘多糖, 通过肥大细胞核嗜碱性粒细胞产生. 通过增强抗凝血酶活性发挥抗凝作用
3. 蛋白C系统: 包括蛋白C等一系列血浆蛋白, 扑灭限速因子8a和5a, 抑制因子X和凝血酶原的激活
### 纤维蛋白的溶解

1. 纤溶酶原激活
2. 纤维蛋白的降解
正常情况下，血液中的抗纤溶酶的含量高于纤溶酶的含量，使纤溶酶的作用不易发挥。在发生血凝块或血栓后，由于纤维蛋白能吸附纤溶酶原和纤溶酶原激活物而不吸附抑制物，因而纤溶酶大量形成和发挥作用，使血凝块或血栓发生溶解液化。

# 血型
最常见血型为ABO血型
红细胞凝集: 抗原抗体. 
凝集原: 红细胞膜上的抗原; 凝集素: 血浆中的球蛋白抗体
### ABO血型
根据红细胞膜上是否存在凝集素A/B判断. 
[[脂质#^72e432]], [[糖#^c44d77]]
ABO存在天然抗体, 通常属于IgM抗体, 无法透过胎盘. 因此孕妇血型和胎儿无影响
A型存在亚型: A1只抗B, A2既抗B又抗A1
![[PixPin_2026-03-25_16-44-32.png]]

A, B为双显性基因
### Rh血型
Rh阳性: 红细胞膜上有D抗原; 阴性反之. 
+ Rh阴性者只有在接受了Rh阳性血后才能产生抗体. 多次输血会导致溶血反应. 
+ 抗体为IgG, 可以透过胎盘. 生育第二胎会发生新生儿溶血
### 其他血型
白细胞血型: HLA抗原

### 氧气
物理溶解1.5%, 化学结合98.5%
主要依靠[[蛋白质功能|血红蛋白]]
特征: 
1. 反应快, 可逆, 不需要酶催化
2. 氧合反应
3. 一分子可以结合四分子氧气

氧容量(理论最大结合)为20.1mL, 氧含量为实际结合, 氧饱和度为前面的比值
### 二氧化碳
溶解5%, 化学结合95%(碳酸氢盐88%, 氨基甲酰血红蛋白7%)

碳酸氢盐: 二氧化碳→(碳酸酐酶)→碳酸→碳酸氢钠  氯转移
氨基甲酰血红蛋白: 
+ 无须酶催化, 迅速可逆, 氧合作用
+ 组织HbO2解离生成的HHb和CO2生成氨基甲酰血红蛋白, 在肺部HbO2生成增多, 促使二氧化碳释放
