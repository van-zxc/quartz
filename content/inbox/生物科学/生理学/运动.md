## 大脑皮层运动区&下行运动通路
1. 大脑皮层运动区是调控和控制运动的最高级中枢
2. 初级运动皮层（点对点关系）、前运动皮层、辅助运动皮层
3. 前+辅助接受后顶叶和前额叶联络皮层的纤维投射
4. 皮层脊髓束：躯干+肢体运动
	1. 上运动神经元从运动皮层出发，下行至脑干，进入中脑的大脑脚；随后继续下行至延髓，形成锥体
	2. 侧束：90%、在延髓锥体交叉到对侧脊髓外侧索下行而形成皮层脊髓侧束，进化上新，控制远端，精细活动
	3. 前束：10%、不在延髓交叉，在脊髓同侧前索下行形成，并通过中间神经元接替，到达相应脊髓阶段和下运动神经元接触时再交叉；进化上老，控制躯干和四肢近段，大幅度活动
5. 皮层脑干束：头面部肌肉活动
## 反射？
1. 脊髓反射：非随意运动
	1. 牵张反射：最简单的反射，仅由两个神经元（传入+传出）构成
		1. 感受器：肌梭，感受肌肉长度变化的感受装置，和梭外肌呈并联关系
		2. 传入神经有Ia和II类，梭内肌传出神经为$\gamma$纤维，梭外肌为$\alpha$纤维
		3. 过程：肌肉拉长→肌梭内感受器兴奋→传入→前角$\alpha$运动神经元兴奋→被牵拉的肌肉收缩
		4. 类型：腱反射、肌紧张
			1. 位相性牵张反射：快速牵拉肌腱时发生的牵张反射；单突触反射，0.7 ms潜伏期；梭内肌同时受到牵拉、反射；快肌纤维参与
			2. 紧张性牵张反射：持续牵拉肌肉导致的收缩，不表现明显收缩动作；同一肌肉内不同运动电位交替性收缩防止疲劳；慢肌纤维参与收缩；维持身体姿势产生肌张力
		5. γ运动神经元提高肌梭对牵拉刺激的敏感性
			1. 肌肉缩短时肌梭仍能传递肌肉长度信息
			2. 肌肉缩短时肌梭持续传入冲动使肌肉收缩，维持肌紧张
			3. $\gamma$神经元可以调节梭内肌负荷
	2. 腱器官反射：
		1. 高尔基腱器官，在肌肉和肌腱的接头处，和骨骼肌纤维串联，感受肌肉张力
		2. 传入神经元和胶原蛋白混杂
		3. 反牵张反射：肌肉收缩的张力传入腱器官→Ib传入纤维放电增加→抑制$\alpha$神经元
		4. 避免肌肉收缩产生过大张力导致受伤
	3. 屈反射/交叉伸反射：多突触、保护性反射
		1. 感受器位于皮肤，多交叉途径
		2. 过程：
			1. 伤害性信号传入：皮肤感受器受到刺激→通过初级传入神经元传入脊髓并分叉
			2. 上行传导：a通路上行至大脑，产生痛觉并调整姿势
			3. 同侧屈肌反射：a通路通过同侧中间神经元，兴奋屈肌抑制伸肌，规避损害
			4. 对侧交叉伸肌反射：c通路跨过脊髓中线，抑制对侧伸肌，兴奋屈肌，使对侧腿强直
		3. 巴彬斯基征
2. 节律运动
	1. 搔抓，行走（节律性&随意运动），呼吸（双重控制）
# 随意运动
1. 阶段：运动计划、运动编程、运动执行
2. 运动皮层：在额叶中，和随意运动强相关
3. 初级运动皮层
	1. 位于中央前回（中央沟前方）
	2. 皮质脊髓束/皮质脑干束传出，引发身体运动
	3. 随意运动的发起和控制
		1. 精确定位，倒置安排，头面部内为正立
		2. 机能代表区大小与运动的复杂度相关
		3. 运动神经元编码力/负载，不仅是空间位置
	4. 放电和运动方向
		1. 多个细胞，非点对点
		2. 群体向量可以预测方向
4. 辅助运动皮层/前运动皮层
	1. 前运动区：前运动皮层、辅助运动皮层
	2. 前运动皮层：皮层的外侧表面；辅助运动皮层；半球的内侧面
	3. 辅助运动皮层
		1. 运动序列执行、技能掌握等
		2. 常是双侧型运动反应
		3. 运动不直接参与运动执行，和运动计划时思想活动过程有关，需要初级运动皮层参与
	4. 前运动皮层
		1. 接受后顶叶和初级运动皮层传入，传出也到达初级运动皮层
		2. 控制躯体中轴肌肉和肢体近段肌肉活动，方向etc. 
5. ==基底神经节==
	1. 皮层下核团统称
	2. 组成：纹状体（尾核 壳核：新纹状体、苍白球：旧纹状体），红核、黑质、丘脑底核等
		1. 尾核和壳核功能类似，输入核团；苍白球输出核团
		2. ![[PixPin_2026-06-23_20-23-22.png]]
	3. 传入
		1. 接受大脑皮层（除视觉&听觉）和黑质致密部，大脑皮层（视听除外）均发出纤维传入到基底神经节
	4. 传出：谷氨酸、GABA、多巴胺等神经递质
		1. 苍白球&黑质，信号投射至皮层和脑干内其他核团
		2. 传出途径：苍白球内侧（GPi）&黑质网状部（SNr），通过直接/间接通路投射到丘脑前腹核/外侧腹核（VA/VL），调节兴奋性
		3. 部分纤维到脑干网状结构，红核、上丘，不直接投射到脊髓
		4. ![[PixPin_2026-06-10_17-30-18.png]]
		5. 基底核核心：中型多棘神经元，分泌GABA但是有两种多巴胺受体
	5. 作用机制：
		1. 不直接引发运动，通过影响其他脑区调控运动
		2. 静息时：苍白球紧张性放电，持续抑制丘脑，使运动皮层无激活；
		3. A被兴奋时：纹状体一过性激活，释放GABA抑制苍白球的放电；苍白球的暂停放电使丘脑去抑制，从而能接受外来输入并激活皮层产生运动。
		4. ![[PixPin_2026-06-10_17-34-43.png]]
	6. 疾病：帕金森（多巴胺神经元大量死亡，纹状体抑制运动难以解除）；亨廷顿舞蹈症（GABA神经元退行性病变，导致尾核/壳核到苍白球外侧部的抑制减弱，丘脑兴奋作用增强，运动过度）
