# 运动过程
## 脊髓运动神经元
![[PixPin_2026-06-10_15-29-39.png]]
进化上来看，靠内侧的为进化早的，反之则进化晚
+ 受$\alpha, \beta, \gamma$运动神经元控制，轴突经过前根离开脊髓后直接达到所支配的肌肉
	+ 大$\alpha$：快肌纤维，瞬间爆发
	+ 小$\alpha$：慢肌纤维，持久运动
	+ $\gamma$：支配梭内肌，有高频的持续放电
+ 运动单位：一个$\alpha$神经元及其所支配的全部肌纤维所组成的功能单元
	+ ![[PixPin_2026-06-10_15-33-55.png]]
	+ 一对多进行调控
## 脑干下行神经通路
脑干是控制调节躯体运动的较高级中枢，许多脑干神经元投射到脊髓灰质的中间神经元和运动神经元上
+ 内侧由以下构成：前庭脊髓束、网状神经束、顶盖神经束
+ 外侧由红核脊髓束构成

脑桥+中脑+延髓
## 大脑皮层运动区及其下行运动通路
+ 大脑皮层运动区是调控和控制运动的最高级中枢
+ 初级运动皮层（点对点关系）、前运动皮层、辅助运动皮层
+ 前+辅助接受后顶叶和前额叶联络皮层的纤维投射
