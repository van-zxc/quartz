	2. 空肠、回肠、大肠（下消化道）

	1. 唾液腺、肝、胰

## 神经
1. 内在神经系统：[[肠神经系统]]
	1. 肌间神经丛，粘膜下神经丛，8-10亿神经元（感觉、运动等）
	2. 可以独立行使功能，包括蠕动，调节分泌吸收，被称为肠脑
2. 外来神经：
	1. 交感神经：内脏神经，脊髓T1-T10，L1-L2，分泌去甲肾上腺素，抑制分泌运动
	2. 副交感神经：主导，迷走神经+盆神经，起源于脑干和脊髓，分泌乙酰胆碱，促进分泌运动
3. 外来神经和内在神经通讯是双向的
## 胃肠激素
1. 消化道是体内最大的内分泌器官
2. 分散分布于胃肠道上皮，多数为肽类激素（胃肠肽）
3. 作用为调节消化液分泌和消化道运动，调节其他激素释放和营养
4. 胃泌素：G细胞、促进胃液分泌和上皮生长
5. 组胺：ECL细胞、刺激胃液分泌
6. 缩胆囊素：I细胞，刺激胰液酶样分泌，收缩胆囊
7. 促胰液素：S细胞，刺激胰液水样分泌，抑制胃液分泌
8. 抑胃肽：K细胞，抑制胃液和胃排空，刺激胰岛素

消化腺同时还有外分泌功能，成分为水，有机物和无机物

# 消化道运动
## 胃的运动
1. 紧张性收缩：经常保持张力弱的收缩，维持胃内压
2. 容受性舒张：空腹时50 mL变到1500 mL，胃内压不会明显升高，由胃主动舒张所致
3. 蠕动：进食后使食糜和胃液充分混合排入小肠，从中部开始到幽门，需要1 min
4. 排空：
	1. 胃的收缩导致胃内压上升和十二指肠内压之间的压力差；幽门括约肌起到控制阀作用
	2. 胃排空是间断性的
	3. 食物理化性质
		1. 排空速度：糖>蛋白质>脂肪
		2. 等渗>非等渗（十二指肠产生负反馈）
	4. 胃内食物量（排空率和留在胃内食物量的平方根成正比）、扩张和蛋白分解物加速胃泌素分泌，蠕动增加；人的情绪等
	5. 十二指肠内容物（盐酸，脂肪，高渗刺激）；对胃酸敏感，导致肠胃反射，分泌激素抑制
## 小肠运动
1. 紧张性收缩：挤压内部 
2. 分节运动：环形肌为主的节律性收缩/舒张，空腹时无；充分混合消化液和食糜
3. 蠕动：推动内容物向前走；蠕动冲可以将食糜从幽门推到大肠
4. 移行性复合运动：空腹时主要形式，定期收缩
	1. 清理粘液，上皮细胞等
	2. 防止胃肠瘀滞和肠道细菌过度生长
	3. 产生饥饿信号，促进摄食
# 消化液分泌
## 胃液
1. 外分泌：贲门腺，幽门腺
	1. 泌酸腺：壁细胞分泌盐酸+内因子；主细胞分泌胃蛋白酶原，还有粘液细胞等
2. 内分泌：G细胞（胃窦、胃泌素），D细胞（生长抑素），ECL细胞（胃底胃体组胺）
3. 胃液：无色，pH=0.9-1.5，分泌1.5-2.5 L/d
	1. 成分：水，盐酸，胃蛋白酶原，内因子，粘液，无机盐
		1. 盐酸：壁细胞主动分泌，0-5 mmol/L，逆浓度梯度主动分泌（质子泵），餐后碱潮；激活胃蛋白酶原、促进其他消化液分泌、抑制和杀死细菌
		2. 胃蛋白酶原：主细胞分泌，将蛋白分解为肽，最适pH=2（>5失活，>6变性），自我激活
		3. 黏液：糖蛋白，有高粘滞性，润滑食物+保护胃粘膜
		4. 内因子：壁细胞分泌，糖蛋白，和维生素B12形成复合体，在回肠末端以胞饮形式回收VB12
	2. 作用：蛋白质变性消化，杀菌，促进$B_{12}$吸收
4. 调节：
	1. 促进：乙酰胆碱（迷走神经，作用于壁细胞），胃泌素（G细胞分泌，血液循环后作用于壁细胞受体），组胺（肠嗜铬细胞）
	2. 消化期胃液调节：分为头期，胃期和肠期
		1. 头期
			1. 神经体液调节，以神经调节为主；条件反射/非条件反射
			2. 迷走-乙酰胆碱-胃酸；迷走-GRP（胃泌素释放肽）-胃泌素
			3. 分泌量占30%，酸度和消化力高
		2. 胃期：神经/体液调节
			1. 扩张胃体，胃底→迷走→迷走长反射→胃腺分泌
			2. 扩张胃幽门→壁内N丛短反射→G细胞释放胃泌素→胃腺分泌
			3. 蛋白质消化产物→G细胞释放胃泌素
			4. 分泌量（60%）酸度高，消化力<头期
		3. 肠期：
			1. 机械刺激/消化导致化学刺激十二指肠黏膜→G细胞释放胃泌素→胃腺分泌
			2. 促胰液素，血管活性肠肽和抑胃肽参与调控
			3. 肠期的胃液分泌量少，可以被忽略
	3. 抑制调节：
		1. 胃窦pH 1.2-1.5→抑制G细胞分泌胃泌素，刺激D细胞分泌生长抑素，减少胃酸分泌；十二指肠pH<2.5刺激S细胞分泌促胰液素；刺激十二指肠细胞分泌抑胃素
		2. 脂肪及其消化产物刺激小肠粘膜→肠抑胃素→抑制胃液分泌
		3. 高渗溶液刺激十二指肠渗透压感受器→引起肠胃反射/分泌肠抑胃素抑制分泌
## 胰液
1. 胰脏同时内分泌/外分泌
	1. 内分泌由胰岛进行
	2. 外分泌组织产生胰液，通过胰腺导管进入十二指肠，每天分泌1-2 L
2. 作用：消化糖，脂肪和蛋白质；对蛋白质消化最为重要
3. 成分
	1. 水和碳酸氢盐：中和胃酸
	2. 胰淀粉酶
	3. 蛋白质水解酶（胰蛋白酶/胰凝乳蛋白酶）：蛋白酶原被自激活；存在胰蛋白酶抑制因子
	4. 胰脂酶，核酸酶
4. 调节：
	1. 神经调节（头期）：食物反射，迷走神经→胰液，迷走神经→胃泌素→胰液；酶多，水和碳酸氢盐少
	2. 体液调节（肠期）
		1. 盐酸→S细胞→促胰液素→导管上皮→胰腺水样分泌→中和盐酸
		2. 蛋白质/脂肪→I细胞→缩胆囊素→腺上皮→酶样分泌增加→消化食物
## 胆汁
1. 肝脏不断生成（800-1000 mL/d），从肝管-胆总管-十二指肠，部分储存在胆囊内
2. 成分：
	1. 胆盐（50%）：胆固醇=胆汁酸+钠离子，90%肠肝循环重吸收（[[胆固醇代谢]]，重吸收可以增加胆汁分泌
	2. 磷脂（30-40%）：乳化脂肪，参与微胶粒形成
	3. 胆固醇：溶解需要适当比例的胆汁酸/胆盐+卵磷脂
	4. 胆色素：血红素代谢产物，胆红素为主
3. 作用：促进脂肪消化吸收
	1. 胆固醇/胆盐/卵磷脂可以乳化脂肪以利脂肪消化
	2. 胆盐+脂肪复合物可以形成水溶性复合物运载到肠粘膜表面
	3. 促进脂溶性维生素吸收
4. 调节因素：
	1. 神经（头期+胃期）：迷走神经+胃泌素促进胆囊收缩，胆汁排放
	2. 体液（肠期）：
		1. 胃酸等分解产物→促胰液素→胆囊收缩→胆汁排放
		2. 蛋白质/脂肪→缩胆囊素→胆汁排放
## 小肠液
分泌量变化大（1-3 L/d）
1. 十二指肠腺分泌粘液；小肠腺分泌粘液&肠激酶
2. 作用：中和胃酸，稀释肠腔内容物帮助吸收，肠激酶激活胰蛋白酶原为胰蛋白酶
3. 小肠绒毛表面存在消化酶可以水解
# 吸收
各部位的吸收，详细的参见[[营养物质消化]]
1. 口腔：部分药物（亚硝酸甘油，吗啡等）
2. 胃：少量水分和酒精
3. 小肠：主要吸收部位
4. 大肠：水分，无机盐，维生素，部分葡萄糖和药物
