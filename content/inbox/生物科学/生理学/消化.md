# 组成
消化道+消化腺

除了口腔, 食管上端+肛门外括约肌为横纹肌外, 其他都是平滑肌
# 消化道结构
### 组成 
+ 黏膜层: 有导管
+ 黏膜下层
+ 肌层
+ 浆膜层
### 神经
1. 内在神经系统: 肠神经系统
	1. 肌间神经丛, 粘膜下神经丛, 8-10亿神经元
	2. 可以独立行使功能, 包括蠕动, 调节分泌吸收, 被称为肠脑
2. 外来神经:
	1. 交感神经: 内脏神经, 脊髓T1-T10, L1-L2, 分泌去甲肾上腺素, 抑制分泌运动
	2. 副交感神经: 主导, 迷走神经+盆神经, 起源于脑干和脊髓, 分泌乙酰胆碱, 促进分泌运动
3. 外来神经和内在神经通讯是双向的
### 激素
1. 消化道是体内最大的内分泌器官
2. 分散分布于胃肠道上皮, 多数为肽类激素(胃肠肽)
3. 作用为调节消化液分泌和消化道运动, 调节其他激素释放和营养

同时还有外分泌功能, 成分为水, 有机物和无机物
# 平滑肌特性
### 一般特性
1. 收缩和舒张起缓慢, 兴奋性低,  变化性大
2. 富有伸展性
3. 具有紧张性: 微弱的持续收缩状态
4. 自动节律性, 规律地且不规则
5. 对刺激特异性敏感
### 电生理特性
1. 静息电位: 不稳定, 低, 波动
2. 慢波: 基本电节律, 周期性去计划和复极化, 可能因为Cajal细胞起搏
3. 快波: 动作电位, 慢波点位达到-40 mV, 引起动作电位和平滑肌收缩
# 胃的运动
1. 紧张性收缩: 经常保持这种状态, 维持胃内压
2. 容受性舒张: 空腹时50 mL变到1500 mL, 胃内压不会明显升高, 由胃主动舒张所致
3. 蠕动: 进食后使食糜和胃液充分混合排入小肠
4. 排空: 
	1. 胃的收缩导致胃内压上升和十二指肠内压之间的压力差. 幽门括约肌起到控制阀作用
	2. 食物理化性质(排空速度: 糖>蛋白质>脂肪), 胃内食物量(排空率和留在胃内食物量的平方根成正比), 人的情绪, 十二指肠内容物(盐酸, 脂肪, 高渗刺激)
# 小肠运动
1. 紧张性收缩: 挤压内部 
2. 分节运动: 环形肌为主的节律性收缩/舒张, 空腹时无
3. 蠕动: 推动内容物向前走
4. 移行性复合运动: 空腹时主要形式, 定期收缩, 清理粘液, 上皮细胞等; 防止胃肠瘀滞和肠道细菌过度生长; 产生饥饿信号, 促进摄食
# 消化液分泌
### 胃液
1. 外分泌: 贲门腺, 泌酸腺(壁细胞分泌盐酸+内因子; 主细胞分泌胃蛋白酶原, 还有粘液细胞等), 幽门腺
2. 内分泌: G细胞(胃泌素), D细胞(生长抑素), ECL细胞: 组胺
3. 无色, pH=0.9-1.5, 分泌1.5-2.5 L
4. 成分: 水, 盐酸, 胃蛋白酶原, 内因子, 粘液, 无机盐
	1. 盐酸: 壁细胞主动分泌, 0-5 mmol/L, 逆浓度梯度主动分泌(质子泵), 餐后碱潮
	2. 胃蛋白酶原: 主细胞为主, 将蛋白分解为肽, 最适pH=2(>5失活, >6变性), 自我激活
	3. 黏液: 糖蛋白, 有高粘滞性, 润滑食物+保护胃粘膜
	4. 内因子: 壁细胞分泌, 糖蛋白, 和维生素B12形成复合体, 在回肠末端以胞饮形式回收VB12
5. 作用: 蛋白质变性消化, 杀菌, 促进$B_{12}$吸收
6. 调节: 
	1. 促进: 乙酰胆碱(迷走神经, 作用于壁细胞), 胃泌素(G细胞分泌, 血液循环后作用于壁细胞受体), 组胺
	2. 消化期胃液调节: 分为头期, 胃期和肠期
		1. 头期: 神经体液调节, 以神经调节为主, 条件反射/非条件反射. 迷走-乙酰胆碱-胃酸; 迷走-GRP-胃泌素, 分泌量占30%, 酸度和消化力高, 
		2. 胃期: 扩张胃体, 胃底-迷走-迷走长反射-胃腺分泌; 扩张胃幽门-壁内N丛短反射-G下播释放胃泌素-胃腺分泌; 蛋白质消化产物-G细胞释放胃泌素. 60%, 酸度高, 消化力<头期
		3. 肠期: 刺激十二指肠黏膜-G细胞释放胃泌素; 醋意耶稣, 血管活性肠肽和抑胃肽也参与调控, 肠期的胃液分泌量少, 可以被忽略
	3. 抑制: 
		1. 盐酸pH1.2-1.5-抑制G细胞分泌胃泌素, 刺激D细胞分泌生长抑素, 减少胃酸分泌
		2. 脂肪及其消化产物刺激小肠粘膜-肠抑胃素-抑制胃液分泌
		3. 高渗溶液引起肠胃反射, 分泌肠抑胃素
### 胰液
同时具有内分泌和外分泌功能: 内分泌由胰岛进行; 外分泌组织产生胰液, 通过胰腺导管进入十二指肠, 每天分泌1-2 L
1. 消化糖, 脂肪和蛋白质, 对蛋白质消化最为重要
2. 成分: 水和碳酸氢盐, 胰淀粉酶, 蛋白质水解酶(胰蛋白酶/糜蛋白酶), 胰脂酶, 核酸酶
3. 调节: 
	1. 神经调节(头期): 食物反射, 迷走神经-胰液, 迷走神经-胃泌素-胰液; 酶多, 水和碳酸氢盐少
	2. 体液调节(肠期): 盐酸-S细胞-促胰液素-导管上皮-胰腺水样分泌-中和盐酸; 蛋白质/脂肪-I细胞-缩胆囊素-腺上皮-酶样分泌增加-消化食物
### 胆汁
肝脏不断生成(800-1000 mL/d), 从肝管-胆总管-十二指肠, 部分储存在胆囊内
1. 成分: 
	1. 胆盐(50%): 胆固醇-胆汁酸+钠离子. 90%肠肝循环重吸收, 重吸收可以增加胆汁分泌
	2. 磷脂(30-40%): 乳化脂肪, 参与微胶粒形成
	3. 胆固醇: 溶解需要适当比例的胆汁酸/胆盐+卵磷脂
	4. 胆色素: 血红素代谢产物, 胆红素为主
2. 作用: 促进脂肪消化吸收
	1. 胆固醇/胆盐/卵磷脂可以乳化脂肪以利脂肪消化
	2. 胆盐+脂肪复合物可以形成水溶性复合物运载到肠粘膜表面
	3. 促进脂溶性维生素吸收
3. 调节因素: 
	1. 神经(头期+胃期): 迷走神经+胃泌素促进胆囊收缩, 胆汁排放
	2. 体液(肠期): 胃酸等分解产物-促胰液素-胆囊收缩-胆汁排放; 蛋白质/脂肪-缩胆囊素-胆汁排放
### 小肠液
分泌量变化大(1-3 L/d)
1. 十二指肠腺分泌粘液; 小肠腺分泌粘液&肠激酶
2. 中和胃酸, 稀释肠腔内容物, 肠激酶能激活胰蛋白酶原为有活性的胰蛋白酶
# 吸收
各部位的吸收
1. 口腔: 部分药物(亚硝酸甘油, 吗啡等)
2. 胃: 少量水分和酒精
3. 小肠: 主要吸收部位
4. 大肠: 水分, 无机盐, 维生素, 部分葡萄糖和药物

小肠黏膜表明有环形皱褶, 出现绒毛/微绒毛, 总吸收体积约为200$m^{2}$, 全长5-7 m
# 糖的消化吸收
+ 多糖→寡糖→单糖
+ 目前认为只有单糖才能被吸收
+ 吸收效率: 半乳糖>葡萄糖>果糖>甘露糖>...
+ 吸收方式: 主动运输
	+ 小肠肠腔→肠粘膜上皮细胞→门静脉...
	+ 跨肠腔运输为SGLT蛋白etc. 
	+ 转运到细胞内用GLUT家族
	+ 葡萄糖的重吸收
