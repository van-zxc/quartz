# 形式
1. 远距分泌（神经内分泌）：最常见的激素
2. 旁分泌：扩散传播
3. 自分泌：分泌出细胞后刺激受体
4. 内在分泌：只调控自身，不出细胞
5. 外散分泌：性激素
# 激素
### 种类
1. 肽类：下丘脑，垂体，肾上腺等
2. 类固醇类：糖皮质/盐皮质激素、性激素，孕激素，VD等
3. 胺类：肾上腺素，去甲肾上腺素，多巴胺，5羟色胺，甲状腺激素，组胺
4. 脂肪酸类：前列腺素
### 作用机理
1. 激活膜受体，产生一系列下游效应
2. 激活细胞内受体-转录因子，形成激素-受体复合物，调控DNA转录
3. 受体本身具有酶活性，结合后导致受体构象改变，发挥酶作用
# 具体example
## 下丘脑-垂体-靶腺轴
![[PixPin_2026-06-20_16-51-00.png]]
1. 下丘脑-垂体的分泌
	1. 腺垂体/神经垂体
	2. 腺垂体（垂体前叶）：与下丘脑间接联系
		1. 有大量内分泌上皮细胞
		2. 上游的下丘脑神经元分泌的释放激素或抑制激素通过垂体门脉系统（不进入全身循环）高效递送给内分泌细胞，内分泌细胞表面的GPCR接受信号，分泌促激素进入全身循环
	3. 神经垂体（垂体后叶）：下丘脑的延伸，直接联系
		1. 下丘脑中的大细胞神经元合成抗利尿激素&催产素
		2. 激素通过运载蛋白运到轴突末端（即神经垂体中）
		3. 当下丘脑感受到渗透压升高/产道扩张时，产生动作电位，释放激素扩散到全身
### 垂体前叶激素
1. 下丘脑调控垂体的分泌：
	1. TSH：促甲状腺激素，当上游释放TRH（促甲状腺激素释放激素）时分泌
	2. ACTH：促肾上腺皮质激素，当上游释放CRH（促肾上腺皮质激素释放激素）时分泌
	3. LH/FSH：分别为促黄体生成素/促卵泡激素，当上游释放GnRH（促性腺激素释放激素）时分泌
	4. GH：生长素，受生长激素释放激素（GHRH）和生长激素释放抑制激素（GIH）调控
	5. PRL：催乳素，受催乳素释放因子（PRH）和催乳素释放抑制因子（PIH）调控
	6. MSH：促黑素细胞激素，受释放因子（MRF）和抑制因子（MIF）调控
	7. 调节肽单向作用于垂体，六种激素相互拮抗（正调控/负调控）
2. 生长激素：191aa
	1. 促生长：促进软骨细胞、肌细胞和肌肉组织细胞蛋白质合成
	2. 机理：募集酪氨酸激酶受体发挥作用
	3. 调节物质代谢，促进各种物质合成；促进蛋白质的合成和脂肪的分解、升高血糖、诱导肝脏产生胰岛素样生长因子 （IGF）
	4. 调节：
		1. 促进肝脏分泌IGF-1，反作用于下丘脑和组织，抑制分泌
		2. 低血糖、运动和慢波睡眠有助于生长激素分泌
3. 催乳素
### 垂体后叶激素
1. 抗利尿激素（参见[[泌尿]]）

## 甲状腺激素
1. T3/T4（三碘甲腺原氨酸/甲状腺素）
	1. 在血液内T4占主导，但是甲状腺素活性主要来源于T3
2. 合成
	1. 甲状腺滤泡细胞膜表面大量表达钠-碘同向转运体，将（2Na 1I）运入细胞；随后再被排放到滤泡腔中
	2. 甲状腺上皮细胞合成TG（甲状腺球蛋白，含有大量酪氨酸残基），随后被分泌到滤泡腔中
	3. TPO（甲状腺过氧化物酶）将I活化，随后转移到酪氨酸上形成一碘酪氨酸（MIT）/二碘酪氨酸（DIT），随后相邻的发生偶联，生成T3/T4（T4>T3）
	4. 当上游TSH刺激时，TG被再次胞吞，溶酶体水解产生T3/T4，被释放进入血液循环；MIT和DIT水解产生I继续轮回
3. 释放
	1. 运输：结合在血浆蛋白（T4），T3游离态；游离态有生物活性
	2. 代谢：在肝脏和靶组织中被脱去碘（T3大多来自T4脱碘）
4. 功能：（通过转录因子发挥作用）
	1. 提升基础代谢率
	2. 促进蛋白合成/糖吸收/脂肪酸分解利用，降低胆固醇
	3. 促进生长分化
	4. 兴奋中枢神经，增加儿茶酚胺类激素的兴奋作用
	5. 结合$\beta_{1}$受体，兴奋心血管
5. 分泌调控
	1. 下丘脑垂体甲状腺轴（上游寒冷信号感受），HPT轴
	2. 甲状腺自身调节：Wolff-Chaikoff效应，摄入大量碘后反而导致甲状腺激素水平降低
## 胰岛
==胰脏同时是内分泌腺和外分泌腺。==胰岛占胰脏体积2%
1. $\alpha$：胰高血糖素（20%）
2. $\beta$：胰岛素（60%）
	1. 21aa的A链和30aa的B链，两个二硫键
	2. 排异性强，外源容易产生抗体
	3. 促进葡萄糖利用，抑制一切不利于葡萄糖利用的部分
	4. ![[PixPin_2026-06-20_20-41-19.png]]
	5. 糖尿病症状：三多一少
	6. 门冬胰岛素（迅速）/甘精胰岛素（长效）
	7. 调控
		1. 迷走促进，交感抑制分泌
		2. 高血糖、高血氨基酸/高血脂促进分泌
		3. 胃肠激素，生长激素、皮质醇、甲状腺激素、胰高血糖素升高血糖，间接刺激胰岛素分泌
3. $\delta$：生长抑素（主要是旁分泌，容易降解）
4. $PP$：胰多肽
## 肾上腺皮质
1. 球状带
	1. 盐皮质激素、醛固酮
	2. 水盐代谢
2. 束状带
	1. 糖皮质激素（皮质醇、皮质酮）
	2. 促进糖异生/脂肪酸氧化，升高血糖
	3. 增加血小板、红细胞、中性粒细胞，减少其他白细胞
	4. 抑制前列腺素分泌，诱导胃酸分泌，导致胃溃疡
	5. 抗炎&抗过敏
	6. 对儿茶酚胺的允许作用（即必要条件），增加平滑肌儿茶酚胺受体数量
	7. 应急反应：紧急情况如剧痛、失血等；交感-肾上腺髓质
	8. 应激反应：长期有害刺激如创伤、精神紧张等；肾上腺皮质/髓质
		1. 两者先后被激活：减少有害介质（前列腺素等）、维持血糖以供心脑使用、允许心脏持续高强度输出
	9. 调控？CRH→ACTH
		1. 受下丘脑视上核昼夜节律调控
		2. 受情绪应激调控
		3. 受ACTH和糖皮质激素的负反馈调控
3. 网状带
	1. 性激素
