# 感受器划分
1. 化学感受器
2. 痛觉感受器/痒觉感受器
3. 温度感受器
4. 机械感受器
5. 光感受器

或者也可以这样划分：
1. 脑神经传入：特殊感觉，如视觉、听觉、嗅觉、味觉和平衡觉，集中于头面部
2. 脊神经+脑神经皮肤分支传入
	1. 表层/皮肤感觉。触觉、温度觉、痒觉、痛觉，外感受器，监视外部环境，集中于皮肤/粘膜
	2. 深部感觉。如本体感觉，深部压觉/痛觉。参与姿势和动作协调，来源于肌肉、肌腱、关节
3. 内脏神经传入：内脏感觉。饥饿感，饱腹感，内脏痛觉。多具有弥散性
# 一般原理
1. 适宜刺激：换能——物理/化学能转化为生物能，感受器对某种刺激的特殊敏感
2. 换能放大：任何形式的能量都需要转为动作电位
3. 感受器电位不和动作电位一样全/无，不同刺激能够导致不同电位幅度变化，容易在时空进行整合，适合短距离传输
4. 双向反应&双向解码
5. 感受器电位：感受器接受刺激后产生的局部去极化膜电位，幅度和时程会随刺激改变
6. 适应：刺激持续作用时感觉会逐渐减弱，有时会消失
7. 感受野：感觉神经元传递的范围
8. 跟[[脑神经]]有强关联
# 化学感觉
1. 嗅觉+味觉
2. 功能：判断食物的存在性和可食性
3. 嗅觉比味觉灵敏20000倍（进化原因）
4. 嗅觉
	1. 一侧鼻腔有600w神经元，120天一次替代
	2. 内短神经纤维传过筛板进入颅腔，终止于嗅球的第二级神经元
	3. 发出纤维组成嗅束透射到大脑边缘系统（边缘系统参与管理记忆和情感）
	4. 感受机制：GPCR信号通路
5. 味觉
	1. 味蕾：舌头上的小乳突，由味觉细胞、支持细胞和基底细胞构成
	2. 味觉细胞是感受器，旁边有感觉神经末梢
	3. 面神经的鼓索支配2/3的味蕾，剩下舌后1/3由舌咽神经分支支配
	4. 不断更新，60天迭代一次
	5. 基础味觉：酸甜苦咸鲜
	6. 分子机制：
		1. 甜、苦、咸：GPCR介导通路
		2. 酸：氢离子通道介导
		3. 咸：钠离子通道导致电位变化
# 机械
1. 触觉感受：
	1. 裸露神经末梢在毛根周围，利用杠杆效应被放大
	2. 迈斯纳小体：无毛区域的真皮中，感受低频震动和滑移，感知迅速
	3. 环层小体：又称帕齐尼小体，位于皮下，对动态的快速变化的信号敏感（如高频振动），感知迅速
	4. 触觉上行：背柱-内侧丘系传入系统
		1. 第一级神经会聚，从脊髓后角切入，传入脊髓背柱中
		2. 第一级轴突在延髓的薄束核和楔束核中与第二级神经元形成突触交换，第二级神经元形成弓状纤维，并且在中线处交叉
		3. 传入神经终止于丘脑的腹后外侧核 ^64235d
	5. ![[PixPin_2026-05-20_17-39-24.png]]
2. 毛细胞：动纤毛运动导致NOMPC1机械门控离子通道打开，内部电位变化，导致动作电位产生
3. 平衡感与前庭器官：半规管+前庭
	1. 内耳迷路中的半规管
		1. 半规管膨大部壶腹中含有壶腹鞘，旋转时壶腹鞘推动胶装的终帽旋转，导致被包裹的毛细胞纤毛弯曲，产生电信号
	2. 前庭（椭圆囊，球囊）
	3. 水平半规管：能感受人体以身体长轴为轴心所作的旋转变速运动
	4. 其他两对半规管：所处平面相一致的旋转变速运动
	5. 椭圆囊：囊斑所处平面呈水平，感受囊斑所处水平方向的直线变速运动
		1. 感受器为椭圆囊斑，表面有一层覆盖耳石的胶质膜（耳石膜），耳石随重力的变化帮助感受头部的静态角度
	6. 球囊：感受竖直方向的直线变速运动
		1. 同样的，感受器为球囊斑，感受椭圆垂直轴的变化
		2. 耳石症：耳石脱落掉入半规管的淋巴液中，需要进行专业复位
# 听觉
1. 过程：
	1. 机械传导：耳廓→外耳道→鼓膜
	2. 机械放大：听小骨→卵圆窗
	3. 感觉换能：内耳感音装置→毛细胞
	4. 神经处理：听神经冲动→皮层听觉中枢
2. 听阈：16-22000Hz
3. 结构
	1. 外耳：耳廓+外耳道，手机声波并引导至鼓膜（坚韧的锥形圆片，外耳道底部）
	2. 中耳：锤骨+砧骨+镫骨（听小骨），传递放大声波&抵抗干扰
	3. 内耳：耳蜗，螺旋形骨性管道，内部充满淋巴液；镫骨的往复运动推动淋巴液运动刺激基底膜中的毛细胞
4. 听域：声压/声频构成的曲线范围
5. 声音传导：
	1. 耳廓+外耳道：集音效应和共鸣腔效应
	2. 鼓膜→听骨链 →内耳卵圆窗（气传导）：中耳增压效应
	3. 耳蜗对声音的感受：使用不同部位的毛细胞
	4. 柯蒂氏器：基底膜振动，由于上面的盖膜不动，导致毛细胞的毛受到侧向剪切力，产生动作电位
	5. 基底膜振动是以行波的形式进行的
		1. 接受高音的基底膜振动耳蜗底部，接受低音的基底膜需要传到耳蜗顶部
		2. 声波频率不同，传播距离不同；频率越低传播越远
	6. 听觉受体：TMC1/2
	7. 氨基糖苷类抗生素可以产生毛细胞毒性，干扰线粒体合成
6. 听觉传导：
	1. 毛细胞纤毛弯曲，释放谷氨酸，传导给螺旋神经节细胞（听神经）
	2. 听神经传导给耳蜗核→上橄榄核→下丘脑→内侧膝状体→颞叶初级听皮层
# 视觉
1. 视觉传递：
	1. 折光系统→视杆视锥细胞换能（膜电位超极化）→视神经纤维传导→皮层中枢
2. 结构：
	1. 折光系统：角膜、房水、晶状体、玻璃体、视网膜前表面
	2. ![[PixPin_2026-06-23_15-26-02.png]]
	3. 眼球壁：纤维膜、血管膜、视网膜
	4. ![[PixPin_2026-05-27_16-42-37.png]]
3. 眼的折光调节
	1. 晶状体变凸、瞳孔缩小（减小进光量）、辐辏反射（双眼球会聚，物相落在双眼视网膜的正中间位置）
	2. 折光异常：近视、远视、散光、老花
4. 换能系统：
	1. 视网膜结构特点：色素细胞层+双极细胞层+神经节细胞层
	2. 结构：光感受细胞层，双极细胞层，神经节细胞层（从外到里）
		1. 中央凹：大量视锥细胞，是我们注视正中心所在的区域，视力强
		2. 盲点：视神经穿过的区域，没有任何感光细胞
	3. 视觉的二元理论
		1. 视杆细胞介导暗视觉：光敏感度高，无色觉，分辨率很差，多
		2. 视锥细胞介导明视觉：光敏感度低，有色觉，分辨率高，少，有三种
	4. 感光物质：视黄醛/视紫红质
	5. 视杆细胞感光换能：
		1. 光照后视黄醛由顺式变成反式，导致视蛋白构型变化，产生动作电位
		2. 没有光时静息电位为-30~-40 mV，钠离子持续内流，光照下cGMP大量催化水解，钠离子通道关闭，感光细胞超极化，级联放大
	6. 视锥细胞感光换能：
		1. 三原色学说：蓝敏、绿敏、红敏（ #补充 Gemini给出了不同的看法）
		2. 视蛋白结构不同导致不同细胞对不同光的敏感性，色觉由拮抗色合成
5. 传导通路：
	1. 感光细胞→双极细胞层→神经节细胞层
	2. 视神经在视交叉（我知道有点废话）处交叉，将视觉信号传导到对侧大脑处理
	3. 视交叉后视束将信息传递到外侧膝状体，随后传递到大脑初级视觉皮层（枕叶）
6. 视力/视敏度，视野
7. 明适应&暗适应
# 躯体感觉
1. 浅感觉：
	1. [[神经#脊髓]]-丘脑束传递
	2. 传导痛觉、温度觉和轻触觉
	3. 先交叉后上行（在脊髓内换源）
2. 深感觉：
	1. 二点辨别、肌肉本体感觉、深部压觉
	2. 先上行后交叉（在大脑附近换源）
3. 半侧脊髓离断时：
	1. 对侧位浅感觉障碍
	2. 同侧位深感觉障碍
4. 深部感觉受到损伤时，来自肌腱和关节的冲动不能传导到大脑，不能确定身体位置和运动方向，可以通过视觉代偿
# 内脏感觉
1. 特点：
	1. 缓慢、持续、定位不清，对刺激分辨率差
	2. 对机械牵拉、缺血、痉挛、炎症敏感，对切割烧灼等不敏感
	3. 由交感/副交感传入纤维传递
2. 痛觉：
	1. 内脏痛
	2. 牵涉痛
		1. 内脏疾病引起的体表部位发生疼痛和痛觉过敏现象
		2. 心肌缺血：心前区、左肩、左上臂疼痛
		3. 胆囊病变：右肩区
		4. 阑尾炎：上腹部，脐区
		5. ![[PixPin_2026-06-03_16-42-31.png|596]]
		6. 机理
			1. 易化学说：皮肤和内脏受一个神经节支配，内脏传来的兴奋会提升皮肤中枢的敏感性
			2. 会聚学说：进入中枢后在末梢投射同一个神经元，通过日常逻辑进行拓展
	3. 体腔壁痛
		1. 体腔壁浆膜受刺激
		2. 症状和躯体痛相似
		3. 躯体神经传入
