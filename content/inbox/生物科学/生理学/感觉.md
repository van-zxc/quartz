2. 痛觉感受器/痒觉感受器
3. 温度感受器

+ 频率和传播长度呈反比，因此在图中会对感受器产生的电位编码为动作电位随后再进行解码
+ 感受器电位：不和动作电位一样全/无，不同刺激能够导致不同电位幅度变化，容易在时空进行整合
+ 适合短距离进行传递
+ 适应：感觉能够适应持续信号
+ 感受野：感觉神经元传递的范围
# 化学感觉
1. 嗅觉+味觉
2. 嗅觉比味觉灵敏20000倍（进化原因）
3. 嗅觉
	1. 一侧鼻腔有600w神经元，120天一次替代
	2. 内短神经纤维传过筛板进入颅腔，终止于嗅球
	3. 发出纤维组成嗅束透射到大脑边缘系统（边缘系统参与管理记忆和情感）
4. 味觉
	1. 味蕾，舌头上的小乳突，由味觉细胞、支持细胞和基底细胞构成
	2. 味觉细胞是感受器，面神经的鼓索支支配2/3的味蕾
	3. 不断更新，60天一次替代

# 平衡感
前庭器官
	1. 内耳迷路中的半规管
	2. 前庭（椭圆囊，球囊）
	3. 水平半规管：能感受人体以身体长轴为轴心所作的旋转变速运动。
	4. 其他两对半规管：所处平面相一致的旋转变速运动。
	5. 椭圆囊：囊斑所处平面呈水平，感受囊斑所处水平方向的直线变速运动。
	6. 球囊：感受竖直方向的直线变速运动。
	7. 椭圆囊和球囊内有耳石（碳酸钙结晶），可以帮助感受平衡。
2. 毛细胞：动纤毛不同方向的运动可以充当感受器
# 听觉
1. 过程：
	1. 机械传导：耳廓→外耳道→鼓膜
	2. 机械放大：听小骨→卵圆窗
	3. 感觉还能：内耳感音装置→毛细胞
	4. 神经处理：听神经冲动→皮层听觉中枢
2. 听阈：16-22000Hz
3. 听域：声压/声频构成的曲线范围
4. 声音传导：
	1. 耳廓放大
	2. 鼓膜→听骨链 →内耳卵圆窗(气传导)
	3. 耳蜗对声音的感受：使用不同部位的毛细胞
	4. 基底膜振动是以行波的形式进行的
# 视觉
1. 视觉传递：
	1. 折光系统
	2. 视杆视锥细胞（膜电位超极化）
	3. 视神经
	4. 皮层中枢
2. 结构：
	1. 角膜
	2. 房水
	3. 晶状体
	4. 玻璃体
	5. 视网膜前表面
	6. ![[PixPin_2026-05-27_16-42-37.png]]
3. 眼的折光调节
	1. 晶状体变凸
	2. 瞳孔缩小
	3. 双眼球会聚：辐辏反射，物相落在双眼视网膜的正中间位置
4. 换能系统：
	1. 视网膜结构特点：神经组织
	2. 结构：光感受细胞层，双极细胞层，神经节细胞层
	3. 视杆细胞介导暗视觉、视锥细胞介导明视觉
	4. 感光物质：视黄醛/视紫红质
	5. 视杆细胞感光换能：没有光时静息电位为-30~-40 mV，钠离子持续内流，光照下cGMP浓度下降，感光细胞超极化，也是一个级联放大过程
	6. 视锥细胞感光换能：视蛋白结构不同导致不同细胞对不同光的敏感性，色觉由拮抗色合成
5. 传导通路：
	1. 感光细胞、爽姐细胞层、神经节细胞层
	2. 传递到外侧膝状体，随后传递到视觉皮层
6. 视觉/视敏度
7. 盲点：视杆细胞密度为0，视锥细胞密度大
8. 明适应&暗适应
# 躯体感觉
1. 浅感觉：痛觉 温觉 触觉 压觉
	1. [[神经#脊髓]]-丘脑束传递
	2. 传导痛觉、温度觉和轻触觉
	3. 先交叉后上行（在脊髓内换源）
2. 深感觉：二点辨别、肌肉本体感觉、深部压觉
	1. 先上行后交叉（在大脑附近换源）
3. 半侧脊髓离断时：
	1. 对侧位侧浅感觉障碍
	2. 同侧位侧深感觉障碍
+ 深部感觉受到损伤时，来自肌腱和关节的冲动不能传导到大脑，不能确定身体位置和运动方向
+ 可以通过视觉代偿
# 内脏感觉
1. 特点：
	1. 缓慢、持续、定位不清，对刺激分辨率差
	2. 对机械牵拉、缺血、痉挛、炎症敏感，对切割烧灼等不敏感
	3. 由交感/附加干传入纤维传递
2. 痛觉：
	1. 内脏痛
	2. 牵涉痛
		1. 内脏疾病引起的体表部位发生疼痛和痛觉过敏现象
		2. 心肌缺血：心前区、左肩、左上臂疼痛
		3. 胆囊病变：右肩区
		4. 阑尾炎：上腹部，脐区
		5. ![[PixPin_2026-06-03_16-42-31.png|596]]
		6. 机理？易化学说（皮肤和内脏受一个神经节支配，内脏传来的兴奋会提升皮肤中枢的敏感性）&会聚学说（进入中枢后在末梢投射同一个神经元，通过日常行为进行拓展）
	3. 体腔壁痛
		1. 体腔壁浆膜受刺激
		2. 症状和躯体痛相似
