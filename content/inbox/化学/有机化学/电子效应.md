# 诱导效应

记为（$\pm$）I效应。由于电负性不同的取代基的影响，整个分子成键电子云密度随之偏移，使得分子发生极化
+ $\sigma$电子效应（只能沿着$\sigma$键传递）
+ 随着碳链增长减弱（3根共价键后不记作用）

# 共轭效应

记为（$\pm$）C效应
+ 单双键交替出现的体系（$\pi-\pi$共轭）/双键碳相邻原子有$p$轨道的体系为共轭体系（$p-\pi$共轭）
+ 在共轭体系中，电子可以扩张到整个体系（电子离域），可以降低体系能量。（亦即共振式越多）
+ 共轭体系中由于取代基作用使得体系内==$\pi$电子==分布发生变化，出现正负交替分布的情况。
+ 吸电子共轭：硝基、氰基、羧基、醛基、酮羰基
+ 给电子共轭：氨基、酰胺基、羟基、醚键、酯基
+ 苯环定位效应

有些基团其共轭效应和诱导效应是相反的，此时按照形势决定：如Cl通常是吸电子、NH$_{2}$通常是给电子
# 超共轭效应

+ C－H的$\sigma$轨道和CC双键的$\pi$轨道接近平行时的体系为超共轭体系
+ 屏蔽效应小，$\sigma$轨道的电子云几乎保持形状，可以和$\pi$ or $p$轨道产生部分重叠
+ C－H键是给电子的，且效应相较共轭效应很弱
+ eg. HBr进攻丙烯分子

# 场效应

与诱导效应不同。诱导效应是基于原子链的，而场效应是基于空间的

当方向合适时，诱导效应可以与场效应发生错位，从而得到不一样的结果
