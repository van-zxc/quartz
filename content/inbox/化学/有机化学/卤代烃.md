# [[饱和C原子的亲核取代]]

Saytzeff规则（或取向）
消除反应的主要产物是C＝C碳原子上连有最多烃基的烯烃
倾向于生成共轭系统
E2: 反式共平面消除

$$
\begin{align}
 & \lim_{ x \to 0 } \frac{\sin(\ln(1+x))-\ln(1+\sin x)}{(\sqrt{ 1+x^{2} }-1)\tan x}  \\
=  & \lim_{ x \to 0 } \frac{\sin(\ln(1+x))-\ln(1+\sin x)}{\frac{1}{2}x^{2} \cdot x}  \\ \\
= & \lim_{ x \to 0 } \frac{2(\sin(\ln(1+x))-\ln(1+\sin x))}{x^{3}} \\
= & \lim_{ x \to 0 } \frac{\left( \cos\ln(1+x)\cdot \frac{1}{1+x} - \frac{1}{1+\sin x}\cdot \cos x \right)}{3x^{2}}
\end{align}
$$
额似乎不是很好做? 那么我们尝试使用泰勒展式: 
$$
\begin{align}
 & \lim_{ x \to 0 } \frac{\sin(\ln(1+x))-\ln(1+\sin x)}{(\sqrt{ 1+x^{2} }-1)\tan x}  \\
= & \lim_{ x \to 0 } \frac{2(\sin(\ln(1+x))-\ln(1+\sin x))}{x^{3}} \\
= & \lim_{ x \to 0 } \frac{2}{x^{3}} \cdot \left( \ln(1+x) - \frac{(\ln(1+x))^{3}}{3!}+\dots - \left( \sin x - \frac{(\sin x)^{2}}{2} + \frac{(\sin x)^{3}}{3} + \dots \right) \right) \\
= & \lim_{ x \to 0 } \frac{2}{x^{3}} \cdot \left( x - \frac{x^{2}}{2} + \frac{x^{3}}{3} - \frac{x^{3}}{3!} - x + \frac{x^{3}}{3!} + \frac{x^{2}}{2} - \frac{x^{3}}{3} + o(x^{4})\right) \\
= & \lim_{ x \to 0 } 2o(x) = 0
\end{align}
$$
