# 分类

+ 小环（3/4）常见环（5/6）中环（7－12）大环（>12）
+ 单环/多环 etc.

稳定性：普通环>中环>小环
# 开环加成

+ 催化加氢：加一分子$H_{2}$变为开链烷烃
	+ 小环远比大环不稳定
+ 加卤素：
	+ 环丙烷可以类似烯烃加成，环丁烷即不可
+ 加氢卤酸
	+ 显然符合马氏加成规则，断裂在链接H最多&最少的H之间
	+ 类似的，加硫酸一样规则
