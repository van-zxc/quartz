# 特征

+ $C$为$sp^{3}$杂化、只有$C-H\ \sigma$键和$C-C\ \sigma$键
+ 结合牢固
+ 可以绕键轴旋转

# 自由基反应

烷烃相对稳定，C－C和C－H键的键能相对较高，没有明显极性且电子云维持在内部。因此难以发生离子型反应。但是$\sigma$键容易均裂产生自由基，因此容易发生自由基反应。

自由基反应一般分为三步：
+ 链引发
+ 链转移
+ 链终止

以烷烃的卤化为例：
+ 链引发：卤素原子在光照/加热条件下均裂产生自由基
+ 链转移：卤素原子自由基进攻烷烃产生新的烷烃自由基和卤化氢、类似的烷自由基也可以进攻卤素分子
+ 链终止：自由基之间互相碰撞形成长链，反应逐渐终止

该反应可能在$hv$、$\Delta$或自由基引发剂的条件下发生
