# 系统命名法

## [[烷烃]]

步骤：
1. 选主链
	1. 碳链最长
	2. 取代基尽可能多
	3. 编号尽可能低
	4. 不优基团先列出
		1. 原子序数大优先、同位素质量大者优先
		2. 第一个原子比不了则比下一个原子
2. 编号
	1. 最低位次（能够碰到最小号的那个方向）
3. 命名
	1. 先列出来不优的、再列出来优的

# [[环烷烃]]

+ 无取代基的在链状烷烃外加“环”
+ 环外基团作为取代基
+ 取代基位置数字取最小
+ 不优基团位置编号取最小
+ 环上复杂烃基时，把环作为取代基（大环+小环时，环作为取代基）
### 顺反异构

在环一侧的基团是==顺式==（cis）、在环平面异侧的是==反式==（trans）

### 桥环

两环共用2C及以上。

命名方法：X环\[a.b.c\]$\lambda$烷
方式：
+ 确定环数
+ 确定主环、主桥和次桥
+ 选主桥的一个桥头碳为1号，延主环C多的边开始，再绕回桥头，再主桥、再次桥
+ 方括号内依次按照主环各侧、主桥和次桥的顺序把去掉桥头的碳原子数写到里面

### 螺环

格式：螺\[a,b\]$\lambda$烷

+ 从罗原子旁边邻位碳开始，从小环到大环
+ 取代基位次最小
+ 由少到多列出C原子数

# [[烯烃]]
1. 简单命名：正异新
2. 含有双键取代基：乙烯基、丙烯基、烯丙基、异丙烯基
3. 系统命名：含有双键的最长链为主链，双键$\to$取代基位次最低
4. 环状环编号从双键开始
