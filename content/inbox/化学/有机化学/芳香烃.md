亲电取代——磺化、卤化、硝化

傅克烷基化：
烷基化试剂可以来自卤代烃、烯烃、醇/环氧乙烷
亲电试剂是[[碳正离子]]，可能发生重排
不适合长链烷烃取代苯
容易发生多取代反应（烷基活化）

傅克酰基化：
酰卤（Cl Br）/酸酐
共振成R－C$\equiv$O$^{+}$ 

若制备长侧链芳香烃，可以考虑先酰基化再使用Clemmensen还原反应（Zn-Hg 浓盐酸）还原为烷基侧链

氧化：
氧气/五氧化二钒 400℃→顺丁烯二酸酐

还原反应：
完全还原（Ni 高温高压）变为环己烷
Birch还原：Na/Li 液氨 EtOH，还原为1,4环己二烯。给电子基团和双键相连，吸电子基团和饱和碳相连

烷基侧链反应：
1. 烷基侧链卤化（苄基自由基很活泼），[[自由基反应]]机理
2. 侧链氧化：有$\alpha-H$容易被切断，无则不会被氧化

亲电取代的定位规则
+ 邻对位定位基团：给电子，致活基团（氨基、羟基、烷基、卤素原子）
	+ 最强：含氮的，羟基
	+ 中等：N+羰基、O+烷基
	+ 弱：烷基、芳基
	+ 弱钝化：卤素
+ 间位定位基团：吸电子，致钝基团（硝基、羰基、羧基、磺酸基）
+ 理论：$\sigma-$络合物的稳定性，有一个共振式电荷刚好被基团稳定
+ 二取代：
	+ 同类定位基服从强的、差别不大时混合物
	+ 不同定位基时服从邻位（活化）
	+ 空间位阻

多环芳烃/稠环芳烃
+ 萘
	+ $\alpha$位（1,4,5,8）、$\beta$位（其他）
	+ 平面环状闭合共轭体系
	+ 电子密度没有平均化、$\alpha$电子云密度大，导致$\alpha$位反应活性高
	+ 邻定位：同环$\alpha$取代；间定位：异环$\alpha$取代
	+ 萘环比苯环/侧链烷基更容易被氧化
+ 蒽菲
