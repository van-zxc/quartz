# $S_{N}2$反应
+ 一步协同的反应
+ 亲核试剂从反应物背面进攻, 然后逐渐构型翻转, 从四面体变为伞形, 原先的基团再脱离. 

典型反应如下: 
![[PixPin_2025-10-08_21-55-11.png]]

同样的, 分子内也可以发生成环反应(只要有强劲有力的亲核试剂). 五元环最容易(张力最小), 六元环其次(虽然可以形成没有键张力的环, 但是氢原子可能帮助稳定势能), 三元环由于原子间距离较近也有可能发生, 四元环不太可能.

也就是说, 是两步分反应的合反应. 前面那步是决速步. 

在形成三角形[[碳正离子]]后, 亲核试剂两个方向的进攻显然都是等价的. 因此, 最终得到的会是[[立体化学#外消旋体]]. 
同时, 又由于碳正离子有Walden重排, 因此常常会生成重排产物.
