在柯朗微积分中，变分法的问题表述如下：
>[!definition] 变分法
>在所有定义在区间$x_{0}\leq x \leq x_{1}$上，取预定的边值$y = \psi(x_{0})$与$y_{1} = \psi(x_{1})$，连续且有连续的一阶与二阶导数的函数中，寻找一个函数使得泛函$I(\psi)$有最小的可能值（或最大的可能值）
>
>亦即求：
>$$
>I(\psi) = \int_{x_{0}}^{x_{1}} F(x, \psi(x), \psi'(x)) \, \mathrm{d}x
>$$
>的极值

# 函数的逗留

泛函的输入是一个函数，直接对函数求极值比较困难。我们假设：
1. 假设 $u(x)$ 是使泛函 $I\{\phi\}$ 取得极小值的真实解函数
2. 引入一个微小的扰动函数 $\eta(x)$，要求它在区间边界上为零（即 $\eta(x_0) = \eta(x_1) = 0$）
3. 构造一个包含单参数 $\varepsilon$ 的函数族：
    $$
    \phi(x, \varepsilon) = u(x) + \varepsilon \eta(x)
    $$
    其中 $\varepsilon \eta(x)$ 称为函数 $u$ 的变分，记作 $\delta u$。

这样一来，原本关于函数 $\phi$ 的泛函 $I\{\phi\}$ 就转化成了关于实数参数 $\varepsilon$ 的普通一元函数：
$$
G(\varepsilon) = \int_{x_0}^{x_1} F(x, u + \varepsilon \eta, u' + \varepsilon \eta') \, dx
$$

因为当 $\varepsilon = 0$ 时，$\phi(x, 0) = u(x)$（即取到极值点），所以普通函数 $G(\varepsilon)$ 必须在 $\varepsilon = 0$ 处取得极小值

一元函数求极值的必要条件：
- **一阶导数等于零**：$G'(0) = 0$
- **二阶导数大于等于零**：$G''(0) \geqslant 0$（若是极大值则为 $G''(0) \leqslant 0$）

于是接下来我们定义“第一变分”：
$$
\varepsilon G'(0) = \varepsilon \left\{ \frac{d}{d\varepsilon} \int_{x_0}^{x_1} F(x, u + \varepsilon \eta, u' + \varepsilon \eta') \, dx \right\}_{\varepsilon=0}
$$    
如果对任意满足条件的扰动函数 $\eta(x)$，方程 $G'(0) = 0$ 都成立，就称积分 $I$ 对 $\phi = u$ 是**逗留的**（相当于多元函数中的驻点）

因此“积分具有逗留性质”等价于“泛函的第一变分等于零（$\delta I = 0$）”。这是泛函取得极值的必要条件

# 欧拉微分方程

对于以下变分：
$$
I(\phi) = \int _{x_{0}}^{x_{1}} F(x, \phi(x), \phi'(x)) \, \mathrm{d}x
$$
若能取到极值函数$u$，则在极值处必须满足：
$$
\frac{ \partial F }{ \partial \phi(x) } - \dfrac{\mathrm{d}}{\mathrm{d}x} \left( \frac{ \partial F }{ \partial \phi'(x) }  \right) = 0
$$
简单的证明思路如下：

根据上文，泛函的第一变分=0，能够推导出：
$$
\dfrac{\mathrm{d}}{\mathrm{d}\varepsilon} \int _{x_{0}}^{x_{1}}F(x, u + \varepsilon \eta, u' + \varepsilon \eta') \, \mathrm{d}x = 0
$$
我们之前假定泛函满足利普希兹连续条件，因此可以交换积分和求导顺序：
$$
\int _{x_{0}}^{x_{1}} \frac{ \partial  }{ \partial \varepsilon } F(x, u + \varepsilon \eta, u' + \varepsilon \eta')  \, \mathrm{d}x  = \int _{x_{0}}^{x_{1}} \left( \frac{ \partial F }{ \partial y } \eta(x) + \frac{ \partial F }{ \partial y' } \eta'(x) \right) \, \mathrm{d}x = 0
$$
此时的$y = u + \varepsilon \eta, y' = u' + \varepsilon \eta'$。

令$\varepsilon \to 0$，有：
$$
\int _{x_{0}}^{x_{1}} \left( \frac{ \partial F }{ \partial u } \eta(x) + \frac{ \partial F }{ \partial u' } \eta'(x)  \right) \, \mathrm{d}x = 0
$$
此时，右侧有：
$$
\int _{x_{0}}^{x_{1}} \frac{ \partial F }{ \partial u' }  \, \mathrm{d}\eta(x) = \frac{ \partial F }{ \partial u' } \eta(x)|_{x_{0}}^{x_{1}} - \int _{x_{0}}^{x_{1}}\eta(x) \, \mathrm{d}\left( \frac{ \partial F }{ \partial u' }  \right)  =  - \int_{x_0}^{x_1} \frac{d}{dx} \left( \frac{\partial F}{\partial u'} \right) \eta(x) \, dx
$$
合并回去：
$$
\int _{x_{0}}^{x_{1}}\left( \frac{ \partial F }{ \partial u } - \dfrac{\mathrm{d}}{\mathrm{d}x}\left( \frac{ \partial F }{ \partial u' }  \right) \right)\eta(x) \, \mathrm{d}x = 0
$$
以上式子对于任意满足条件的微扰函数$\eta(x)$均成立，因此有：
$$
\frac{ \partial F }{ \partial u } - \dfrac{\mathrm{d}}{\mathrm{d}x} \left( \frac{ \partial F }{ \partial u' }  \right) = 0
$$
