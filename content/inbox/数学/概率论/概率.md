在笔记开始之前, 我们首先需要明确一件事情: **什么是概率**? 概率是一个数学概念, 而一个不是良定义的概念无法在数学的世界内立足. 
# 古典概率
我们先从人们生活中最直观的概念开始: [[古典概率]]
# 统计概率
如果我们考虑从概率的"稳定性"出发, 那么似乎我们也可以简单一点, 使用类似[[大数定理]]的方法来定义什么是概率. 我们假设进行了足够多次试验(假设进行了$N$次), 随后在$N$次试验中出现了$m$次成功, 则我们可以将概率简单定义为$\dfrac{m}{N}$. 

但是还是有不可避免的问题: 我们实际上只是在统计**频率**而非概率. 这个定义实际上只是一个描述性的, 不可被验证的东西. 我们无法确信, 得到的$p=\frac{m}{N}$就是概率, 甚至我们都无法说这个概率$p$是否真的存在, 或者极限$\lim_{ N \to \infty } \frac{m}{N}$是否真的存在? 因此这个定义在严格意义上是毫无作用的! 
# 概率的公理化
真正的概率, 需要严格, 需要公理化, 需要一套成体系的数学大厦. 

真正的概率论, 从柯尔莫哥洛夫开始, 他给了概率一套基于测度论的定义
>[!definition] 概率的公理化定义
>我们假设$\Omega$为全样本空间, $\mathcal{F}$为事件集合, 假设$A \in \mathcal{F}$
>定义实值函数$P(A)$, 满足下述三个公理, 则可以称$P(A)$为$A$事件的概率
>1. 数值性要求: $0 \leq P(A) \leq 1$, 即任何概率都必须属于$[0, 1]$
>2. $P(\Omega) = 1$, $P(\varnothing) = 0$, 即必然事件的概率为1, 不可能事件的发生概率为0
>3. 加法公理: 定义$A_{1},A_{2}\dots, A_{i}, \dots,A_{n}$是$n$个相互独立的事件($\forall i\neq j,  A_{i} \cap A_{j} = \varnothing$), 有
>$$
>P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)
>$$

从这里, 我们看出概率论彻底摆脱了现实世界的约束, 它变成了一个纯抽象的东西, 它定义的"概率"也可以完全和现实世界不相同, 但是由于现实世界遵守着这样一套概率的法则, 因此我们多数也遵守自古以来的那一套.
