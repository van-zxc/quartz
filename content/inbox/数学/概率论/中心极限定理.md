需要明确的是, 中心极限定理是一类定理而非一个. 在最初的定理上有大量拓展. 
# De Moivre-Laplace定理
这是最早期的中心极限定理, 棣莫弗证明了$p=\dfrac{1}{2}$的情形, 而Laplace证明了更加一般的情况. 
>[!proof] 证明
>设随机变量$Y_n$服从参数为$n$和$p$的二项分布$B(n, p)$，其中$0 < p < 1$，令$q = 1-p$
>根据二项分布定义，$Y_n = k$的概率为：
>$$
>P(Y_n = k) = \frac{n!}{k!(n-k)!} p^k q^{n-k}
>$$
>当$n \to \infty$时，考察位于均值$np$附近的取值$k$。定义标准化偏差变量(等价于$\dfrac{k-\mu}{\sigma}$)$x_k$为：
>$$x_k = \frac{k - np}{\sqrt{npq}}$$
>$$n-k = nq - x_k \sqrt{npq}$$
>引入斯特林公式：
>$$n! \approx \sqrt{2\pi n} \left(\frac{n}{e}\right)^n$$
>代入: 
>$$P(Y_n = k) \approx \frac{\sqrt{2\pi n} n^n}{\sqrt{2\pi k} k^k \sqrt{2\pi (n-k)} (n-k)^{n-k}} p^k q^{n-k}$$
>重新组合: 
>$$P(Y_n = k) \approx \sqrt{\frac{n}{2\pi k (n-k)}} \left(\frac{np}{k}\right)^k \left(\frac{nq}{n-k}\right)^{n-k}$$
>当$n \to \infty$且$x_k$有界时，$k \approx np$且$n-k \approx nq$: 
>$$\sqrt{\frac{n}{2\pi k (n-k)}} \approx \sqrt{\frac{n}{2\pi (np)(nq)}} = \frac{1}{\sqrt{2\pi npq}}$$
>令$A = \left(\frac{np}{k}\right)^k \left(\frac{nq}{n-k}\right)^{n-k}$，取对: 
>$$\ln A = -k \ln\left(\frac{k}{np}\right) - (n-k) \ln\left(\frac{n-k}{nq}\right)$$
>代入$k$和$n-k$的表达式：
>$$\frac{k}{np} = 1 + x_k \sqrt{\frac{q}{np}}$$
>$$\frac{n-k}{nq} = 1 - x_k \sqrt{\frac{p}{nq}}$$
>[[Taylor展开]]:$\ln(1+u) \approx u - \frac{u^2}{2}$，保留到二阶项：
>$$\ln\left(\frac{k}{np}\right) \approx x_k \sqrt{\frac{q}{np}} - \frac{x_k^2 q}{2np}$$
>$$\ln\left(\frac{n-k}{nq}\right) \approx -x_k \sqrt{\frac{p}{nq}} - \frac{x_k^2 p}{2nq}$$
>代回: 
>$$-k \ln\left(\frac{k}{np}\right) = -(np + x_k \sqrt{npq}) \left( x_k \sqrt{\frac{q}{np}} - \frac{x_k^2 q}{2np} \right)$$
>展开化简为
>$$-x_k \sqrt{npq} - \frac{1}{2} x_k^2 q + O(n^{-1/2})$$
>第二部分: 
>$$-(n-k) \ln\left(\frac{n-k}{nq}\right) = -(nq - x_k \sqrt{npq}) \left( -x_k \sqrt{\frac{p}{nq}} - \frac{x_k^2 p}{2nq} \right)$$
>展开化简为：
>$$x_k \sqrt{npq} - \frac{1}{2} x_k^2 p + O(n^{-1/2})$$
>化简: 
>$$\ln A \approx -\frac{1}{2} x_k^2 q - \frac{1}{2} x_k^2 p = -\frac{1}{2} x_k^2 (p+q) = -\frac{1}{2} x_k^2$$
>故: 
>$$A \approx e^{-x_k^2 / 2}$$
>得到了**局部极限定理**：
>$$P(Y_n = k) \approx \frac{1}{\sqrt{2\pi npq}} e^{-x_k^2 / 2}$$
>注意到相邻两个取值$k$和$k+1$之间，对应的$x_k$的步长（微分元）为：
>$$\Delta x = x_{k+1} - x_k = \frac{(k+1) - np}{\sqrt{npq}} - \frac{k - np}{\sqrt{npq}} = \frac{1}{\sqrt{npq}}$$
>将$\Delta x$替换到概率公式中：
>$$P(Y_n = k) \approx \frac{1}{\sqrt{2\pi}} e^{-x_k^2 / 2} \Delta x$$
>当我们需要计算标准化变量$Z_n = \frac{Y_n - np}{\sqrt{npq}}$落在区间$[a, b]$内的概率时，对该区间内的所有$k$对应的概率求和。在$n \to \infty$时，步长$\Delta x \to 0$，离散的黎曼和严格收敛为定积分：
>$$\lim_{n \to \infty} P(a \le Z_n \le b) = \lim_{n \to \infty} \sum_{a \le x_k \le b} \frac{1}{\sqrt{2\pi}} e^{-x_k^2 / 2} \Delta x = \int_a^b \frac{1}{\sqrt{2\pi}} e^{-x^2 / 2} dx$$
>Q. E. D

# Lindeberg-Lévy定理
这是拓展的中心极限定理, 不再局限于若干离散变量的求和. 具体表述如下: 

设$X_1, X_2, \dots, X_n$是独立同分布的随机变量序列，具有有限的数学期望$E[X_i] = \mu$和有限的正方差$Var(X_i) = \sigma^2$。则对于任何实数$x$, 都有: 
$$
\lim_{ n \to \infty } P\left( \dfrac{1}{\sqrt{ n }\sigma}\left( \sum X_{n}  - n\mu\right)\leq x \right) = \Phi(x)
$$
其中$\Phi(x)$为标准正态分布方程.
