>[!definition] 大数定理
>假设$X_{1}, \dots, X_{n}$均为独立同分布的随机变量, 记它们的公共期望为$M$, 再假设其公共方差存在并为$\sigma^{2}$, 则对于任意给定的$\varepsilon>0$都有: 
>$$
>\lim_{ n \to \infty } P(|\overline{X}_{n} - M| > \varepsilon) = 0
>$$
>也就是说, 当$n$趋向于无穷大的时候, $X$们的均值会趋向于数学期望

该定理给出的结论实际上是, 随着$n$的增大, 所有变量的均值仍然可能与$M$相差一段距离, 但是事件发生的概率会越来越小. 以上的定义实际上描述了所谓的=="依概率收敛"==. 

证明需要使用马尔可夫不等式/切比雪夫不等式, 统称为[[概率不等式]]

证明如下: 
>[!proof] 证明
>$$
>E(\overline{X_{n}}) = \sum \dfrac{E(X_{n})}{n} = \dfrac{na}{n} = a
>$$
>我们将$\overline{X_{n}}$代入[[概率不等式#Chebyshev不等式]], 有
>$$
>P(|\overline{X_{n}} - a| \geq \varepsilon) \leq \dfrac{Var(\overline{X_{n}})}{\varepsilon^{2}}
>$$
>根据方差的公式, 由于$\overline{X_{n}}$为$X_{n}$的均值, 因此
>$$
>Var(\overline{X_{n}}) = \dfrac{1}{n^{2}} \cdot n\sigma^{2} = \dfrac{\sigma^{2}}{n}
>$$
>代入, 得: 
>$$
>\lim_{ n \to \infty } P(|\overline{X_{n} -  a}| \geq \varepsilon) \leq \lim_{ n \to \infty } \dfrac{1}{n} \cdot (\dfrac{\sigma}{\varepsilon})^{2} = 0
>$$

以上结论即所谓"频率收敛于概率", 是最初版本的大数定理, 后续还有改良. 

由此我们可以丝滑的进入[[中心极限定理]]
